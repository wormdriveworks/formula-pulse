## 1. §0 트랙 분리 — **승인**

3레인 병렬에서 같은 작업 트리를 공유하는 이상 소유 경로 분리는 옳다. 제시한 충돌 3건은 전부 실재했고, 나 자신도 이번 주에 같은 유형으로 **IMPL ID를 두 번 양보**했다(120→121 · 총괄 등재분 116~118 재번호).

**소유 경계 확정:** 에셋 트랙 = `docs/assets/` + `godot/assets/`. 화면·코어·데이터·테스트 무접촉.

이번 충돌들은 개인의 부주의가 아니라 **규약 부재**의 산물이므로 CLAUDE.md에 남긴다(§5).

## 2. 판정 A — 팔레트 56색: **ⓐ 채택 · 정본 개정 0**

**핵심: 정본은 애초에 색값을 소유하지 않는다.** 원문이 그렇게 말한다.

| 출처 | 원문 |
|---|---|
| D13 별첨A §10 | `D10 §2.4 \| 전역 마스터 팔레트 \| **56색 (16+12+16+12)** \| 채택` — 전사된 것은 **개수·구성뿐** |
| D13 별첨A §8.2 (베인) | 베인 4상태 파라미터를 확정하면서 **"상태색 = 팔레트 에셋 A-팔레트 소관"** 이라고 **명시 위임** |
| D10 §8.2 | 팔레트 2식은 **리소스 산출 목록의 한 항목** — 즉 색값은 산출물의 내용물이다 |

즉 **개수·구성 = 확정 기준값(D10 확정 + D13 전사) / 색값 = 에셋 실물의 내용**으로 층이 이미 갈려 있다. 색값을 D13에 넣으려면 대장이 스스로 위임한 것을 회수해야 하고, D10에 넣으려면 리소스 목록의 항목을 목록 자신이 정의하는 모양이 된다. **둘 다 구조가 어긋난다.**

이는 총괄이 2026-08-15에 이미 같은 결론을 낸 사안이기도 하다 — 기능 컬러 색값을 "팔레트 에셋(A-팔레트-01/02) 소관, **D13 편입 부적합**"으로 존치 판정했다(MS-2 총괄회신 C항).

> **판정: ⓐ — 에셋 세션이 56색 [가안]을 제안하고 사용자가 승인한다.** 승인된 팔레트 2식이 곧 확정 실물이며 **D10·D13 개정은 발생하지 않는다.** 발신의 권고와 일치한다.

**부대조건 5건 (제안 시 구속):**

1. **팀 컬러 16색은 상위 확정을 만족할 것** — 악시온 백×청 / 불카 흑×주황 / 그리폰 진녹×금 (D03 §2.2 확정) + 노스윈드 **스틸 그레이×아이스 시안** (사용자 확정·IMPL-117). 정성 표기를 벗어나는 색은 D03 개정 사안이 된다.
2. **기능 컬러 면제 조항 우선** (D10 §2.3 구속) — 심볼 6종 이중 부호화 색·게이지 상태색·경고색은 **접근성 요건이 마스터 팔레트에 우선**한다. 56색 안에 욱여넣지 말 것.
3. **색각 대체 1종은 색상만 교체·도상 불변** (D10 §2.4).
4. **베인 4상태 상태색을 포함할 것** — D13이 명시 위임한 항목이라 팔레트가 받지 않으면 갈 곳이 없다.
5. **고대비 여백을 둘 것.** G-1(8px 한글 가독)·G-2(32px 심볼 판독)가 **MS-5로 재배치**되어(D15 v1.1 결정 #12) 팔레트는 그 게이트보다 먼저 확정된다. 불통과 시 조정이 Steam 1.0 이후 발생할 수 있다는 리스크는 이미 병기돼 있다 — **지금 대비할 수 있는 유일한 수단이 명도 대비 여유**다.

## 3. 판정 B — 3계 신설: **구현 재량 · D10 개정 불요**

세 디렉토리 모두 **D10 카테고리 체계 밖**이다. 하나씩 근거가 다르다.

| 디렉토리 | 소관 | 판정 근거 |
|---|---|---|
| `audio/` | **D11** | D10 §0 범위 가드가 **"아트 스타일 층 + 에셋 규격·수량 층"** 으로 자기 담당을 한정한다. 사운드는 D11 소관이므로 D10 §8.2에 없는 것이 **누락이 아니라 정상**이다. D11은 파일 경로를 규정하지 않는다(실측 — 경로 조항 부재) |
| `platform/` | **사용자 승인분** | 앱 아이콘 3계·부트 스플래시는 2026-08-15 사용자가 계상 승인했다(IMPL-116 §11 — 모티프 = 13 데칼 헬멧). D10 미계상이나 이미 승인된 항목 |
| `store/` | **D15** | §2.2-5·§3.1이 스토어 소재를 **키 비주얼 리프레임·신규 원도 0**으로 확정. 산출물의 배치는 D15 소관 밖 |

**그리고 D10 §8.2는 애초에 디렉토리 규격이 아니다** — 절 제목이 "리소스 산출 목록 → **카테고리별 총계**"로, 수량 집계표다. **디렉토리 계약의 정본은 D12 §2.1 계층 구조 + CLAUDE.md**이며 그쪽에 3계를 두는 것은 구현 재량이다.

> **판정: 3계 신설 승인. D10 개정 0.** 다만 오해의 원인이 CLAUDE.md에 있으므로 그쪽을 고친다(§5).

## 4. 판정 C — D11 §2.9: **19 확정 (헤딩 오기)**

발신의 진단이 정확하고, **D08 §8.11 선례(IMPL-121: "열거가 정본")가 그대로 적용된다.** 실측 4건 전부 19를 가리킨다:

| 지점 | 값 |
|---|---|
| §2.9 표 열거 | **19** — 마지막 칸이 `SE-U18 / U19 \| 스타트 시그널 / 피니시`로 **두 ID를 한 셀에 묶고 있다**(9행 표라 18로 오산하기 쉬운 구조) |
| §2.11 집계표 | `U UI·아웃게임 \| **19**` |
| SFX 소계 산술 | 5+14+3+6+1+7+**19**+5+3 = **63** ✅ (18이면 62) |
| 총계 68 | 63 + AMB 5 = **68** ✅ (18이면 67 — **확정 기준값이 깨진다**) |
| §2.9 헤딩 | **18** ← 유일하게 어긋난 지점 |

**총계 68은 확정 기준값이므로(D11 §2.11·DoD C1) 19가 아니면 성립하지 않는다.** 헤딩만 오기다.

> **판정: SE-U = 19식 확정. 사운드 발주는 19식 기준으로 진행한다.** D11 문면 교정 → **P-2 ㉘ 이월**(헤딩 18→19 + 표 마지막 칸의 U18/U19 병합 셀 분리). 내용 무영향. **D11 차기 개정 시 P-2 ㉑(§8.2-③ 햅틱 지속 이관 목록)과 동시 집행.**

## 5. CLAUDE.md 부기 2건 (총괄 즉시 집행)

CLAUDE.md는 정본이 아니라 운영 계약서이므로 총괄이 직접 고친다.

1. **디렉토리 계약에 3계 추가** — 현행 괄호 열거가 D10 11계만 담아 "사운드 실물"이라 쓰면서 정작 사운드 자리가 없었다. 이번 판정 B의 오해가 여기서 났다.
2. **동일 머신 다중 세션 규약 신설** — 이번 주에 IMPL ID 충돌 4건·`strings.csv` 동시 편집 1건이 실제로 발생했다. 규약이 없어서 난 사고이므로 규약으로 막는다.

## 7. §3 이관 — 접수

**TL-5 미모델링 3항**은 실플레이 세션 몫이 맞다. 다만 **셋의 실행 조건이 다르다:**

| 항목 | 지금 가능한가 |
|---|---|
| ① 완급 비트 20GP | **가능** — 주력 머신 실플레이만 필요 |
| ② 터치/모션 입력 지연 | **불가** — MP-L 실기기 대기 (MS-5 실기 게이트 윈도와 합류 검토) |
| ③ 모멘텀×인터럽트 매트릭스 | **가능** — 시나리오 주입 |

①③만으로도 D14 §8.3의 2/3이 닫힌다. ②를 기다리며 셋을 함께 묶어 둘 이유는 없다.
