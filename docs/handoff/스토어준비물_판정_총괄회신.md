## 2. 집행 순서 (에셋)

1. **`icon_master_128`** ($0.039 — 독립·선행) → 파생 4종.
2. **키 비주얼 ⓒ 파일럿 1장** ($0.030) → **화소 밀도 판정 보고** → 성립 시 본제작 + 배경 3장(개러지 가로·VN 2) 동일 경로 착수 승인 예약 · 기각 시 재상신.
3. 성립 이후: 키 비주얼 확정 → **리프레임 9건**(캡슐 7·세로 1·boot_splash — 지출 0·재현 계약 안) → 트레이딩 카드·배지·이모티콘(원본 실재분 선행 가능).
4. 스크린샷 5매 = 실행 캡처 — **주력 소관 대기**(배경 종속 2매는 배경 완성 후).
