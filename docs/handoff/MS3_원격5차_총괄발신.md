## 1. 작업 ① — 패드 입력맵 잔여 5행 결선 (D09 §1.3 기계 전사)

원격 4차 잔여 보고분. 소유 충돌 없음 판정 완료 — §6.4 리매핑 탭(주력)은 액션 재바인딩 UI이고 액션·기본 바인딩의 존재는 그 전제 골격이다.

| 매핑표 행 | 패드 | 조치 |
|---|---|---|
| 확인 / 선택 | A | `ui_accept` 에 Joypad Button 0 추가 |
| 포커스 이동 | D패드·좌스틱 | `ui_up/down/left/right` 4행에 D패드 + 좌스틱 축 추가 |
| 탭 전환 | LB·RB | **액션 신설** (Q·E 키보드 병기 — 매핑표 원문) |
| 일시정지 메뉴 | Start | **액션 신설** (Esc 최상위 병기) |
| 상세 정보 | Y | **액션 신설** (T 병기) |

- 전건 D09 §1.3 공통 층 매핑표 명문 — [가안] 불요. `ui_cancel` 전례(IMPL-178)와 같은 형식으로 주석 근거 병기.
- **신설 액션 3종의 화면별 소비부는 결선하지 말고 실태 조사·보고만** — 탭 전환(SYS-03·04 탭 행)·Start(일시정지 호출부)·Y(툴팁 고정)가 현재 어떤 입력을 듣는지 전수 grep. 소비부 결선은 화면 층 몫이라 배정 경유.
- 회귀: 입력맵 액션·바인딩 존재 단언 검사(UISCR 또는 별도 축) — 리매핑 탭이 나중에 기본값을 바꿔도 "액션 자체의 존재"는 불변 계약이다.

## 2. 작업 ② — PAL 문맥 제외 2축 신설 (판정 = 검사 층 분리 승인)

에셋 §4-③ C계 판정 집행. 조달 대장은 *도색* 전속 — 배율·감광 층은 색이 아니다.

| 제외 축 | 대상 | 예 |
|---|---|---|
| 프로퍼티 문맥 | `modulate` / `self_modulate` 값 | `Color(1.6,1.6,1.6)` (게인) · `Color(1,1,1)` (항등) |
| 순 무채 + 알파 | R=G=B(무채)이고 알파 < 1 | `Color(0,0,0,0.55)` 스크림 · `Color(1,1,1,0)` 투명 |

- **제외 사유를 검사 주석에 명문** — 허용 목록이 아니라 검사 정의의 일부다(허용 목록은 판단 기록 전속 유지).
- `Color(0.04,0.05,0.06,0.72)` ×4 같은 **유채+알파는 제외 대상 아님** — 무채 조건을 좁게 걸어라(감광 층으로 위장한 도색이 새지 않게).
- 신설 후 **재계수 보고** — 예상 잔여 ≈ 171±α (C계 10 중 순수 제외분만 빠진다). 돌연변이: 유채+알파 도색 1건이 여전히 경고로 잡히는지 확인.

## 3. 완료 기준

게이트 전건 통과 + 회귀 축 명세 + 돌연변이 반증 + impl_log 등재 + 회신. ①·② 순서 무관, 병행 가능.
