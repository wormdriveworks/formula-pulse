## 2. 판정 10건

### ① 타이틀 → 업적 널 역참조 — **차단급 접수 · 방향 = 가드 신설 (비활성 금지)**

- **차단성: MS-3 게이트 차단급.** Steam EA 첫 세션이 100% 밟는 경로다. 프로세스 생존 여부와 무관하게 "빈 껍데기 + 에러 약 78건"은 출시 불가 상태다.
- **방향: 비활성(기록실 동형)은 기각.** D09 본문 145행이 명문이다 — *"(옵션 SYS-03·업적 SYS-04는 타이틀·일시정지 양측에서 진입)"*. §A-1도 SYS-01 이탈 대상에 SYS-04를 적시한다. 기록실 잠금은 §A-1 E02(세이브 선택 경유 규격)라는 별도 근거가 있는 것이고, SYS-04에는 그런 근거가 없다 — **타이틀 진입은 규격이므로 화면이 무커리어 문맥에서 성립해야 한다.**
- **표시 규칙 [가안]:** 무커리어 시 정적 데이터(`data.achievements`)로 5탭·목록·히든 "???"을 전부 세우고 달성 표시 0 처리. **단 이것이 최종형이 아님을 명기한다** — 업적은 Steam 도전과제 1:1(D12 §7.4)이라 성격상 통산이며, 통산 적재 층(프로필 수준 저장)은 Steam 연동 결선 시 확정으로 **이월 등재**한다. 그 전까지 달성 0 표시는 "이 세션에서 아직 커리어를 열지 않음"의 표시로 [가안] 성립.
- **집행 = 원격** (스크립트 전속 + 무커리어 인스턴스화 회귀 검사). 상세 = `MS3_원격4차_총괄발신.md` ①.

### ② 아이콘 13종 소비부 미결선 — **결선 배정 = 주력 (원격 ① 이후)**

- 업적 6종: §A-4 명문 — 항목 행 = **"아이콘"**·명칭·조건·달성 일시. 아이콘 열은 규격이다. `achievement_screen`에 결선하라. **원격 ①(같은 파일 가드)이 먼저다 — 충돌 방지.**
- 화자 2종: E10 명문 — "중계 마이크 아이콘 / 무전 크루 미니 초상". `log_feed.gd:50` 예고 주석대로 TextureRect 교체.
- 시스템 4종: 소비처 규격이 별첨A에서 즉답되지 않는다 — **결선 전 화면별 명세를 확인하고, 규격 부재면 결선하지 말고 보고**하라(임의 배치 금지).
- `status_ad_exempt`: 데스크탑 부재 = **정상 확정** (D16 모바일 전속 — MS-5).
- 결선 완료 후 `achv_rival`·업적 6종 실배치 재판독(본 회신 ③의 납작 판단 포함).

### ③ `achv_rival` — **파편 제거 = 에셋 재작업 확정 · 납작(11px) 판단 = 재판독까지 유보**

- 우측 파편 3px: 총괄 PNG 디코드로 확정 — **제거 재작업.** 도상 본체 무변경(파편만 소거 — D10 §2.4 도상 불변 계열 처리).
- **검사 구멍 보수 동반:** 고립 픽셀 검사(4-이웃 단일)가 연결 파편을 놓쳤다 — **분리 성분 검사**(본체에서 떨어진 불투명 연결 성분 검출)로 강화하라. 이번 파편이 돌연변이 표본이다.

### ④ 릴 심볼 시각 질량 14:1 — **현행 유지 · MS-5 관측 병기**

위험 신호(트러블·브레이킹)가 주목을 독점하는 것은 **기능상 순방향**이다(경고 시인성). 찬스·펄스의 체감 강도는 연출 층(매치 연결선·SFX·L2)이 보조하므로 도상 잉크 단독으로 판단하기 이르다. 도상 자체는 D10 §5.1 확정이라 재작업 = 정본 개정 사안. → **대장 §9-⑫에 MS-5 실기 관측 항목으로 병기**(에셋): 잉크 질량 6종 실측값 + 슬립스트림↔펄스 색 인접(시안 계열 2종) 관측 후보.

### ⑤·⑥ 씬 색 리터럴 3종 (테두리 15곳 `#475261` · 주텍스트 61곳 `#E6EBF2` · 부텍스트 40곳 `#8C94A3`) — **팔레트 수렴 원칙 확정 · 값 판정 = 에셋 → 적용 = 주력**

- **원칙 판정: 씬 색은 팔레트 정본으로 수렴한다.** 마스터 56색 밖 값이 씬에 116곳 — "주 텍스트(N16)가 화면에서 성립하지 않는다"는 발견이 정확하다. 부텍스트 무해가 **우연**이라는 기록도 옳다.
- **수렴 슬롯 확정 = 에셋 소관** (불변규칙 2 단서): `#475261`→N10(FRAME_LINE 통일) 후보 · `#8C94A3`→N13(5.68≈5.64 사실상 동일) 후보 · `#E6EBF2`→N16 수렴이 원칙이나 **61곳 밝기 하향은 화면 인상이 크게 변한다** — 팔레트 위쪽 확장은 정본 개정 사안이므로 신중 판단하라.
- 적용 = 주력(씬 소유권) + 적용 후 눈 대조. 에셋 판정 선행.

### ⑦ 색 축 검사 — **신설 승인 · 명칭 PAL · 경고형 신설 → 위반 정리 후 차단형 flip (FONT 전례 그대로)**

기계 판정(색값이 조달 대장 안인가 — 미적 판단 아님)이라 차단형 성격이나, **기존 위반 116+곳이 실재하므로 경고형으로 신설**하고 ⑤·⑥ 정리 완료 후 차단형 전환을 별도 판정한다. 대상 = `.tscn`·`.gd` 색 리터럴 vs 마스터 56 + 기능색 + 정본 §6 지정색 + 명시 허용 목록. 집행 = 원격(validators 소관).

### ⑧ SYS-03·04 패드 탈출 불가 — **D09 §1.3 저촉 확정 · 수정 배정**

본문 89행 명문 — *"모든 화면은 패드 포커스 순회가 폐쇄 루프를 이룬다(도달 불가 요소 0건 — H38). 초기 포커스는 화면별 주 행동 버튼에 둔다."* 초기 포커스 부재 + 패드 복구 입력 0 = **저촉이다.** 수정(초기 `grab_focus` + `ui_cancel` 처리) = 원격(스크립트 전속), 패드 실기 확인 = 주력 후속. 패드 취소 바인딩이 정본에 규정돼 있으면 그대로, 침묵이면 엔진 관례 [가안] 등재.

### ⑨ `race_screen` 단독 경로 O9 미적용 — **경로 정합 채택 (주석이 계약이다)**

"동등한 개시 경로 — 라우터가 하는 일을 그대로 한다"가 계약 문면이므로 **코드를 주석에 맞춘다**: `_boot()`에 `UiPalette.apply_options()` 결선. 하네스가 O9를 관측할 수 있게 되는 실익 동반. `test_ui_options.gd:117` 사각 주석 갱신 포함. 집행 = 원격.

### ⑩ `log_feed.gd:21` 초기값 8 — **리터럴 해소 배정 (IMPL-159와 별개 선행)**

`configure()` 미호출 경로가 생기면 D13 값(9) 밖의 8이 실렌더되는 잠재 지점 — FONT-B 유형. 초기값의 D13 창구 경유 또는 미구성 상태 명시적 차단으로 해소. 집행 = 원격.
