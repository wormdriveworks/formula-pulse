## 2. D11 결속 5항 — 이행 대조

| 결속 | 이행 |
|---|---|
| `jg_01`/`jg_02` **온도차가 본체** · 상위 = 밝은 상승 종지 | C5→E5→G5 순차 상승 + **마지막 음만 454ms**. 도약이 아니라 순차로 열고 종지를 끌어 닫습니다 |
| **중하위 = 담백 · 실패 정서 배제** (D09 §5.1) | **중하위는 차가운 소리가 아니라 덜 뜨거운 소리입니다.** D09 §5.1 이 "실패/GAME OVER 계열"을 금지하므로 **하강 선율·단조는 규격 위반**입니다 — 내려가는 음정은 그 자체로 실패 정서입니다. 그래서 **같은 음(C5) 2타**로 뒀습니다: 방향이 없으니 아래로도 위로도 읽히지 않습니다. 온도차는 **상승의 유무 + 종지 연장의 유무**로만 줬고(−4.5dB 대 −8.0dB), **파형·듀티·필터는 `jg_01` 그대로**입니다 — 음색이 갈리면 두 결과가 다른 세계의 소리가 됩니다 |
| `jg_03` **하강 단결** · BGM 정지 후 단독 | **여기서는 하강이 규격입니다** — 리타이어는 소프트 실패가 아니라 주행의 종료이고, 같은 사건의 SFX(`se_d07`)도 하강 램프입니다. 다만 신파 금지(D04 §8.3)라 **종지를 끌지 않았습니다**(255ms = `jg_01` 종지의 절반). **절제는 방향이 아니라 길이에서 나옵니다.** BGM 이 멈춘 뒤 단독 재생이라 크게 둘 필요도 없어 −5.0dB 입니다 |
| `jg_04` **모티프 인용** | §3 |
| `jg_05` **짧은 팡파르** | 도약과 반복 — E5→G5→C6 로 두 번 뛰어오르고 5식 중 **최단(349ms)**, 유일하게 C6 사용. `se_u17`(업적 획득)과 동시 발화 가능성이 있어 음역을 위로 띄웠습니다(U17 은 중역 아르페지오) |

## 3. 메인 모티프 [가안] 확정 — `tools/audio/motif.json`

D11 §4.1 은 BGM-01 을 *"메인 모티프 원형(노스윈드 테마 1개만 운용)"* 으로 확정했지만 **선율 자체는 정본에 없습니다** — 작곡 지침(무드·문법·금지)까지가 D11 의 몫이고 음 자체는 제작 재량입니다. 기안 §2.1 의 배정대로 여기서 [가안] 확정하고 **원장을 한 곳에 뒀습니다**.

| 항목 | 값 |
|---|---|
| ID | `MOTIF-NORTHWIND` · 4음 |
| **오프셋** | **[−5, 0, +2, +4]** (근음 기준 반음) = 5→1→2→3 |
| 형태 | 완전4도 도약으로 열고 순차 2음으로 걸어 올라가 **장3도에서 닫는다** |
| 징글 렌더 | G4(392.00) · C5(523.25) · D5(587.33) · E5(659.26) |
| 실물 되읽기 | **±8센트** (반음 100센트 대비 무해 — 주기 정수 양자화가 곧 레트로 질감) |

**절대 주파수가 아니라 오프셋으로 적었습니다.** BGM-01 은 타이틀 음역, JG-04 는 징글 음역이라 **같은 선율이 다른 옥타브에서 나야 합니다** — 절대값으로 적으면 옥타브를 옮길 때 원장이 갈립니다. 불변인 것은 `degrees` 4개이고 옥타브·박·편곡은 각 트랙 재량입니다.

**3음(장3도)에서 멈추는 것이 규격입니다.** 5음까지 올리면 팡파르(`jg_05`)와 겹치고, 8음까지 올리면 총화가 되어 **BGM-12 의 '최대 해방'과 BGM-01 의 '원형'이 구분되지 않습니다**(D11 §4.1 이 둘을 갈라 뒀습니다). 원형은 여지를 남깁니다. 단조 아님·반음 없음(실패 정서 배제 계열 정합 + 칩 문법의 명료함).

**`jg_05` 가 모티프를 인용하지 않는 것도 같은 이유입니다** — 칭호는 시즌 챔피언의 축소판이 아니라 **다른 종류의 사건**이고, 인용하면 두 사건의 위계가 선율로 섞입니다.

**`checkMotif` 를 신설했습니다** — 원장⇔`jg_04` 인용 대조 + **원장 자체의 오프셋⇔헤르츠 자기 정합**(반음비 2^(1/12) · 1센트 허용). BGM-01·BGM-12 도 이 원장을 승계하므로 갈리면 **세 곳이 조용히 어긋납니다**. 초판은 `jg_04` 가 없어도 조용히 통과했는데(원장만 있고 인용부가 없는 상태) 그 자리에서 막았습니다 — 전량 주행에서 인용부 부재는 실패입니다.

## 4. 자기 결함 자수 — **주파수 공식이 3옥타브 틀렸습니다**

멜로디는 음정이 틀리면 전부 틀리므로 `p_base_freq` → 헤르츠 변환을 먼저 유도했습니다. 상류 코드에서 `period = 100/(p²+0.001)` 를 읽고 `F = 44100/period = 441×(p²+0.001)` 로 계산했습니다.

**실측이 8.03배 높게 나왔습니다.** 영교차로 주기를 재보니 목표 196Hz 가 1575Hz 였습니다 — **+3608센트, 정확히 3옥타브**. 원인은 상류가 **출력 샘플당 8 서브샘플**을 돌리는 것이었습니다(고전 sfxr 의 필터링 구조).

**F = 3528 × (p² + 0.001)** · 3528 = 441 × 8.

공식을 고친 뒤 **생성된 `jg_04` 실물에서 4음의 주기를 다시 재어** 원장과 ±8센트 이내임을 확인했습니다. **파라미터가 맞는 것과 소리가 맞는 것은 다릅니다** — 공식을 짐작했으면 5식 전부가 3옥타브 위에서 울렸을 것이고, 그건 귀 검수에서 "이상하다"로 돌아왔을 뿐 원인은 안 보였을 겁니다.

**이 공식도 `vendor/sfxr.js` 산술의 복제입니다** — `deadParams` 의 발화 시점 공식과 같은 성격이라 **대장 §7 조건 ⓑ 를 확장했습니다: 벤더 갱신 시 재대조 대상이 1개에서 2개로.**

## 5. 검사 확장 — 5행 추가가 아니라 **채널화**로 했습니다

발주는 "AUD·AUDIO-A 징글 5행 확장"이었습니다. 경로·계수를 손으로 늘리는 대신 **`sound_map.csv` 의 channel 열을 대장으로 두고 그 표를 도는 구조**로 바꿨습니다.

```
AUD_CHANNELS = { "sfx": {dir: audio/sfx, total: 68}, "jingle": {dir: audio/jingle, total: 5} }
```

이유 = **BGM 이 다음 회차에 들어옵니다.** 5행을 손으로 박으면 BGM 회차에 같은 일을 또 하게 되고, 그때 경로·계수·루프 목록이 세 군데로 흩어집니다. 징글 5 는 D11 §4.1 결정 #5 로 **트랙 계상 외 별도 소계**이므로 **68 에 합산하지 않고** 별 항으로 셉니다.

| 검사 | 이전 | 이후 |
|---|---:|---:|
| AUD (파일·선언) | 821 | **882** |
| AUDIO-A (임포트 결과) | 350 | **376** (하한 340→**370**) |

**사각을 코드 주석에 명기했습니다** — *"표에 없는 채널은 조용히 통과한다(부재가 아니라 무대상). BGM 유입 시 행 추가를 잊으면 파일이 들어와도 아무도 보지 않는다."* 그 자리가 이 검사의 구멍이고, 구멍을 아는 것과 모르는 것은 다릅니다.
