## 2. 사운드 축 — 발주 명세와 조달 경로

### 2.1 발주 명세는 정본이 이미 확정해 두었다

- **계수**: SFX 63 + AMB 5 = **68식** (D11 §2.11 확정 기준값 · 상한 75) / BGM 13트랙 = **18스템**(레이스 5무대 × A/B) + 예비 1 유보 / 징글 5식(트랙 계상 외 — 결정 #5).
- **포맷** (D12 §10.1 확정): SFX·징글 = WAV/PCM 44.1kHz 16bit(질감 베이크) / BGM = OGG Vorbis 44.1kHz ~q0.7 · 심리스 루프 필수 · 90~150초 · A/B 동일 길이·동일 템포·박 동기.
- **아이덴티티** (D11 §1.1 결정 #2): SFX = 16비트 질감(짧은 칩, 어택 명료·꼬리 짧음) / BGM = 32비트 문법. 금지 = 실사·오케스트라·라우드니스 전쟁형.
- **루프 포인트 필수 6식**: `se_r02`·`se_t03`·`se_u15`·`amb_01`·`amb_04`·`amb_05`.

### 2.3 조달 경로 — 사용자 결정 사안

RD(retro-diffusion)는 **이미지 전용**이라 사운드 조달 경로는 신규 판단이다.

**SFX 68식** — 선택지:

| 안 | 경로 | 성질 |
|---|---|---|
| **A (권고)** | **절차적 생성 도구 파일럿** — sfxr 계열(jsfxr/rfxgen 등 스크립트 구동) 파라미터 생성 | 16비트 칩 질감 = 도구의 본령이라 아이덴티티 정합. **파라미터·시드 = 커밋 가능** → 재현성 문화 그대로. 비용 0. 단 톤 품질은 귀 검수 전 미지 — **파일럿 8식(R군 5 + I01·I10·U01) 선행 → 귀 판정 → 전량 확대 or 전환** |
| B | 외부 소스 큐레이션 (CC0/CC-BY 팩) | 품질 보증되나 68식 톤 통일이 어렵고 **라이선스 대장 신설 필요**(Steam 출시 — D15). 큐레이션 = 귀 작업이라 자동화 이득 없음 |
| C | 외주·사용자 조달 | 리포 밖 트랙. 발주서(본 명세)만 총괄이 공급 |

**BGM 18스템 + 징글 5** — 작곡 영역. 루프·A/B 박 동기 규격이 엄격해 절차 생성으로 안 되고, AI 음악 생성도 스템 분리·심리스 루프 보증이 약하다. **권고 = SFX 파일럿 결과 확인 후 별도 재기안**(외주/사용자/AI 도구 비교 — 지금 확정하지 않는다). 징글은 수초 단곡이라 BGM보다 싸지만 멜로디 작곡이 필요해 같은 축에 묶는다.

### 2.4 사운드 내부 순서 (승인 시 발주서에 기재)

① 레이스 코어 39식(R·I·T·E·L·RS·D) — T6 즉효 → ② U군 19식 → ③ V군 5식 → ④ AMB 5식 → ⑤ 징글·BGM(별도 기안). **SE-E05(중립)는 최후순위** — 미발화 확정(IMPL-157 판정 ① · P-2 ㉚), 목록 유지·순서만 후치.

### 2.5 검수 체계 — 축을 처음부터 가른다

- **기계 축** (원격/총괄): WAV 헤더(PCM·44.1kHz·16bit)·OGG 규격·루프 포인트 메타 실재·A/B 스템 길이 일치·파일명 대장 대조·`sound_map` 참조 정합. 유입 회차에 검사 신설(경고형 → 실측 → 총괄 판정 → 차단형, FONT·PAL·ANCH 절차).
- **귀 축** (주력+사용자): 톤·아이덴티티·봉인 체감(정지 연출 전 무신호). 기계가 대신하지 않는다 — 아이콘 트랙의 "눈 소관" 원칙 그대로.

## 5. 순서 권고안 종합

```
회차 N   에셋: RD §8 재검 + SFX 파일럿 8식(2.3-A 채택 시)   ← 병렬 →   사용자: T7 집필 착수 대기
         원격: T7 납품 양식 계약서 작성(§3.2)                              (계약서 승인 후 집필)
회차 N+1 파일럿 귀 판정(주력 or 사용자) → SFX 전량 확대 / 경로 전환
회차 N+2~ SFX 잔량 → 이미지 A급(프레임→글리프→머신→캐릭터) → T7 편입 회차(유입 시 우선 처리)
후속 기안  BGM·징글 조달(§2.3) · B급 이미지
```

**판단 근거**: 사운드는 수용부가 완비된 유일한 축(파일만 오면 T6·게이트가 닫힌다)이고, T7은 사용자 시간이 지배 변수라 가장 먼저 착수시켜야 총 소요가 준다. 이미지 A급은 소비부가 이미 런타임 대체물로 돌고 있어 긴급도가 한 단 낮다.

### 7.1 에셋 트랙 발주서 — SFX 파일럿 8식 (도구 생성)

- **대상 8식**: `se_r01`~`se_r05`(릴 텐션 전군 — 아이덴티티 핵심·봉인 문법의 청각 축) + `se_i01`(개입 창 오픈) + `se_i10`(확정 입력) + `se_u01`(커서 이동 — 최고 빈도). 파일럿의 목적 = **도구가 D11 §1.1 "16비트 질감"을 내는지 귀로 판정할 표본**.
- **도구**: sfxr 계열 절차 생성기 중 **스크립트 구동 가능한 것**을 에셋 트랙이 선정한다(후보: jsfxr(npm)·rfxgen CLI — 원격 헤드리스에서 도는 것이 조건). **파라미터 정의 = 커밋 대상**(생성 스크립트 + 파라미터 파일 → 실물 재생성이 결정적이어야 한다 — 스와치 생성기·아이콘 파이프라인과 같은 재현성 계약).
- **소유 경로 확장 선언**: 기존 `docs/assets/`+`godot/assets/` 에 **`tools/audio/` 신설 편입**(생성기·파라미터 거처 — `tools/assets/` 아이콘 검사 전례).
- **규격** (D12 §10.1): WAV/PCM 44.1kHz 16bit · 파일명 = 대장 §5.1 그대로 · 배치 = `godot/assets/audio/sfx/` · **LFS 확인 후 커밋**(오디오 = LFS — `.gitattributes`) · `.import` 동반 커밋(IMPL-003·021). `se_r02` = 루프 — **WAV 임포트 루프 설정의 실증 포함**(대장 루프 6식의 선행 표본).
- **거동 유의 2건**: `se_r03` = **1파일**(§2.2-ⓑ — 3피치는 런타임 재생 거동·파일 아님) / SE-R04·R05는 봉인 정합 대상이나 그것은 디스패처가 이미 강제한다 — 에셋은 소리만 만들면 된다.
