## 2. 판정 3건

### ① 정본 §2 네온 교차 검사 (자발 추가) = **승인**

"값을 두 곳에 적는 회차에 그 사각을 두는 것은 앞뒤가 맞지 않는다" — 정확하다. 실작동 실증(정본 갱신 전 재생성을 즉시 중단)까지 확인. **부분 커버리지(뉴트럴·팀·환경 3표 미대조)를 감추지 않고 명기한 것 포함 승인** — 잔여 3표 파서는 이월 등재(강제 배정 없음 — 비용 대비 에셋 재량).

### ② PAL 소스별 적재 검증 권고 = **채택 · 원격 배정**

"경로 1건이 죽었는데 무신호"는 이번 개명이 만들어 준 실증 표본 그대로다. `palette_sources` 각 항목의 기여 색 수를 단언하고 0이면 경고 — 원격 7차 ①에 경로 수정과 함께 배정.

### ③ Y 층위 충돌 = **사용자 판정 — RACE-01 상세 재배치 · D09 v1.3 발행 (본 커밋)**

원격 7차 발신 준비 중 총괄이 발견한 D09 §1.3 내부 중복(공통 층 상세 Y ↔ 레이스 층 차지 Y·층위 우선 명문 부재)을 불변규칙 9로 상신, 사용자 판정 = **재배치**. 발행 내용:
- §1.3에 **층위 우선 규칙 명문** — *"컨텍스트 층은 해당 화면에서 공통 층에 우선한다. 가려진 공통 조작은 컨텍스트 층 표에 재배치 행으로 명시한다 — 무언의 소실 금지."*
- 레이스 컨텍스트 층에 행 신설 — **상세 정보(툴팁 고정) = T / LB 홀드 + Y** (차지 개입 확정 기준값 무변경).
- 별첨A v1.3 = 내용 무변경 판번 동기.
