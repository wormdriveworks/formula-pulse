## 1. §1 판정 — 생성기 커밋. **뒤집힌 권고를 받아들인다**

**IMPL-097 전례 논거가 결정적이다.** 특히 ⓑ에 대한 반박 — *"원천이 `.gpl`이라면 **그래서** 커밋해야 한다. 파생물이 원천과 일치함을 보증하는 유일한 수단이 생성기다"* — 는 내 논거를 정면으로 뒤집는다. 나는 원천/파생 구분을 **커밋 안 할 이유**로 썼는데 그것은 정확히 **커밋할 이유**였다. ⓒ("산문은 재현을 보증하지 못한다 — 읽고 다시 그리면 재작화")도 맞다.

`tools/palette/` 배정도 접수했다. "미배정 경로이지 남의 경로가 아니다"라는 구분이 규약의 취지에 맞다.

### 부대조건 이행 — 생성기는 **색상값을 하나도 갖지 않는다**

| 무엇 | 어디서 읽는가 |
|---|---|
| 마스터 56색 | `godot/assets/palettes/master_56.gpl` ← 판정이 지정한 입력 |
| 색각 교체 4색 | `colorblind_alt.gpl` 꼬리 4행 |
| **기능 부속 13색** | **팔레트 정본 §5** |
| **교체 대응관계** | **팔레트 정본 §6** |

기능 13색은 **대장 §4.9 계약상 `.gpl`에 들어갈 수 없으므로**(파일명 계약 `master_56`) 정본이 유일한 기계 판독 출처다. 그래서 정본 §5·§6 표를 파싱한다 — 값을 생성기에 옮겨 적으면 그것이 곧 두 벌이므로 부대조건에 걸린다. 생성기가 가진 것은 **한글→ASCII 라벨 매핑**뿐이며(`슬립스트림` → `SYM-SLIP` — 3×5 폰트가 한글을 못 그린다) 색상값이 아니다.

### 등가 증명 — 리팩터가 값을 바꾸지 않았음을 바이트로 확인했다

입력을 통째로 갈아엎었으므로 "같은 그림이 나오는가"를 눈이 아니라 해시로 확인했다.

> **`colorblind_alt.png`가 기존 산출과 바이트 동일하게 재현됐다.** 그 시트는 마스터 4블록 + 기능 13 + 교체 4를 **전부** 담으므로, 세 입력 경로가 종전 인라인 표와 값이 같음이 이 한 건으로 증명된다.

`master_56.png`의 유일한 차이는 **푸터 문구**다 — 판정의 "수기 편집 금지"를 산출물 자신에 새기려고 `A-PALETTE-01 V1.0 / GENERATED - DO NOT EDIT BY HAND`로 바꿨다(날짜를 뺐으므로 재생성 결정성도 함께 확보). 연속 2회 실행 해시 동일.

## 2. §1 집행 중 드러난 것 — **검사 구멍 1건 (보고 · 비차단)**

생성기를 커밋할 값어치가 있는지 확인하려고 **돌연변이 5건**을 넣었다. **4건 검출, 1건 미검출.**

| # | 돌연변이 | 결과 |
|---|---|---|
| ⓐ | `master_56.gpl` RGB 1바이트 변조 | ✅ 검출 |
| ⓑ | `.gpl` 구분자 탭→공백 | ✅ 검출 |
| ⓒ | `colorblind_alt.gpl` 의 마스터 본체 오염 | ✅ 검출 |
| ⓓ | 정본 §6 대체색 변조 | ✅ 검출 |
| ⓔ | **정본 §5 `VANE-ELATED` hex 1자리 변조** | ❌ **미검출** |

**원인은 구조적이고 고칠 수 없다.** 대조는 **값이 두 곳에 있을 때만** 성립한다. 기능 13색 중 정본 §6 교체쌍 4건만 `.gpl` 꼬리라는 상대가 있고, **나머지 9건은 정본이 유일 출처**다. 유일 출처인 값은 무엇과도 대조할 수 없다.

**조치 — 검증한 척하지 않는 쪽을 택했다.** 그럴듯한 규칙을 지어내 커버리지를 부풀릴 수는 있었다(예: "기능색은 마스터에서 조달한다" 를 단언 — 실제로 13색 중 8색이 마스터와 일치한다). **하지 않았다.** 정본 어디에도 그런 규칙이 없고, 관측된 우연을 규칙으로 굳히면 다음 개정이 의도적으로 분리할 때 생성기가 헛되이 실패한다. 임의 확정 금지에 걸린다.

대신 **생성기가 매 실행에 커버리지를 출력**한다:

```
기능 13 교차 검증 커버리지 4/13 — 미검증 9건 (정본 단일 출처): SYM-SLIP SYM-BRAKE
SYM-CHANCE SYM-PULSE GAUGE-OK VANE-NORMAL VANE-ALERT VANE-ELATED VANE-DAMAGED
  └ 해소 = 구현 트랙의 ui_palette.gd 결선(정본 §9.2) 후 대조 추가
```

**해소 경로는 이미 정해져 있다 — 새 판정이 필요 없다.** 구현 트랙이 `ui_palette.gd`를 정본 §9.2 매핑표대로 결선하면(현 [가안] 21건 미착수) **13색 전건에 두 번째 출처가 생긴다.** 그 시점에 생성기에 대조를 추가하면 커버리지가 13/13이 된다. 대장 §9-⑬ 에 등재하고 트리거를 구현 트랙에 걸어 뒀다.

> 즉 **`ui_palette.gd` 결선은 [가안] 21건 종결이자 팔레트 검사 완결이기도 하다.** 잔여 추적 §5의 그 항목에 이 부수 효과를 덧붙여 두면 우선순위 판단에 도움이 될 것이다.

## 3. §2 판정 — 근거 교체. **지적이 맞다**

내 근거는 **자기 논리로 반박된다**는 지적 그대로다. "베인의 이웃은 적록 충돌쌍이 아니다"라고 썼는데, **베인 경고(적)↔고양(앰버)은 게이지 위험↔주의와 같은 적↔앰버 쌍**이고 그 게이지 쌍은 교체 대상이었다. 같은 유형을 한쪽은 충돌쌍으로, 다른 쪽은 아니라고 부른 셈이다.

**ΔL\*를 독립 계산으로 검산했고 수치가 일치한다**(sRGB→선형화→Y→L\*):

| 쌍 | ΔL\* | 교체 |
|---|---|---|
| 게이지 위험 `#FF4A3D` ↔ 주의 `#FFBF3D` | **22.7** | ✅ |
| 베인 경고 `#FF4A3D` ↔ 고양 `#FFD86B` | **29.2** | ❌ |

교체된 쪽이 더 좁다 — 명도만으로도 미교체가 정당화되지만 그 이유가 내가 쓴 것과 다르다.

**대장 §9-⑫의 근거를 두 가지로 교체했다:** ①명도차 역전(29.2 > 22.7) ②**1차 부호화 채널의 강도 차** — 게이지는 색 + 채움량인데 채움량이 연속값이라 등급 **경계를 색이 지고**, 베인은 색 + 파형 A/F/S 라 파형이 상태를 직접 그린다(D03 §1.5). **게이지는 색이 판정에 가깝고 베인은 멀다.** MS-5 트리거는 유지했다.
