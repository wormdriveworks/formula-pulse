## 1. 문안 설계 판단 4건 — **취향이 아니라 구속의 귀결**

문면을 짜기 전에 정본이 이미 가둔 것을 먼저 확정했습니다. 아래 4건은 **편입 회차가 되돌리면
정합이 깨지는** 판단이라 회신문에 올립니다.

### ① 화자를 마르타·테오·베인 3자로 고정

- 사샤·오스카·나디아는 **합류 여부가 가변**입니다(D08 §8.7 앵커 — 기대 중앙값만 있고 보장 없음).
  막 전이는 마일스톤 래치라 크루 미합류 상태에서도 발생하므로, 미합류 인물을 화자로 두면
  **그 VN이 경로에 따라 성립하지 않습니다.**
- 부수로 **스탠딩 2인**(D09 별첨A §A-19 좌/우 상한)·**신규 전용 아트 0**(D01 G2 조건 1 ·
  D08 §8.9 부대조건 ①)이 함께 닫힙니다.
- **기원 공개의 화자도 마르타입니다** — D03 §1.2가 "보레아스 인수의 전말을 쥔 인물"로 마르타를
  확정했고, 사샤(단서 단계 운반체)는 합류 미보장이라 공개 단계 화자로 둘 수 없습니다. 사샤 몫은
  단서 2("…그건 다룰 수 있는 물건이 아니야. 아무도.")이며 본 납품은 그것을 대체하지 않습니다.

### ② 베인 라인의 1인칭을 비웠다 (1막 제외)

- 베인 단계 전환은 **주행 데이터 누적 연동**(D07 §8 · 0.35×E1 / 1.0×E1)이고 **막 진행과 독립**입니다
  — 4막에도 1단계일 수 있습니다.
- D04 §5.4의 단계 표지 중 **1인칭이 유일한 필수 표지**입니다(1단계 "본 유닛" / 2·3단계 "저").
  이를 비우면 존댓말·수치 언어를 유지한 채 **3단계 전부에서 성립** — 단계별 3중 집필(분량 ×3)
  없이 §5.4를 어기지 않는 유일한 경로입니다.
- 1막만 예외인 이유 = 게임 시작이므로 1단계가 **구조적으로 확정**(D09 §2 플로우).
- **회수 설계:** 1막 `주행 이력 조회 실패. 참조 데이터 없음.` ↔ 에필로그
  `이번에는 조회에 실패하지 않습니다.` — 같은 어휘의 양단 대칭으로 성장을 표현하며
  어느 쪽도 1인칭·감정어를 쓰지 않습니다.

### ③ 4막을 VN 2건으로 갈랐다

D08 §8.2 로렌츠 격파 행이 서사 효과를 **둘** 줍니다 — "4막 진입(래치) **·** 기원 '공개' 단계 개방".

### Q1. CG-02 '대면' = 관계 단계 몇? → **단계 1. 판정 불요 (도출)**

D04 §4.2 상태 열거와 `achievements.csv` 임계가 **양단을 고정**하므로 중간이 유일하게 정해집니다.

| 단계 | 상태 (D04 §4.2 "회피 → 대면 → 응어리 → 화해/결착") | 고정 근거 |
|---|---|---|
| **0** | 회피 | 초기 = 화살표 좌단 · `relation_stages` 기본값 0 (`outgame_state.gd:456`) |
| **1** | **대면** ← CG-02 판정선 | 양단 고정의 귀결 |
| 2 | 응어리 | 동상 |
| **3** | 화해/결착 | `achievement_relation_reunion` `threshold=3` · D08 §8.11 **"재회 종착"** |

- 4상태 − 초기 1 = **전이 3회** = `threshold1~3` 과 정확히 1:1. 좌단·우단이 고정되면 다른 배정이 없습니다.
- **동형 교차 검증:** 왕좌 축도 4상태(노이즈→변수→위협→대등)이고 업적이 '대등'을 `threshold=3`
  으로 봅니다 — 같은 매핑이 이미 성립해 있습니다.
- **계약서가 우려한 지점의 해소:** "체인 비트 수와 관계 단계 수가 1:1이 아닐 수 있다"는 우려는,
  두 축을 **`threshold` 가 매개**하는 구조로 해소됩니다 — **"대면 = 단계 1 = 카운터 2"** 가 한 벌의
  답입니다(카운터 2의 도출은 §4-① 참조).

**구현 결선(편입 회차) — 실독한 지점:** 주석 근거는 `race_screen.gd:1007`이고 **코드가 늘어나는
자리는 디스패처 `_l3_encounter_id()`(`:1033`)** 입니다. `l3_reunion_for()` 를 `l3_kinship_for()`
(`:1026`)와 동형의 순수 static 함수로 신설한 뒤 — 판정 = 듀얼 결판 ∧ 상대 = 카이 ∧
`relation_stage("relation_reunion") >= 1` — `throne → kinship` 폴백 사슬에 갈래 1개를 더합니다.
반환 id = **`cg_02_reunion`** (기존 `cg_01_throne`·`cg_03_kinship` 대칭).

### Q3. 막(`act`) 전이 규격 → **정본에 기확정. 집필이 답할 사안이 아니다**

낡았음을 보고합니다**(총괄 인지 요청 — §5-④).

| 항목 | 확정 내용 | 정본 |
|---|---|---|
| 진입 마일스톤 | 1막 = 게임 시작 / 2막 = **첫 포디움** / 3막 = **첫 투어 우승** / 4막 = **로렌츠 첫 격파** | D04 §1.2 · D08 §8.2 |
| **발효 시점** | 이층 처리 — 시스템 층 = **즉시** / **서사 층 = 달성 후 최초의 투어 경계 래치** (막 전이 공표·막 상태 태그·**막 결속 이벤트 풀 교체**) | **D08 §8.1** |

| 경계 경합 | **막 전이 > 크루 합류 > 기원 단서 > 일반 성취** · 잔여분 차기 경계 이월 | D08 §8.4 |

## 4. 판정 요청 3건 — **총괄 처리 사항**

### ① [질문 4 — 신규] `relation_reunion` threshold2·threshold3 = **D13 부재** (불변규칙 2)

**닫힌 것 — `threshold1 = 2` (도출·창작 아님):**

D08 §8.7 사샤 데드락 검증의 구조 보장이 값을 하나로 가둡니다.

1. §8.7-2 알타 리지는 셔플 규칙상 **매 시즌 투어 2~4 중 반드시 1회 등장**(구조 가드 3)
2. §8.7-3 체인은 알타 리지 투어 내 브리핑·이벤트·벽 조우로 **1~2비트씩 전진** · 기대 도달 =
   **시즌 1 알타 리지 투어 내**
3. → 1투어 최대 전진량 2비트 ∧ 시즌 1 내 도달 ⇒ `threshold1 ≤ 2` · §8.7-3 "체인 **2~3**비트째"
   ⇒ `threshold1 ≥ 2` → **= 2 (유일 해)**
4. 반증: `3` 이면 시즌 1 내 도달 불가 → §8.7-3 기대 도달과 §8.7-4 조건 결속("대면 ≤ 단서 2단계
   교차"가 **항상 성립")이 함께 깨져 **사샤 영입이 구조 보장에서 확률 기대로 후퇴**(D07 구속 위반)

**열린 것 — threshold2·3:**

| 사실 | 근거 |
|---|---|
| D13 별첨A §5.2 관계 카운터 임계 표에 **재회 행이 없다** (동기·계승·왕좌 3행뿐) | D13 별첨A §5.2 |
| **누락이 아니다** — 재회는 형식 A라 형식 B 임계 설계의 대상이 아니었다 | D07 §5.5 · D08 §8.8 |
| 그런데 스키마는 `threshold1~3` 을 **필수 `int:1,99`** 로 요구한다 | `config.json` |
| D08 §8.8 재회 행은 "체인 순차 전이"만 두고 **총 체인 비트 수를 침묵** | D08 §8.8 |

→ **형식 A 축을 형식 B 스키마에 담아야 하는 구조적 비대칭**입니다. 임의 기입하지 않았습니다.

**안 2종 (택일 또는 제3값 지정):**

| 안 | 값 | 논리 | 귀결 |
|---|---|---|---|
| **A (권고)** | **2 / 3 / 4** | 형식 A 순차 전이의 항등 표현 — **1비트 = 1단계** | 알타 리지 매 시즌 1회 · 시즌당 1~2비트 → 종착 = **시즌 2~3**. 진엔딩 중앙값(D08 §8.2 시즌 챔피언 S2~S3)과 같은 구간 |
| B | 2 / 4 / 6 | 단계당 2비트 | 종착 = **시즌 3~6**. 히든 업적의 포스트게임 여운은 커지나, §8.7-4 단서 2·사샤 영입 결속 이후 축이 장기간 정지 |

**권고 근거(A):** D08 §8.7-3이 체인 전개를 "1~2비트씩 전진"으로만 규정하고 **단계당 비트 수를 두지
않았으므로** 1비트 = 1전이가 정본에 가장 가깝습니다. 또한 재회 종착은 D08 §8.11 업적 "관계 최종

**"구현 주석의 [가안]·미결선 표기는 정본의 공백을 증명하지 않는다 — 주석이 인용한 조항을 직접
