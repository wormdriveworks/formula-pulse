## 2. ⚠ 발주 문면대로 감산하면 컷인이 화면에서 사라진다

발주는 *"원도에서 초상 제거"* 였고, 이 엔트리의 초상은 **오버레이 2장**이었다. 그러니 선언에서 `overlays` 를 지우면 끝나는 일로 보였다. **아니었다.**

```
cg05(구) 배경 = rd_raw/backgrounds/garage_320.png · scale 2 · crop [0,0,640,360]
garage_h    배경 = rd_raw/backgrounds/garage_320.png · scale 2 · crop [0,0,640,360]   ← 같다
```

실측: 두 산출물은 **오버레이 사각 밖에서 최대 채널차 0** — 바이트 동일이다. 즉 오버레이만 빼면 `cg05 == garage_h` 다.

그리고 `garage_h` 는 **바로 이 비트의 VN 바탕**이다:

```
vn_backdrops.csv:13   vnbg_crew_sasha,,vnbeat_crew_sasha,garage_h,
cg_cutins.csv:6       cgcut_sasha,cg05_sasha_return,,,vnbeat_crew_sasha
```

층 순서가 *바탕 → CG → 스탠딩*이므로, 감산판 컷인은 **자기 뒤에 이미 깔린 그림을 한 번 더 그린다.** 얼굴 4개는 사라지지만 **컷인 자체가 사라진다** — 눈에는 "CG 가 안 뜬다"로 보이고, 그것은 15차의 *"검은 화면은 부재의 그림과 잘못된 열쇠의 그림을 구분해 주지 않는다"* 와 같은 자리다. 게이트도 테스트도 붉지 않는다(파일은 있고 치수도 맞다).

**그래서 형제 5장처럼 자기 원판을 갖게 했다.**

## 5. 시도했다 실측에 기각된 게이트 — '인물 0' 은 여전히 기계가 못 본다

판정이 요구한 것은 인물 0 이고 지침 §9-⑦(네거티브 필드 부재)에는 기계 게이트가 없다. 그래서 **팔레트 피부 3색(SK1·SK2·SK3) 화소를 세면 얼굴을 잡는다**고 보고 도구를 쓰기 직전까지 갔다. 실측이 전제를 깼다.

| 대상 | 피부 순색 화소 | 최대 연결 성분 |
|---|---|---|
| `crew_sasha_base` (얼굴 있음) | 3,285px | 1,953px |
| `crew_marta_base` (얼굴 있음) | 5,074px | 3,547px |
| **`garage_h`** (인물 0 — 확실) | **23,760px** | **8,932px** |

**인물 0 인 개러지가 얼굴 둘보다 '피부'를 많이 갖는다.** 양자화 때문이다 — 작업등 아래 콘크리트·벽 광량이 최근접 색으로 **SK1 로 끌려간다**(garage_h 의 SK1 = 22,376px). **팔레트의 피부 슬롯은 피부 탐지기가 아니다.**

지난 회차에 제가 쓴 문장이 그대로 걸렸다 — *"척도가 다른 곳으로 옮긴 숫자는 문턱이 아니라 남의 문턱이다."* 팔레트의 피부 슬롯은 **인물을 그릴 때 쓰라고 둔 칸**이고, 그것을 **인물이 있는지 판정하는 도구**로 읽으면 방향이 뒤집힌다. 세우고 나서 발견하지 않고 세우기 전에 재서 버린 것이 이번의 차이다.

§9-⑦ 는 **닫히지 않았다.** 인물 0 의 방어는 여전히 3겹(스타일·긍정 표현·육안)이고, 본 건의 육안 몫은 주력 vn3 재캡처다. 지침 §9-⑦ 에 반증표째 등재했다.

## 6. [정정] "CG = 장소·사물, 인물은 스탠딩" 은 문면이 없다 — 그리고 cg06 은 인물이 있다

발주 배경의 전제를 대조했다. **규약으로 쓰인 문장을 찾지 못했다** — `docs/design/` 전량·`docs/assets/` 전량 grep 0. D10 §7 은 장면 이름만 두고 구도를 구속하지 않는다(그래서 본 집행이 정본 충돌을 만들지 않는다 — 불변규칙 9 무해).

그리고 **형제가 인물 0 인 것도 아니다.** 사양서 문면과 실물이 둘 다 반대다:

| CG | 사양서 문면 | 실물 (전량 눈 대조) |
|---|---|---|
| cg01 | *관중의 바다* | **관중 다수** · 얼굴 0 |
| cg02 | *마주 선 두 레이서* | 인물 0 (머신 2대) — 문면과 실물이 갈린 자리다 |
| cg03 | *차폭 하나의 병주* | 인물 0 (빈 그랜드스탠드) |
| cg04 | *어두운 폐기 창고* | 인물 0 |
| **cg06** | ***껴안는 팀·드라이버*** | **군중 수백 (실루엣)** · 얼굴 0 |

5장 중 2장이 인물을 담고 있다. 그러나 **5장 전부 얼굴이 0** 이다. 즉 형제가 지키고 있던 것은 *"인물을 그리지 않는다"* 가 아니라 **"얼굴을 그리지 않는다"** 다 — 실루엣·헬멧·거리로 처리한다(A-CG-02 *'맨얼굴 금지'* 가 그 명문이고, IMPL-416 ②가 *"주인공은 6장 전부 얼굴이 없다"* 로 이미 이 축을 잡았다). **cg05 만 유일하게 스탠딩을 가진 네임드를 맨얼굴 초상으로 담았다.**

**집행에는 영향이 없다.** 판정 문면이 *초상* 제거이고 총괄 배정이 *인물 0* 이라 저는 **더 엄한 쪽(인물 0)** 으로 집행했고, 그것은 두 문면을 다 만족한다. 정정하는 이유는 **다음 회차의 추론을 위해서**다 — 전제를 그대로 두면 *"cg05 에 실루엣 인물을 넣는 것도 규약 위반"* 이라는 잘못된 귀결이 나오고, 실제로는 형제 규약이 허용하는 처분이다. 총괄 479 판독문의 *"cg04·cg06 은 인물이 없어"* 도 같은 정정 대상이다(판독 결론 자체는 유효 — cg06 은 얼굴이 없으므로 스탠딩과 충돌하지 않는다).

## 7. 눈의 몫 — 주력 vn3 재캡처에서 볼 것

1. **스탠딩과 의자의 겹침.** 의자 둘이 640 기준 x≈200–260 · 400–460 에 있고 `StandingLeft`/`StandingRight` 는 양 끝이다. *"의자 옆에 선 두 사람"* 으로 읽히면 의도대로고, *"의자를 밟고 선"* 으로 읽히면 좌표를 좁힌다(에셋 몫).
2. **얼굴 개수 = 2.** 4 → 2 가 본 건의 판정 성립 조건이다.
3. **해빙 차분이 그 장면에서 열리는가** — '풀린 표정'을 이제 차분만 진다(판정 ①과 본 건이 여기서 만난다).
4. **같은 방으로 읽히는가.** 바탕 `garage_h`(주광·문 닫힘) 대 컷인(야간·문 열림·작업등 1개) — *"같은 개러지의 다른 시각"* 으로 읽어야 한다. 갈라져 보이면 어법 조정이 에셋 몫이다.
