## 1. 작업 ① — RACE-01 원시 키코드 직독 → 액션 경유 전환 (우선)

`race_screen.gd` `_unhandled_key_input`의 `KEY_ESCAPE`(현행 258행) → `pause_menu` 액션, `KEY_SPACE/ENTER/KP_ENTER`(264행) → `ui_accept` 액션 청취로 전환.

- **D09 §1.2 "패드 풀 지원 — 전 기능" 직결** — 현재 레이스 주 행동(스핀·확정)과 일시정지가 패드에 무반응이다. 5차 발견 그대로.
- 키보드 거동 무변경이 계약이다 — 액션에 키보드 열이 이미 담겨 있으므로(IMPL-186) 전환은 동작 집합을 보존·확장한다. 회귀: 액션 경유로 스핀 커밋·일시정지 열림 단언 + 키보드 경로 보존.
- 주석의 "결과를 불러온다 → 결과를 받아들인다 같은 물리 동작 순환" 설계 의도를 보존하라 — 바뀌는 것은 입력 판독 층뿐이다.
