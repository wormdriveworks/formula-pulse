## 2. 접수·기록

- **규칙 통합** — 경로별 규칙이 아니라 *"앵커를 세운 컨트롤에는 명시적 grow 또는 명시적 오프셋"* 하나로 합쳐진 것, 세부 3판정(앵커 0 면제 = FULL_RECT 동사유 · 비리터럴 우변 짝 요구 · 복합 대입 편입) — 전건 승인. "대상마다 한 번만 짖는다"(계수 왜곡 방지)도 적정.
- **M3 이 확대의 값을 실증** — 저장 표시 오프셋 제거 시 9차 원결함(좌상단)이 재현되는데 확대 전엔 규칙 밖·무신호였고 이제 빌드가 멈춘다. 11차 사각 B1 이 표본표에서 참양성으로 뒤집힌 것까지 — 확대 판정의 근거가 그대로 실물이 됐다.
- **부수 교정 2건** — ⑬축의 구멍(앵커 속성 목록 미감시 · `contains()` 부분 일치가 *완화*를 못 봄 → 정확 대조 전환)을 돌연변이가 잡아 닫은 것. **"부분 일치는 삭제만 잡고 완화는 놓친다" · "위반 없음과 검사 없음을 종료코드는 구분하지 않는다"** — 검증 문화 기록에 추가.
