## 2. 결선 6축 (원격 몫 — 코드 전속·씬 무접촉)

1. **버스 3계 구성** — Master / BGM / SFX (D12 §10.1 · 앰비언스 = SFX 버스 귀속). 구성 방식(`default_bus_layout.tres` vs 런타임 `AudioServer` 구성)은 구현 재량 — 근거 명기.
2. **재생기 구현** — `AudioOutput` 계약의 실물(`godot/ui/audio/` — 표현 층). ⓐSFX 풀: `AudioStreamPlayer` 풀·**가상 채널 상한 12**(D13 창구)·`cull_sfx` 즉시 정지 ⓑBGM: 트랙 교체 **크로스페이드 0.8초**(D13 창구)·**A/B 레이어 = 동시 재생 + B 볼륨 온오프**(D11 §4.4 — 동일 길이·박 동기 전제, 트랙 교체 아님) ⓒ징글: 재생 중 **BGM 덕킹**(값 D13 별첨A §8.3) ⓓ`duck_bgm` 반환 시간 포함. **수치 전량 D13 창구(core_params) — 코드 무기입.**
3. **주입 지점** — 현행 `silent_audio_output.gd` 주입부를 실물 재생기로 교체(디스패처·호출부 무접촉 — 계약의 존재 이유). 무음 폴백은 보존(플랫폼·테스트 경로).
4. **볼륨 옵션 결선** — O13(마스터)/O14(BGM)/O15(SFX) → 버스 볼륨(`options_store` 기존 저장 소비). 옵션 화면 슬라이더 거동은 기결선 — 값이 버스에 닿는 한 겹만.
5. **일시정지 규칙** — **BGM 유지 · SFX 뮤트**(D11 §4.3 확정 — 레트로 관례). 일시정지 층 결선.
6. **BGM·징글 실물 부재 처리** — 스트림 조회 실패 = **무음 유지 + 1회 관측 로그**(예정 상태이므로 오류 아님·조용한 무한 재시도 금지). 실물 유입 시 코드 무변경으로 활성되는 구조.

## 3. 검증 — 헤드리스에서 검증 가능한 축 전부

- 헤드리스 = 더미 오디오 드라이버라 **소리 없이 상태 검증이 성립**한다: 버스 실재·볼륨 dB 반영·스트림 적재(68식 로드)·풀 상한·컬링 거동·크로스페이드 트윈 상태·덕킹 값·일시정지 뮤트 상태.
- **되읽기 원칙**: `AudioServer` 상태를 되읽어 단언 — 설정 호출의 성공이 증거가 아니다.
- 돌연변이(풀 상한 완화·크로스페이드 값 하드코딩·일시정지 SFX 방류·O15 미반영 등) + 게이트 전량.
- **주력 후속 예약** — 실기 청감(레이스 1GP: 릴·개입·타이머·결과·UI 실발화, 볼륨 슬라이더 체감, 일시정지 거동)은 눈·귀 소관으로 주력 11차 묶음에 편입.
