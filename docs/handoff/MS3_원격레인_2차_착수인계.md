## 1. 착수 6건 (권장 순서)

### ① 오버홀 순위 0 절상 — 총괄 판정 집행 (IMPL-141 ①)

**판정: 순위 밖 = 최하위 등급 (주력 발신 권고 ① 채택).** 근거 = D06 §5.3 G-M1 구속("성적 무관 최소 1슬롯 보장" + "시즌 완주 = 오버홀 발생 예외 없음") — 빈 추첨도, SET-02의 1 절상(최상위 대우)도 정본 위반이다.

**집행 규격:**

| 지점 | 처리 |
|---|---|
| `season_state.gd` `close_season()` (`order.find(PLAYER_ID) + 1`) | find 실패 시 **최하위 순위로 절상 — 절상은 이 단일 지점에서만** |
| `season_result_screen.gd:86` `maxi(player_position, 1)` | **제거** — 받은 값 그대로 전달 (표시값은 판정값에서 파생 — IMPL-100·124·134 동일 원칙) |
| `record_season_result()` best rank | 별도 조치 불요 — 원천 절상이 0 오염(0 < 어떤 순위)을 동시에 닫는다. **회귀 검사만 추가** |
| `test_tc_o.gd` 경계 검사 `overhaul_slots(0).is_empty()` | 새 규격으로 갱신 — "순위 밖 입력 → 최하위 등급(1슬롯·2후보)" |

**제약: 절상값 16 하드코딩 금지** (불변규칙 2). 구조값에서 파생하라 — 엔트런트 수(그리드 규모) 또는 오버홀 테이블의 `rank_max` 최댓값. 어느 쪽이든 출처를 주석으로 남길 것.

### ② 오디오 디스패처 결선 (D12 §10 `sound_map`) — **현 최대 병목**

사운드 실물이 유입돼도 재생 주체가 없는 상태다. 에셋 트랙 병목이 해소된 지금, 전 트랙 통틀어 이것이 남은 최대 병목이다.

- 범위: `sound_map` 데이터 테이블 로드 + 이벤트 → SFX/BGM 디스패치 경로 + 실물 부재 시 무음 폴백(플레이스홀더 경로 성립).
- 정본: 구조 = **D12 §10** / 이벤트 결속·층위 = **D11** (SFX 68식 · 이벤트 결속 원칙 §1.4).
- **불변규칙 5 주의:** 릴 정지 연출 완료 전 결과 상관 사운드 금지 — D11 §1.3 봉인 사운드 규정. **SEAL 계열 검사에 오디오 경로를 편입**하라. 주력 2차에서 SEAL-E가 튜토리얼 콜아웃(신규 화면 요소)의 봉인 위반을 실제로 잡았다 — 오디오는 같은 축의 다음 후보다.
- 하드코딩 금지: 이벤트→사운드 매핑은 전량 데이터(D12 §4).

### ③ `ui_palette.gd` [가안] 21건 종결 — **이중 효과 항목**

- 정본 = `docs/assets/팔레트_정본_v1_0.md` **§9.2 매핑표** 그대로. **기계 전사 권장** — 56행 hex를 손으로 옮기면 반드시 어긋난다(에셋 트랙 전례).
- **이중 효과:** 이 결선이 끝나면 기능 13색 전건에 두 번째 출처가 생겨 **에셋 트랙 스와치 생성기의 교차 검증 커버리지가 4/13 → 13/13**이 된다(대장 §9-⑬ — 트리거가 이 작업에 걸려 있다). **완료 시 커밋 메시지에 §9-⑬ 트리거 도달을 명기**해 에셋 트랙이 생성기 대조를 추가할 수 있게 하라.
- 완료 후 주력이 실화면 시각 확인을 1회 한다 (값 검증은 기계·눈 검증은 주력).

### ④ Steam 어댑터 널 배선 — SYS-04 동기 표기 지원 (IMPL-128 ③)

화면이 어댑터를 직접 물면 혼입 0(불변규칙 1) 저촉 — **널 구현 배선 + '미연동' 표기**까지가 현 단계 몫이다. 실 SDK 연동은 MS-3 스토어 준비물·G-7 트랙.

### ⑤ `tl5_runner.gd.uid` 커밋 (IMPL-118 잔여) + 하네스 quit 가드

- `.uid`는 **원격 자기 로컬본으로** 커밋 (기존 판정 그대로).
- **동반 교정:** 러너가 `_initialize()` 런타임 오류 시 `_process` 무한 대기에 빠진다 — 주력 실측 3.6시간 상주 (주력 2차 발신 §4 부기). **초기화 실패 시 `quit()` 탈출을 결선**하라. `_current == null`을 정상 상태로 두지 말 것.

### ⑥ V-계열 확장 — 코드 생성 Control 폰트 정적 검사 (v2.35 ⑧ 지시분 — 상태 확인 후)

기착수·완료면 건너뛴다. 미착수면: 코드에서 생성되는 Control의 폰트 오버라이드 누락을 잡는 정적 검사 — "눈으로 훑으면 또 샌다"가 지시 취지다. V7 전례대로 **차단형/경고형 성격을 스스로 정하지 말고** 신설 시 총괄에 성격 판정을 발신하라.
