## 1. 본몫 ① 스킬 슬롯 UI — 결선 완료

### 1.1 계약 준수 — 화면은 창구 하나만 읽는다

`engine.skill_slots()` **하나**로 슬롯이 그려진다. `data.skills`·`outgame.deck` 무접촉이고 가용 판정을 재구현하지 않는다.

이 계약이 **검사로 못박혀 있다**: 툴팁의 스킬명이 `skills.csv` 의 `name_key` 를 거친 문면과 일치하는지 본다. 화면이 이름을 자기 리터럴로 갖는 순간 축이 깨진다 — 돌연변이 M1 이 `tooltip=S1 ◆2 expected=풀 스로틀` 로 잡았다.

### 1.2 라벨 = `S{n}` + 비용 ◆n — **추정이 아니라 재서 정했다**

별첨A §A-6 배치도 자체가 `[리스핀R][S1~S5][차지C]` 로 슬롯을 번호로 적는다. 그리고 실측이 그 선택을 강제한다.

| 구성 | 최소폭 | 예산 371.6px 대비 |
|---|---|---|
| `S{n}` 5슬롯 만재 | **339.0px** | 여유 32.6 — **성립** |
| 스킬명 라벨 5슬롯 | **427.0px** | **55.4 초과** |

예산은 **씬이 선언한 값에서 끌어냈다** — 캔버스 640 − Middle 분리 4 → LeftColumn 신축 비율 6/(6+4) → ReelZone 여백 10. 상수를 박제하지 않았으므로 비율이 바뀌거나 열에 컨트롤이 늘면 이 축이 함께 움직인다. **대조군(스킬명 라벨은 예산을 넘는다)까지 검사에 넣어** 판단 근거를 코드에 남겼다.

이름·효과는 툴팁이 진다(툴팁 고정 = `detail_info` T·Y).

### 1.3 세 입력 경로를 **한 자리에서** 못박았다

클릭(`pressed`) · F1~F5(`_unhandled_key_input`) · 패드 RB 조합이 **같은 `_on_skill_slot(i)`** 를 탄다. 12차에 마우스만 죽어 있던 결함(IMPL-301)이 슬롯에서 재발하지 않게 구조로 막았다.

- **`CLICK_EXEMPT` 를 비웠다** — 종전 사유("소비부가 없는 이월 트랙")가 해소됐고, **사유가 사라진 면제를 남겨 두면 그 화면이 다시 빠져도 검사가 통과한다.** 상수는 남겼다(다음 면제의 자리 + 넓히려면 이 줄을 함께 고쳐야 한다는 규율의 표지).
- 이제 UISCR ⑳ 가 5슬롯을 **면제 없이** 본다 — 돌연변이 M2 가 `부재 5건: RACE-01/Skill1~5(pressed)` 로 잡는다.
- F 경로는 **별도 다리**로 본다 — M3 검출.

**패드 커서는 포커스로 보인다.** 스킬 버튼에 `grab_focus()` 를 걸어 기존 포커스 링이 선택을 말하게 했다(릴 커서가 프레임 색으로 말하는 것과 같은 축 — 새 시각 어휘 0). RB 뗌에서 포커스를 확정으로 되돌린다: 남겨 두면 **다음 A 가 조합 없이 스킬을 쏜다.**

종전 주석의 *"활성화 경로가 아직 없다"* 는 해소했고, 가로채기가 필요했던 이유(RB 홀드 중의 A 가 스핀으로 오발화)는 그대로이므로 소비 처리는 유지했다.

### 1.4 인자 — 홀드 선택을 그대로 읽는다

이 화면의 릴 지정 어포던스는 E05 클릭·E06 토글·패드 커서 **하나뿐**이다(별첨A §A-6 "클릭 = 홀드 토글"). 스킬용 선택 어휘를 새로 만들면 같은 릴에 두 선택 상태가 생긴다.

| 계열 | args |
|---|---|
| `hold` (SH1·SH2·SH3) | `{"keep": 선택 릴}` |
| `convert` (SC1·SC2·SC4) | `{"target": 선택 릴}` |
| `convert` (SC3) | `{"target", "donor"}` |
| `amplify`·`insure` | 없음 |

### 1.5 거부는 문면이 아니라 소리로 답한다

계약의 `error` 15종은 UI 문면 분기용이지만 **`strings.csv` 가 내러티브 배타 창구**라 만들 수 없다. `sfx("input_rejected")` + 상태 무변경으로 처리했다(기본 개입 3종 전례). 필요한 키는 §5 에 올린다.

## 2. 본몫 ② SH3 신구 병치 — 배치와 조작으로 가른다

살아 있는 릴이 **새 후보**이고 그 위에 뜨는 줄이 **이전 후보**다. **줄을 누르면 되돌아가고 확정하면 새 후보로 간다** — 새 문면 0으로 성립시켰다(줄의 정체는 툴팁 `ui.skill.sh3`).

**확정이 택1만 해소하고 턴을 넘기지 않는 것이 규칙이다.** 한 입력이 두 결정(택1 + 확정)을 겸하면 되돌릴 기회가 사라져 병치의 의미가 없어진다. 돌연변이 M4 가 `before=3 after=0`(국면이 넘어감) + `provisional=[]` 로 잡는다.

씬 노드 5개 신설(`E05Snapshot` Button + `SnapshotRow` + 도상 3기 · 초기 `visible=false` · 색 리터럴 0 — 기본 테마 사용).

**[보고] 문면 2건이 있으면 더 분명하다.** 새/이전 라벨이 없어 정체를 배치와 툴팁이 진다. 키 이름을 §5 에 올리되 **만들지 않았다** — 미등재 키를 참조하면 `StringTable.text()` 가 키 문자열을 그대로 돌려주어 **화면에 `ui.race.…` 가 뜬다**(검증기는 이 방향을 보지 않는다).

## 4. 검증

**돌연변이 4종 주입 → 4종 검출**

| # | 주입 | 검출 |
|---|---|---|
| M1 | 툴팁이 엔진 행을 거치지 않게 | `tooltip=S1 ◆2 expected=풀 스로틀` |
| M2 | 스킬 버튼 `pressed` 결선 제거 | `부재 5건: RACE-01/Skill1~5` + 클릭 다리 `spent=0 cost=2` |
| M3 | F1~F5 경로 제거 | `키보드 F1 — spent=0 cost=2` |
| M4 | 확정의 택1 가로채기 제거 | `before=3 after=0` · `provisional=[]` |

**자수 — M4 는 처음엔 검출되지 않았다.** 두 번의 교정이 필요했다.

1. 개입 창을 닫은 상태로 세워 두어 가로채기를 지워도 `_on_primary_action` 이 아무 갈래도 타지 않았다 → **"턴을 넘기지 않는다"가 공허하게 통과**했다. 창을 열어 대조가 성립하게 고쳤다.
2. 그러자 이번엔 `provisional[0]` 무가드 접근이 **호출 프레임을 통째로 중단**시켜(GDScript 기제) 검사 3개가 실행되지 않았고, 스위트는 **검사 수만 줄어든 채 PASS** 했다(IMPL-309 ⑥ 이 경고한 그 형태). 크기 가드를 넣어 조용한 축소를 **큰 소리의 FAIL** 로 바꿨다.

**실기 (신규 커리어 RACE-01)** — 5슬롯 잠금 표기 · 액션 열 미초과(확정 최우측 유지) · 스냅샷 줄 숨김 · 오류 0. 덱 적재 상태의 렌더는 기계 축(㉑ 4돌연변이 + 폭 실측)이 진다 — 덱을 실기로 채우려면 해금(DP 30↑)→장착→투어 경계가 필요해 회차 비용이 GP 4개다.

## 5. 필요한 `strings.csv` 키 (내러티브 창구 — 만들지 않음)

## 6. 관측·판정 요청

### 6.1 **[중대] 기계 게이트가 플레이어 세이브를 지운다 — 실피해 발생**

`tests/test_tc_p.gd:_clean_profiles()` 가 **프로필 −2~11 을 전부 삭제**한다(`param_save_profile_count`=3 이므로 실 슬롯 1·2·3 전건 포함). 다른 스위트도 `begin_career(1)`·`begin_career(2)` 로 **실 프로필에 쓴다**(`test_narrative`·`test_audio_wiring`·UISCR `_fresh_session`·`capture_hub_shots`).

**실피해:** 이번 회차 게이트 실행으로 **사용자 슬롯 2 커리어가 덮여 없어졌다**(credits 137 → 0). 회차 시작 시 떠 둔 백업으로 **복원 완료**(현재 credits 137 확인). 12차의 내 시험 커리어(슬롯 1)도 같은 경로로 소멸했다 — 그때는 원인을 몰랐다.

CI(신선한 컨테이너)에서는 무해하지만 **실기 검증을 하는 주력 머신에서는 게이트가 실기의 전제를 파괴한다.** 12차에서 "1GP 완주 뒤 실기"가 유난히 비쌌던 이유의 일부가 이것이다.

**부분 교정을 하지 않았다.** UISCR 쪽만 막으면 TC-P 가 여전히 지우는데 "처리됨"이라는 오해를 만든다. 제안 = **`SaveManager` 에 저장 루트 재지정 훅**(테스트는 `user://test_profiles/`)이며 이는 `core/save` 소관이라 원격 레인 발주 사안으로 올린다.
