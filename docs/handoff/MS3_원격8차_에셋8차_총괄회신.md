## 2. 원격 8차 — 접수·기록

- **4지점(지시 3 + `:693`)** — `defendFail01` 은 주력 조사와 총괄 검수가 **양쪽 다 놓친 지점**이다. 문면 6종 전수 대조로 잡은 것, 그리고 3줄 손 수정 대신 **`_entrant_params` 창구로 5지점 전량을 경유**시켜 "짝이 손 규약이 아니라 구조가 되게" 한 것 — 지시보다 나은 집행으로 기록.
- **M3 — 은닉 의존 제거**: 표기 층 선해결이 사전 삽입 순서의 우연으로 가려져 있던 것을, 검사를 고치는 대신 **의존 자체를 제거**(순서 역전으로 선해결을 유일 경로화)해 드러냈다. "우연히 맞아 돌아가는 상태"를 없앤 것 — 기록.
- **PAL flip 보류 = 정확한 이행.** 승인 문면의 "0 미달 시 자동 무효"를 실측(`warnings=3`)으로 확인하고 멈췄다 — 성립하지 않은 차단형을 넣지 않는 것도 불변규칙 7의 준수다. **조건부 승인은 유효하게 살아 있다** — 주력 치환 후 재실측이 트리거.

## 3. 에셋 8차 — 판정·추인 3건

### ① `RewardValue` A2 → N16 정정 = **추인**

**총괄 원판정(IMPL-209 §2-1)의 전제가 틀렸다** — "값 텍스트 = 크레딧 의미 동일"은 `CreditsValue`(크레딧 전속)에만 성립하고, `RewardValue`는 credit/dp/chassis 3종이 지나는 자리다. A2 고정이면 dp 보상이 크레딧 앰버로 찍혀 옆의 시안 카트리지 아이콘과 어긋난다 — 원칙 ③이 정확히 걸린다. **타입 신호는 아이콘이 지고(D10 §5.2 실루엣 1차) 값 텍스트는 중립(N16)** — 논거 채택. hex 동일 → 역할 동일로 건너뛴 세 번째 사례를 자기 적발·정정한 것도 기록.

### ② `speaker_filler_16` 시점 변경 · ③ `achv_garage_16` 요소 삭감 = **추인 2건**

축약 규격(§6.8.2 실루엣 연속)을 어긴 사실의 공시와 함께 온 위반이라 판정이 성립한다 — ⓐ는 **판별을 위한 위반**(16px 측면 헬멧 = `achv_rival_16`과 실루엣 언어 충돌), ⓑ는 IMPL-165 실증 패턴("두 요소가 서로를 먹는다")의 재적용. 둘 다 추인 — **최종은 주력 결선 후 눈이 진다**(§4-⑤).
