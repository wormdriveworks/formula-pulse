## 1. ① 무커리어 널 역참조 (차단급)

**구현 방식 — 창구 2개로 닫았다.** 호출부마다 널 검사를 흩뿌리는 대신 `_achieved()` · `_progress_for()` 두 조달 창구만 두었다. 근거: `outgame` 은 `begin_career()` 에서만 생기므로 **커리어 미개시가 정상 상태**이고 널은 예외가 아니다. 창구가 하나면 새 소비부가 생겨도 같은 자리를 지나므로, 가드를 "기억해서 붙이는" 구조가 되지 않는다.

**한 가지 함정을 피했다.** `_progress_for()` 는 무커리어에서도 `threshold` 를 데이터에서 그대로 읽는다. 0 으로 뭉개면 "임계 2 이상만 진척 표기" 분기가 **무커리어에서만 다르게 갈려** 커리어 유무로 목록의 모양이 바뀐다.

**[가안] 무커리어 = 달성 0 표시 — 이월 등재 완료.** 통산 업적 적재 층(플랫폼 도전과제 역방향 조회 · D12 §7.4 Steam 연동 결선 시 확정) 전까지의 잠정 표시 규칙이다. 그 층이 서면 커리어 없이도 "이 계정이 통산 달성한 것"을 보일 수 있고, 그때 이 규칙은 교체된다.

**회귀 축 (UISCR):**

| # | 검사 | 잡는 것 |
|---|---|---|
| 1 | 전제 — 무커리어 세션은 `outgame` 을 갖지 않는다 | **전제 성립 확인.** 이게 깨지면 아래 5축이 조용히 무의미해진다 |
| 2 | 헤더 문면 세팅 | `_on_bound()` 초입 중단 |
| 3 | 요약 문면 세팅 | `_refresh_summary()` 중단 (구 결함 지점) |
| 4 | 탭 5개 생성 | `_build_tabs()` 중단 |
| 5 | **업적 행 전수 생성 (39)** | `_build_row()` 중단 — 무커리어라고 목록이 줄어도 잡힌다 |
| 6 | 무커리어 달성 표시 0 | [가안] 규칙 자체의 고정 |
| + | **커리어 적재 시 거동 무변경** (행 전수 + 달성 1건 반영) | 가드를 넣느라 정상 경로가 상하는 **반대 결함** |

## 2. ② 패드 순회 — 집행분과 **잔여 보고**

### 집행분

| 대상 | 초기 포커스 | 근거 |
|---|---|---|
| SYS-03 옵션 | **첫 탭 첫 항목** | §A-3 명시. 라벨은 포커스를 안 받으므로 "첫 항목"의 실물은 단계 감소 버튼이다 |
| SYS-04 업적 | **첫 탭 버튼** `[가안]` | §A-4 는 초기 포커스를 명시하지 않는다 → 본문 §1.3 89행 일반 규칙 적용. 닫기를 첫 포커스로 두면 "열자마자 나가기"가 되므로 탭을 잡았다. §A-4 에 명시가 서면 그쪽을 따른다 |

두 화면에 `ui_cancel` → 닫기(`_unhandled_input`) 결선.

### 입력맵 — **[가안] 불요였다**

인계 §2 는 "정본에 규정돼 있으면 그대로, 침묵이면 [가안]"이었다. **규정돼 있었다** — D09 §1.3 **공통 층 매핑표**가 `취소 / 뒤로 = Esc / 우클릭 | **B**` 로 명시한다. 따라서 [가안] 없이 정본대로 넣었다.

- 실측: 엔진 기본 `ui_cancel` = **Escape 단독** (패드 바인딩 부재)
- 조치: `project.godot [input]` 에 Joypad Button 1 추가
- 재실측: `Escape` + `Joypad Button 1 (Right Action, Xbox B)` ✅

### ⚠ 잔여 보고 — **패드 순회는 이번 커밋으로 완결되지 않는다**

인계는 "`ui/sys/` 밖 화면들도 같은 축이 의심되면 전수 grep 하여 **보고만**"이라 했다. 화면을 훑기 전에 **입력맵 자체**를 실측했고, 같은 매핑표의 나머지 행이 통째로 비어 있었다:

| D09 §1.3 공통 층 매핑표 행 | 패드 | 현행 |
|---|---|---|
| 확인 / 선택 | A | **바인딩 부재** |
| 취소 / 뒤로 | B | ✅ 본 커밋에서 결선 |
| 포커스 이동 | D패드·좌스틱 | **바인딩 부재** (`ui_up/down/left/right` 4행) |
| 탭 전환 | LB·RB | 액션 자체 부재 |
| 일시정지 메뉴 | Start | 액션 자체 부재 |
| 상세 정보 | Y | 액션 자체 부재 |

**즉 현재 상태는 "포커스는 서지만 패드로 움직일 수도 누를 수도 없다"** 다. 화면별 `grab_focus` 는 필요조건이었지 충분조건이 아니었다. 이번 몫이 SYS-03·04 로 한정돼 있어 입력맵 전체는 손대지 않았다 — **배정 요청**한다. (D09 §6.4 ④조작 리매핑 탭이 주력 트랙에 있어 소유 충돌 여지가 있으니 배정 시 그쪽과 함께 보는 편이 안전하다.)

## 3. ③ 단독 경로 O9 — 검사 배치를 옮긴 이유

`_boot()` 에 `UiPalette.apply_options(session.options)` 결선. 인계는 검사를 `test_ui_options.gd` 에 두라 했으나 **UISCR 로 옮겼다.** 이유는 그쪽에서 검사가 **거짓 통과**하기 때문이다:

- UIOPT 는 `_init()` 동기 실행이라 `root` 가 없어 실화면을 세울 수 없다.
- 스크립트만 `new()` 해 `_boot()` 을 부르면 `@onready` 노드가 Nil 이라 `_e04_timer_ring.configure(...)` 에서 **함수가 중간에 끊긴다**. `apply_options` 는 그 앞줄이라 단언은 통과하지만, 통과의 근거가 "중단 지점이 우연히 뒤에 있었다"가 된다.
- UISCR 은 첫 프레임에서 돌므로 **실제 씬을 세워** 같은 축을 본다.

UIOPT §117 사각 주석은 그 이관을 명기하도록 갱신했다.

## 4. ④ `log_feed` 초기값 — 방식 선택과 **검사 사각 1건**

`var _font_size := 8` 제거. **D13 값으로 초기화하는 대신 미구성 상태를 명시적 차단**으로 갔다 — D13 값을 넣으면 `configure()` 미호출이 여전히 "그럴듯하게" 그려져 결함이 숨는다. 센티넬(`UNCONFIGURED = -1`) + 소비 지점 보고로 미구성을 **오류 상태**로 만들었다.

> **FONT-B 사정거리 밖임을 확인하고 검사를 별도로 세웠다.** FONT-B 는 `add_theme_font_size_override` 의 **리터럴 인자**를 보는데, 여기서는 멤버 변수를 넘긴다 — 즉 리터럴 8 이 되돌아와도 FONT 는 못 잡는다. UISCR 3검사로 덮었다(센티넬 보유 / 센티넬이 렌더 가능 범위 밖 / 구성 후 D13 값 보유). 두 번째 축은 "센티넬을 8 로 둔갑시키는" 우회를 막는다.

**부수 실측 1건:** 최초 구현의 `push_error` 문면을 한글로 썼더니 **V4 가 즉시 차단**했다(`hangul literal`). 영문으로 교체. 검증기가 자기 일을 한 사례라 그대로 기록한다.

## 5. ⑤ PAL 검사 — 신설 + **현행 위반 계수 보고**

### 구성

| 축 | 내용 |
|---|---|
| 대장 | 마스터 56(`master_56.gpl`) + 정본 §6 대체 4색(`colorblind_alt.gpl` CB 행) + **기능색 부속(`ui_palette.gd` 전사분)** + 명시 허용 목록 |
| 기능색 출처 | `.gpl` 실물이 없어 `ui_palette.gd` 를 썼다 — IMPL-144·167 로 정본 대조가 선 **유일한 기계 출처**. 그래서 그 파일 자신은 스캔 면제(UIOPT `ROUTE_EXEMPT` 와 같은 성격) |
| 대상 | `godot/ui/` 의 `.gd` + **`.tscn`** |
| 8bit 환산 | **채널당 ±1 허용** (`0.9×255=229.5` 경계 — 인계 §5 지적분). 마스터 인접 색은 그보다 훨씬 멀어 허용이 다른 색을 삼키지 않는다 |
| 허용 목록 | **비운 채 신설.** 무엇을 허용할지는 정리 작업의 판단이고 검사 신설이 대신 정할 사안이 아니다. 항목마다 `reason` 필수이며 없으면 그 자체가 경고 |
| 성격 | **경고형** — 차단형 전환은 별도 판정 (FONT IMPL-147 → 148 절차 그대로). **V7 무접촉** |

전량이 경고로 나오면 "대장을 못 읽은 것"과 구분되지 않으므로 먼저 그것부터 배제했다:

| 주입한 색 | 결과 |
|---|---|
| 기능색 hex `Color("#3FE0F5")` | **경고 없음** — 부속 13색 적재 확인 |

| `Color(0.9, 0.92, 0.95)` (구 `TEXT_PRIMARY`) | 경고 — 대장 밖이 맞다 |
| `Color("#123456")` (임의색) | 경고 — 음성 대조 |

> **규모 산정 참고 — 정리의 성격이 두 갈래다.**
> **(가) 대체 가능 5종 150건** = 구 팔레트 값이므로 신값으로의 기계 치환이 성립한다(색별 일괄).
