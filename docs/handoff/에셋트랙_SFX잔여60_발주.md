## 2. 규격 — 확정분 전건 승계

- **포맷**: WAV/PCM 44.1kHz 16bit 모노 · `compress/mode=0`(PCM 무압축) = **68식 전량 규격 확정분**(IMPL-246 판정 ①) · `.import` 동반 · LFS.
- **⚠ 루프 5식** = `se_t03`·`se_u15`·`amb_01`·`amb_04`·`amb_05` — **`edit/loop_mode=2`**(파일럿 함정 등재분 — 값 1은 조용히 Disabled). 전건 **런타임 되읽기로 FORWARD 확증**(`.import` 문면은 증거가 아니다).
- **⚠ AMB 5식 = 잡음 계열** — mulberry32 시드 보험이 **실작동하는 첫 구간**이다. 항목별 seed 고정 + `--check` 2회 생성 해시 동일 확증을 AMB에서 특히 명기할 것.
- **음량 기조**: 파일럿의 dBFS 폭(빈도 반비례 — 커서음 최소)이 귀 판정을 통과했으므로 그 기조를 잔여에 연장한다. U군은 `se_u01`(−12.5) 근방, 스팅·결판 계열(L·D)은 상단.

## 4. 오디오 항구 검사 신설 — **이번 회차가 그 회차다**

`sfx_import_probe.gd`는 파일럿 일회 프로브다(에셋 자기 명문). 전량 유입 개시 회차에 설계한다는 예약(IMPL-246)이 발동한다:

- **검사 축(안)**: ①대장 §5.1 68식 파일명 전수 실재 ②WAV 헤더 3항(PCM·44100·16bit) 전건 ③루프 6식 = 런타임 `loop_mode=FORWARD` 되읽기 ④`compress/mode=0` 전건 ⑤L군 길이 상한(0.8/1.5/2.5s) ⑥`sound_map.csv` `sfx_id` 참조 전건이 실물과 대조. — 축 구성은 에셋 재량으로 가감하되 **가감 근거 명기**.
- **성격**: 신설 + 오검출·위반 0 실측 보고까지. **차단/경고 성격은 총괄 판정 경유**(불변규칙 7 — 구현이 정하지 않는다). 실측이 깨끗하면 STRF 전례(즉시 차단)로 처리할 예정.
- 검사 거처 = `run_validators.gd` 편입(상시 게이트) — 프로브처럼 별도 스크립트로 두면 "위반 없음과 검사 없음"을 게이트가 구분하지 못한다.
