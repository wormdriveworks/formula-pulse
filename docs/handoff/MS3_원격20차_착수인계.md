## 본몫

1. **엔진 API** — 개입 창(T4)에서 장착 덱의 스킬 인스턴스를 투입하는 경로. 기존 개입 4타입 처리(홀드·차지 보험·듀얼 증폭)가 이미 서 있으므로 **스킬 = 그 타입들의 데이터 인스턴스 주입**이 구현의 실체다(신규 타입 신설 0 — Convert만 현재 엔진에 소비부가 없을 개연이 높다·확인 후 결선).
2. **소비 규칙** — `charge_cost` 차감·`uses_per_tour` 카운터(투어 경계 리셋)·잔여 0/자원 부족 시 투입 거부. 카운터·차감의 세이브 직렬화(재로드 리롤 무효 계열).
3. **RNG** — 스킬 효과가 난수를 쓰면 스트림 소속 확인 (D12 §6 — 개입 계열이 어느 스트림을 쓰는지 기존 관례 승계·신설 금지).
4. **검사** — TC-C 확장(타입별 효과 = 데이터 값 정합·투입 거부 경계·투어 리셋) + 돌연변이(비용 미차감·횟수 무한·봉인 창 효과 누설·듀얼 밖 증폭). **TL-5 §8.3 ③ Convert 행 재측정** — 스킬 인스턴스가 서면 "엔진 API 부재"가 해소되므로 매트릭스 잔여 1행을 이 회차에서 닫는다.
5. **세션 창구** — 주력이 13차에서 UI만 얹으면 발동하는 형태로(선택지 오버레이 `find_child()` 전례 — 이름·계약 명문 회신).
