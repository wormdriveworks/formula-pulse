## 1. 판정 A — 순위 0 = 최하위 등급. **정본이 이미 답해 뒀다**

코드 주장 3개소(`season_state.gd:367` 순위 0 산출 · `outgame_state.gd` 무절상 전달 · `season_result_screen.gd:86` 1 절상)는 전건 원문 실측으로 일치를 확인했다. 판정 근거는 D06 §5.3의 **G-M1 구속**이다:

> *"시즌 완주 시 성적 무관 **최소 1슬롯 보장**"* · *"시즌에 하드 실패가 없고 항상 5투어를 소화해 결산에 도달하므로, **'시즌 완주 = 오버홀 발생'이 예외 없이 성립**"*

즉 결산에 도달한 플레이어에게 **빈 추첨은 어떤 순위에서도 허용되지 않는다** — 현행 추첨 경로(0 → 빈 dict)는 G-M1 위반이고, SET-02의 1 절상(최상위 대우)은 같은 절의 성적 차등 취지("성적 차등은 선택의 폭") 위반이다. 현행 두 지점 다 옹호할 수 없으므로 ①이 유일한 귀결이다. ③(D13 행 신설)을 과하다고 본 판단도 옳다 — 값 신설 없이 닫힌다.

**집행 규격 (원격 이관분 — 참고):**

- 절상은 **`close_season()` 단일 지점**으로 통일한다. SET-02의 `maxi(pos, 1)`은 제거 — 두 지점 절상이 아예 사라지고, 이 레인이 세 번 쓴 원칙("표시값은 판정값에서 파생시키고 같은 것을 두 번 계산하지 않는다") 그대로다.
- **부수 소득:** `record_season_result()`의 `best_championship_rank`도 현행이면 0에 오염된다(0 < 어떤 순위) — 원천 절상이 이것까지 동시에 닫는다.
- 절상값 **16 하드코딩 금지**(불변규칙 2) — 엔트런트 수 등 구조값에서 파생.
- TC-O 경계 검사(`overhaul_slots(0).is_empty()`)를 새 규격으로 갱신.

현 상태를 검사로 못박아 둔 처리가 좋았다 — 판정이 어느 쪽이든 회귀 지점이 남지 않는다.

## 2. 판정 B — 후자 채택. 단 제약은 지금 구속으로 기록한다

**D04 §8.1 문면 확정 시 재편**을 채택한다 — 무엇을 가르칠지는 문면과 한 몸이고, 데이터 표라 코드 무변경으로 바뀐다는 논거 그대로다. 현행 5단은 [가안] 유지.

단 **"무비용 행동(스핀·확정)이 자원 소모 개입보다 앞선다"는 제약은 문면과 무관한 구조 발견**이므로 지금 구속으로 기록했다(마스터플랜 v2.37 ②) — T7 문면 재편 시 어떤 순서를 짜든 이 제약만은 불변이다. 초안이 실기에서 2단계 도달 불가로 적발된 사례가 근거 그 자체다.

**착수인계 누락 지적 = 정당.** `MS3_주력레인_착수인계.md` 머리말에 추기했다 — 착수 목록의 정확한 계수는 TUT-01 포함 7건.

## 4. TL-5 판단 B — 사용자 판정 = ① 명문화, **집행 완료**

사용자 승인(2026-08-16)으로 **D14 §8.5 실측 기입 blockquote에 부기했다** — 성분 분해(기계 강제 1.7 + 개입 창 ≤10 + 자율 ~9)는 측정값이므로 기입란 성격에 맞고, **판번 무증가**(기입란 충전 = D15 §1.1 실일자 전례)다. 핵심 문장은 이것이다:

> *"이후 회차에서 GP 길이가 대역 하한(10분)을 밑도는 것 자체는 이상 징후가 아니라 자율 페이스 단축이며, 회귀 판정은 기계 강제 성분(연출·개입 창)의 증감으로 본다."*

D13 §4.1 산식 주석은 **P-2 ㉙로 등재**했다(트리거 = D13 차기 개정). "값 조정 요청이 아니다"라는 선긋기가 정확했다 — 이 발신은 §8.4를 한 뼘도 침범하지 않았다.
