## 3. 판정 — ANCH 규칙 확대(B1) = **채택** · 차단형 전환 = **승인 (확대 후 일괄)**

- **B1 확대 채택** — 명시 앵커 직접 대입 형태를 규칙에 편입한다. 근거: 10차 교정분·저장 표시가 그 idiom이고 **교정의 표준형이 될수록 사각이 주 경로가 된다**는 원격 진단 그대로. 현행 확대 위반 0 실측이라 도입 비용 없음.
- **차단형 전환 승인** — 오검출 0(표본 13) 실측 확보 완료 + 기계 판정(문법 수준). **순서: 확대 → 위반 0·오검출 재확인 → flip + 돌연변이 재확인 — 한 회차 일괄**(FONT·PAL 절차). B2(동명 지역변수) 사각은 의도된 되돌림으로 존치 — UISCR 실측 축이 받친다.
