## 2. 작업 ② — FONT 검사 차단형 전환

**판정 원문 = `MS3_원격2차_총괄회신.md` §2** — FONT는 "폰트를 지정했는가"라는 문법 수준 기계 판정이라 V7(작법 판단) 경고형 사유가 적용되지 않는다. 성격상 V4 축 = **차단형**.

- `tools/validators/run_validators.gd` FONT 검사 2곳(현행 797·805행 부근)의 `_warn` → `_fail` 전환.
- **돌연변이 FONT 2건이 차단 경로로도 검출되는지 재확인** (판정 부대조건 — 경고 경로에서 검증했던 그 돌연변이 그대로).
- 전환 후 현행 코드베이스 재주행 — 직전 게이트가 `VALIDATORS_PASS warnings=0`(FONT 51검사 포함)이었으므로 **위반 0이 정상**이다. 새 위반이 잡히면 임의 수정하지 말고 중단·보고.
- **V7은 건드리지 않는다** — 여전히 경고 전용(불변규칙 7).

## 3. 작업 ③ — `finish_tour()` 동형 절상 + 회귀 검사 1축

**판정 원문 = `MS3_원격2차_총괄회신.md` §4-②** (총괄 추가 발견분).

- `season_state.gd`의 `finish_tour()`가 `order.find(PLAYER_ID) + 1` **무절상**이다(시즌 쪽만 교정됨). 소비처 `record_tour_result()`가 `position <= 1`로 투어 우승을 세므로, find 실패(0 도달) 시 **무순위가 투어 우승으로 계상**되는 역전.
- **시즌 쪽 교정과 같은 방식으로 통일**: find 실패 시 `_grid_size()` 절상.
- **회귀 검사 1축 추가** — 시즌 건 회귀 검사와 나란히.
