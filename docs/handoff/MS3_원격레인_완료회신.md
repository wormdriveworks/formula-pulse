## 0. 진행 순서 확인 (사용자 요청 사항)

**"원격 완료 → 총괄 판정 → 주력 진행" 순서는 안전하며, 오히려 재작업을 줄이는 순서다.** 근거:

| 확인 축 | 판정 |
|---|---|
| 판정 대기 항목이 **원격 잔여 작업**을 막는가 | **막지 않는다.** T9 TL-5 지표 12항에 업적·관계 축·이벤트 카테고리가 없고, 오버홀 추첨 스트림 판정이 바뀌어도 통계 결론은 유지된다(재실행만 필요·자동 배치라 저비용) |
| 판정 결과가 **주력 작업**에 영향을 주는가 | **준다.** SYS-04 업적 화면은 `achievements` 데이터에 직접 의존하므로 39종/35종 판정이 탭 구성을 바꾼다. RACE-01 E13 소모품 UI도 T2 [가안](듀얼 턴 제외 등)에 의존한다 → **판정을 주력 착수 전에 두는 것이 정확하다** |
| 묶어서 올리면 이득이 있는가 | **있다.** TL-5 판정 요청 3건(아래 §4)이 이번에 추가됐다. 개별 왕복 대신 1회로 처리된다 |

**유의점 1건:** 오버홀 추첨 스트림(reserve)이 다른 배정으로 판정되면 TL-5 수치가 달라진다. 결론(허용 범위 판정)은 통계적이라 무효화되지 않으나, 최종 기록은 재실행본으로 갱신하는 것이 정확하다.
