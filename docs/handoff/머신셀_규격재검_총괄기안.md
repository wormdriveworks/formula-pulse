# [총괄 기안 → 에셋] 머신 셀 치수 재검 — 사용자 판정 ⓒ 집행 (파일럿 → 최소 성립 치수 상향)

> 작성: 총괄 (remote-hq 세션) · 2026-08-23 · IMPL-323 · 근거 = IMPL-319 판정 (사용자: "ⓒ 규격 재검 — 셀 치수 상향 검토")
> **선결 확인 — 재검의 정본 지위는 가볍다:** 셀 치수(측면 96×48·추격 64×64)는 **D10이 아니라 사양서 v1.1의 확정 기준값**이며, 사양서 §3(162행)이 스스로 **"실기 조정 창구"**를 명문한다. D10 §4는 시점 2종·1원도+4프레임 구성만 규정하고 **픽셀 치수를 규정하지 않는다** (총괄 실독 2026-08-23). → **D10 개정 불요 · 사양서 개정(v1.3→v1.4)으로 성립하는 구현 층 사안.** IMPL-319의 "정본 사안이라 에셋 재량 밖" 분류는 절차상 옳았고(단독 확정 불가), 다만 무게는 설계 개정이 아니라 구현 기준값 조정이다.

## 1. 구속 조건 (재검이 지켜야 하는 것)

| 구속 | 원천 | 귀결 |
|---|---|---|
| 씬 패널 표시 = 384×100 (원도 408×100 크롭·1:1 합성) | 대장 §4.6 · E15 `custom_minimum_size 100` 실독 | **추격 셀 높이 ≤ 100 강제.** 측면도 100 초과 불가 |
| "배경 여유 확보" (96×48의 명문 근거) | 사양서 §3 | 상향할수록 씬 컷 구도가 차량 클로즈업으로 이동 — **192×96(높이 96/100)은 배경 여유 소멸**이라 성립 실증에도 불구하고 최후 후보 |
| 비정수·정수 불문 **생성 후 축소 금지** | IMPL-319 실측 (192×96→2:1 정수 축소 = 13번·바퀴 소멸) | **생성 치수 = 소비 치수** — 중간 치수는 직접 생성만 유효 |
| 오버레이 = 베이스와 동일 셀·동일 좌표계 | 대장 §4.5 | **RD는 치수와 무관하게 좌표 정합을 못 한다** (§9-㉙ ⓒ 원논점) — 오버레이 23장은 상향 후에도 RD 밖 |
| RD 하한 = 복잡도 대비 픽셀 수 | IMPL-319 일반화 | 64px 폭 기각·192px 폭 성립 — **사이 구간(128·160) 미측정** |

## 2. 경로 (기안)

**1단계 — RD 최소 성립 치수 파일럿** (예상 ~$0.15 · 기승인 파일럿 관례 내):
- 측면 **128×64** · **160×80** (edge-to-edge 프롬프트·`bypass_prompt_expansion`·야간 프리픽스 제거 — IMPL-319 확립분 승계)
- 추격 **96×96** (64×64 기각분의 유일한 상향 여지 — 높이 100 구속 내)
- 판독 축 = IMPL-319과 동일 (차형·바퀴·리버리 2색·카 넘버 판독)

**2단계 — 성립 최소 치수로 사양서 v1.4 개정** (총괄 발행·"실기 조정 창구" 문면 경유):
- 측면·추격 각각 성립한 최소 치수 채택 (배경 여유 최대 보존 원칙 — 예: 128×64 성립이면 160·192 불채택)
- 씬 컷(B급·미착수)은 개정 치수 전제로 착수하므로 재작업 0 — **지금이 치수를 바꿀 수 있는 마지막 무비용 시점**이다

**3단계 — 하이브리드 제작:**
- **베이스 14 = RD** (개정 치수 직접 생성 → `quantize.js` 양자화 → 육안 검수 항목 3건 적용)
- **오버레이 23 = 수작업 차분** (베이스 실물 위에 윙·리버리만 — 좌표 정합은 수작업만 보장·작업량은 풀 도트 37장 대비 소폭)

**폴백:** 1단계 전 치수 미성립 시 → ⓐ 수작업 회귀 (사용자 재판정 불요 — 본 기안이 폴백을 미리 정한다).

## 3. 발주 (에셋)

1단계 파일럿을 실행하고 결과(성립/기각 × 치수별·시안 실물)를 회신하라. 성립 치수가 나오면 **사양서 개정 문면 초안**(§3 셀 크기 행 + §4 대조표 행 + 대장 §4.5)을 함께 올려라 — 발행은 총괄. 추격 96×96까지 전멸이고 측면만 성립하는 경우도 그대로 보고 (시점별 경로 분리 = 측면 RD·추격 수작업도 성립하는 조합이다).
