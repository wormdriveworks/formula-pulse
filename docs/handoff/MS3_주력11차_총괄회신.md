## 3. 접수·기록

- **ⓐ축은 공회전으로 남지 않았다 — FAIL했다.** 노드를 세우자 부재 축 3검사가 즉시 FAIL(회귀가 전환을 감지) → **부재를 실물 제거로 재정의**(`free()` — 두 축이 모두 실물 계약을 봄·스텁 이중 계약 해소) + 도달 관측점을 생략 기록 → 오버레이 실표시로 교체("생략이 도달의 증거였던 것은 노드 부재 시절의 대용"). 검사가 상태 전환을 넘어 살아남는 구조 전환 — 기록.
- **실기 결함 발견·교정 — null 뷰포트**(연속 진행 입력이 마지막 라인을 넘긴 프레임 · 소비 표시를 진행보다 먼저로 2줄 교환). **관측점 선정 실패의 정직한 기록**: `is_input_handled()` 단언이 **항진명제**였고(리셋 창구 부재 — 결함 복원 상태에서도 PASS 실측) 원문 순서 단언으로 교체. **"헤드리스 검사가 `_advance()`를 직접 부르므로 입력 경로를 타지 않는다"** — 실기가 잡는 결함의 층을 명확히 한 사례. 단독 회차라 타 레인 파일 직접 교정 = 발주 명문 내.
- **⑰-ⓓ 배치 축** — "`visible`·`disabled`만 보는 스킵 생존 단언은 겹쳐도 통과한다" → 실 rect 교집합(10차 콜아웃 동형) + **M1이 못 짚자 M1′(실제 겹침)을 따로 돌린 것**("겹침 단언이 실제로 무는 것을 확인한 것은 M1′") — 돌연변이 위생 기록.
- **스피너 = 회전체 단독 대체** 근거 3(동심 불가 = 믹셀 금지·나란히 = 모서리 점유 배가·정보 보존 = "방향성 글리프는 절반의 각도에서 정보를 **거짓으로** 전했다") — 전건 승인. 값 무변경·창구 유지 확인.
- **VN 실기** — 1막 개시형 실기 확인(IMPL-271 실증)·아카이브 표제 6종 상이 6/6·걸린 라인 0.
- **징글 파형 객관 계측**(ZCR·RMS — "온도차가 네 축 전건에서 같은 방향" · 방향은 기계가, 적정성만 귀가) — 기계/귀 축 분리의 모범. `jg_02` 저레벨 관측은 비차단 품질 대장 승계.
