## 3. ③ 투어 결산 동형 절상

### 함수명 1건 — 발신 문면과 실물 차이 (동일 대상으로 판단해 집행)

발신 §3은 `finish_tour()` 로 지칭했으나 실물 함수명은 **`close_tour()`**(`season_state.gd:267`)다. 다만 발신이 적시한 결함 서술 3요소가 전건 일치한다 — `order.find(PLAYER_ID) + 1` 무절상(278행) · 소비처 `record_tour_result()` 의 `position <= 1` · 시즌 쪽만 교정된 상태. **동일 대상으로 판단하고 집행**했다. 다른 함수를 의도한 것이었다면 알려 달라(투어 결산 함수는 이것 하나다).

### 결함의 성질 — 시즌 건보다 날카롭다

시즌 쪽 0 은 "등급 표에 걸리는 행이 없어 빈 추첨"이었으나, 투어 쪽 0 은 **부호가 뒤집힌다**:

| 소비처 | 0 이 도달했을 때 |
|---|---|
| `record_tour_result()` `if position <= 1` | **무순위가 투어 우승으로 계상** (통산 `tour_wins` 오증가) |
| `_record_milestones({"tour_rank": 0})` | 0 을 '가장 좋은 순위'로 읽어 순위 마일스톤 오발동 |
| `close_tour()` 자신의 `if player_position == 1` | 여기만 0 을 걸러낸다 — **한 함수 안에서 두 축이 엇갈려 있었다** |

`close_season()`(IMPL-142)과 **동형**으로 `_grid_size()` 절상, 절상은 이 단일 지점 전속.

## 4. 착수 중 실측 1건 (환경 — 조치 완료·인지만)

착수 직후 첫 게이트가 `COMPILE_GATE_FAIL` 로 떨어졌다. 원인은 **`SilentAudioOutput` 미선언** — 타 레인이 커밋한 신규 `class_name` 이 원격 로컬 `.godot` 클래스 캐시에 없어서였다. `godot --headless --path godot --import` 1회로 해소(`scanned=88` 전건 통과).

> **`git pull` 후 신규 `class_name` 이 유입된 회차에는 `--import` 가 선택이 아니라 필수다.** 안 하면 파스 에러가 실제 코드 결함처럼 보인다 — 이번엔 게이트가 정직하게 실패해 3분 만에 갈렸으나, CLAUDE.md 원격 워크플로의 "(필요시)" 표기보다 강한 조건으로 읽는 편이 안전하다.
