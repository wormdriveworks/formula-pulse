## 2. ⓑ VN 시즌 상한 리셋 — **차단급 잠복 교정**

### 2.1 결함

`NarrativeService.begin_season()` 의 유일 호출처가 `RunSession.setup()`(커리어 개시 1회)이었고,
계수는 세이브에 직렬화되므로 **재로드로도 돌아오지 않았다.** 즉 `param_vn_season_cap 15` 가
**커리어 전체 상한**으로 작동했다. 시즌 1 이 정확히 15를 채운다 — 개막 1 + 브리핑 5 + 마일스톤 8 + 엔딩 1.

`begin_next_season()` 에 `narrative.begin_season()` 한 줄. 세이브 호환은 **구세이브 관용 그대로** —
`season_vn_count` 는 이미 `payload.get(…, 0)` 으로 읽으므로 스키마 변경 0이고, 구세이브가
15에 걸린 상태로 들어와도 **다음 시즌 전환에서 정상 리셋된다**(교정이 소급까지 덮는다).

### 2.2 이월 규칙 해석 — **문면 대조 결과, D08 의 이월은 이 상한의 규칙이 아니다**

발주가 "이월의 구체 기제를 원격이 세우고 근거 명기"를 요구했다. **정본 문면을 그대로 읽으면 세울
기제가 없다.** D08 §8.4:

> "**동일 투어 경계에 마일스톤 VN이 2건 이상 몰릴 경우** 우선순위: 막 전이 > 크루 합류 > 기원 단서 >
> 일반 성취 (확정) — **잔여분은 차기 경계로 이월**."

이월의 주어는 **한 투어 경계에서 우선순위 경합에 밀린 마일스톤 VN**이고, **시즌 상한 초과분이 아니다.**
`trigger_vn` 의 기존 주석(*"상한 초과분은 차기 경계로 이월된다 — D08 §8.4 잔여분 이월 명문"*)이
범위를 넓혀 인용하고 있었고, 그 주석이 발주 문면으로 이어졌다. **주석을 교정했다.**

판단 3건:
1. **시즌 상한 초과의 이월 기제는 정본이 침묵한다 → 세우지 않았다** (불변규칙 9). 상한에 걸린 발화는 그 자리에서 미발생이다.
2. **정본의 이월 규칙은 아직 적용 대상이 없다** — 마일스톤 VN **발화 경로가 미결선**이라 한 경계에 2건이 몰릴 수 없다(대기열도 우선순위도 실행되지 않는다). 발화가 서는 회차에 함께 온다.
3. **리셋이 서면 초과 자체가 드물어진다** — 시즌 1 정확히 15는 상한이 커리어 전체였기 때문이고, 시즌당이면 기대 11~13(D08 §8.4)이라 여유가 남는다.

### 2.3 관측점 — "조용히 안 뜨는" 결함이므로 계수를 먼저 세웠다

이 결함은 종료코드·화면 어디에도 흔적이 없다. **미발화는 정상과 구분되지 않는다.** 그래서
서비스 층 리셋만 보지 않고 **세션을 시즌 2까지 몰아 개막이 실제로 서는지**를 축으로 세웠다 —
결함이 정확히 그 자리였다(리셋 **함수는 있고 호출이 없었다**). 반증이 그것을 확인한다:

```
I1 시즌 상한 리셋 제거 → [FAIL] 시즌 전환이 VN 계수를 리셋한다 15
                        [FAIL] 시즌 2 개막 실발화 { "occurred": false, "reason": "season_cap" }
```

## 3. ⓒ D09 §2.3 순서 교정 (판정 A안)

```
전: HUB-08 오버홀 → begin_next_season() → 개막 VN → HUB-01
후: HUB-08 오버홀 → 엔딩 VN → begin_next_season() → HUB-01 → (개러지 이탈) 개막 VN → 브리핑 → RACE-01
```

**개막을 오버홀에서 빼는 것이 교정의 실질이다.** 엔딩만 끼우면 두 경계 비트가 개러지 완충 없이
연속 6라인으로 읽혀 닫힘과 열림이 같은 호흡에 들어간다(내러티브 6차 §4.2). 그래서 축도 두 방향이다 —
"엔딩이 있다"가 아니라 **"개막이 그 자리에 없다"**까지 본다(I3 검출).

### 3.1 개막의 새 자리 = 개러지 이탈 · **시즌당 1회 가드가 요건이 됐다**

D09 §2.3 이 `HUB-01 → 다음 시즌 오프닝 VN` 으로 두므로 `garage_screen._on_depart` 가 맡는다.
그 자리는 **투어 경계마다 지나간다** — 가드 없이는 매 투어 개막이 뜬다.

`vn_slots.per_season 1` 은 `trigger_vn` 이 보지 않으므로(시즌·마일스톤 상한만 본다)
**발생 대장(`vn_seen`)으로 판정한다**: 세이브에 직렬화되고 **스킵도 발생으로 세므로**(발생 = 도달)
재개·스킵 어느 경로에서도 두 번 서지 않는다. 엔딩도 같은 대칭. I5·I6 검출.

### 3.2 커리어 개시 경로는 개막을 유지한다 (판단·근거)

D09 §2.3 의 신규 분기(`SYS-02 → 프롤로그 VN → 튜토리얼 GP`)는 **HUB-01 을 지나지 않는다.**
`save_slot_screen` 에서 빼면 **시즌 1 개막이 어디에서도 서지 않는다.** 그래서 개시 경로는 그대로 두고
시즌 2+ 만 개러지 이탈이 맡는다 — 발생 대장 가드가 시즌 1 의 이중 발화를 막는다(첫 개러지 이탈 시점에
이미 `vn_seen` 에 있다). 순서 자체(1막 브리핑과 개막의 선후)는 **IMPL-263 ② 사용자 승인분**이라 무접촉이다.
