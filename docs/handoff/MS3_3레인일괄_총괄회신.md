## 3. 접수·기록 (검증 문화)

- **원격 ③ "하한은 처음부터의 축소를 정상으로 못박는다"** — `_match_row` 자료형 오독으로 검사 프레임이 통째로 중단돼 32검사가 실행되지 않은 채 PASS가 났고, 하한 게이트는 그 붉은 상태 위에 세워져 무력했다. 발견 경로 = 돌연변이 4종 미검출. **"돌연변이가 검사를 검사한다"** — 검증 문화 승격. 측정 함정 3종(상한 절단·하한 절단·정산 ⑧이 측정을 지움 — "어떤 시드에서는 통과하는 검사") 기록.
- **원격 ⑦ "이름의 부재는 기능의 부재가 아니다"** — IMPL-133의 `convert_symbol` 부재 단언은 추측 이름이라 소비부가 서도 통과했을 검사. 실측 교체 승인 — 관측점 선정 실패의 정직한 기록 계열(IMPL-294 항진명제 전례).
- **원격 철회 1항** — `param_skill_respin_cap` 신설 철회·기전사 `param_hold_total_cap_per_turn` 소비("창구는 값당 하나"의 4번째 이행·발견 경로 = 픽스처 표 FAIL).
- **봉인 설계 1건 특기** — `use_skill_check`가 인자 의존 조건을 일부러 보지 않는다("버튼 상태가 곧 결과 상관 신호가 된다") — 불변규칙 5를 UI 활성 판정 층까지 밀어 넣은 정확한 독해.
- **내러티브 §1 계수 교정** — 발주 문면 "721키"는 총괄의 `wc -l` 계수 착시(인용 안 개행). **"검산 축은 레코드 수와 필드 수다"** — 총괄 자인·기록 (동형 4번째: 계수는 기계 정의로 센다).
- **내러티브 ko 무변경 이어붙임** — 재직렬화 회피(인용 재정규화·전행 디프 오염 방지), `raw[a:b]` 접합 방식 승인. 작법 규칙(D04 변수 배치)이 어순 함정 0의 원인이라는 실증("작법 규칙이 번역 단계에서 배당을 냈다") 기록.
- **주력 IMPL-312 "가시 플래그는 '보인다'의 증거가 아니다"** — 저장 표시가 설계 이후 한 번도 렌더된 적 없었고(형제 순서 = 그리기 순서·불투명 배경) 기존 축은 `visible`만 봐서 통과했다. 축을 "덮이지 않는 자리"(형제 인덱스)로 교체 — **실기 회차의 존재 증명**. 하네스 자수 2건(무효 근거 제거·교체 = GDI가 GL 표면을 못 잡음 / **"무반응 관측은 결함 후보가 아니라 하네스 후보로 먼저"** = 좌표 캐시 금지) 접수.
- **에셋 IMPL-305 절차 모범** — 발주 전제("정본 전건 기존재")가 정본 대조에서 깨지자 임의 신설 없이 **판정에 픽셀을 붙였다**(시안 원장·산출 경로 2중 격리 + 미지 플래그 거부). "발주문도 검증 대상"의 재이행.
