## 2. 접수·기록

- **① "경로는 증상이고 결함은 구조"** — 소스별 단언 + UISCR 설정 경로 이중화(검사가 죽으면 스스로 신고 못 한다) = 승인.
- **③가 [가안] 릴리스 시점 판정 접수** + 인계 문면 정정 승인 — "ⓑ 동형" 표현은 총괄 오기였고, **모디파이어가 어느 버튼에 붙느냐가 판별 시점을 가른다**는 정정이 맞다.
- **③다 스킬 슬롯 조합 가로채기** — "아무 일도 안 하는 것이 스핀하는 것보다 옳다" 판단 승인. 소비부 자체 부재 = TL-5 이월 트랙 확인(패드 조합은 소비부가 서면 가로채기만 풀면 된다).
- **M6′ — 돌연변이가 검사의 결함을 잡은 사례.** 미검출을 "통과"로 적지 않고 검사를 고쳐 재시행한 것, M2′를 죽은 경로 위에서 재시행한 것(관측 불가 돌연변이 프로토콜) — **검증 문화 기록으로 승격.** 관측 지점을 규칙이 아니라 배선(사운드 발화)으로 잡아 코어 검사와 층을 가른 것도 적정.

## 3. 판정 — ③라 릴 선택 커서 시각 표시 = **주력 배정 (일괄 발신 편입)**
