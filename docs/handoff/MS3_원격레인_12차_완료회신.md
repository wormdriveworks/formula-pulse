## 1. ① B1 확대 — 규칙이 하나로 합쳐졌다

확대 후 규칙은 경로별로 갈리지 않습니다:

> **앵커를 세운 컨트롤에는 명시적 `grow_*` 또는 명시적 오프셋이 함께 있어야 한다.**
> 경로 ①비-FULL_RECT 프리셋 호출 · 경로 ②앵커 직접 대입 — **같은 요건**을 진다.

### 세부 판정 3건

| # | 판정 | 근거 |
|---|---|---|
| ⓐ | **앵커 0 대입은 면제** | 앵커 0 은 부모 좌상단 기준이라 **오프셋 0 과 배치가 일치**한다 — FULL_RECT 면제와 같은 사유다 |
| ⓑ | **리터럴 아닌 우변은 짝을 요구** | 값을 모르면 0 이라고 볼 근거가 없다 |
| ⓒ | **복합 대입(`+=`)도 편입 · 단 0 면제 미적용** | 앵커를 손으로 옮기는 선언이지만 결과값을 알 수 없다 |

**대상마다 한 번만 짖습니다.** 앵커는 보통 2~4줄이 붙어 나오므로 줄마다 경고하면 **결함 1건이 4건으로 불어나 계수가 사실을 왜곡**합니다.

### 확대 후 위반 0

```
ANCH anchor placement: PASS (15 checks)
```

15 = 프리셋 호출 5 + 0 아닌 앵커 대입 10(툴팁 4 · 모달 4 · 저장 표시 2). 셋 다 짝을 이미 갖고 있어 **도입 비용 0** — 총괄 예측대로입니다.

## 2. ① 오검출 재확인 — 표본 23종 · **오검출 0**

11차 13종에 B1 계열 10종을 증설했습니다.

**B1 계열 증설분 (10종)** — 참양성 4: 앵커 대입 단독 · 자기 대입 · **복합 대입(`+=`)** · **비리터럴 우변** / 참음성 6: 앵커+오프셋 · 앵커+`grow` · **앵커 0 단독** · 주석 안 대입 · **동명 지역변수 선언**(`var anchor_left := 0.5`) · **앵커 비교문(`==`)**

집계: **참양성 7 · 참음성 15 · 잔여 사각 1(B2)** — 오검출 0.

> **11차에 사각으로 보고했던 B1 이 참양성으로 넘어왔습니다.** 표본표에서 그 한 행이 뒤집힌 것이 확대의 실증입니다. B2(동명 지역변수가 짝을 가림)는 지시대로 의도된 되돌림으로 존치했고, UISCR ⑫ 실측 축이 받칩니다.

## 3. ② 차단형 flip — 근거와 실증

`_warn`→`_fail` 2지점. 근거는 **FONT 와 같습니다** — 문법 수준 기계 판정이라 V7(작법 판단 = D04 소관)의 사유가 적용되지 않고, 오검출 0 실측과 **눈 검증 곤란**(화면은 정상적으로 뜬다)이 근거입니다. **V7 무접촉.**

### 돌연변이 8건 전건 검출

| # | 돌연변이 | 검출 |
|---|---|---|
| M1 | 프리셋 경로 — 툴팁 결함 복귀 | `VALIDATORS_FAIL` exit 1 |
| M2 | **B1 경로 — 모달 `grow` 2줄 제거** | `[FAIL] ANCH: confirm_dialog.gd:39 앵커 직접 대입(anchor_left)...` |
| M3 | **B1 경로 — 저장 표시 오프셋 4줄 제거** | `[FAIL] ANCH: save_indicator.gd:51 ... (대상 'self')` |
| M4 | 프리셋 경로 — 온보딩 팁 `grow` 제거 | `VALIDATORS_FAIL` exit 1 |
| M5 | 앵커 속성 목록 비움 | `[FAIL] ANCH 앵커 속성 4종 전량 감시` |
| M6 | 짝 목록에 `position` 재편입 | `[FAIL] ANCH 짝 목록 = grow 2 + 오프셋 4 (추가·삭제 0)` |
| M7 | 차단형 → 경고형 되돌림 | `[FAIL] ANCH = 차단형 (경고 호출 잔존 0)` |
| M8 | ANCH 등록 제거 | `[FAIL] ANCH 검사 등록(호출) 실재` |

> **M3 이 이번 확대의 값을 가장 잘 보여 줍니다.** 저장 표시의 오프셋 4줄을 지우면 **9차 원결함(우상단 → 좌상단)이 그대로 재현**되는데, 확대 전에는 그 형태가 규칙 밖이라 아무 신호도 없었습니다. 이제 빌드가 멈춥니다.

## 4. 부수 교정 2건 — **내 감시 축의 구멍을 돌연변이가 잡았다**

⑬축(검사 실재)에 두 구멍이 있었습니다.

- **ⓐ 앵커 속성 목록이 감시 밖이었다.** 그 목록을 비우면 **B1 규칙이 통째로 죽고도** `ANCH ... PASS (5 checks)` 로 통과합니다. 면제 목록과 같은 축으로 고정했습니다.
- **ⓑ 짝 목록은 `contains()` 로 감시하면 *추가*를 못 본다.** 뒤에 `"position"` 을 덧붙여도 기존 조각이 그대로 남아 통과합니다(M6 첫 시행 미검출). **부분 일치는 삭제만 잡고 완화는 놓칩니다** — 목록을 통째로 떼어내 **정확 대조**로 바꿔 닫았습니다.

> 차단형이 됐다고 이 축이 불요해지지 않습니다 — **위반이 없는 것과 검사가 없는 것을 종료코드는 구분하지 않습니다.**
