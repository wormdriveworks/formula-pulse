## 2. 햅틱 결선 — **T6 사운드 축의 마지막 한 겹** (총괄 실측 신설)

BGM 청취 승인으로 오디오 실물·재생기가 닫혔으나, **사운드 결선의 자매 축인 햅틱은 선언만 있고 결선이 없다**(총괄 실독):

| 층 | 상태 |
|---|---|
| 어댑터 계약 `IHaptics` | ✅ 실재(`godot/adapters/i_haptics.gd` — D12 §2.2·§10.4) |
| 데스크탑 구현 `DesktopHaptics` | ✅ 실재(`Input.start_joy_vibration` — 연결 패드 전체) |
| 데이터 `sound_map.csv` `haptic` 열 | ✅ 실재 — `none 75 · strong 6 · micro 3 · weak 1 · mid 1` (V1 enum 검증분) |
| 값 창구 `core_params` | ✅ `param_haptic_damp_ratio`·`param_haptic_l1_sec`·`param_haptic_l2_sec` 등 |
| **디스패처 → `vibrate()` 호출** | ❌ **0건** — 표에 강도가 적혀 있는데 아무도 읽지 않는다 |

**결선 요건:**

1. **디스패처가 `haptic` 열을 소비**한다 — 발화 시 `IHaptics.vibrate(강도, 지속)` 경로. 강도·지속은 **전량 D13 창구**(`core_params` — 코드 무기입). 등급 5단(`none/micro/weak/mid/strong`) → 강도 매핑도 데이터에서 온다(대장에 없으면 **작업 중단·보고**).
2. **혼입 0 준수** — 플랫폼 분기는 어댑터 뒤. 코어는 `IHaptics` 계약만 안다(`platform_services` 경유 주입 — 오디오 재생기 주입과 동형 구조 재사용 권고).
3. **O3 감쇠 옵션 정합** — D09 진동 감쇠 옵션이 있다면 그 소비부까지(볼륨 옵션 → 버스 전례와 같은 자리. 저장만 되고 소비 0인지 실독 후 보고).
4. **봉인 준수** — 릴 정지 연출 완료 전 결과 상관 진동 금지(불변규칙 5 — 진동은 **출력 경로**다. 디스패처 봉인 게이트를 그대로 타는지 확인).
5. **무햅틱 폴백** — 패드 미연결·미지원 플랫폼에서 no-op(무음 폴백과 같은 구조. 데스크탑 실기 진동 확인은 **패드 실기 이월분**에 합류 — 이 회차는 상태 검증까지).
6. 검사: 표 등급 5단 → 호출 매핑·봉인 창 중 억제·옵션 반영·부재 폴백. 성격은 기존 AUDIO-* 계열 편입 권고(신설 검사면 차단/경고는 총괄 판정 경유).

## 3. 재회 체인 브리핑 VN — **거처·조건 규격 기안** (판정 IMPL-284 ②)

**구현하지 않는다.** 산출물 = `docs/handoff/재회브리핑_규격기안.md`(또는 회신문 내 절) — 총괄 검수 → 사용자 승인 경유 → 별 회차 집행.

### 기안이 답해야 할 것

| # | 항목 | 배경 |
|---|---|---|
| ① | **거처** — 기존 3구조(`vn_slots.csv`·`milestone_vn.csv`·`act_vn.json`) 중 하나인가, 신설인가 | 선택지 = CSV 2표 전례(IMPL-257) · `act_vn.json` = 막 인스턴스 축 전속(16차 판단) |
| ② | **조건 표현** — 발생 조건이 "알타 리지 무대 ∧ 재회 축 단계"인데 **DSL 문맥 7필드에 무대·관계 단계가 없다**(총괄 실독: `player_rank·act·season·tour_slot·vane_stage·jude_rank_delta`) | **문맥 확장은 구현 권한 밖**(T7 계약서 §1.3·D12 §5.4 "필드 비교·AND/OR 한정") — 확장이 필요하면 **신설안 문안으로 제안**하고 사용자 승인 경유. 대안(조건을 데이터 밖 코드 규칙으로 두는 경로)의 손익도 함께 평가할 것 |
| ③ | **발생 슬롯·상한 정합** | 투어 브리핑 슬롯 · **투어당 비트 상한 2**(D13 v1.10 재회 행 주 — threshold1=2 도출의 전제)와 막 VN·시즌 오프닝의 슬롯 경합(D08 §8.4 우선순위: 막 전이 > 크루 합류 > 기원 단서 > 일반 성취) |
| ④ | **`record_reunion_beat` 결선 지점** | 16차 교정분(막 VN은 비트가 아니다 — `act_vn_entry()` 실재로 가름)과 충돌하지 않는 판별 |
| ⑤ | **관측 이월 해소 경로** | 세 번째 다리 복원 시 "시즌 1 내 대면 도달" 빈도 재검토(IMPL-275 ② 이월분) — 기안이 그 재검토에 필요한 관측 항목을 제시 |
