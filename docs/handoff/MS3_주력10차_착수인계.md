## 착수 전 (주력 환경 규약)

- `git pull` 후 에셋 실물이 수백 바이트면 `git lfs pull` 먼저.
- 신규 파일 유입 회차이므로 임포트 필요 — **에디터가 켜져 있으면 `--headless --import` 금지**, GDAI `execute_editor_script`로 `EditorInterface.get_resource_filesystem().scan()` 1회 (IMPL-137 규약).
- CLI는 예외 없이 `_console.exe`. 스테이징 = 파일 단위 명시 경로 전속. IMPL ID = pull 직후 최대값+1.

## 배정 5건

### ① 튜토리얼 콜아웃 재배치 — **착수 조건 성립 (문안 유입 완료)**

- 주력 3차 접수분: TUT-01 콜아웃이 상단 스트립과 겹치는 결함 — *"튜토리얼 문면 유입 시 재배치와 동시 처리"* 로 이월돼 있었다. **문안 5키가 실문안으로 유입됐다**(내러티브 1차 — `ui.tutorial.*`, `[문안 미유입]` 소멸).
- 할 것: 실문안 기준으로 콜아웃 크기·배치 재점검(문안 폭 19.0~23.0 전각 — 플레이스홀더와 다르다) + 상단 스트립 겹침 해소. 씬 소유권 = 주력. 하이라이트 하반부 시 패널 상단 이동 규칙(IMPL-138)과의 정합 유지.
- 확인: 5단계 전 단계에서 콜아웃이 지목 요소·스트립 어느 쪽도 가리지 않는 실기 캡처.

### ② VN 6건 실기 눈 대조 — **T7 편입분 (원격 14차)**

`act_vn.json` 6건(1~4막·기원 공개·에필로그, 75라인)이 결선됐다. 눈으로만 확인되는 것:

| 축 | 확인 |
|---|---|
| 라인별 화자 | 화자 라벨이 **라인마다** 교대하는가(마르타/테오/베인) · 지문 라인은 화자 라벨이 **공란**인가(`speakerNarration` = 빈 값) |
| 문안 표시 | 갈무리 9px 렌더에서 75라인이 1줄·24폭 안에 실제로 앉는가 — 표본이 아니라 **6건 전량 스킵 없이 1회 통독** |
| 큐음 발화 | 실물 SFX 미유입이므로 소리는 안 난다 — **디스패처 `fired` 기록**으로 베인 라인에만 `SE-V01*`, 타 화자에 `SE-V02`가 쌓이는지 대조(UISCR ⑭가 기계로 보지만 실기 교차 1회) |
| tone 전환 | 3·4막·기원 진입 시 `vn_enter_tense`, 1·2막·에필로그 `vn_enter_calm` 발화 기록 |
| 막 래치 | 첫 포디움 달성 → **다음 투어 경계**에서 2막 VN이 뜨는지(즉시가 아님 — D08 §8.1 이층) |

### ③ 툴팁·모달 실기 눈 대조 (기배정 누적 — ANCH 교정분)
