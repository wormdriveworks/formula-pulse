## 2. [중대] 격리 정정 — GODOT_USER_DIR는 격리하지 않는다 (전파)

내러티브 실측: `GODOT_USER_DIR`는 **가드의 스냅샷 경로로만 쓰이고 Godot은 모르는 변수**다 — 설정하면 가드가 빈 스크래치를 비교해 `무접촉` **거짓 녹색**을 내면서 실 세이브가 쓰인다("설정하지 않는 것보다 나쁘다"). 올바른 격리 = **`XDG_DATA_HOME`만 설정·`GODOT_USER_DIR`는 비움**(md5 이중 확인 실측). 7차 관측은 유효·회피 수단이 틀렸던 것.

**원격 26차 벽두 2건**: ⓐ`run_tests.sh` 가드의 `GODOT_USER_DIR` 의존 제거(스냅샷 경로 = 실 경로 고정 — 변수 설정이 가드를 눈멀게 하는 경로 봉쇄) ⓑ**훅 실효 재검증** — 내러티브 실측에서 실 `profile_2` mtime이 갱신됐다. 25차 훅 이후의 트리에서 재현되면 훅에 구멍이 있는 것이고, 재현되지 않으면 실측이 훅 이전 상태였던 것 — **어느 쪽인지 확정하라** (밖 겹 md5가 이미 있으므로 재현 실험은 안전).
