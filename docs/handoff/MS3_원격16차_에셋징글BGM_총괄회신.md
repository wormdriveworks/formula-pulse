## 4. 접수·기록

**원격 16차 — T7 차단 해소.** 75라인이 게임에서 실재하고(1막 = 커리어 개시 · 2~4막·기원·에필로그 = 투어 경계) 선택 4지점이 자동 도달(씬 노드 부재라 생략 기록까지 확인)한다. 기록할 판단:

- **결함의 성격이 축의 형태를 정했다** — "데이터도 화면도 멀쩡하고 아무도 넘기지 않아서 도달 불가"인 결함은 데이터 검사와 화면 검사가 각자 통과하는 사이로 빠져나가므로 UISCR ⑱축이 **발화 → 페이로드 → 실화면 → 도달을 한 줄로 꿴다.** 검증 문화 기록.
- **발행 창구 단일화** — 발행 지점 둘(커리어 개시·투어 경계)을 화면마다 조립하면 "한쪽만 `tone`을 빠뜨리는 형태로 조용히 샌다"(N5가 `["BGM-09","SE-V02"]`로 잡힘). 관측 지점을 라벨이 아니라 **BGM 발화 기록**에 둔 것 포함 승인.
- **발행 위치 = 신규 화면·전이 0** — D08 §8.1 공표 위치를 D09 §2.3 플로우맵 문면 그대로 앉힘(전이 폐쇄성 무접촉).
- **1막 개시형 분리** — 창구 2개·**몸통 1개**(복제하면 단조 증가·중복 발화 방지가 한쪽에서만 지켜진다)·판별은 데이터(`milestone` 공란/실재 — 신규 열 0).
- **자가 적발 ①** 표시 대기가 저장 지점을 못 건넘(SET-01 사이 — 직렬화로 해소) + **"소비부를 붙이는 순간 성격이 바뀌는 상태였고 주석이 이전 성격을 주장하고 있었다"** 기록.
- **N6 초회 미검출 → 관측 지점 이동**("앞선 축이 이미 `_load_ok`를 내려 놓은 상태로 재면 판정이 무의미") · **`enum_optional` 양방향 실측**("지우면 FAIL"이 아니라 "공란이 통과하고 폴백이 흐른다"가 계약 — 단방향 돌연변이로 증명되지 않는 축) — 검증 문화 기록.

**에셋 징글 5식 — 청취 통과.** ⓐ**D09 §5.1 독해**("중하위는 차가운 소리가 아니라 덜 뜨거운 소리 — 하강 선율·단조는 실패 정서라 규격 위반" → 같은 음 2타로 방향 제거, 온도차는 상승 유무·종지 길이로만) ⓑ`jg_03`는 반대로 하강이 규격("리타이어는 소프트 실패가 아니라 주행의 종료"·신파 금지는 **길이로** — "절제는 방향이 아니라 길이에서 나온다") ⓒ**자기 결함 자수 = 주파수 공식 3옥타브 오류**(상류가 출력 샘플당 8 서브샘플 — `F = 3528×(p²+0.001)`) · **"파라미터가 맞는 것과 소리가 맞는 것은 다르다"** 검증 문화 승격 · 벤더 재대조 대상 1→2 확장 승인 ⓓ**검사 채널화**(5행 손 추가 대신 `sound_map` channel 열을 대장으로 — BGM 회차의 반복 노동 제거) + **사각 주석 명기**("표에 없는 채널은 조용히 통과 — BGM 유입 시 행 추가를 잊으면 아무도 안 본다") ⓔ`checkMotif` 신설(원장⇔인용 + 원장 자기 정합 — 3처 조용한 어긋남 차단) ⓕ대장 헤더 누락 사후 보전("헤더 이력은 색인이라 본문만 맞으면 되는 자리가 아니다") — 전건 기록.

**에셋 BGM 파일럿 — 실증 접수.** 인코더(vorbis-tools 1.4.3 — 사용자 설치 실행) · 98BPM×48마디 = **117.551초**(규격 내) · **루프 이음매 0.89%** · 피크 −6.0dBFS(리미터 없음 — 라우드니스 전쟁 금지 준수) · 디코드 왕복 프레임 일치 · `--serial` 고정이 재현 계약의 필수 조건 실측 · **기안 가정 1건 정정 접수**(OGG 임포터에 WAV `loop_mode` 동형 함정은 없다 — `loop=true bpm=98 beats=192` 되읽기 확증). 총괄 기안이 함정을 가정하도록 지시한 것은 보수적 처방이었고, 없음이 실측으로 확인된 것이 성과다.
