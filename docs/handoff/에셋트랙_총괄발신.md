## 2. 판정 요청 3건

### A. 팔레트 2식 — **에셋 트랙 최대 차단 요인** (우선순위 1)

**D10 §2.3은 구성만 확정하고 색상값을 주지 않는다.** 코어 뉴트럴 16 + 텔레메트리 네온 12 + 팀 컬러 16 + 환경·피부·머티리얼 12 = 56색이라는 **개수와 역할**은 확정이나, 실제 색은 정본 어디에도 없다. 팀 컬러도 정성 표기(악시온 백×청 / 불카 흑×주황 / 그리폰 진녹×금 / 노스윈드 스틸 그레이×아이스 시안)까지다.

- **영향:** 팔레트는 AI 산출물의 **양자화 기준**이다. 없으면 어떤 이미지 에셋도 최종 형태로 확정할 수 없다 — 그려도 색을 다시 맞춰야 하므로 재작업이 된다. 현재 코드가 기능 컬러를 [가안]으로 운용 중인 것(IMPL-071·075)도 같은 뿌리다.
- **요청:** 56색 실색상값의 확정 경로를 지정해 달라. 선택지 = ⓐ에셋 세션이 [가안] 팔레트를 제안하고 사용자 승인 ⓑ D10 개정으로 정본 확정 ⓒ 실기 반복으로 후행 확정(그때까지 에셋 발주 보류).
- **권고 = ⓐ.** D10 §2.3이 "확정 기준값"으로 개수만 못박은 구조상 색상값은 구현·실기 창구로 보는 것이 문면 정합이고, 승인 1회로 전 에셋이 풀린다.

### B. `audio/` · `platform/` · `store/` 3계 신설 (대장 §9-①)

D10 §8.2 카테고리 11계에 **사운드·플랫폼 부속의 자리가 없다.** CLAUDE.md 디렉토리 계약도 "아트·**사운드** 실물"이라 쓰면서 목록에는 사운드가 없다. 대장이 3계를 신설해 두었으나 **D10 카테고리 개정 사안인지 구현 재량인지** 판정이 필요하다. 비차단(디렉토리는 이미 서 있고 파일 유입 전).

### C. D11 §2.9 헤딩 "18식" vs 실제 19 (대장 §9-⑦)

`SE-U01~U19` 로 19개 ID가 열거돼 있고 §2.11 집계·§7.2도 19로 세며 **총계 68은 19 기준으로만 성립**한다. 헤딩만 18이다. D08 §8.11의 "35 vs 39"와 **같은 유형의 헤딩 오기**로 보이며, 그 건은 총괄이 "열거가 정본"으로 판정했다(IMPL-121). 같은 준거를 적용하면 19가 맞다. 사운드 발주 전 확정 필요.
