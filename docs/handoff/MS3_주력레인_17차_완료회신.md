## 2. ② 해빙 차분 — 교체판은 슬롯에 **얼굴만** 세웠다

사샤가 **턱에서 잘린 얼굴 하나**로 뜬다. 원인은 CG 가 아니라 **차분 적재 방식**이다.

```
crew_sasha_base.png          180×240   ← 버스트업 스탠딩
crew_sasha_face_special.png  112×112   ← 얼굴 레이어 (실측 · 차분 34장 전건)
```

초판은 `char_id + suffix` 를 통째로 적재해 **교체**했다. 슬롯이 `KEEP_ASPECT_CENTERED` 라 112 짜리가 폭에 맞춰 확대되고 몸이 사라진다 — 얼굴이 base 대비 **1.61배**로 뜬다.

**정본이 이 방식을 금지한다.** D10 §3.1: *"차분 = 얼굴 영역 레이어 교체 방식(**전신 재작화 금지**)"*. 교체는 전신 재작화의 결과와 같은 그림을 만든다.

### 왜 36차에 안 보였나 — 결함이 결함을 가리고 있었다

구 cg05 는 사샤·마르타 초상을 담아 화면에 얼굴이 4개였고, 그중 하나가 잘린 것은 **차폐 소음**으로 읽혔다. 원도를 고치자 남은 하나가 드러났다. 총괄이 재캡처를 *4항 검수*로 발주한 것이 이 자리를 연 것입니다.

그리고 기계도 못 봤습니다 — 35차 축은 **접미 문자열**(`standing_suffix == "_face_special"`)만 봤습니다. 문자열은 무엇이 그려졌는지 말하지 않습니다.

### 값을 만들지 않았다

- **x 는 값이 아니라 유도다.** 배치 대장 §4.4.3 이 *"x = (180−112)÷2 = 34(중앙 정렬)"* 로 두 확정 기준값에서 뽑으므로, 상수를 적지 않고 **두 실물의 폭에서 그 자리에서** 구합니다.
- **y 는 인물별 실측값이라 표에서 옵니다.** 같은 문서가 *"크롭 y 가 3~27 로 흩어진 것이 공용 템플릿이 서지 않는 증거"* 라고 적어 뒀습니다(±6px). 거처가 D13 이 아닌 것은 D10 §3.1 이 이 값을 *"조정 창구 = 원화 실작업"* 으로 위임했기 때문이고, **팔레트 실색상이 에셋 실물 소관인 것과 같은 자리**입니다.
- 표 열 `face_offset_y` 신설 — `vn_speakers.csv` char_id 7행에 대장값 전사(27/3/16/19/4/20/16), 얼굴 없는 2행 = `-1`. V1 열 선언 `int:-1,128`(상한도 180−112 유도값).

**[판단 1건 — 추인 요청]** 열의 거처를 `vn_speakers.csv` 로 둔 것. 값이 **인물 art 의 성질**이고 소비부가 VN 스탠딩 하나뿐인데, 크루 표(4인)·라이벌 표(9인)는 13인을 함께 담지 않아 화자 표가 유일한 인물 키 표입니다. 다른 소비부가 생기면 인물 표로 승격할 자리입니다.

### 실패는 기본으로 떨어진다

합성이 실패하면 **인물은 서고 차분만 빠집니다**. 조용하지 않게 — 사람에게 `push_error`, 기계에는 접미 메타가 `_base` 로 남아 축이 붉습니다(반증 M3 에서 실제로 그 경로가 발화했습니다).

### 축·반증

신설 4점 — 전제(실물 치수가 갈린다) · **합성 결과 = 기본 시트 치수** · 얼굴 구획이 갈린다 · **구획 밖 = 기본과 동일**(전신 재작화 금지의 기계 확인).

| 반증 | 주입 | 결과 |
|---|---|---|
| M1 | 교체판 복원(초판 결함) | `합성 결과 = 기본 시트 치수` FAIL — `(112, 112)` |
| M2 | 오프셋을 표에서 안 읽고 0 | `구획 밖 = 기본과 동일` FAIL — 1609px |
| M3 | 무동작 합성 | `얼굴 구획이 갈린다` FAIL — 0px (+ 폴백 경로 실측 발화) |

## 3. ③ 하네스가 고쳐진 결함을 계속 그리고 있었다

vn8 스테이지는 36차에 기록실이 *그때* 넘기던 사전(`{vn_id, replay, next}`)을 손으로 적었고, 그것이 ㊹ 의 증거였습니다. 원격이 조립을 `archive_replay_payload()` 로 옮기자(IMPL-483) **손으로 적은 사전은 생산에 없는 형태**가 됐고, 재캡처는 고쳐진 뒤에도 폴백 1줄을 그렸습니다.

컷이 결함을 증언하는 것이 아니라 **하네스가 자기 옛 입력을 증언**한 것입니다. 창구 호출로 바꾸자 실문안이 섰습니다(화자 공란 = 지문 · 파형 없음). **16차 VN 컷과 같은 교훈의 두 번째 자리 — 컷은 생산 경로를 지나야 합니다.**

**판독 전제 정정도 전사했습니다**(총괄 IMPL-484 §1 ⓐⓑ) — 36차가 적은 *"CG = 장소·사물, 인물은 스탠딩"* 은 정본 문면이 아니고(grep 0), 형제 규약의 실체는 *"인물 없음"* 이 아니라 **"얼굴 없음"** 입니다. 결론은 유효하므로 문면만 고쳤습니다. 다음 회차가 *"실루엣도 위반"* 으로 오귀결하는 것을 막는 것이 정정의 목적입니다.
