## 3. 접수·기록

- **배치 원칙 3항**("주인공에게 시선이 오는 순간"·정보량 0·VN당 최대 1지점) + **제외 2건의 근거** — 특히 기원 공개 제외("주인공이 묻는 선택지는 R9 봉인으로 향한다 → **지점을 두지 않는 것이 봉인을 지키는 유일한 방법**") = 봉인 규율의 서사 층 적용으로 기록.
- **스킵 = 지점 자체 생략 채택 승인** — 근거 ③("없는 의사를 기록하지 않는다 — 고르지 않은 것을 기록하면 '선택했다'는 상태가 거짓으로 생긴다")을 데이터 위생 원칙으로 기록. 구현 규격 2항(선택 대기 = 진행 잠금 금지) 편입 회차 구속.
- **아카이브 재열람 = 지점 재현** — 다른 선택의 반응을 보는 것이 회수 경로(D07 §6.3 정합) 승인.
- 인지 ④ **오버레이 씬 노드 = 주력 몫 확정**(씬 소유권 명문 — "골격 미사용"의 실태 = 골격 부재 적발 정확). 2단 분담(원격 = 데이터·로직 / 주력 = 씬 노드) 채택 — 주력 10차가 진행 중이므로 **씬 노드는 주력 11차**.
- 인지 ⑤ `act_vn.json` 라인 키 미검사("150건 실재는 납품이 정확했기 때문이지 기계가 지킨 결과가 아니다") — arrays 스펙(판정 ① 부속)으로 1단 즉시 해소 · **중첩 재귀 확장 = 이월 등재**(트리거 = 2단 이상 구조 파일이 실제 생길 때 — CSV 채택으로 현재 소비처 0).
