## 2. 주력 레인에 넘기는 것 (씬·아트 소유권)

1. **RUN-01 섀시 게이지 표시** — 필드 정비 실행은 개방됐으나 화면에 현재 섀시 표시 요소가 없다
   (씬 소관). 비용·활성 판정은 코어 값으로 이미 결선 — 게이지만 붙이면 된다.
2. **HUB-02 완전 회복 고스트 게이지 + 총비용 표시** — `full_repair_cost()` 조회 신설돼 있다.
3. **RUN-01 소모품 보충·덱 교체 선택 UI** — 3종 선택(씬) 필요라 잠금 유지. 구매 로직(`buy_consumable`)은 기존재.
4. **RACE-02 네임드 초상 미니** (§A-7 E01 잔여 — 아트 실물).
5. **로그 화자 축(카 넘버 배지 포함)** — 이벤트 스키마 화자 필드 + 배지 도상과 한 묶음 (IMPL-071 이월).
   number 값은 이벤트에 이미 실려 있어 결선 시 즉시 붙는다.
