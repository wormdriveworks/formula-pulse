## 3. 접수·기록

**원격 17차 — 재생기 결선.** 세 채널 전부 실발화(BGM 13행 스트림 부재 0). 기록할 판단:

- **버스 = 런타임 구성**(`.tres` 미사용) 3근거 승인 — 특히 ⓒ *"검증이 되읽기로 성립한다 · 리소스 파일은 '선언이 증거가 아니다' 함정을 다시 만든다"*. 멱등 구성(중복 생성 시 send 사슬의 조용한 어긋남 차단).
- **페이드를 `Tween`에 맡기지 않음** — `advance_fades(delta)`로 시간 축을 검사에 넘긴 것(디스패처 `clock_override_msec` 동형). **"중간값이 규격이다 — 완료 게인 1.0은 하드코딩과 값 창구를 구분하지 못하고 절반의 0.5만이 0.8초를 증명한다"** — 검증 문화 승격.
- **무음 폴백은 플래그가 아니라 구조**(트리 없는 문맥에서 무음이 유일 가능 거동) · 숙주 = 라우터("화면에 매달면 BGM이 전이마다 끊긴다").
- **자가 적발 3건**: ⓐ뮤트 합성 누락(볼륨 0 + 일시정지 → 재개가 사용자가 끈 소리를 되살림 — **"한 자리를 둘이 쓰면 합성해야 한다"**·덕킹 동형) ⓑ**2레이어 기본 스템 미탐색**(에셋 `_a`/`_b` 유입으로 드러남 — "레이스 트랙 5개가 상태는 정상이고 소리만 없는, 가장 조용한 실패") + **"검사를 남의 조달 일정에 묶지 않았다"**(부재 전제 → 불변식 전환: 디스크에 있으면 전건 해소·없으면 전건 관측) ⓒ**V4는 표시 문자열과 오류 문면을 구분하지 않는다**(내러티브가 같은 2건을 독립 관측 — 교차 확인).
- **A13·A15 미검출 원인이 같다 — 축이 공회전했다**(부재 경로는 슬롯을 잡지 않으므로 점유 0이 늘 참 / 세션→버스 한 겹을 보는 축 자체가 없었다 = **"저장만 되고 소비부 0이던 원래 상태와 종료코드로 구분되지 않는 자리"**) — 0==0 계열 4번째 실증.
- **범위 추가 = 아카이브 표제 결선**(고아 6건 해소) + **리터럴 표 채택 근거**("V6는 조립한 키를 보지 못한다 — 소비부가 있는데 없다고 보고하는 상태를 남기면 다음 사람에게 잡음이 된다"·표의 대가는 UISCR 축이 받는다).

**에셋 — BGM 18스템 완결.** ⓐBGM-01↔12를 음역·성분·강도·꼬리 4축으로 가름(원장 공유·편성으로 가름 지시 이행) ⓑ**BGM-07 모티프 인용을 B층에 둔 판단**(긴장 레이어에서 총화가 열린다) ⓒBGM-09/10 음색 무변경(밀도만) ⓓA/B 5쌍 프레임 동일·합산 무클리핑 ⓔ**돌연변이 ⑥이 원장 단일성을 증명**(원장 변조 시 3처가 동시에 걸림) ⓕ**실사고 자수 = 미지 플래그 무시로 실물 18개가 덮임** → **"파일을 쓰는 도구는 몰랐으면 안 쓴다"**(미지 플래그 거부·값 없는 `--only` 거부) · **"돌연변이 시험의 위험은 돌연변이가 아니라 원복·주행 경로에 있다"** — 검증 문화 승격.

**내러티브 3차 — 표제 6문안.** ⓐ**자수 규격을 실기에서 도출**(라벨 140px 역산 — 기계 미강제 도메인에서 "스스로 정하고 근거를 명기"한 발주 요구의 모범 이행) ⓑ막 제목 계열 정합(`기원 공개` = D04 §6.2 공개 단계 명칭·D08 §8.6 행) ⓒ로컬라이제이션 130% 팽창 실측 확인 ⓓV6 고아 6건을 **예견된 상태로 선언**하고 담는 방식을 원격·총괄에 인계 — 규약 준수와 정보 전달을 동시에 한 처리.

## 4. 규약 3항 보완 — CLAUDE.md 집행 (본 회차 총괄)

> 3. 공유 파일은 **자기 몫만** 반영한다 … (기존) + 다음 3문면:
> - **덮어쓰지 않는다** — 표 형식 공유 문서(`impl_log.md` 등)는 **append 지점만** 만지고 파일 전체를 재작성하지 않는다. 자기 기준본으로 read-modify-write 하면 타 세션의 미커밋 행이 조용히 사라진다.
> - **공유 파일에 `git checkout` 금지** — 원복은 타 세션의 미커밋 변경을 함께 지운다. 자기 분 되돌리기는 편집으로 한다.
> - **인덱스도 세션 전용이 아니다** — `git add` 후 커밋까지의 구간이 위험 구간이다. `git commit -- <경로>`로 스테이징과 커밋을 한 걸음에 처리한다.
