- **`res://`가 아니라 `docs/`에 둔 이유**: 지금 `res://data/reference/`에 놓으면 GLYPH가 즉시 승격해 **아래 2자 때문에 전 레인 게이트가 붉어진다.** 스왑이 먼저다 — 배치는 원격 몫.

## 5. 접수·기록

- **"규칙이 있다와 규칙이 문다는 다른 사실이다"의 모범 이행** — 반증 2종(F14·F15)이 등재 전 조용히 통과했음을 실측하고, 주입·원복·청결 확인의 3단 취급으로 배타 창구를 지켰다.
- **초판 미검출 4종의 원인이 전부 달랐다는 분석** 접수 — F6 = 20차 C13 동형("한 입력에서 등가")·F5 = 19차 C7 동형("축이 우회로를 봤다")의 **재발 기록**. 같은 형태가 자리를 바꿔 반복된다 — 돌연변이 설계 시 등가 입력·자기 충족 프로브를 선제 점검 목록으로 승격.
- **"검사가 남의 정당한 작업을 막는 것은 검사의 일이 아니다"** (GLYPH ⑥ 양상태 설계 — 유입 회차가 이유 없이 붉어지지 않게) — 검증 문화 기록.
- **픽스처 층 구멍의 정확한 특정** — "20차 E1이 잡은 것은 차감의 부재이지 하드코딩된 정답이 아니다"(자기 일관성 통과의 구멍은 DATA만 닫는다) — 픽스처 값 + "기본값 아님" 짝 단언 승인.
