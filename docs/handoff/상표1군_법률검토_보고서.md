## 2. TM-1c 'Grid' — 유일한 중간 위험의 해부

1. **관할 구조가 일본과 3관할에서 반대다.** 일본 = 단독어 소멸·복합표장만 생존(부제 종속요소 지위가 유리). EU·UK·US = **EA가 단독어 GRID 워드마크를 생존·갱신 보유**(EUTM 006458475 [만료 2027-11-22·이의 0건·2021 Codemasters→EA 이전] · UK 2건[국내 등록 9류 = **"car racing" 한정 — 우리 장르 정면 포착**] · US 3712611/4023030 REGISTERED AND RENEWED).
2. **항변 성립성:** UK 중간~중상(Johnstone origin-function 관문 + **Mothercare 표제 선례 계보** — 3관할 중 유일한 직접 계보) > EU 중간(Gerolsteiner "혼동 존재 ≠ 항변 실패" / **Medion "독립적 식별 역할" = 최대 위험** — 반론 = 'Spin the Grid'는 명사 병치가 아니라 문장형 어구로 Grid를 목적어로 흡수) > US 낮음(Punchbowl II — 게임 제목 = 출처 표시라 Rogers 배제. 실질 방어선 = **전체 표장 비유사에 기한 혼동 부정** + KP Permanent 부담 배분).
3. **세 관할의 결정 지점이 한 사실에 수렴한다: 'Grid'가 얼마나 독립적·현저하게 표시되는가** — Medion(EU)·"as a mark"(US)·Hearst 현저성(UK). **이것은 우리가 통제하는 변수다** → §3 규율 1·3·4.
4. **집행 실측:** EA는 GRID 출원을 감시하나(TTAB 연장 신청 실재) **실제 이의 제기 0건**(THE GRID ESPORTS 등록 방치). Steam에 제3자 단독어 `GRID` 페이지 실재·'grid' 표제 1,115건 혼잡·상표 사유 개명 사례 0(부재 증명 아님). **단 스토어 리스크는 별개다**: Hidden Cats 모델(등록번호 + 신고 폼 → Valve "개명 아니면 삭제"·유효성 무심사) · Praey for the Gods(대형 권리자에게 이의는 권리 유지 의무 — 과거 미집행 ≠ 미래 미집행) · EDGE(권리자가 최종 패소해도 개발자는 삭제·3회 개명·17년 소송).
5. **결론: "이길 수 있는 사건이지만, 싸울 필요가 없는 사건으로 만드는 것이 압도적으로 싸다."** 부제 유지는 방어 가능하되 §3 규율 1~4 + 개명 컨틴전시(예비 점검 §6 후보 3안 — Race the Reels·Spin the Circuit·Spin the Season, 전 후보 미점검 상태 유지)가 동시 집행될 때만 성립하는 결론이다. 기존 사용자 판정(2026-08-23 — 현행 유지·법률 검토 1순위·후보 대기)은 본 검토로 그 조건이 구체화된 채 유지된다.
