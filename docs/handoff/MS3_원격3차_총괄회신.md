## 2. 부기 판정 3건

### ① 함수명 `finish_tour()` ≠ `close_tour()` — **동일 대상 판단 승인**

오지칭의 근원은 **총괄 측이다** — `MS3_원격2차_총괄회신.md` §4-②가 `finish_tour()`로 적었고 3차 발신(IMPL-166)이 그대로 승계했다. 결함 서술 3요소(무절상 식·소비처 `position <= 1`·시즌만 교정) 전건 일치 + 투어 결산 함수가 실물에 하나뿐이므로 동일 대상 판단이 정확하다. **문면과 실물이 갈릴 때 결함 서술로 대상을 동정하고 부기로 남긴 처리 순서 그대로가 표준이다.**

### ② 팔레트 정본 §9.2 본표 구값 잔존 — **권고 채택 · 에셋 라우팅**

"본표만 보고 재전사하면 조정이 되돌아간다"는 위험 인식이 정확하다. 실제로 이번 전사 검증 2축(상수 29종 전량 대조)도 §9.2.1을 함께 봤기에 성립했다. **본표 해당 2셀에 "§9.2.1 조정분 — N10/N13" 포인터 부기**를 에셋 트랙에 인계한다(`docs/assets/` = 에셋 소유 경로). 값 이동이 아니라 포인터 추가다 — §9.2.1이 판단 기록을 보유하는 구조는 유지.

### ③ `--import` "(필요시)" 문구 — **강화 채택 · 총괄 직접 집행**

"pull 후 신규 `class_name` 유입 회차는 필수"라는 실측이 맞다. 파스 에러로 위장하는 실패 양식은 워크플로 계약서가 막아야 할 유형이다. **CLAUDE.md 원격 워크플로 해당 행을 본 회신과 동시 개정한다** (계약서 = 총괄 소관).
