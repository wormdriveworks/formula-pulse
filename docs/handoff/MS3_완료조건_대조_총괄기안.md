## 2. 경계 사안 2건 — 판정 요청

### 사안 1 — 인게임 스킬 소비부 (MS-3 편입 여부)

D15 §1.1 문면(5무대·20서킷·4막·에필로그)에는 **없다.** 그러나:
- **D05 §T4 개입 창의 명문 요소다** — "홀드·리스핀 / **스킬** / 펄스 차지 투입 또는 확정" · §5.5 "스킬 사용: 장착 스킬의 개입 효과 발동(§6.1)" · §6.1 "스킬은 개입 4타입의 데이터 인스턴스".
- 현재: 덱·티어 개방(HUB-04)·스킬 16종 데이터 = 완결. **RACE-01 5슬롯 = 상시 `disabled`·소비부 0** ("활성화 경로가 아직 없다" — `race_screen.gd:416` 주석·`CLICK_EXEMPT` 면제 5건).
- EA는 "전 콘텐츠 탑재 진입"(D15 §2.1)인데 스킬이 레이스에서 못 쓰이면 **D07 16종·덱 시설이 장식**이 된다. 아웃게임(수집·장착)만 있고 인게임(발동)이 없는 반쪽이다.
- 결선하면 동시 해소 3건: TL-5 Convert 행(§8.3 ③ 미측정분) · `CLICK_EXEMPT` 5건 축소(IMPL-302 결속) · 코어 루프 문면 완결.

**총괄 권고 = MS-3 편입·차기 발주** (원격 = 엔진 API·소비 경로·검사 / 주력 = 슬롯 UI 활성·실기).

## 3. 실측 2건 (본 대조 회차 신규)

- **Galmuri 일본어 커버리지 (cmap 직접 파싱):** 히라가나 86/86 · 가타카나 90/90 · 반복 부호 4/4 · CJK 한자 약 6,400자 — **가나 완전.** 단 **Galmuri14만 가나 결자 7**(히라 3·가타 4 — 사용처가 표제 층이면 접촉 가능). 상용한자 2,136 전수 포함 여부는 목록 대조가 필요하나, **실제 요구는 ja 스트링이 실제로 쓰는 글자의 커버**이므로 번역 유입 시 스트링×cmap 기계 대조가 정답이다 — **글리프 커버리지 검사 신설 후보**(현행 FONT 검사는 크기 창구 전속·커버리지 축 없음. 차단/경고 성격 = 총괄 판정 경유 원칙).
- **스토어 소재 실물 0:** `godot/assets/store/` 미존재 (디렉토리 계약상 예정 위치만 있음).

## 4. 의존 그래프 — 크리티컬 패스 = 이미지

```
이미지 B급 80 (수작업 주역 — 최장) ─→ 완급 비트·L3 컷인 재생 결선 ─→ TL-5 ① 재측정
이미지 A급 129 (RD 파이프라인) ─→ 화자 초상·배지 + 전 화면 실물 교체 ─→ 스토어 스크린샷·키 비주얼 ─→ ⑥ 스토어
번역 en·ja (외부 입력) ─→ 커버리지 검사 ─→ ③ G-4
상표 1군 예비 점검 (독립 — 즉시 가능) ─→ 법률 검토 ─→ ⑥ 상표
스킬 소비부 (독립 코드 트랙) ─→ TL-5 Convert 행 + CLICK_EXEMPT 축소
실물 플레이 검증 회차 (독립 — 주력) ─→ 이월 실기 대장 소거
                                    (전건 합류) ─→ ④ G-6·⑤ G-7 (직전 실행) ─→ MS-3 마감
```

kickoff의 통찰("크리티컬 패스는 콘텐츠 완결")의 현재형이다 — **이미지가 T6 잔여·TL-5 재측정·스토어 준비물 세 갈래의 공통 전제**이므로 이미지 발주 재개가 최우선이고, 나머지 독립 트랙(스킬·상표·실기·번역)은 전부 병행 가능하다.
