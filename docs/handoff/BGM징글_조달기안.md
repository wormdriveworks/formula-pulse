## 1. 발주 명세 — 정본이 이미 확정해 두었다

### 1.1 징글 5식 (트랙 계상 외 — D11 결정 #5)

| 파일 | 용도 | 성격 |
|---|---|---|
| `jg_01` / `jg_02` | GP 리절트 인 (상위 / 중하위) | **성과의 온도를 징글이 전담**(BGM-08은 담백) — 둘의 온도차가 본체 |
| `jg_03` | 리타이어 | BGM 즉시 정지 후 재생(D11 §4.3 전이표) |
| `jg_04` | 시즌 챔피언 | 메인 모티프 인용 여지(BGM-01·12 계열) |
| `jg_05` | 칭호·특별 달성 | — |

- 수초 단곡·멜로디 시퀀스(제작 단위가 SFX급 — D11 명문). 포맷 = **WAV/PCM 44.1kHz 16bit** ([가안] §9-② — SFX 버스 귀속·덕킹 주체라 SFX 포맷 준용, 유지).
- **에셋 실측(IMPL-260): 현행 도구로 즉시 가능** — `compose`(다단 합성)가 이미 있어 짧은 음정렬을 낼 수 있다. `se_u18`(스타트 시그널 3+1 음정렬)이 그 실증이다.

### 1.2 BGM 13트랙 = 18스템 + 예비 1 (D11 §4 · D12 §10.1)

- **규격**: OGG Vorbis 44.1kHz ~q0.7 · **심리스 루프 필수** · 길이 90~150초 · 레이스 5무대 = **A/B 2스템(동일 길이·동일 템포·박 동기 — B = A 위 가산 스템)**.
- **작곡 지침은 정본에 있다**: 무대별 무드 5종(D11 §4.2 — 네온 신스 업템포/하이스피드 그루브/미니멀 타이트/무겁고 건조한 저음/총화 최대 강도), 메인 모티프 원형(BGM-01)→진엔딩 회귀(BGM-12), VN 2정조, 32비트 문법(샘플 기반 — D11 §1.1), 금지(실사·오케스트라·라우드니스 전쟁).
- **재생기 수용부**: 17차(사운드 결선) 완료 시 파일만 오면 울리는 구조(무음 폴백 → 자동 활성).

## 2. 조달 경로 — 두 축의 성격이 다르다

### 2.1 징글 = 도구 생성 연장 (권고 — 결정 여지 작음)

SFX 파이프라인(jsfxr + compose·파라미터 커밋·결정성)의 연장. **파일럿 불요 — 5식 일괄 생성 → 사용자 청취 관문**(SFX 전례). 담당 = 에셋 트랙. 유의: jg_04의 모티프는 BGM-01 확정 전이므로 **모티프 선율 3~5음을 징글 회차에서 [가안] 확정**하고 BGM-01이 그것을 승계한다(역방향 금지 — 모티프의 원장은 한 곳).

### 2.2 BGM = 파일럿 1트랙 검증이 선행돼야 한다

sfxr 밖의 영역(멜로디·화성·믹스·심리스 루프·스템 동기). 선택지:

| 안 | 경로 | 평가 |
|---|---|---|
| **A (권고)** | **절차 합성 파이프라인 파일럿** — 시퀀서(BPM 그리드·패턴)+신시사이저(샘플 기반 합성)+믹서를 `tools/audio/`에 구축, **BGM-02(개러지) 1트랙 파일럿** → 귀 판정 → 확대/전환 | 재현성 계약 유지(파라미터·시드 커밋)·비용 0. **루프·A/B 박 동기는 절차 생성이 구조적으로 정확**(같은 그리드에서 스템 2벌 믹스다운 = 어긋날 수 없음). 위험 = 32비트 문법의 품질이 도구 한계에 걸릴 수 있음 — 그래서 파일럿. 실패해도 명세·무드 번역이 외주 발주서로 재활용된다 |
| B | 외주·사용자 조달 | 품질 확실·비용 발생. 총괄은 발주서(§1.2 + 무드 번역)만 공급. 루프·스템 동기 요건을 계약 문면에 명시해야 함 |
| C | AI 음악 생성(Suno 등) | 무드는 낼 수 있으나 **심리스 루프·A/B 스템 분리·박 동기 보증이 없다** — 후가공(루프 지점 수술·스템 근사 분리)이 사람 손이라 A/B의 단점을 합친 형태. 비권고 |

**A의 선행 조건 1건**: 원격 서버에 **OGG 인코더가 없다**(ffmpeg·oggenc 부재 — 총괄 실측). 파일럿 1단계 = 인코더 확보 — `vorbis-tools`(oggenc) 또는 `ffmpeg` **시스템 설치(사용자 승인 필요)** + 버전을 PROVENANCE에 기록(벤더 계약 준용). 설치 불가 시 WAV 마스터 생성 → 인코딩만 주력 머신 위임의 이원 경로가 대안.

### 2.3 순서 권고

**징글 5식 선행**(즉시 가능·jg_04에서 모티프 [가안] 확정 — BGM-01의 입력이 된다) → **BGM 파일럿 1트랙**(경로 A 승인 시) → 귀 판정 → 잔여 12트랙(17스템) 확대. 전 회차 에셋 트랙 담당·`tools/audio/` 소유 경로 내.

## 3. 검수 체계 (승인 시 발주서에 기재)

- **기계 축**: OGG 규격(샘플레이트·q)·길이 90~150s·**A/B 길이 샘플 단위 일치**·루프 임포트 설정 **런타임 되읽기 확증**(WAV `loop_mode` 함정 전례 — OGG 임포터에도 동형 함정 가정하고 실증)·AUD/AUDIO-A 확장.
- **귀 축**: 사용자 청취(무드 정합·루프 이음매·A/B 가산 자연스러움) — 트랙 단위 관문.

## 4. 판정 요청 (사용자)

① 징글 = 도구 생성 5식 일괄(§2.1) ② BGM 경로(§2.2 A/B/C) ③ A 채택 시 인코더 시스템 설치 승인.

## 5. 승인·발효 (2026-08-20 사용자 결정 — 권고 3건 전건 채택)

**① 징글 = 도구 생성 5식 일괄 · ② BGM = 절차 합성 파일럿(A) · ③ 인코더 설치 승인.** 이하 = 에셋 트랙 발주 명세 (2회차 순차).

### 5.1 회차 1 — 징글 5식

- `jg_01`~`jg_05` WAV/PCM 44.1kHz 16bit 모노 · `godot/assets/audio/jingle/` · LFS·`.import`(**신규 경로 첫 파일 — `csv_translation` 함정 계열 주의: WAV는 해당 없음이나 임포트 설정 행 단위 대조 관례 유지**).
- `compose` 다단 합성 — 음정렬·화음은 파라미터 커밋(재현 계약). D11 결속: jg_01/02 = **온도차가 본체**(상위 = 밝은 상승 종지 / 중하위 = 담백 — 실패 정서 배제 D09 §5.1 결) · jg_03 = 하강 단결(BGM 정지 후 단독 재생 전제) · jg_04 = **메인 모티프 선율 [가안] 확정 동반**(3~5음 — BGM-01 승계 원장·`tools/audio/`에 모티프 정의 커밋) · jg_05 = 짧은 팡파르.
- 기계 검증: AUD·AUDIO-A 징글 5행 확장(파일명 대장·헤더·`sound_map` `jingle` 채널 정합) · deadParams 통과.
- 완료 후 **사용자 청취 관문**(5식 + 모티프 [가안] 승인).

### 5.2 회차 2 — BGM 파일럿 (BGM-02 개러지 1트랙)

1. **인코더 확보** — `vorbis-tools`(oggenc) 우선·불가 시 ffmpeg. sudo 필요 시 설치 명령을 회신에 적고 사용자 실행(`!` 프리픽스) 대기. 버전 = PROVENANCE 기록.
2. **파이프라인 구축**(`tools/audio/` — 시퀀서 BPM 그리드·샘플 기반 신시사이저·믹서 → PCM 마스터 → OGG q0.7). 파라미터·시드 커밋 = 재현 계약. 결정성 2회 생성 대조.
3. **BGM-02 생성** — 90~150초 심리스 루프(그리드 정수배 = 구조적 보장) · D11 §4.2 무드("일상·정비의 온기 — 룸톤 공존 설계") · 32비트 문법 · 금지 3종 준수.
4. **루프 임포트 실증** — OGG 임포터 루프 설정 **런타임 되읽기 확증**(WAV `loop_mode` 함정 동형 가정).
5. 완료 후 **사용자 귀 판정** = 잔여 12트랙(17스템 — A/B 포함) 확대 트리거. 미달 시 외주 전환(명세 재활용).
