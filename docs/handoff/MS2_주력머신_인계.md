## 0. 시작 절차 (매번)

```powershell
git pull
& "C:\SDKs\godot\Godot_v4.7.1-stable_win64_console.exe" --headless --import   # pull 후 1회
& "C:\SDKs\godot\Godot_v4.7.1-stable_win64_console.exe" --headless --path . --script tools/validators/run_validators.gd
bash tools/validators/run_tests.sh    # 또는 각 테스트를 console.exe로 개별 실행
```

- **CLI는 예외 없이 `_console.exe`.** GUI exe는 stdout을 셸에 반환하지 않아 `--check-only` 에러·검증기 결과·테스트 PASS/FAIL이 전부 소실된다(IMPL-005 실측).
- 기대 출력: `VALIDATORS_PASS warnings=0` · `TESTS_PASS suites=4`.
- 하나라도 깨져 있으면 **먼저 고치고 보고.** MS-2 작업을 그 위에 올리지 않는다.

## 2. 주력 머신 몫 — 작업 목록

### 2.1 D09 실화면 구현 (씬 소유권)

- **`.tscn` 구조의 소유권은 이 머신에 있다.** 원격 MCP가 만든 `.tscn`은 비표준 최소 포맷이라 에디터가 재정규화하며 디프가 튄다 — 그래서 원격은 씬을 만들지 않았다.
- 대상: `godot/ui/debug_race.gd`·`.tscn`(MS-1 최소 골격)을 **D09 §8.1 화면 대장의 실화면으로 대체.** 레이스 4존·개입 창·중계 로그 존을 실규격으로.
- **세이브는 `SaveManager` 경유로 한다.** 디버그 UI가 `SaveService`를 평면 경로로 직접 불러 프로필 분리·백업 회전·마이그레이션을 전부 우회하던 것을 이번에 결선했다(IMPL-037). 실화면에서 다시 `SaveService`를 직접 부르면 같은 우회가 재발한다.
- 대체 시 함께 정리할 이월 2건:
  - **§0.2-9 UI 레이아웃 수치** — `debug_race.gd`의 separation 8/12/16·font_size 28은 MS-1 임시값이다. D09/D10 값으로 교체한다.
  - **§0.2-8 리스핀 후 즉시 공개** — `_show_provisional_now()`가 정지 간격 없이 갱신한다. 개입 창 내라 정보 누출은 아니지만 정지 연출 규격이 아니다. TC-C11 하네스를 실화면에 물릴 때 함께 정리.
- 표시 문자열은 **전량 스트링 키**다. V4가 확대돼 `.text`에 리터럴을 넣으면 한글이 아니어도 빌드가 막힌다(IMPL-027) — 서식 문자열도 키로 옮긴다(`ui.debug.timerFormat` 전례).

### 2.2 아트 투입 (D10)

### 2.5 export preset 자격증명 종단 확인 (IMPL-017 이월)

- 경로 실측은 끝났다: 4.7 엔진의 자격증명 저장 경로 = `res://.godot/export_credentials.cfg` → `.gitignore`의 `.godot/`로 이미 차단.
- **남은 것:** 에디터 익스포트 다이얼로그에서 preset 1개를 실제로 만들고, 서명 정보가 `export_presets.cfg` **본체에 평문으로 들어가지 않는지** 눈으로 확인. 헤드리스 에디터는 preset 미변경 시 재저장하지 않아 원격에서 닫을 수 없다.
- 평문이 들어간다면 **A안 폐기 → C안(템플릿 커밋 + 빌드 시 주입)으로 후퇴**하고 보고한다.

### 2.6 디버그 UI 실제 플레이 눈 검증

원격은 컴파일·헤드리스 부팅·로직 관통까지만 검증했다. 실제 플레이에서 봉인(릴 정지 전 결과 노출)·타이머·개입 창의 체감을 확인한다.

## 4. 사용자 판정 대기 — 작업 전 확인 필요

**RB-1 (독립 검증 제기):** 부속성이 **규칙 계수**(섀시 ×1.15 · 게이지 ×1.5)에도 ½로 작용하는지. 현 구현은 ½ 적용(IMPL-022 [가안])이고, 독립 레인은 **미적용**이 문면에 더 부합한다고 반론했습니다 — ①D13 별첨A §1.3의 ½ 문장은 목적어가 '기본 분포·재정규화'로 확률 열에 한정 ②곱 적용 항 열거(배틀존 ×1.5 · 최종 랩 ×1.2 = **최대 ×1.8**)에 부속성 항이 없음 ③½ 독법은 주·부가 같은 속성일 때 1.875로 그 상한과 충돌. 판정이 바뀌면 **mn2 s4·mn3 s4의 게이지 계수가 1.25 → 1.0**으로 변합니다(밸런스 직접 영향). 그때까지 ×1.8 초과는 전 서킷 전 섹터 검사로 봉인해 두었습니다.

**U-4 (impl_log):** 슬롯 진행 보정의 '투어 슬롯'이 D13 별첨A §6.2(4항: +0.00/+0.05/+0.10/+0.15)와 D08 §2.3(투어 1~5)에서 갈린다. 판정 전까지 AI 5층 합성에서 **슬롯 진행 보정 층은 미배선(0)** 이다. 무대 1이 직접 영향권이므로(투어 인덱스 독법이면 +0.00, GP 슬롯 독법이면 서킷마다 다름) 밸런스 체감 판단을 이 층 위에서 하면 나중에 뒤집힌다.

## 5. 커밋 규칙 (재확인)

- 커밋한다: `.gd` `.tscn` `.tres` `project.godot` `*.uid` 에셋과 `.import`
- 커밋 안 한다: `.godot/` `.mcp/` `.omc/`
- 작업 시작 전 `git pull`, 끝나면 커밋·푸시. 두 머신이 같은 브랜치를 오간다.
- 커밋 전 `VALIDATORS_PASS warnings=0` + `TESTS_PASS`를 **종료코드로** 확인한다. 파이프(`| tail`)를 걸면 종료코드가 가려진다 — 실제로 그렇게 실패 상태를 커밋한 사례가 있다.
