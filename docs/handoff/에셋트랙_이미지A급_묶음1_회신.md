## 2. 정본 대조 — 발견 4건 (전건 실측)

### ⓐ D10 §5.5 C-B2 = "2종 외 화자 아이콘 신설 금지"

```
D10 §5.5 화자 아이콘 2종 (C-B1~B3 이행)
  | 중계 마이크      | 방송 마이크 실루엣 (인물 요소 0) |
  | 필러 공용 헬멧   | 제네릭 헬멧 실루엣 (…) |
  **C-B2 수량 고정: 2종 외 화자 아이콘 신설 금지.
    C-B3 분류: 본 2종은 'UI 아이콘 트랙'이며 인물 스탠딩 트랙이 아니다** (마스터플랜 P-5-⑤ 이행)

D10 §8 대장:  UI 아이콘 = 심볼 6 + 속성 6 + 재화·상태 3 + **화자 2** + 저장·시스템 4 = 21종
사양서 §6.5 제목: 화자 2종 (C-B1~B3 — **수량 고정·신설 금지**)
```

C-B3 이 두 아이콘을 *"인물 스탠딩 트랙이 아니다"* 로 갈라 둔 것은 **나머지 2종이 그쪽이라는 뜻**이고, 실제로 `log_feed.gd` 가 이미 그렇게 적어 두었다:

```gdscript
# 화자 → 도상. **4종 중 2종만 실물이 있다** — `CREW`(크루 미니 초상)·`RIVAL`(카 넘버 배지)는
# D09 §3.3 이 아이콘이 아니라 **초상·배지**로 규정한 축이라 A-UI 아이콘 27종에 애초에 없다.
```

즉 **결손은 아이콘 27종의 미완이 아니라, 계상 자체의 공백**이다. 아이콘 트랙에 `speaker_crew_16.png`·`speaker_rival_16.png` 를 넣으면 그 순간 C-B2 위반이 된다 — 파일명·디렉토리·매니페스트가 전부 그 트랙이다.

> C-B2 를 형식 조항으로 볼 수 없는 근거: D04 결정 로그(2026-07-19)가 R11·R12 의 목적을 *"봉인 규칙 2의 텍스트 층위 보장 + **D10 아트 수량 통제**"* 로 명문한다. **수량 통제가 조항의 취지 자체**다.

### ⓑ A급 129 검산 — 화자 표지 2종은 그 안에 없다

```
프레임 25 + 글리프 20 + 캐릭터 47 + 머신 37 = 129   ← 기안 §4 "이미지 A급 129" 와 일치
아이콘 27 = 유입 완료(별도) · 플랫폼 6 = 별항
```

발주는 화자 표지 2종을 A급 소화분 1순위로 잡았으나 **129 의 어느 항에도 대응하지 않는다.** 계수에 없는 것을 소화할 수는 없다.

### ⓒ 초상 파생 경로가 16px 에서 성립하지 않는다 — 2중으로

정본이 초상 미니에 정한 경로는 파생이다:

```
사양서 §10 (AI 생성 비대상):
  | 네임드 초상 미니 (RACE-02 대치 표기) | 스탠딩 아트 얼굴 영역 크롭/축소 파생 — 신규 원도 0 |
사양서 §3.1: 스탠딩 원도 180×240 · **얼굴 레이어 영역 112×112** (확정 기준값)
```

| 축 | 실측 | 판정 |
|---|---|---|
| 축소비 | 얼굴 112 → 표지 16 = **7:1** | §6.8.3 이 **2:1 축소를 실측 기각**했다(`achv_career` 월계관 통째 소멸 · `currency_credit` 실루엣 붕괴). 7:1 은 출력 1픽셀이 입력 49픽셀 중 1을 고른다 — 논할 여지가 없다 |
| 입력 실재 | `ls godot/assets/characters \| wc -l` → **0** | **파생의 입력이 아예 없다.** 크루 스탠딩 5시트는 A급 129(캐릭터 47) 안이고 이 발주의 **우선순위 3** 이다 |

즉 크루 초상은 ⓘ 우선순위 3(캐릭터 47)이 먼저 서야 하고 ⓘⓘ 서더라도 7:1 파생은 못 쓴다. **16px 표지는 손 작화 신설이 유일 경로**이며, 그것이 곧 ⓐ 의 판정 사안이다.

### ⓓ 카 넘버 배지 — 미계상 + 1파일로 표현 불가

D09 §3.3 은 위계를 이렇게 둔다: **초상(크루) > 넘버 배지(네임드) > 공용 헬멧(필러)** — *"도상 위계가 D03 §2.1 인물 위계를 자연 표현"*. 그런데

- **네임드 8인 카 넘버 = 1 · 2 · 18 · 81 · 5 · 51 · 24 · 77** (D03 결정 #13 — 로렌츠 1 · 마로 2 · 디아스 18 · 볼코바 81 · 홀로웨이 5 · 비앙카 51 · 카이 24 · 주드 77)
- 한 장의 배지로는 8 을 담을 수 없다. **번호가 없는 배지는 위계의 담지자가 못 된다** — 필러가 이미 *"공용 헬멧 + 카 넘버"* 로 번호를 텍스트에 두고 있어, 배지도 번호를 텍스트에 넘기면 **두 화자의 표기 구조가 같아진다.**
- D10·사양서 어느 표에도 배지 항목이 없다 → **진성 미계상**(업적 6종과 같은 성격).

## 3. 시안 — 판정에 픽셀을 붙인다

**원격은 화면을 못 보므로 도상 판정에는 PNG 실물이 필요하다.** 그래서 유입 없이 보이게 하는 경로를 만들었다.

```
원장   tools/assets/icon_art_proposal.json     (icon_art.json 과 별 파일)
산출   docs/assets/시안/*.png                  (godot/assets/ui/icons/ 와 별 경로)
명령   node tools/assets/icon_draw.js --proposal
대조   node tools/assets/icon_draw.js --proposal --check   → ICON_DRAW_PROPOSAL PASS icons=4
```

> **왜 원장을 갈랐는가.** `icon_art.json` 은 `icon_draw.js` 가 아이콘 디렉토리로 파생시키는 **유입 원장**이다 — 판정 대기 도상을 거기 적으면 그 줄을 쓴 순간 실물이 트랙에 들어가고 매니페스트 계상이 따라온다. `--proposal` 은 아이콘 디렉토리를 **열지도 않는다.**
>
> **부수로 미지 플래그를 거부하게 했다.** `bgm_gen.js --only`(그 도구에 없는 플래그)가 조용히 무시돼 실물 18개를 덮은 사고(IMPL-280)의 기제가 이 도구에도 그대로 있었고, **여기서는 오타 하나가 시안을 유입으로 번지게 한다.** 파일을 쓰는 도구는 "몰랐으면 안 쓴다"가 맞다.
> ```
> $ node tools/assets/icon_draw.js --proposals
> FATAL: 미지의 플래그 --proposals — 알려진 것은 --check --proposal   (exit 2)
> ```

**판면을 N16(11.09:1)에서 N14(7.11:1)로 내린 것이 판단이다.** 164px 짜리 판이 98px 짜리 얼굴(11.24:1)과 같은 밝기면 피드에서 배지가 초상보다 크게 읽혀 **D09 §3.3 의 위계가 광량에서 뒤집힌다.** N14 에서는 얼굴 밑·필러 위에 정확히 앉고 판 위 번호 대비도 9px 텍스트 문턱(4.5:1)을 넉넉히 넘는다.
**초상만 피부색을 쓰는 것도 같은 축이다** — 0.1초 판독(D09 §6.6)에서는 형태보다 색이 먼저 잡히므로, 피부 계열을 쓰는 도상이 피드에 하나뿐인 것이 위계의 기계적 근거가 된다.

> **MT3 무광 오프화이트(`#E4E0D8`)를 쓰지 않은 것도 판단이다** — D10 §3.2 가 그 색을 **주인공 헬멧**에 확정 배정하고 팀 컬러와 독립이라고 못 박았다. 라이벌 배지가 주인공의 서명색을 빌릴 수 없다.

### 3.3 시안 제작 중 자체 교정 2건 — 실측·판독이 잡았다

| # | 초판 | 실측 | 교정 |
|---|---|---|---|
| ⓐ | 머리 = N04 `#1C222A` (검은 머리) | 바탕 대비 **1.08:1** — 18px 머리 덩이가 화면에 통째로 녹는다 | **N11 `#6A737E` (3.60:1)**. 16px 초상에서 머리는 윤곽선이 아니라 **실루엣의 상단 질량**이라 사라지면 얼굴만 떠 있는 도상이 된다. 필러의 어두운 윤곽(1.34:1)은 성격이 다르다 — **밝은 이웃과 갈라 주는 선이고 질량이 아니다.** 뉴트럴을 고른 것도 판단이다: 크루 5인의 머리는 회색 묶음·부스스·헝클어짐·단정·쇼트헤어로 갈리고, **제네릭 표지가 특정인의 머리색을 고르면 이름 라벨과 어긋난다** |
| ⓑ | 볼·턱 SK2 음영 10px | ×10 확대 판독에서 **짧은 수염으로 읽혔다** | **음영 소거 · 목 2px 만 남김.** 크루 5인 중 **3인(마르타·나디아·사샤)이 여성**이므로 제네릭 표지가 성별을 특정하는 것은 머리색을 특정하는 것과 같은 결함이다. 16px 에서 얼굴 음영은 모델링이 아니라 **우연한 형상**을 만든다 — 평면 피부 + 실루엣 좁힘으로 턱을 지게 했다 |

> **헤드셋을 얹지 않은 것은 의도다.** 피트 무전이니 헤드셋이 기능을 직설한다는 유혹이 있으나, 16px 에서 머리를 가로지르는 띠는 **헬멧 끈으로 읽혀 `speaker_filler_16`(정면 헬멧)에 가까워진다** — 무전을 표시하려다 위계를 지운다. 무전은 자리(피드)가 이미 말한다.

### 3.4 배지 2안 대조

**에셋 소견 = ⓑ 권고.** 8종은 수량이지 구조가 아니다 — 숫자 6자 원도로 조합되므로 `icon_art_proposal.json` 의 맵 생성이 기계적이고, ⓐ 는 *"배지를 두었는데 배지가 아무것도 식별하지 않는다"* 는 상태로 남는다. 다만 **수량 8 은 C-B2 의 취지(아트 수량 통제)와 정면으로 만나는 지점**이라 에셋이 정할 사안이 아니다.

## 4. 벽두 소건 — `sys_save.png` 보류 존치 전사 (IMPL-294 ③)

| 산출 | 내용 |
|---|---|
| 대장 §4.1 행 | `sys_save.png` → *"저장 (정지 표기 — **보류 존치**, §4.1.2 부기)"* |
| 대장 §4.1.2 부기 | 근거 2건 + 상태 기호 판단 |
| `icon_manifest.json` | `sys_save.png` `reason` 에 판정 전사 |

**폐기가 아니라 보류인 근거 2건:**
ⓐ **원도는 재파생의 출발점이다.** 참조 0 은 "파일이 틀렸다"가 아니라 "지금 아무도 부르지 않는다"이고, 지우면 다음 재작화가 32px 도상을 처음부터 다시 만들어야 한다. **`attr_hazard.png` 가 소비부 0 상태에서 두 회차(IMPL-230·234)에 걸쳐 재파생 출발점으로 쓰였고**, 그 회차 총괄 채택 근거가 정확히 *"이 파일의 역할은 재파생의 출발점"* 이었다(§9-⑭ ⓑ).
ⓑ **정지 표기 용도가 대기 중이다.** D09 §181 은 저장 표시를 *"아이콘 + 회전 애니메이션"* 으로 규정하고, 정지 표기와 회전체의 분리 여부는 화면 층에 열린 판단이다.

**상태 기호는 ✅ 유지 — 🔒 로 내리지 않았다.** 🔒 는 범례가 *"파일 불요 — 런타임 렌더·파생·미채택"* 이고 이 건은 **대기**다. 부수로 매니페스트 선언도 함께 남긴다: **선언을 지우면 실물이 유령 파일이 되고 실물을 지우면 선언이 유령 선언으로 걸린다**(`icon_check` SEP 축) — 둘은 함께 있어야 검사가 성립한다.
