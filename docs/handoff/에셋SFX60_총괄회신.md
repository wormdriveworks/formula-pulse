## 3. 접수·기록

- **검사 2층 분리 가감 = 승인.** "run_validators는 프로젝트리스 실행이라 루프 런타임 축이 원리적으로 불가" — 발주 문면("run_validators 편입")을 실행 모델 실측으로 이긴 정당한 가감. **양방향 한계 실측**(되읽기는 파일 부재를 못 본다 — 임포트 캐시가 적재를 성공시킨다)과 축 2 가산(파라미터 미등재·표 밖 잉여)까지 — AUD(파일·선언 821) / AUDIO-A(임포트 결과 350·차단·하한 340) 구조 기록.
- **자수 ⓐ 하드 클리핑 6식** — 원인 규정("`sound_vol`은 `exp(v)-1` 게인 — 값과 체감이 비선형") + **목표 dBFS 이분법 역산**(클리핑 0 동시 요구) 18식 재조정 = **"값으로 짐작하지 않고 목표에서 역산한다" 기록.**
- **자수 ⓑ 미발화 6건** — `se_u02`/`u03`(방향 반전 쌍)이 같은 파일이 되는 사고 포함 5건 수정 + `deadParams` 검사 신설. **r04 때문에 경고형으로 둔 판단**(차단이면 귀 승인 실물이 게이트를 막는다) = 절차 정합 승인 — ① 집행으로 그 사유가 소멸하므로 소회차에서 재판단.
- **발주 문면 정정 접수 — 총괄 오기 자인**: 잡음 첫 실작동 구간 = AMB가 아니라 **E군**(슬립스트림·브레이킹·접촉 = 잡음 필수 · 총 11식). 발주가 대장 §5.1의 군 내용을 실독하지 않고 "AMB = 앰비언스 = 노이즈"로 유형 추정했다.
- 함정 등재 2건(`.import` 되돌려도 재임포트 안 됨 — 캐시 축 · 파일럿 비루프 7식 선언 명시화) · `compose` 신설(포락선 1벌 한계) · `sfx_import_probe.gd` 제거(항구 검사 대체 — 예고분 정리) 접수.
