## 1. 코어 뉴트럴 16

순회색이 아니라 **청 기미**를 넣었다 — 야간이 이 게임의 기본 조명 조건이고(D10 §1.1 "야간 네온"), 중성 회색은 주간·실내로 읽힌다. 고밀도 디더링(VA-11급)이 성립하려면 단 간격이 고를수록 좋으므로 **연속 띠에서 턱이 지는 구간이 없는지**가 이 블록의 합격선이다.

## 2. 텔레메트리 네온 12

## 3. 팀 컬러 16

각 팀의 **정본 정성 표기를 만족하는지**가 합격선이다.

| 팀 | 정본 표기 | 4색 |
|---|---|---|
| 악시온 다이내믹스 | 백 × 청 (D03 §2.2) | `#0B2A5E` 음영 / `#1E5BC6` 팀 블루 / `#6FA8FF` 하이라이트 / `#EEF3FA` 보디 백 |
| 불카 헤비 인더스트리 | 흑 × 주황 (D03 §2.2) | `#141009` 보디 흑 / `#2A211A` 차콜 / `#E2620F` 주황 / `#FF9A3C` 하이라이트 |
| 그리폰 모터스 | 진녹 × 금 (D03 §2.2) | `#0B2A1E` 암부 / `#17563A` 진녹 / `#C9A227` 금 / `#F0DC8A` 하이라이트 |
| 노스윈드 개러지 | 스틸 그레이 × 아이스 시안 (사용자 확정·IMPL-117) | `#2B3239` 스틸 암부 / `#5A6670` 스틸 / `#8FB8C4` 아이스 / `#BFEFF7` 아이스 시안 발광 |

- **노스윈드 = 무채 2 + 냉색 2의 2:2 분할.** 악시온이 백청(고명도·청 채도)인 데 반해 노스윈드는 중명도 무채가 주고 냉색이 액센트다 — **명도 축과 채도 축 양쪽에서** 갈린다.
- **⚠ 이 팔레트의 유일한 실질 리스크가 여기다.** 머신은 그리드에서 96×48px로 그려진다. 아티팩트의 「소형 판독 검사」(32px 띠)에서 악시온과 노스윈드가 갈리는지 **직접 확인해 주십시오.** 안 갈리면 노스윈드 스틸을 한 단 낮추는(더 어둡게) 조정으로 해소된다.
- 주인공 헬멧 무광 오프화이트(`MT3 #E4E0D8`)는 팀 컬러와 **독립**이다(D10 §3.2 확정·실차 관례) — 웜 기미를 넣어 악시온 백(`#EEF3FA`, 쿨)과 분리했다.

- **EV4 사암은 '양피지 톤' 금칙에 걸리지 않는지 확인 대상.** D10 §9 ToF 비유사 ④가 판타지 채도·양피지 톤을 배제하는데 붉은 사암이 근접 색역이다. `#B4703A`는 채도를 낮추고 명도를 올려 **햇빛 받은 암석**으로 읽히게 뒀으나, 실기에서 양피지로 읽히면 조정한다.

## 5. 기능 컬러 부속 13 — **56색 밖**

D10 §2.3 면제 조항: *"심볼 6종 이중 부호화 색·색각 대체 팔레트·게이지 상태색·경고색은 접근성 요건이 마스터 팔레트에 **우선**한다."*

**적(`#FF4A3D`)과 라임(`#7BE04A`)은 네온 3계열(시안·마젠타·앰버)에 없다** — 면제 조항이 없으면 이 두 색은 갈 곳이 없다. 이것이 부속을 56 밖에 두는 근거다.

| 군 | 항목 | HEX |
|---|---|---|
| 심볼 6종 | 슬립스트림 / 라인 / 브레이킹 / 트러블 / 찬스 / 펄스 | `#3FE0F5` / `#7BE04A` / `#FFBF3D` / `#FF4A3D` / `#FF4FB0` / `#BFEFF7` |
| 게이지 상태 | 정상 / 주의 / 위험 | `#3FE0F5` / `#FFBF3D` / `#FF4A3D` |
| 베인 4상태 | 평상 / 경고 / 고양 / 손상 | `#12A6C4` / `#FF4A3D` / `#FFD86B` / `#6B7686` |

- 심볼 6색은 **색상환에서 최대한 벌렸다** — 이중 부호화(색+도상)의 색 축이 제 몫을 하려면 인접 색이 없어야 한다.
- 베인 손상이 무채(`#6B7686`)인 것은 의도다 — D03 §1.5 "끊기는 노이즈"는 **탈색**으로 읽는 편이 파형 렌더에서 선명하다.

## 6. 색각 대체 팔레트 (A-팔레트-02) — 교체 4색

D10 §2.4: **색상만 교체·도상 불변.** 이중 부호화가 1차 방어이고 이 팔레트는 2차 보정이므로 교체는 최소로 둔다. 적록 축에서 충돌하는 것만 청–황 축으로 옮긴다.

| 대상 | 기본 | 대체 | 사유 |
|---|---|---|---|
| 심볼 · 라인 | `#7BE04A` 라임 | `#E8EEF5` 백 | 적록 축 충돌 이탈 |
| 심볼 · 트러블 | `#FF4A3D` 적 | `#7A5CFF` 청자 | 동상 |
| 게이지 위험 | `#FF4A3D` 적 | `#7A5CFF` 청자 | 상태색 일관 |
| 게이지 주의 | `#FFBF3D` 앰버 | `#FFD400` 순황 | 위험과의 분리 강화 |

시안·마젠타는 적록 색각에서도 분리되므로 유지한다.

| # | 구속 (총괄 판정 2026-08-16) | 대조 | 판정 |
|---|---|---|---|
| 1 | 팀 컬러가 D03 §2.2 + 노스윈드 확정 만족 | 4팀 16색 전건 정성 표기 내 | ✅ |
| 2 | 기능 컬러 면제 조항 우선 — 56에 욱여넣지 말 것 | 13색을 56 밖 부속으로 분리 | ✅ |
| 3 | 색각 대체는 색상만 교체·도상 불변 | 교체 4색뿐·도상 무접촉 | ✅ |
| 4 | 베인 4상태 상태색 포함 (D13 위임분) | 부속에 4색 계상 | ✅ |
| 5 | 고대비 여백 — G-1·G-2보다 선행 확정이므로 | N16/N03 ≈ 12:1 · 심볼 6색 전부 바탕 대비 7:1↑ | ✅ **단 실기 재검 필요** |

**5번은 산술 통과일 뿐이다.** G-1(8px 한글 가독)·G-2(32px 심볼 판독)는 MS-5로 재배치되어(D15 v1.1 결정 #12) 실측이 한참 뒤다. 명도비는 확보했으나 **8px 한글의 획 뭉침과 32px 심볼의 순간 판독은 계산으로 대체되지 않는다** — 그래서 대비에 여유를 뒀다.

## 8. 승인 요청

블록 단위로 보시면 됩니다. **세 가지만 통과하면 나머지는 파생입니다:**

1. **뉴트럴 계조의 균질성** — 연속 띠에 턱이 없는가

3. **환경 6색의 무대 변별** — 무대 5종이 배경만으로 구분되는가
