> 작성: 총괄 (remote-hq 세션) · 2026-08-22 · 근거 = IMPL-289 §5 (마스터플랜 v2.73)
> **순서: 원격 18차 종료 후 단독 회차**(사용자 지시 — 병행 충돌 방지). 본 회차 종료 후 원격 19차가 이어진다.

## 착수 전

- `git pull` 후 에셋 실물이 수백 바이트면 `git lfs pull`. **BGM 18스템·징글 5식이 새로 유입**됐다(LFS).
- 신규 파일 유입 회차 — **에디터 켠 상태로 `--headless --import`·`--script` 금지**(IMPL-137·259). GDAI `execute_editor_script`로 `EditorInterface.get_resource_filesystem().scan()` 1회.
- 규약 3항 보완분 준수: 공유 파일 append 전속 · `git checkout` 금지 · `git commit -- <경로>`. IMPL ID = pull 직후 최대값+1 · **푸시 직전 재확인**.

## ① 선택지 오버레이 씬 노드 — **계약은 이름 2개뿐**

원격 15차가 코드·데이터를 전량 결선했고 **노드만 없다**(현재 4지점 10선택지가 도달해서 생략으로 기록되는 상태 — 관측 확인분).

| 항목 | 계약 |
|---|---|
| 노드 | `ChoiceOverlay`(Control · **초기 `visible = false`**) + 그 아래 `ChoiceList`(Container — 버튼 레이아웃은 컨테이너가 한다) |
| 발동 | **이름만 맞으면 코드 변경 0**으로 발동한다(`find_child()` 호출 시점 탐색) · UISCR ⑰ⓑ가 이미 그 계약으로 스텁 주입 검사를 돌고 있다 |
| 규격 | D09 별첨A §A-19 **E05** — 대괄호 표기·1줄 14자·**전이 관련 표시 전무** |
| 배치 구속 | **스킵 버튼(우상단)을 덮지 않는다** — 지점 위 스킵 생존이 규격이다(D01 G2 조건 2 · 내러티브 2차 §3) |
| 확인 | 4지점 실기 도달(1막 beat12 뒤 · 3막 beat11 · 4막 beat10 · 에필로그 beat10) · 버튼 수 = `option_count`(3/3/2/2) · 문면 = 데이터 값(대괄호 포함) · 선택 후 반응 1라인 재생 → 합류 · **선택 대기 중 진행 입력 무소비**(판정 IMPL-269 ②) · 지점 위 스킵 = 오버레이 닫힘·반응 미재생 |

씬 노드가 서면 UISCR ⑰의 ⓐ(부재)·ⓑ(실재) 두 축 중 실물 경로가 ⓑ로 바뀐다 — **회귀가 그 전환을 감지하는지**(ⓐ 축이 공회전으로 남지 않는지) 함께 확인해 주기 바란다.

## ② `sys_save_spin` 회전체 소비부

에셋이 회전 대칭 스피너(20×20 원도·잉크 160·90°/180°/좌우 대칭 실증)를 유입했고 **소비부 결선은 화면 층 판단**으로 남겼다.

- 판단할 것: **정지 표기(`sys_save`)와 회전체(`sys_save_spin`)를 분리**할지, 회전체만 쓸지. 근거 = 주력 10차 §5 판독(방향성 글리프가 180°에서 '불러오기'로 반전 — 2회전이면 두 번 통과).
- 값 = D13 v1.8 확정분(유지 2.0s · 주기 1.0s) — 코드 무기입·`core_params` 창구.
- 결선 후 회전 감각 판정(이월 항목)도 이 회차에서 함께 볼 수 있으면 본다 — 실물 빌드 없이 필름스트립으로 대체한 10차 방식도 가능.

## ③ VN 6건 실기 — 75라인이 **게임에서** 도달한다

원격 16차가 소비부를 결선해 1막 = 커리어 개시, 2~4막·기원·에필로그 = 투어 경계에서 실제로 뜬다(10차의 통독은 트리 직접 세우기였고 **이번은 실플레이 경로**다).

- 확인: 커리어 개시에서 1막이 뜨는가(첫 투어 경계가 아니라 **개시** — IMPL-271 개시형 분리분) · 라인별 화자 라벨 교대·지문 공란 · 3·4막·기원이 **BGM-10(긴장)**으로 열리는가(tone 결선) · 아카이브 표제 6종이 각각 다르게 뜨는가(내러티브 3차 6문안 + 원격 표제 결선분) · 막 래치가 투어 경계에서 발효되는가.
- **실물 BGM이 이제 있다** — VN 진입 시 BGM-09/10이 실제로 울린다. 트랙 전환이 장면 이동처럼 튀지 않는지(에셋 판단: 음색 통일·밀도만 차이) 귀로 확인.

## ④ 사운드 실기 청감 — 재생기 결선분

원격 17차가 재생기·버스 3계·볼륨·일시정지를 결선했고 **91식이 전량 유입**됐다. 헤드리스에서 상태는 전건 검증됐으나 **귀는 여기서만 열린다**.
