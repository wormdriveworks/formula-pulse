## 본몫 A — 스킬 슬롯 UI (원격 20차 회신 §1 계약 전속)

| 항목 | 계약 |
|---|---|
| 렌더 | `engine.skill_slots()` 하나로 그린다 (행: `{id, name_key, family, effect, charge_cost, uses_per_tour, uses_left, usable, reason}` · `uses_left −1` = 무제한) |
| 활성 판정 | `usable`/`reason` 그대로 — **화면이 재판정하지 않는다** ("판정은 한 곳뿐" — E17 돌연변이가 지키는 계약) |
| 투입 | `use_skill(skill_id, args)` — args 규약: 홀드 SH1 `{"keep":[2개]}`·SH3 자유 / 변환 `{"target":릴}`·SC3 `{"target","donor"}`(인접) / 증폭·보험 무인자 |
| 거부 문면 | `error` 16종 → `ui.race.*` 기존 키 분기 (신규 표시 문자열이 필요하면 **키 목록 회신** — 내러티브 창구) |
| SH3 | **신·구 후보 병치 2단 UI** — `snapshot_previous` 비어 있지 않으면 택1 대기. 병치가 없으면 SH3 효과 자체가 불성립 (원격 명기) |
| SFX | `sfx("skill_%s" % family)` 1줄 (SE-I05~I08 표 기존재) — 베인 발화(`vane.brief.skillUse01`)는 내러티브 5차 유입 후 발화되므로 이 회차에서 키 참조만 걸어 두면 된다 |
| 검사 결속 | **`CLICK_EXEMPT` 5건 축소를 UI 활성과 한 걸음으로** (IMPL-302 결속 명문 — 목록이 남으면 5버튼의 죽음을 ⑳이 못 본다) |
| 봉인 | 슬롯 활성 상태가 잠정 결과와 무관해야 한다 — 원격이 `use_skill_check`에서 인자 의존 조건을 뺀 취지를 UI가 되살리지 말 것 (툴팁·하이라이트로 "지금 트러블이 있다" 류 노출 금지) |

확인: 16종 실기 발동(가능한 범위 — 차지·마일스톤 제약 내)·SH1 keep 2개 강제·SC3 인접 강제·거부 문면·비용 차감 표시·`uses_left` 갱신.

## 본몫 A-2 — 로그 화자 표지 결선 (에셋 IMPL-317 유입분 · 화면 층 인계)

에셋이 크루 미니 초상 1 + 카 넘버 배지 8(B안·파일명 = `speaker_rival_{char_id}_16`)을 유입했다. 결선은 화면 층 판단 1건을 품는다:

- **크루 = 1줄** — `ICON_BY_SPEAKER`에 `Speaker.CREW: "speaker_crew_16"` 추가 (`log_feed.gd` 주석 "실물이 서면 여기 한 줄" 그대로).
- **라이벌 = 표에 못 들어간다** — `ICON_BY_SPEAKER`는 화자 종류 → 단일 자산 사상인데 라이벌은 화자 *종류*가 아니라 *특정 인물*이다(`Speaker.RIVAL` 하나에 8자산). **호출부가 `char_id`를 넘기는 경로 설계 = 주력 몫.** 텍스트 폴백은 유지하라 — 적재 실패와 **미지 라이벌**이 같은 자리로 떨어져야 한다.
- 확인 = 실기에서 크루 초상·네임드 8인 배지 각 표출 + 미지 화자 텍스트 폴백 생존.
