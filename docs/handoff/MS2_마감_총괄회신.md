### A-5. 총괄 발견 — **[진성 결함] CI 회귀 · TL-1 상시 결속 위반 (즉시 교정)**

MS-1의 완료 조건 ②'CI 파이프라인(TL-1) 성립'을 검토하다 **현재 진행형 결함**을 발견했다.

- **원인:** `.github/workflows/validate.yml`이 `actions/checkout@v4`를 **`lfs: true` 없이** 사용한다(입력 기본값 = false). 워크플로 최종 수정은 2026-08-11인데, **첫 LFS 에셋은 이틀 뒤 2026-08-13에 유입**됐다(`d732448` 아이콘 16종 → 이후 폰트 5종, 현재 21종).
- **귀결:** 그날 이후 CI 체크아웃은 PNG·TTF를 **포인터 텍스트**로 받는다. 이는 원격 레인이 **IMPL-091에서 실측한 조건과 동일**하다 — `--import`가 포인터를 이미지로 임포트해 `.import` 오염 + **SEAL-E가 텍스처 영구 null로 행(hang)**(36분 무진행 실측). 워크플로는 그 두 단계를 그대로 실행한다(`--import` → `run_tests.sh` → `test_seal_ui.gd`).
- **판정:** 8/13 이후 **빌드 게이트가 사실상 비활성**이었을 개연이 높다. 양 레인이 게이트를 로컬로 돌려 왔기에 아무도 눈치채지 못했다. 불변규칙 7의 취지(검증기 = 빌드 게이트·우회·완화·비활성화 금지) 위반 상태다. ⚠ **단정 유보:** 주력 머신에 `gh` CLI가 없어 Actions 실행 이력을 직접 확인하지 못했다 — 구조·선례 일치에 근거한 고확신 판정이며, 실행 이력 확인은 CLI 가용 시점의 후속 몫이다.
- **교정 (사용자 승인 2026-08-15 — '지금 교정 + 재발 방지'):** ①`checkout` `lfs: true` ②**LFS 포인터 잔존 가드 단계 신설** — `lfs: true`가 조용히 실패해도(쿼터·네트워크·러너 LFS 미설치) 행 대신 **수초 내 명시적 실패**로 원인을 이름으로 알린다. 총괄 로컬 실측: 정상 통과 `LFS_GUARD_PASS files=21`(exit 0) · 포인터 주입 시 파일명과 함께 검출(exit 1) — **양방향 확인**.
- **가드 자체의 결함 1건을 출하 전 자기 적발:** 초안은 `grep -q … && echo "$f"` 형태였는데, Actions의 `run`은 **`bash -e`로 실행**되므로 정상 경로(마지막 파일이 포인터가 아님)에서 `&&` 리스트가 비0을 반환해 명령 치환 대입이 errexit에 걸린다 — **가드가 초록 빌드를 죽이는** 정반대 동작. `bash -e`로 재현(exit 1 실측) 후 `if` 형태로 교정하고 양 경로 재실측했다. 로컬 셸은 errexit이 꺼져 있어 첫 검증을 통과시켰다 — **CI 스크립트는 CI의 셸 조건으로 검증해야 한다**는 교훈을 주석에 명문화했다.
- **MS-1 완료 판정에는 무영향** — MS-1 시점(08-10~11)에는 리포에 LFS 추적 실물이 0건이라 CI는 실제로 성립했다. 8/13 회귀는 **MS-2 기간의 별건**이며, D15 §1.2 "MS-1 성립 → 이후 전 마일스톤 상시"의 상시 결속을 깬 사안이다.
