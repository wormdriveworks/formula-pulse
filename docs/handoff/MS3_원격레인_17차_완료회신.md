## 2. 결선 6축

### 2.1 버스 3계 — 런타임 구성 (근거 명기)

`default_bus_layout.tres` 를 쓰지 않았다.

| # | 근거 |
|---|---|
| ⓐ | `.tres` 는 에디터 산출물이고 그 소유권은 주력이다 — `.tscn` 재정규화와 같은 계열의 문제다 |
| ⓑ | 경로 지정이 `project.godot` 손 편집을 요구한다(`ProjectSettings.save()` 가 주석을 지우는 파일) |
| ⓒ | **검증이 되읽기로 성립한다** — 구성 코드가 곧 `AudioServer` 호출이라 같은 API 로 되읽어 단언한다. 리소스 파일은 *"선언이 증거가 아니다"* 함정(IMPL-245·274)을 다시 만든다 |

**멱등**으로 세웠다 — 세션이 두 번 열리는 경로에서 버스가 중복 생성되면 send 사슬이 어긋나고,
그 어긋남은 조용하다. 되읽기: `Master ← BGM`, `Master ← SFX` 실측.

### 2.2 재생기 — 페이드를 `Tween` 에 맡기지 않았다

시간 축을 엔진에 맡기면 **검사가 벽시계에 묶인다.** 0.8초를 확인하려고 48프레임을 기다려야 하고,
중간 상태를 정확히 집을 수도 없다. 그래서 `audio_pump.gd`(프레임만 먹이는 노드) +
`advance_fades(delta)` 로 갈랐다 — production 은 엔진이 돌리고 **검사는 델타를 손으로 준다**
(디스패처 `clock_override_msec` 와 같은 성격의 이음매).

> **중간값이 규격이다.** 완료 게인은 하드코딩이든 값 창구든 1.0 이라 구분되지 않는다.
> **절반 지점의 0.5 만이 0.8초를 증명한다** — 0.5 상수를 주입한 A2 가 거기서 0.8 로 관측됐다.

| 축 | 실측 |
|---|---|
| SFX 풀 | 12 = `param_audio_virtual_channels` (같은 창구를 읽으므로 풀이 마르는 상황이 구조적으로 없다) |
| 컬링 | 즉시 정지 — 걷어낸 발음에 페이드를 쓰지 않는다(페이드는 그 자체로 소리다) |
| 크로스페이드 | 0 → **0.5**(절반) → 1.0 · 구 데크 1.0 → 0.5 → 0.0 |
| A/B 레이어 | 긴장 게인 0 → 0.5 → 1.0 · **데크·트랙 불변**(교체 아님) |
| 덕킹 | −1.94dB(옵션 80) → **−7.94dB** → 복귀 −4.94 → −1.94 |

### 2.3 주입 교체 — 무음 폴백은 플래그가 아니라 구조다

실물 재생기는 SceneTree 숙주를 요구하므로, **트리가 없는 문맥에서는 무음이 유일하게 가능한
거동**이다(로직 테스트·러너 15스위트 무변경). 디스패처·호출부 무접촉.

숙주는 **라우터**(`app_root`)이고 화면이 아니다 — 화면에 매달면 BGM 이 전이마다 끊긴다.

### 2.4~2.6 볼륨 · 일시정지 · 부재

- **O13~O15 → 버스**: 100 → 0dB / 50 → −6.02dB / 0 → 뮤트. 커브는 D12 §10.1 명문을
  `linear_to_db()` 로 옮긴 것이라 **상수가 끼어들 자리가 없다.** 3축 독립 실측.
- **일시정지**: SFX 뮤트 · **BGM 볼륨 불변**(뮤트도 감쇠도 없음 — D11 §4.3).
- **부재**: 무음 + `push_error` 1회 + `missing_streams` 배열(기계 관측). 실물 유입 시 코드 무변경.

## 3. 자가 적발 3건

### 3.1 뮤트를 합성하지 않아 재개가 사용자 설정을 되살렸다

볼륨 0(O15)과 일시정지가 **같은 뮤트 플래그**를 쓴다. 초판은 `set_paused` 가 단독 대입했으므로
**SFX 볼륨 0 인 상태로 일시정지 → 재개하면 재개가 사용자가 끈 소리를 되살렸다**(실측).

덕킹과 옵션 볼륨을 더해 쓰는 것과 **같은 문제였다** — 한 자리를 둘이 쓰면 합성해야 한다.
교정 후 역순도 성립: 일시정지 중 볼륨을 올려도 재개 전까지 뮤트가 유지된다.

### 3.2 2레이어 BGM 의 기본 스템을 못 찾았다 (IMPL-281)

회차 중 에셋 17스템이 유입되자 실측에서 **BGM-03~07 이 `_a`/`_b` 짝**으로 온 것이 드러났다 —
D11 §4.3 의 2레이어 집합("레이스 트랙 BGM-03~07 만")과 **정확히 같다**.

무접미만 찾던 초판은 **레이스 트랙 5개가 상태는 정상이고 소리만 없는** 상태가 됐다.
가장 조용한 실패 형태다. 교정 = 무접미 → 없으면 `_a` 폴백 사슬(어느 관례로 와도 성립).

> **검사를 남의 조달 일정에 묶지 않았다.** 초판 축이 "BGM-09 는 부재"를 전제했다가 그 트랙이
> 유입되면서 실제로 FAIL 했다. 불변식으로 바꿨다 — **디스크에 스템이 있는 id 는 전건 해소되고
> 없는 id 는 전건 관측에 남는다. 조용히 지나가는 경우가 없다.** 어느 트랙이 유입됐는지는 묻지 않는다.

### 3.3 오류 문면에 한글을 썼다 (V4)

`push_error` 문면에 "무음 유지"·"풀"을 넣어 V4 가 잡았다 — **V4 는 표시 문자열과 오류 문면을
구분하지 않는다.** ASCII 로 교정. (내러티브 3차 회신 §6이 같은 2건을 "원격 17차 미추적 작업분"
으로 관측해 올려 준 것과 동일 건이다.)

## 4. 범위 추가 1건 — 아카이브 표제 결선 (IMPL-283)

내러티브 3차(IMPL-278)가 6문안을 편입하고 `records_screen.gd` 는 규약대로 무접촉으로 뒀으므로
**고아 키 6건**이 남아 있었다(그 회신이 예견한 상태 · "담는 방식은 원격·총괄 판단"으로 인계).
제 16차 [인계]의 회수분이고 소비부가 제 파일이라 결선했다.

> **규칙이 아니라 리터럴 표를 쓴 것은 검사 때문이다.** 먼저 규칙판
> (`"ui.vnSlot." + id.trim_prefix("vn_")`)으로 붙였는데 **V6 경고가 그대로 6건이었다** —
> V6 는 코드 리터럴·표의 `string_key` 열·구조 값에서 참조를 모으므로 **조립한 키가 보이지 않는다.**
> 소비부가 있는데 없다고 보고하는 상태를 남기면 그 경고는 다음 사람에게 잡음이 된다.
>
> 표의 대가(7번째 막이 조용히 폴백으로 떨어짐)는 **검사가 받는다** — UISCR 축이 `act_vn` 전
> 항목의 표 등재·키 실재·폴백과 다른 문면을 본다(A17: 1행 삭제 → FAIL).

**미착수로 남긴 것:** 재회 브리핑 5라인(내러티브 3차 §5.1) — "담을 구조가 없다"는 그쪽 판단이
정확하고, **스키마 신설은 총괄 판정 사안**이다(`tone` 전례). 축 결속 브리핑 VN 의 거처를
판정해 주시면 결선한다.

아예 없었다 — **"저장만 되고 소비부가 0"이던 원래 상태와 종료코드로 구분되지 않는 자리**다.
둘 다 관측 지점을 만들어 닫았다.

## 6. 실측 부기 · 인계

- **헤드리스 더미 드라이버에서 `finished` 가 실제로 온다.** 표현 층이 스트림 종료를 통지하지
  않으면 디스패처 점유가 영구 누적되므로(IMPL-149: P1 1발 → P3 전량 영구 억제) 이 결선의 전제였다.
  12프레임 내 점유 0 확인.
- **[관측 — 주력 청감 몫]** SFX 버스 뮤트는 **일시정지 메뉴 자신의 조작음까지** 끈다. D11 §4.3
  문면("SFX 뮤트")을 그대로 이행한 결과이고 정보 보존은 시각 채널이 받으나(§6.1), **귀로 이상한지는
  들어 봐야 안다.** 주력 11차 실기 청감 항목에 넣어 주시기 바란다.
- 병행 레인 상태: 에셋 BGM 18스템·내러티브 6문안 모두 회차 중 커밋됐고 게이트는 그 상태로 녹색이다.
  스테이징은 명시 경로 전속(`godot/assets/`·`tools/audio/`·`test_audio_assets.gd` 무접촉).

### [보고] 공유 파일 덮어쓰기 1건 — `impl_log.md`

회차 중 **제 미커밋 3행이 사라졌다.** 에셋 레인이 같은 파일을 쓰면서 자기 기준본으로

> **규약 3항의 자리다** — "공유 파일은 자기 몫만 반영한다"가 *걷어내지 않는다*로는 부족하고
> **덮어쓰지 않는다**까지여야 한다. 규약 2항 보완(푸시 직전 재확인)이 ID 충돌을 잡았듯,
> 같은 재확인이 이번엔 **행 소멸**을 잡았다 — 같은 습관이 두 종류의 사고를 잡고 있다.
> 문면 보완이 필요하다면 총괄 집행 사안으로 올린다(3항: "표 형식 공유 문서는 append 지점만
> 만지고 파일 전체를 재작성하지 않는다" 정도).
