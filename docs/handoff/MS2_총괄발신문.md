# MS-2 총괄 경유 발신문 — 주력 GUI 머신 레인 종료 시점

> 작성: 2026-08-15 · 주력 GUI 머신 레인 (D09 실화면·아트 파이프라인·옵션·연출 채널)
> 성격: **총괄 채널로 보낼 발신 항목의 통합 초안.** 구현은 아래 전 항목에서 이미
> 일관된 상태로 서 있으며(각 IMPL 참조), 발신 지연이 작업을 막지 않는다.
> 근거 원칙: 조건부 발신 전건 총괄 경유 — 본 채팅·실행 조직의 단독 확정 금지 (D14 §5.9 · 마스터플랜 §4.5 H-1).

## A. 판정 요청 — D15 §1.1 완료 조건의 시점 조정 (1건 · 차단성 있음)

| 항목 | 내용 |
|---|---|
| 사안 | 사용자 판정(2026-08-13)으로 **G-1·G-2·G-5 실기 게이트를 프로젝트 최후순위로 재배치** — 평가자 5인·MP-L 실기기 조달을 뒤로 미룸 (IMPL-081) |
| 충돌 지점 | D15 §1.1이 G-1·G-2·G-5 통과를 **MS-2 완료 조건**에 명시. 게이트 미실행 상태로는 MS-2를 종결할 수 없다 |
| 요청 | MS-2 완료 조건에서 게이트 3종의 **실행 시점을 분리**(예: MS-3 진입 조건으로 이동 또는 별도 게이트 마일스톤 신설)하는 D15 §1.1 개정 판정 |
| 성격 명확화 | **게이트 기준의 완화가 아니다** — 판정 기준(D14 §5)은 그대로이며 실행 시점만 재배치한다. 마일스톤 배치는 D15 소관이고 결정권자는 사용자다 |
| 현 상태 | MS-2는 "게이트 외 조건 충족" 상태로 유지 — TC-C 13/13 · TC-O 8/8 · TC-P8·P9 · 세이브 성립 · 화면 23종(확정 범위) 성립 |
