### IMPL-018 — D12 §1.1 재검증 조항 잔여분 이행 결과 (2026-08-11)

**결론: D12 §1.2 타겟 스펙 하한 4항 전건 4.7에서 유지. 상향 없음 → 중단·보고 조건 불성립, D14 디바이스 매트릭스 조정 불요.**

| 하한 | 4.7 실측 | 근거 |
|---|---|---|
| 데스크탑 OpenGL 3.3 | 유지 | 공식 시스템 요구사항 문서 4.4~4.7 수치 불변 |
| 모바일 OpenGL ES 3.0 | 유지 | 동상 |
| Android 8.0 (API 26) | 유지 (여유 2단) | 엔진 `minSdk 24`(4.7 브랜치 `platform/android/java/app/config.gradle`) · AdMob 플러그인 `minSdk 24`(`platforms/android/build.gradle`) · GMA Next-Gen SDK 요구 `minSdk 24` — 전건 ≤ 26 |
| **iOS 14+** | **유지 (여유 0)** | 엔진 iOS 배포 타겟 = **14.0** (`platform/ios/detect.py` 4.7 브랜치 `-miphoneos-version-min=14.0` / `-mios-simulator-version-min=14.0` — **4.6과 동일, 상향 없음**) · AdMob 플러그인 SPM `platforms: [.iOS(.v14)]` · 플러그인이 고정한 GMA iOS SDK 13.6.0 자체 요구는 `.iOS(.v13)` |

**오독 방지 (중요):** 공식 문서 시스템 요구사항 표의 iOS 행이 4.5/4.6 **14.1 → 4.7 15.0**으로 오른 것은 **Forward+/Mobile(Vulkan) 경로 전용 수치**다. 본 프로젝트는 **Compatibility 단일 고정**(D12 §1.1)이라 해당 행의 구속을 받지 않으며, 엔진의 실제 빌드 하한은 위 표대로 14.0으로 불변이다. 문서 표에는 Compatibility 렌더러 전용 iOS 수치가 4.4 이래 애초에 존재하지 않으므로, **판단 근거는 문서 표가 아니라 엔진 소스의 배포 타겟**으로 삼는다.

**여유 0 경보 (iOS):** 엔진 14.0 · 광고 플러그인 14 · §1.2 하한 14 — 세 값이 정확히 일치해 완충이 없다. **엔진 또는 AdMob 플러그인 어느 한쪽의 차기 상향이 즉시 §1.2 상향으로 직결**된다(§11.1 "SDK 최소 OS 요구는 §1.2와 착수 시점 동기 — 상향 시 총괄 인지 보고"). D14 MP-L 행(iOS 14 · A11급 · iPhone 8/SE 2세대)이 직접 영향권이므로 **MS-2 이후 매 착수 시점 재확인 대상**으로 승계한다.

**플러그인 생태 (D12 §7.3 · §11.1):**

| 대상 | 4.7 호환 | 비고 |
|---|---|---|
| AdMob (poingstudios/godot-admob-plugin) | ✅ 확인 | 요구 Godot 4.2.0+ · Asset Store 4.0~4.8 범위. **단 v5.0.0은 monorepo·iOS SPM 전환·GMA Next-Gen SDK 채택의 구조 대개편 메이저 버전** — 실착수(MS-5 광고) 시 마이그레이션 검토 필요 |
| Play Games Services Saved Games (Android 클라우드) | ✅ 확인 | 최소 Godot 4.3 · 4.3~4.8 커버 · 유지보수 활발 |
