## ① 문서 목적·범위

본 문서는 Steam 데스크탑(1차 플랫폼)의 **전체 화면 체계·레이아웃·인터랙션·피드백·옵션·Steam 연동 UX**를 확정하여, D05~D08이 확정한 규칙·콘텐츠에 화면 실체를 부여하고 D10(아트)·D12(구현)·D13(수치)·D09-2(모바일)가 이어받을 수 있는 기반을 제공한다. 아울러 선행 문서의 D09 이관 항목 전량(릴·타이머 규격, 자수 교차 검증, 연출 등급 구현, 아웃게임 화면 규격, 결산 리포트, 레조넌스 공표 UI 등)과 총괄 부대조건 P-1 4건을 해소한다.

**범위 가드:** 화면 구조·레이아웃 원칙·인터랙션 규격·표기 규칙·옵션 체계까지. **아트 실물(아이콘 도상·폰트 실선정·컬러 실팔레트)은 D10 / SFX·햅틱 실규격은 D11 / 구현·데이터 구조·스트링 키는 D12 / 수치 밸런스는 D13 / 모바일 재구성·광고 UX는 D09-2 / 스토어 페이지·상품 구성은 D15.** 텍스트 실문안은 작성하지 않는다(D04 규격 준수 의무만 선언 — 문면 *규격*이 본 문서 소관인 항목은 예외적으로 규격을 확정한다: 칭호 이력 문면 §5.5, 옵션 고지 문면 §6.2).

**확정 기준값 정책 (결정 #5):** 본 문서의 수치·단계·시간 값은 전부 **'확정 기준값'**이다 — 문서 층위에서 확정하되, 개발 반복 테스트(실기)·D13에서 세부 조정을 허용한다. 조정 대상은 *값*이며 구조·규칙·상한의 존재는 불변이다 (D03·D07 확정 전례 준수).

**플랫폼 층 표기 규칙 (구조 결정 사안 3 — 확정):** 본 문서의 전 조항은 **[공통]** 또는 **[데스크탑]** 태그를 갖는다. [공통] = UX 규격으로서 D09-2가 그대로 승계(레이아웃 재배열만 허용, 규칙 재판정 불요). [데스크탑] = 입력·해상도·Steam 등 플랫폼 전속으로서 D09-2가 대체 설계. 절 단위 태그를 기본으로 하고, 절 내 예외는 행 단위로 부기한다.

### 1. 기준 환경 (DoD B5~B8)

#### 1.1 해상도·스케일링 정책 (결정 K1 — DoD B5) [데스크탑]

| 항목 | 규격 |
|---|---|
| **기준 해상도** | **1920×1080 (16:9)** — 전 레이아웃 설계 기준 |
| **최소 지원** | 1280×720 |
| **4K·QHD** | 벡터/고해상 에셋 + 정수 배율 우선 스케일 (에셋 규격 D10) |
| **21:9 울트라와이드** | **16:9 세이프 존 원칙** — 게임플레이 정보·조작 요소는 중앙 16:9 존 내 고정, 좌우 확장분은 배경·무드 레이어만 |
| **16:10 (Steam Deck 1280×800)** | 상하 확장분은 배경 처리, 정보는 16:9 세이프 존 유지 (§6.5) |

- **세이프 존 원칙의 근거:** 개입 창 10초 내 판단(§0)은 시선 이동 거리에 민감하다. 정보를 세이프 존에 고정하면 어떤 종횡비에서도 시인 동선이 불변하며, D09-2의 세로 재구성에도 "정보는 세이프 존"이라는 단일 원칙이 승계된다.
- **UI 스케일 옵션:** 100 / 110 / 125% (확정 기준값 — 반복 테스트 세부 조정) (§6.1).

**공통 층 (전 화면):**

| 조작 | 키보드/마우스 | 패드 |

| 취소 / 뒤로 | Esc / 우클릭 | B |

| 탭 전환 | Q·E | LB·RB |
| 일시정지 메뉴 | Esc(최상위) | Start |
| 상세 정보(툴팁 고정) | 마우스 오버 / T | Y (포커스 대상) |

**레이스 컨텍스트 층 (RACE-01, §3):**

| 조작 | 키보드/마우스 | 패드 |
|---|---|---|
| 스핀 개시 (T2) | Space / 스핀 버튼 클릭 | A |

- **층위 우선 규칙 (v1.3 명문):** 컨텍스트 층은 해당 화면에서 공통 층에 우선한다. 컨텍스트 층이 공통 조작의 입력을 가리면, 가려진 조작은 컨텍스트 층 표에 **재배치 행으로 명시**한다 — 무언의 소실 금지.
- **확정 = 스핀과 동일 키 원칙 (확정):** "결과를 불러온다 → 결과를 받아들인다"가 같은 물리 동작으로 순환한다 — 매턴 2회의 핵심 입력을 단일 키에 고정하여 10초 리듬의 근육 기억을 만든다. 오입력 방어는 T3 잠정 결과 표시 후 **0.3초(확정 기준값 — D13 세부 조정) 입력 무시 윈도**로 처리한다(스핀 연타가 즉시 확정으로 새는 것 차단).
- 포커스 내비게이션 규칙: 모든 화면은 패드 포커스 순회가 폐쇄 루프를 이룬다(도달 불가 요소 0건 — H38 검증 항목). 초기 포커스는 화면별 주 행동 버튼에 둔다 (별첨A 화면별 명세).

#### 6.3 채널 감쇠 모델 (결정 K8 — DoD D18 연동) [공통]

- **확정 구조:** 연출 등급 L0~L3의 **발동·기록은 D08 데이터대로 불변**이며, 접근성 옵션(O1~O3)은 **표현 채널별 감쇠 레이어**로만 작동한다. 옵션이 등급 판정·데이터에 관여하는 경로는 존재하지 않는다 (D12 구조 단순성·D08 데이터 순결성).
- **정보 보존 의무 (확정):** 정보 전달 기능이 있는 연출은 감쇠 시 **비감각 채널(텍스트 배너·아이콘)로 정보가 보존**되어야 한다. 대표 적용: 레조넌스 발동 공표(§3.6 — 플래시를 꺼도 배너·섹터 변이는 유지) / 듀얼 예고 점멸(끔 시 게이지 만충 아이콘 유지) / 트러블 경고. "옵션을 켜도 정보는 잃지 않는다"가 접근성의 본령이다.
