## ① 문서 목적·범위

본 문서는 《Formula Pulse: Spin the Grid》의 **출시 실행 계획(마일스톤·스토어·심의·로컬라이제이션·상표)**과 **출시 후 운영 계획(업데이트·재보정 운영)**을 확정한다. 담당 층위는 **계획·절차·판정 층**이다.

**범위 가드 (구속 명문):**
1. **밸런스·광고 값의 조정은 D13 확정 기준값 대장(92항) 단일 창구**로만 수행한다 — 본 문서는 재보정의 **운영 계획·데이터 경로**만 규정하며 값 자체에 접촉하지 않는다 (D16 §8.3 경로·규칙 층 침범 금지).
2. **검증 게이트·테스트의 실행 규격은 D14가 완결**한다 — 본 문서는 검증 단위의 **마일스톤 결속과 트리거 공급**(G-4)만 수행한다 (D14 §10·§12).
3. **상표의 최종 법률 판단은 외부 전문 검토 소관**이다 — 본 문서는 점검 목록·절차·리스크 등급·대응 방침까지를 확정한다. 충돌 발견에 따른 개명은 해당 상류 문서 개정 사안으로서 **전건 총괄 경유**한다.

**신규 식별자 3계열 (§0.7-7 준수 — 결정 #2):** `MS-n`(마일스톤) · `TM-n`(상표 점검 항목) · `UC-n`(업데이트 후보). 전 계열 2문자 접두+하이픈. **충돌 검사 수행 완료(2026-08-09):** 확정 문서 20파일+마스터플랜 전수, 하이픈형(`MS-`·`TM-`·`UC-`)·무하이픈 양형(`MSn`·`TMn`·`UCn`) 공히 **히트 0** (기존 5계통 + D14 6계열 = 11계통 대상). 기존 식별자 인용 시 출처 병기 원칙 준수 (예: "D01 §4 G1", "D06 §7 G1~G4").

### 6.2 광고 값 재보정 운영 (H-7-③ — D14 후속 이관 #4 이행)

**절차 (확정):** ①소프트 런칭 계측 (D14 §8.1 세션 계측계 — 계측은 테스트/소프트 런칭 빌드 층, D12 §11.5 출시 제품층 분석 SDK 불채택과 층 분리 기성립) → ②표본 충족(§3.3-③) 시 **계측 데이터 인계** → ③**D16 §8.3 경로 → D13 확정 기준값 대장 재보정 (총괄 경유)**. **1순위 = 교환비(1:3)·면제 폭(4대회)** (D16 결정 #15 — 수익 우위 필요 시 하향은 반드시 이 창구, 규칙 층 침범 금지).

**사이클 (확정):** 소프트 런칭 후 1회(MS-6 진입 조건) + 글로벌 출시 후 정기 (확정 — 분기 1회 검토, 임계 이탈 시 수시).

### 6.3 축적형 잔액 소비처 단가 (H-7-⑤ — D06 R8)

업데이트 콘텐츠(UC 착수분)가 신규 소비처를 추가할 때의 단가 책정 절차만 확정한다: 후보 단가 산정 → **값 등재 = D13 대장 창구 (총괄 경유)** — "D06 §7 G1~G4" 환전 가드·기존 Source/Sink 구조(D06 §2.1) 무접촉 검증을 착수 조건에 포함.

### 6.4 운영 리듬 (DoD #29)

- 재보정 판단 주기: §6.2 사이클 준용. 밸런스(비광고) 값 이탈 보고는 D14 §8 판정 경로(원인 분석→총괄 보고) 승계 — 값 임의 조정 금지.
- 업데이트 착수 판단 기준 (확정): ①UC 대장 우선순위 ②착수 조건 충족 ③해당 문서 개정의 총괄 경유 성립 — 3항 동시 충족 시에만 착수.
- 스토어 리뷰·커뮤니티 피드백의 문서 반영 경로: 개별 판단이 아니라 **UC 대장 신규 등재 또는 D13 재보정 안건화의 2경로**로만 수용 (확정 — 수용 창구 단일화 원칙).
