## ① 문서 목적·범위

### 0.1 목적

본 문서는《Formula Pulse: Spin the Grid》의 **QA & 테스트 계획서**로서, 선행 확정 문서(특히 D12 §12 검증 게이트 대장, D13 §4.2 몬테카를로 인계 규격)가 D14로 인계한 검증 임무 전량을 **실행 규격 완결형**으로 확정한다.

- **범위 판정 (결정 #1 — A안):** 본 문서는 게이트·시나리오·매트릭스별로 **실행 절차 · 환경·표본 · 합격/불합격 판정 기준 · 기록 양식 · 불통과 시 발신 경로**를 "실기 빌드가 성립하면 그대로 집행 가능한 수준"으로 문서 확정한다. **실측 결과 기입란은 공란 양식으로 내장**하며, 실행 자체는 빌드 성립 후 본 문서를 집행 규격으로 삼아 수행한다.

> **공통 원칙:** 게이트 불통과는 결함(DF)이 아니라 **게이트 판정**이며, 대응은 아래 각 항의 발신 경로 전속이다. **조건부 발신은 전건 총괄 채널 경유 — 본 채팅·실행 조직의 단독 확정 금지** (마스터플랜 §4.5 H-1). 각 게이트는 실측 기록 양식(§5.8)을 공란으로 내장한다.

#### 5.1 G-1 — 8px 한글 실기 가독성 (D12 §9.4)

- **전제:** 하한 프로파일 기기(MP-L·§6.2) + 실기 렌더 빌드(비트맵 폰트 8px 원도 탑재).
- **절차 (D12 확정 승계):** 하한 기기에서 로그 존 실표시 → 판독 과제 수행.
- **판정 (결정 #3 KQ-1 — 이원 기준):** ①**문자 오독률 ≤ 5%** **및** ②**수치·단위 어휘(숫자·Cr·%·DP·초) 오독 0**. 어느 한 축 위반 시 불통과.
- **표본 설계 (확정):** 평가자 5인 × 문항 40 (실제 로그 존 문장 풀에서 무작위 추출 — 수치·단위 어휘 포함 문장 비율 30%). 문항당 노출 시간 = 실플레이 로그 체류와 동등 조건 3초.
- **불통과 발신 (D12 확정 경로):** 조정 창구 = **로그 존 폭 기준값 D13 발신** (자수 22자·시각 줄 2 **불변** — D10 §5.7 확정 경로) — 총괄 경유.

#### 5.2 G-2 — 심볼 32px 실기 판독 (D12 §9.4)

- **전제:** 하한 프로파일 기기 + 심볼 6분류 실기 렌더 빌드.
- **판정 (결정 #3 KQ-1 — 이원 기준):** ①**분류 오독률 ≤ 2%** **및** ②**혼동쌍 편중 불검출**. 혼동 행렬(6×6)을 기록하며, **단일 혼동쌍의 오독이 전체 오독의 50% 초과 시 편중 판정 → 불통과** (전체율 통과와 무관).
- **표본 설계 (확정):** 평가자 5인 × 제시 60회 (6분류 × 10회 무작위 순서·단독 제시와 릴 맥락 제시 반반).
- **불통과 발신 (D12 확정 경로):** **D10 발신 (도상 보정)** — 총괄 경유.

#### 5.3 G-3 — O-M2 절감 실측 (D12 §9.7 — P-5-④ · H-2) [모바일]

- **전제:** 광고 SDK 연동 모바일 빌드 + O-M2 구현(프레임 상한 30fps + 시스템 주사율 60Hz 요청 — 요청 층 보장 불가 명문 승계) + 고정 리플레이 시나리오.
- **프로토콜 (D12 §9.7 확정):** 고정 리플레이 시나리오 **30분 × 켬/끔 × 3회**, OS 배터리 통계 기반 평균 절감률 산출.
- **측정 세부 보정 (D14 창구분 — 확정):** 화면 밝기 50% 고정 · 무선 = Wi-Fi 유지/셀룰러 차단 · 백그라운드 앱 0 · 배터리 80%에서 시작 · 측정 전 온도 안정화 10분 · 측정 기기 = MP-L·MP-M 각 1대(프로파일별 절감률 병기).
- **판정:** 평균 절감률 **≥ 5% 통과**. **5% 미만 = 옵션 제거 재고 → 총괄 경유 D09-2 발신** (D09-2 §9.2 — 재고 판정은 본 채팅 소관 아님).

#### 5.4 G-4 — 최장 키 언어 라벨 검증 (D12 §8.5)

- **트리거 = D15 지원 언어 확정.** 본 문서는 실행 규격을 완결하고 **트리거 대기 상태**로 등재한다 (실행 규격 완결 = DoD #12 충족 — 집행은 트리거 후).
- **절차 (D12 확정 승계):** 라벨 단위 최장 렌더 폭 언어 산출 → D10 폰트 6원도·레이아웃 폭 대조 → 초과 라벨 목록 산출.
- **판정:** 초과 라벨 0. 초과 발생 시 대응 우선순위 = **번역 지시 우선 / 폭 조정은 D13 창구** (D12 확정).
- **집행 도구 (확정):** 스트링 테이블 전수 × 언어 폭 산출 스크립트 (V3 자수 산출법 재사용 — 전각/반각 가중).

#### 5.5 G-5 — 베인 파형 렌더 실기 스모크 (D12 §9.3)

- **성격:** 런타임 렌더 **채택 판정(D12 §9.3 기확정)의 확증** — 재판정이 아니다.
- **전제:** 하한 프로파일 기기 + 베인 파라미터형 4상태 렌더 빌드.
- **스모크 규격 (확정):** 4상태 각 60초 연속 표시 + 상태 전환 20회. 판정: 하한 기기에서 **프레임 유지(30fps 기준) 및 시각 결함(찢김·잔상) 0**.
- **이상 시 발신:** **폴백 재론** — 총괄 경유 (단독 재판정 금지).

#### 5.6 G-6 — 봉인 노출 경로 0 (D02 §4 · D12 §6.3)

- **전제:** **출시 후보 빌드** (디버그 표시 제거 대상 빌드).
- **검사 축 (D12 확정 승계):** 릴 정지 연출 완료 전 **5경로 — UI·로그·사운드·햅틱·디버그 오버레이** — 에 결과·결과 상관 신호 노출 0.
- **방법 (확정):** ①디버그 결과 표시 코드의 출시 빌드 제거를 **정적 검사**(컴파일 플래그·심볼 스캔 — TL-1 결속) ②릴 정지 전 구간의 5경로 출력을 **런타임 캡처 대조** (TC-C11과 동일 하네스 재사용, 출시 후보 빌드로 재실행) ③사운드 축은 D11 층위 원칙(정지 전 결과 암시음 금지) 문면 기준으로 이벤트 발화 로그 대조.
- **판정:** 3방법 전건 노출 0. 위반 = **SV-1 차단 결함** 등록 (본 게이트는 발신 경로가 아닌 결함 트랙 — 자사 빌드 결함이므로).

#### 5.7 G-7 — 결제 모듈 미포함·권한 검사 (D16 §8.2-⑦ · D12 §11.6)

- **전제:** 스토어 제출물(플랫폼별 최종 패키지) 성립.
- **검사:** ①IAP·결제 SDK 심볼 **0** (전 빌드 — 데스크탑·모바일) ②스토어 결제 권한 선언 0 ③모바일 권한 매니페스트가 허용 목록과 일치.
- **권한 허용 목록 (확정 기준값):** 네트워크(광고 — 모바일 전속)·인터넷 상태 조회·진동(햅틱). 그 외 권한 선언 = 불통과. (저장은 앱 전용 영역 사용으로 별도 권한 불요 — 실플랫폼 API 대조는 G-7 집행 시 수행하며, 불일치 발견 시 본 목록을 총괄 경유로 동기한다.)
- **판정:** 3검사 전건 통과. 위반 = SV-1 등록 + 제출 중지.
