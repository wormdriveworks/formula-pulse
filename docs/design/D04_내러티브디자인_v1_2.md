## ② 본문

### 1. 메인 스토리 뼈대 — 마일스톤 연동형 선형 아크 (결정 2)

#### 1.1 구조 원칙

- **뼈대는 선형, 진행은 마일스톤 연동.** 서사 비트를 '시즌 몇 회차'가 아닌 **플레이어의 성취 마일스톤**에 연동한다. 잘하는 유저와 못하는 유저 모두 자기 속도로 같은 이야기를 완주한다. (D01 §8-5 "뼈대는 선형" 준수, 로그라이트 가변성과 양립)
- **진엔딩 조건:** 시즌 챔피언 달성 (무개정 확정 — 4막 아크는 여기서 완결된다).
- **에필로그 계층 (v1.1 신설 — 포스트게임):** **2연속 시즌 챔피언** 달성 시 에필로그 결말 재생 + '더블 챔피언' 칭호 취득(서사 프레임은 '계승' — §9). 에필로그는 진엔딩의 상위 목표가 아니라 **진엔딩 이후의 별도 계층**으로, 4막 아크·휠투휠 정서 규정(§1.2)을 침범하지 않는다. **부대조건(총괄):** ①기존 VN 규격·재사용 자산 범위 내 처리 — 신규 전용 아트 0 (G2 준수) ②트리거의 시스템 판정·실배치는 D08 이관(본 문서는 서사 내용만 확정). (이원 챔피언십은 D05 불채택 확정 — 구 예약 문구 삭제)
- 마일스톤 시스템은 §4의 이벤트 풀 변형 구조와 동일 인프라를 공유한다(데이터 드리븐, D01 §8-3).

#### 1.2 메인 아크 — 4막 구조

| 막 | 이름 (확정 — 결정 로그 #6) | 서사 질문 | 진입 마일스톤 (확정 — 트리거 수치는 D08) |
|---|---|---|---|
| 1막 | **그리드의 노이즈** | 폐차 직전의 머신과 무명 신인이 그리드에 설 수 있는가 | 게임 시작 (튜토리얼 포함) |
| 2막 | **북풍** | 노이즈가 '변수'로 인식되기 시작한다 — 그리드가 이 이름을 기억하는가 | 첫 포디움(3위 이내 입상) |
| 3막 | **브레이킹 포인트** | 완성된 연산(로렌츠)을 한 코너의 순간이 무너뜨릴 수 있는가 | 첫 투어 우승 |
| 4막 | **휠투휠** | 왕좌와 나란히 달릴 자격 — 미완성인 채로 그 곁에 서는가 | 로렌츠 첫 격파(단일 그랑프리 선착) |

**명명 해석 (확정 — 의도의 명문화):**
- **북풍 (2막):** 이중 의미의 복선 — 표면적으로는 노스윈드가 그리드에 이름을 알리는 막이며, 동시에 **보레아스(그리스 신화 '북풍의 신')**의 이름이 수면 위로 떠오르는 막이다. 기원 서사의 '단서' 단계(§6.2)가 2막에서 개시되는 것과 동기화된 **의도된 복선**이다.
- **브레이킹 포인트 (3막):** '순간'의 언어 — 추월은 브레이킹에서 결판난다. 3막의 절정인 로렌츠 첫 격파(단일 그랑프리)와 정확히 조응한다. 태그라인의 이중 노출은 노출 레이어 분리(대외 태그라인 / 인게임 막 제목)로 정당화한다 (D02 결정 로그 #8의 '펄스 3회 사용' 정당화와 동일 논리).
- **휠투휠 (4막):** 휠투휠은 '대등한 접전'을 말할 뿐 '넘어섬'을 말하지 않는다 — 이것이 언더독 서사의 도달점이다. **이 팀의 꿈은 왕을 밟는 것이 아니라 왕과 나란히 달릴 자격이었고, 우승은 그 결과로 따라온다.** 진엔딩의 정서 규정으로 삼는다.
- **표기 결의 대비:** 4막 중 '북풍'만 한자어 — 차가운 그리드의 언어(외래어) 속에서 팀의 장(章)에만 모국어가 배정되는 **의도된 대비**로 확정한다.

- **막 전환의 의미:** 막은 챕터 화면이 아니라 **이벤트 풀의 교체 단위**다. 막이 오르면 중계·라이벌·크루의 대사 풀이 다음 막 버전으로 갱신되어, 세계가 플레이어를 대하는 태도가 변한다. (No.13 의미 반전 아크의 구현 — D03 §1.1)
- **첫 시즌 필패 설계(D03 §2.3)의 흡수:** 1막 중 로렌츠와의 첫 조우 그랑프리는 필패 마일스톤로 처리한다. 패배 자체가 서사 비트가 되며, 배치·수치는 D08 소관.

#### 1.3 주요 마일스톤 목록 (확정 — 최종 배치·트리거 수치는 D08 공동)

### 4. U3 서사 축 5종 — 이벤트 풀 변형 구조 (DoD A4)

#### 4.1 변형 문법

- **관계 상태 태그 × 이벤트 풀 변형.** 각 서사 축은 소수의 **관계 상태**를 가지며, 동일한 이벤트 슬롯(예: 투어 종료 마일스톤 VN)에 상태별 변형 이벤트 셋을 둔다. 상태가 바뀌면 같은 슬롯에서 다른 이야기가 나온다.
- 상태의 **추적·저장은 D07(기록실)**, **전이 트리거 수치는 D07/D08** 소관. 본 문서는 상태의 정의와 각 상태의 서사 내용 방향만 확정한다.
- 상태 수는 축당 3~4개로 제한한다 (확정) — 라이팅 분량 = 슬롯 수 × 상태 수이므로, 상태 인플레이션이 곧 비용 인플레이션이다.

#### 4.2 축별 상태 정의 (확정 — 결정 로그 #10)

| 축 | 상대 | 관계 상태 진행 | 상태 전이의 서사 의미 |
|---|---|---|---|
| 왕좌 축 | 로렌츠 | 노이즈 → 변수 → 위협 → 대등 | "데이터 부족으로 평가 불가" → 처음으로 연산에 잡히는 존재 → 대책이 필요한 존재 → 왕좌를 다투는 상대 (D03 §2.3 관계 훅의 단계화) |
| 재회 축 | 카이 | 회피 → 대면 → 응어리 → 화해/결착 | 떠난 자의 죄책감이 냉소 뒤에서 드러나는 과정. 마르타와의 결별 전말이 함께 풀린다 |
| 동기 축 | 주드 | 동행 → 경쟁 → 호적수 | 같은 언더독의 병주(竝走). 순위 인접 시 변형 이벤트가 가장 자주 도는 축 (D08) |
| 계승 축 | 비앙카 / 셀린 | 무시/견제 → 동요 → 인정/집착 | '물려받은 자'(비앙카)와 '영원한 2번'(셀린)이 맨손의 13번에게 각기 다르게 흔들린다 |
| 파트너 축 | 베인 + 크루 | 베인 3단계(§5.4) + 크루 합류 상태(§7) | 메타 프로그레션(D06/D07)에 연동 — 별도 태그가 아닌 시스템 상태를 그대로 사용 |

- **운용 원칙:** 부정적 상태 고착을 만들지 않는다 — 모든 축은 전진형(관계가 깊어지는 방향)으로만 전이한다 (확정). 후퇴 전이는 추적·라이팅 비용 대비 효용이 낮다.

### 5. 작법·연출 규격 (Writing & Presentation Standards)

#### 5.1 레이스 텍스트 로그 규격 (DoD B5)

- **주 화자 = 중계진 (결정 로그 #7, D02 v1.3 §3.2로 정식 발효).** 레이스 중 벌어지는 사건의 서술은 **중계의 해설**로 전달한다. 베인은 로그의 서술자가 아니라 **릴 국면(전술 인터페이스)의 화자**로 역할이 분리된다 (§8.1).
  - 채택 근거: ①베인 성장 모순 해소 — '서툰 콜드 스타트 베인'과 '초반부터 온전해야 하는 로그 품질'의 잠재 충돌을 제거하고, 베인의 성장은 릴·전술 영역에서만 표현 ②릴 비인지 규칙(R2)과 완전 정합 — 중계는 릴을 볼 수 없는 존재 ③시대상 전달 지침(D02 §1)의 1순위 운반체가 원래 중계 문구.
  - 중계 화자는 **무명·최소 인격**으로 운용한다 (확정 — 결정 로그 #10, 미결 #7 해소. 네임드 캐스터·해설 체제는 설정 최소주의에 따라 불채택 — 일반명사이므로 D02 용어집 등재 불요).

| 항목 | 규격 |
|---|---|
| 화자 | 중계진 (무명 — 확정). 플레이어는 "No.13"·"노스윈드" 등 공적 호칭으로만 지칭 |
| 분량 | **최대 2줄** (D01 §8-4 절대 규칙). 1줄 권장. 줄당 전각 22자 이내 (조건부 확정 — D09 레이아웃 확정 시 보정 가능) |
| 시제 | 현재형 고정. ("추월한다", "막아선다" — 중계의 현장감) |
| 문형 | 단문. 한 문장 = 한 사건. 접속사로 두 사건을 잇지 않는다 |
| 주어 | 명시 원칙. 대명사(그, 그녀) 사용 금지 — 카 넘버·이름·팀명으로 지칭 (번역 친화 §5.6 겸용) |
| 수사 | **연출 등급 연동 (결정 로그 #9)** — 아래 '수사 허용량' 표 참조. 평시(L0)는 담백, 등급 상승 시 중계의 열기 해방. 톤 기조(§8.3 "절제가 기본값이기에 분출이 보상")의 로그 층위 구현 |
| 금지 | 릴·확률·시스템 언어의 세계관 내 노출 ("좋은 결과가 나왔다" ✕ → "슬립스트림에 올라탄다" ○). R11(릴·텔레메트리 언급 금지) 상시 적용 |

**수사 허용량 — 연출 등급(§5.5) 연동 (확정):**

| 등급 | 수사 허용량 | 감탄부호 |
|---|---|---|
| L0 스탠더드 | 수식어 0~1개. 평가어·감탄사 금지 — 정보 전달 우선 | 금지 |
| L1 임팩트 | 감탄사 또는 평가 수식어 **1개** 허용 ("과감합니다", "노련한 방어") | 최대 1개 |

- **설계 근거:** 로그는 최다 노출 텍스트 — 전면 완화 시 100번째 레이스에서 감탄사가 소음이 된다(반복 피로). 수사의 온도를 SFX·진동과 같은 등급 축에 태워, L2+의 그랑프리당 상한(§5.5)이 뜨거운 문장의 희소성을 시스템으로 보장한다.

#### 5.3 무언 주인공 — 선택지·지문 작법 규격 (DoD B6-2)

- **주인공의 발화는 존재하지 않는다.** 따옴표 대사 절대 금지 — 선택지도 '말'이 아닌 **행동·태도**로 쓴다.
  - ○ `[고개를 끄덕인다]` / `[스티어링을 고쳐 쥔다]` / `[마르타를 본다]`
  - ✕ `"알겠습니다"` / `"제가 하겠습니다"`
- 선택지 텍스트: 1줄, 전각 14자 이내 (조건부 확정 — D09 보정 가능). 대괄호 표기 통일.
- 선택지 수: 지점당 2~3개. **서사 분기를 만들지 않는다** — 선택은 직후 상대 반응의 변주만 발생시킨다 (D01 §8-5 분기 금지 준수).
- 1인칭 독백·내면 서술 금지. 주인공의 감정은 베인·크루·라이벌의 반응이 대신 그린다 (D03 §1.1).

#### 5.6 번역 친화 작법 규칙 (DoD B8 — 총괄 리뷰 이행)

1. **한 문장 = 한 절.** 복문·중문을 만들지 않는다 (기계·인간 번역 공통 안전).
2. **대명사 금지, 지시어 최소화.** 지칭은 이름·카 넘버·팀명으로 (성별 대명사 번역 오류 차단, §5.1과 겸용).
3. **변수 규칙:** 변수(플레이어명, 순위 등)는 문장 끝 또는 독립 성분 배치 지향. 변수 뒤에 조사가 붙는 문형 지양 — 조사 처리 불가 언어 대비, 문형 자체를 회피한다. (키 구조·구현은 D12)
4. **관용구·말장난·언어유희 금지.** 유머는 상황과 캐릭터로 만든다.
5. **모터스포츠 용어는 국제 통용 영문 기원 표기** (슬립스트림, 포디움, 폴 포지션 등) — 전 언어권 팬덤 공용어라 번역 안정적.
6. **경어 체계 단순화:** 베인 = 존댓말 고정(3단계 공통), 크루·라이벌은 캐릭터당 단일 어조 고정. 관계 변화에 따른 경어 전환을 만들지 않는다 (경어 없는 언어로의 번역 시 정보 손실 방지).
7. **텍스트 확장 여유:** UI 인접 텍스트는 영문 번역 시 약 130% 팽창을 전제 — 규격 상한(§5.1~5.3)은 이를 반영한 값이다 (조건부 확정 — D09 레이아웃과 교차 검증 후 보정 가능).

### 6. 베인·보레아스 기원 — 내용 정의 + 3단계 공개 (결정 3, DoD D14)

#### 6.1 기원의 내용 (본 문서 확정, 세계관 내 봉인 유지)

- **정의:** 보레아스(NW-01)와 베인은 **악시온 다이내믹스가 수년 전 폐기한 비공개 실험 라인** — 자가 학습형 관제 AI와 그 전용 실험 섀시다.
- **폐기 사유 (확정):** 학습형 AI의 판단은 재현·검증이 불가능하다 — "같은 입력에 같은 출력"을 신조로 하는 악시온의 데이터 지상주의가 스스로 낳은 이단을 용납하지 못했다. **회사의 철학 자체가 폐기 사유**이며, 이는 왕좌 축의 테마 대립(완성된 연산 vs 미완성 연산)을 혈통 차원에서 완성한다.
- **경위 결합:** 폐기 자산이 채권 정리 시장으로 흘러나와 마르타가 헐값 인수 (D03 §1.2와 무봉합 연결). 사샤 린드(현 악시온 재직)가 이 라인의 존재를 아는 인물로 설정된다 (확정) — §7.1의 복귀 서사와 결합.
- **봉인 유지 조건 (D03 이관 조건 이행):** 기원의 공개는 '누가, 왜 버렸는가'까지만. **릴이 어떻게 작동하는가와는 어떤 경우에도 연결하지 않는다** (R9). D02 용어집의 보레아스 정의('출처 불명의 재생 프로토타입')는 **개막 시점의 세계관 내 공적 인식**으로서 본 절과 무모순 — 공개는 4막의 서사 내 사건이므로 용어집 갱신 불요 (전수 리뷰 판정 R-C). 악시온 내 개발자 개인·프로젝트명 등 신규 고유명사를 만들지 않는다 (확정 — 설정 최소주의).
- **테스트 드라이버 이력 (v1.2 보강 — D08 v1.0 · 총괄 판정 A-3, 사용자 승인):** 폐기 이전, 보레아스 원형의 최종 검증 단계에서 당시 악시온 소속의 빅터 로렌츠가 테스트 드라이버를 맡았다. 완전한 제어 — 변수의 소거 — 라는 그의 접근으로는 탑재 AI의 미승인 출력이 재현·검증되지 않았고, 그는 이를 결함으로 보고했다. 악시온의 폐기 결정은 위 확정 사유(재현·검증 불가 = 회사 철학)의 **구체 사례이며 이를 대체하지 않는다** (C-3-②). 그 판단은 그의 세계 안에서 옳았다 — 그 철학으로 그는 더블 챔피언이 되었다. 플레이어와 베인의 관계는 이 한계와 대비되는 '접근의 차이(제어가 아닌 동기화)'로만 서술한다 — **동기화가 출력을 여는 원리는 봉인한다 (R9, C-3-①).** 신규 고유명사(프로젝트명 등)는 만들지 않는다 (C-3-③). 단서 3의 '요행' 대사(D08 §8.6)는 본 이력의 이중 의미 근거로 조응한다. 반영 문안 초안은 D08 채팅 제공, 집행은 총괄.

### 7. 크루 합류/복귀 이벤트 서사 (DoD D15 — 조건·효과는 D07)

#### 7.1 사샤 린드 — 복귀 (심화 설계)

- **구조:** 3비트 — ①적으로서의 조우(악시온 소속으로 그리드에서 마주침. 침묵과 관찰) ②흔들림(기원 단서와 교차 — 악시온이 버린 것을 노스윈드가 달리게 하고 있다) ③복귀(명분: "데이터가 설명하지 못하는 걸 봤다. 그걸 분석할 수 있는 자리는 여기뿐이다") — 구조 확정, 대사는 방향 예시(실제 텍스트는 범위 밖)
- **응어리 처리:** 사샤의 이적은 배신이 아닌 생존이었다 — 마르타는 이를 탓한 적이 없고, 탓하지 않았다는 사실이 사샤에게는 더 무거웠다. 복귀 후 테오와의 온도차(반김/서먹함)가 잔여 서사 재료 (확정).
- **기능 결합:** 사샤 = 기원 서사(§6)의 '단서' 단계 운반체. 복귀 서사와 메인 아크가 한 인물에서 교차해 라이팅 효율을 높인다.

#### 7.2 오스카 브란트 — 합류

- **구조:** 2비트 — ①탐문(오스카가 제 발로 개러지에 나타나 보레아스를 뜯어보게 해달라 요구. 합류가 아닌 구경이 목적) ②합류("이 머신의 펄스 드라이브는 어디서도 본 적 없는 물건이다. 내가 없으면 당신들은 이걸 죽인다") — 구조 확정, 대사는 방향 예시. 개체 특이성 한정 표현으로 D02 §3.1(표준 동력)과 정합 (전수 리뷰 보정 R-B)
- **결:** 팀에 대한 충성이 아닌 머신에 대한 애정으로 합류하는 기술 낭만파 — 이후 팀 정으로 물드는 과정은 파트너 축 풀에서 소화.

#### 7.3 나디아 리스 — 합류

- **구조:** 2비트 — ①접근(첫 포디움 마일스톤 이후 — 조건 수치는 D07/D08, "팔리는 이야기"가 된 노스윈드에 스폰서 딜을 물고 등장) ②합류(수완가의 계산 뒤에 있는 진심 — 그는 이 팀의 전성기를 기억하는 사람이다)
- **기능:** 나디아의 합류 = 아웃게임 경제(스폰서 계열, D06/D07)의 서사적 개통 시점과 동기화한다 (방향 확정 — 개통 시점·조건 수치는 D06/D07).

### 8. 화자 규칙 · 시간 압박 연출 · 톤앤매너

#### 8.1 화자 규칙 (DoD C10)

| 화자 계열 | 담당 | 규칙 |
|---|---|---|
| **중계** | 레이스 로그 **주 화자** (결정 로그 #7) — 전개 국면의 사건 서술 + 월드 텍스처(시대상·군중 열기) + 순위 변동의 공적 서술 | §5.1 규격. 3인칭 현재형·합쇼체(확정). 무명·최소 인격(확정 — 미결 #7 해소). 플레이어를 "No.13" 또는 팀명으로만 지칭. 릴 비인지(R2) |
| **베인** | **릴 국면 화자** (전개 후보 제시·전술 조언·시간 압박 §8.2), VN 대화 상대, **튜토리얼 내레이터** | §5.4 규격. 튜토리얼은 베인 1단계 말투로 수행 — '설명이 서툰 실험체'가 곧 세계관 정합적 튜토리얼 화자 (확정) |
| 피트 무전 (크루) | 전술 정보 + 정서 (마르타=간결한 지시, 테오=감정 반응 등) | 캐릭터당 단일 어조 고정 (§5.6-6) |
| 라이벌 무전/현장 발화 | 관계 상태(§4.2)의 레이스 내 표출 — 도발·인정·경계 | 짧은 1줄 위주. 릴 비인지(R2) 절대 준수 |
| 시스템 | 순수 UI 정보(결산 수치, 메뉴) | 서사 성분 배제. 본 문서 규격 밖 — D09 소관 |

- **국면 분리 원칙 (결정 로그 #7):** **릴 국면 = 베인 전속** (판단·전개 후보의 언어) / **전개 국면 = 중계 주도** (벌어진 일의 언어). 전개 국면에서 화자 경합 시 중계 > 피트 무전 > 라이벌 순 (확정). 한 로그 슬롯에 화자 1인 원칙.
- **총괄 부대조건 (D02 v1.3 결정 #15 — 구속, 결정 로그 #8):**
  1. **중계 화자는 텍스트 전용 — 스탠딩 아트 없음.** VN 이벤트에 중계 화자를 등장시키지 않으며, D10 아트 목록에 포함을 금지한다 (아트 수량 증가 차단).
  2. **중계 화자의 릴·텔레메트리 언급 절대 금지.** 중계는 '텔레메트리 릴'이라는 단어 자체를 발화할 수 없다 — 릴 결과는 언제나 트랙 위의 사건(추월·방어·라인 선택)으로만 서술된다 (D02 봉인 규칙 2의 텍스트 층위 보장. §5.7 R2와 연동).
- **D02 정합:** 본 화자 체계는 D02 v1.3 §3.2(연출 역할 재배분, 결정 #15)로 정식 발효되었다. 베인의 '연출 코스트 0 운반체' 지위·차별화 3조건은 불변.

#### 8.2 F2 시간 압박의 연출 문법 (DoD C11 — 수치는 D05)

- **적용 국면:** 본 절은 **릴 국면(베인 전속)**의 문법이다 — 화자 개편(#7)과 무관하게 베인 축약 발화 설계를 유지한다.
- **원칙: 압박을 설명하지 않고 발화가 짧아진다.** 잔여 시간 구간에 따라 베인 대사 풀이 축약형으로 전환된다 (구간 구조 확정 — 구간 경계 수치는 D05):
  - 여유 구간: 표준 2줄 로그 → 경고 구간: 1줄 → 임박 구간: 체언 종결 ("3번 코너. 판단을.")
- **타임아웃:** 무작위 행동 자동 발동(D01 F2)의 서사 번역 = **"베인이 대신 판단했다"가 아니라 "머신이 코너에 진입해버렸다"** — 베인의 자율 행동으로 쓰면 R6(관제 한정)과 충돌하므로, 시간의 경과 자체가 결과를 강제한 것으로 서술한다. 타임아웃 직후 베인의 수습 대사 계열을 둔다 (확정).
- **세계관 근거 승계:** "판단의 유예는 곧 기회의 상실" (D02 §4). 시각 연출(타이머 UI 등)은 D09 소관.

#### 8.3 톤앤매너 (결정 4, DoD C13)

- **기조: 절제된 프로페셔널 + 결정적 순간의 열기.** 평시 텍스트는 건조하고 정제되어 있다. 감정의 분출은 마일스톤·L2 이상 연출 순간에만 허용 — 절제가 기본값이기에 분출이 보상이 된다.
- **기본 정서:** 팩토리의 세련된 위압 vs 언더독의 낡고 뜨거운 것 (D02 §1의 대비). 언더독 측 텍스트에도 자기 연민·신파 금지 — 가난은 담담하게, 승리는 뜨겁게.
- **캐릭터 변주 (기조 위의 양념):** 경쾌 담당 = 테오·나디아·볼코바 / 냉소 담당 = 카이 / 기품 담당 = 홀로웨이. 변주는 캐릭터 대사에만 허용하며 중계·지문은 기조를 유지한다.
- **금지:** 열혈 스포츠물 문법(외침·긴 감정 토로), 제4의 벽 개그, 밈 인용.

### 9. 더블 챔피언 칭호 — 변동·연장 연출 원칙 (DoD D16 — 실배치는 D08 공동)

- **칭호 고정 + 수식 갱신형 (확정 — v1.1에서 근거 보정·계승 규칙 부가):** '더블 챔피언'은 **개막 시점 기준** 로렌츠의 브랜드화된 고유 칭호로 고정 운용한다(용어집 정합). 플레이어가 챔피언 달성에 실패한 시즌마다 로렌츠가 연속 우승을 이어가는 경우, 칭호를 "트리플—"로 갱신하지 않고 **중계·이벤트의 수식어로만** 연장을 표현한다 (예: "3연패를 노리는 더블 챔피언").
  - 근거 (v1.1 보정): ①용어집(D02 §8)의 칭호 정의 안정성 — 단독으로 본 결정을 지탱한다. (구 근거 ② '이원 챔피언십 충돌 예방'은 D05 불채택으로 소멸 — 결정 로그 #12)
- **칭호 계승 규칙 (v1.1 신설):** 플레이어가 **2연속 시즌 챔피언**(D02 정의와 동일 조건 — 연속만 인정, 홀로웨이 선례 준용)을 달성하면 '더블 챔피언' 칭호를 **취득**한다. 세계관 정의는 이력 조건 충족형이므로 로렌츠의 칭호는 **박탈·이전되지 않는다** — '계승'은 에필로그의 서사 프레임이며, 중계 표현은 "두 번째 더블 챔피언의 탄생" 계열로 작성한다(칭호 이전 표현 금지). 취득 이후의 수식 운용(플레이어 지칭 등)의 실배치는 D08 이관.
- **왕좌 축 연동:** 로렌츠의 연속 우승 누적은 왕좌 축(§4.2)의 '위협' 상태 이벤트 풀에서 "더 높아진 벽"으로 회수한다 (확정).
- ~~D05에서 이원 챔피언십 채택 시 본 절을 재검토한다~~ → **해소 (v1.1):** D05 불채택 확정. 본 절은 계승 규칙 부가로 재검토 완료 (미결 #4 해소, 결정 로그 #12).
