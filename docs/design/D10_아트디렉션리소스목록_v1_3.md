- 화면·요소의 구조 기준 = D09/D09-2 별첨A (요소 ID `화면ID-E##`는 본 문서 에셋 목록의 공통 참조 키)

- 수치 조정 창구 = D13·실기 반복 테스트 (본 문서의 '확정 기준값'은 구조 불변·값만 조정 원칙 — D09 결정 #5 전례 준수)

### 1.4 포스트 이펙트 불채택 (결정 #3)

CRT·스캔라인·글리치 등 화면 필터류는 **불채택**한다. 신규 옵션 0 — D09 §6.1 확정 옵션 체계 무접촉. 레트로 무드는 도트 기법·팔레트·의장으로만 확보한다.

## 2. 기술 규격 — 캔버스·그리드·컬러 (K2·K3)

### 2.1 기준 캔버스 (확정)

| 플랫폼 | 도트 원도 캔버스 | 표시 배율 | 출력 |
|---|---|---|---|
| 데스크탑 | **640×360** | **×3 (정수)** | 1920×1080 (D09 1080p 앵커 정합) |
| 모바일 (세로) | **360×780 (확정 기준값)** | ×3 (정수) | 1080×2340 (D09-2 기준 해상도 정합) |

- 모바일 논리 좌표(390dp)와 도트 캔버스의 매핑, 기기별 배율 처리는 **D12 공동 검증** (§11 이관, P-5-③ 확장 — §2.5).
- 1080p 초과 데스크탑 해상도: 정수배 우선(×4=1440p 근사, ×6=4K) + 잔여는 레터박스/니어리스트 (확정 기준값 — D12 실기 검증).

### 2.2 그리드 규율

1. **믹셀 금지 (제작 층):** 한 화면 내 도트 픽셀 크기는 단일 그리드를 유지한다. 회전·비정수 스케일이 적용된 에셋의 사전 베이크 금지.
2. **레이어별 디테일 밀도 차등 (허용):** 버스트업 = 고밀도 디더링 / 필드 스프라이트·씬 컷 = 간결 셀 — 픽셀 크기는 동일하되 묘사 밀도만 차등 (PC-98~32비트기 실물 문법).
3. **표시 층 예외 조항:** D09 O8 UI 스케일(110/125%)은 확정 기준값이므로, 해당 옵션 적용 시의 비정수 표시 확대는 **니어리스트 네이버 허용 (확정)** — 판독성 실기 검증 D12. 본 예외는 표시 스케일 층에 한정되며 제작 층 믹셀 금지 원칙과 층위가 다르다.

### 2.3 마스터 팔레트 (K3 = B안)

- **전역 마스터 팔레트 60색 (확정 기준값):** 코어 뉴트럴 16 (야간 아스팔트·강철·콘크리트 계조) + 텔레메트리 네온 16 (시안·마젠타·앰버·자색 발광 계열) + 팀 컬러 블록 16 (악시온·불카·그리폰·노스윈드 각 4) + 환경·피부·머티리얼 12.
- **기능 컬러 면제 조항 (구속):** 심볼 6종 이중 부호화 색·색각 대체 팔레트·게이지 상태색·경고색은 접근성 요건이 마스터 팔레트에 **우선**한다. 하드웨어 팔레트 락(스프라이트당 색수 제한)은 재현하지 않는다.

### 2.4 색각 대체 팔레트 (D09 §6.1 이관 해소)

대체 팔레트 **1종 (확정 — D09 옵션 기준값 '팔레트 1~2종' 내).** 적용 대상 = 심볼 6종·속성 아이콘 6종·게이지류·상태 컬러. **색상만 교체, 도상 불변** — 색+도상 이중 부호화(§5.1)가 1차 방어이며 팔레트는 2차 보정. 색 배정표는 §8.2 에셋 목록에 부속.

### 2.5 너비 가변 대응 — 도트 자산 방식 (P-5-③ D10 측 입력)

도트 자산의 너비 가변 대응 = **고정 캔버스(360) + 배경 블리드 여백** (확정 기준값: 좌우 각 +24px 블리드 원도) 방식을 채택한다. 신규 에셋 비용은 배경류의 블리드 여유분에 한정되며 UI 컬럼 재배치 비용은 발생하지 않는다. **최종 판정(폴백 '고정 폭 컬럼' 전환 여부)은 D12 합류 공동 판정으로 예약** — 전면 도트 채택으로 판정 쟁점에 '정수 스케일 정합(기기별 배율)'이 확장됨을 명기한다 (마스터플랜 P-5-③).

## 4. 머신 아트 규격
