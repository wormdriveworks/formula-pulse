## ① 문서 목적·범위

본 문서는 프로젝트의 비전·핵심 재미·타겟·플랫폼 전략을 확정하여, 이후 모든 기획·아트·기술 문서(D02~D16)가 공유할 단일 기준점을 제공한다. 시스템의 상세 규칙(스핀 규칙, 재화 수치 등)은 다루지 않으며, 해당 내용은 각 후속 문서로 위임한다.

## ② 본문

### 1. 한 줄 컨셉 (Elevator Pitch) — 확정

**이원 운용 구조:** 감성 태그라인(훅)과 장르 라인(판별)을 분리 병기한다.

> **[태그라인]**
> 코너마다 돌아가는 운명의 슬롯.
> 찰나의 브레이킹 포인트에서 승부수를 던져, 트랙 위 예측불허의 드라마를 써 내려가라.
>
> **[장르 라인]** 턴제 레이싱 로그라이트 (Turn-based Racing Roguelite)

- **태그라인:** 첫 문장이 메카닉(슬롯)×소재(레이싱)를 0.5초 안에 결합 전달하고, 둘째 문장이 핵심 재미(F2 결단의 순간)와 드라마(F3 서사 축적)를 수식한다. "브레이킹 포인트"는 레이싱 용어이자 '결단의 순간'의 이중 의미로 기능한다.
- **장르 라인:** 주 타겟(로그라이트 코어층)이 스토어에서 자기 게임인지 즉시 판별하는 용도. 스토어 페이지·보도자료 등 모든 대외 표기에서 태그라인과 병기한다. (→ D15 승계)

### 2. 핵심 재미 (Core Fun) — 3요소

역기획 4단계의 코어 정의("타임 리미트의 텐션 속에서 자원을 소모해 무작위성을 통제하고, 그 결과로 파생되는 상황적 드라마를 돌파하는 쾌감")를 다음 3요소로 구조화한다.

| # | 요소 | 내용 |
|---|------|------|
| F1 | **통제된 무작위성 (Controlled Randomness)** | 스핀(릴)의 무작위 결과를 자원·스킬·지식으로 부분 통제하는 의사결정 재미. 사전 텐션(릴 회전의 기대/불안)과 사후 개입(자원 소모로 수습)의 이중 구조. (역기획 2단계 원칙 승계) |
| F2 | **소프트 타임 리미트 하의 결단** | 턴제이지만 무한정 고민할 수 없는 부드러운 시간 압박. 빠른 결정에 소폭 보너스, 시간 초과 시 무작위 행동 자동 발동. (역기획 4단계 규칙 승계) |
| F3 | **창발적 라이벌 드라마** | 무작위 결과가 수치 증감이 아닌 '레이스 상황(추월·방어·사고·명장면)'으로 번역되어, 라이벌과의 관계와 기록이 세션을 넘어 축적되는 서사적 보상. |

### 3. USP (Unique Selling Points)

| # | USP | "왜 ToF/VS/기존 로그라이트가 아니라 이 게임인가" |
|---|-----|------------------------------------------------|
| U1 | **슬롯 릴 × 레이스 전개** | 스핀 결과가 데미지 숫자가 아니라 레이스 상황(추월/블로킹/슬립스트림/사고)으로 번역된다. 슬롯 메카닉을 레이싱 문법으로 재해석한 사례는 시장에 부재. |
| U2 | **순위 경쟁형 로그라이트** | 적을 '죽이는' 구조가 아니라 라이벌들과 '순위를 다투는' 구조. 같은 RNG 결과라도 순위 맥락에 따라 가치가 달라져, 기존 전투형 로그라이트와 다른 의사결정 지형을 만든다. |
| U3 | **라이벌 서사의 축적** | 시즌을 거듭하며 라이벌과의 대전 기록·관계·명장면이 누적되어 '나만의 그랑프리 역사'가 된다. 로그라이트의 반복 플레이에 서사적 이유를 부여한다. |

*비고: '소프트 타임 리미트'는 USP가 아닌 핵심 재미(F2)의 구성 요소로 분류. '저비용 고밀도 연출'은 유저향 소구점이 아닌 제작 전제(§8)로 분류.*

### 4. 타겟 유저

**전략: "A를 B로 포장" — 인게임은 코어층 기준으로 설계하고, 아웃게임과 표현층에서 내러티브 매력을 입힌다.**

| 구분 | 대상 | 역할 |
|------|------|------|
| **주 타겟 (설계 기준)** | 로그라이트 코어층 — Slay the Spire, Balatro 등에서 빌드·시너지·확률 계산에 재미를 느끼는 유저 | 인게임(레이스) 시스템의 깊이·밸런스는 전적으로 이 층을 기준으로 설계한다. Steam 구매 전환의 중심. |
| **포장 레이어 (표현 기준)** | 내러티브/캐주얼층 — 스토리와 캐릭터에 끌리는 유저 | 아웃게임(허브, 시즌 서사, 라이벌 관계, 기록실)에서 서사적 매력을 전달. 코어층에게도 반복 플레이의 정서적 보상으로 작동. |
| **마케팅 훅 (설계 비용 0)** | 레트로 레이싱 애니메이션 세대 (사이버 포뮬러 등) | 소재의 향수로 유입시키는 마케팅 소구점으로만 활용. 이 층을 위한 별도 시스템은 설계하지 않는다. |

**가드레일 (후속 문서 구속 규칙):**
- **G1. 스토어 페이지 미스매치 방지:** 스크린샷·트레일러의 첫 소구는 반드시 시스템(릴·레이스 화면)으로 하고, 서사는 두 번째 훅으로 배치한다. 내러티브 기대만으로 구매한 유저의 부정 리뷰 리스크를 차단한다. (→ D15 승계)
- **G2. 내러티브의 비강제성 (개정):** 아웃게임 서사 콘텐츠는 열람형(도감·기록실·관계도 등)을 원칙으로 하되, **시즌 시작·종료 및 투어 시작·종료 시점을 VN(비주얼 노벨)식 내러티브 이벤트의 허용 지점으로** 둔다. 시즌 시작·종료는 기본 배치 지점이며, 투어 시작·종료는 허용 지점으로서 실제 배치 밀도(전체/일부 투어 여부)는 D04·D08에서 확정한다. (→ D04, D07 승계)
  - **VN 이벤트 정의:** 인물 일러스트 + 간단한 대사로 서사를 강화하는 저부하 장치. 게임 핵심 메카닉에 개입하지 않는다.
  - **조건 1 — 아트 규격:** 인물 아트는 이벤트별 전용 일러스트가 아닌 **캐릭터당 1종 스탠딩(버스트업) + 소수의 표정 차분**의 재사용 자산으로 한정한다. 아트 코스트는 '이벤트 수'가 아닌 '캐릭터 수 × 표정 수'에만 비례해야 한다. (→ D10에서 수량 확정. §8-1의 '희귀 이벤트 전용 일러스트'와는 별개 트랙)
  - **조건 2 — 비강제성 유지:** 모든 VN 이벤트는 스킵 가능하며, 놓친 서사는 기록실에서 다시 열람할 수 있다.
  - **조건 3 — 단문 원칙 승계:** '짧게' 원칙을 승계한다. VN 이벤트 전용 대사 규격(대화당 줄 수, 이벤트당 대사 수 상한)은 D04에서 정의.
  - **조건 4 — 반복 피로 대책 [가안]:** 이벤트는 데이터 드리븐 풀로 구성하고, 시즌 성적·라이벌 관계에 따라 변형되는 구조를 지향한다. (→ D04, D08에서 확정)

### 6. 경험 구조 (세션 루프 → 메타 루프)

**3계층 구조: 대회(그랑프리) → 투어 → 시즌.** '런(Run)'은 중간 계층인 투어에 배치한다.

| 계층 | 단위 | 길이 | 역할 |
|------|------|------|------|
| 소 | **대회 (그랑프리)** | **10~15분 (확정 — D08 v1.0, H1 해소안 ①)** | 최소 플레이 호흡. 모바일 "한 판 더" 단위. 대회 종료마다 중간 결산·저장. |
| 중 | **투어 (Tour)** = 대회 4개 [가안] | 40~60분 [가안] | **로그라이트의 '1런' 단위.** Steam 한 호흡. 완주/탈락 판정이 이뤄지는 층. 각 투어는 고유한 지역 무대를 가진다. |
| 대 | **시즌 (Season)** = 투어 5개 = 대회 20개 [가안] | 여러 런에 걸침 | **장기 서사·챔피언십 단위.** 투어 성적이 챔피언십 포인트로 누적되고, 라이벌 관계·기록이 축적되는 무대. 시즌 시작·종료 VN 이벤트(기본) 및 투어 시작·종료 VN 이벤트(허용 지점)가 붙는 층. (G2) |

```
[메타 루프 — 허브(개러지)]
   영구 성장 · 머신 튜닝 · 기록/도감 열람 · VN 이벤트 다시보기
        │  시즌 진입 ─ [VN: 시즌 오프닝]
        ▼
[시즌 = 투어 5개]                          [가안: 투어 수 5]
   ┌─ 투어 1 (지역 무대 A) ────────────┐   ← 투어 시작·종료 = VN 허용 지점
   │   대회1 → 대회2 → 대회3 → 대회4   │   ← 1런(Run) = 투어 1개
   │   (대회마다 중간 결산·저장)        │      [가안: 투어당 대회 4]
   │   투어 종합 순위 → 챔피언십 포인트 │
   ├─ 투어 2 (지역 무대 B) ────────────┤
   ├─ ...                              │
   └─ 투어 5 → 시즌 챔피언십 결산 ─────┘
        │  시즌 종료 ─ [VN: 시즌 엔딩]
        ▼
   메타 재화 획득 → 허브로 귀환 → 다음 시즌
```

- **이중 페이싱의 의도:** Steam에서는 투어 한 호흡(40~60분, 로그라이트 1런 기대치 충족)으로, 모바일에서는 대회 단위(**10~15분 — D08 확정**, ToF식 "한 판 더")로 끊어 즐긴다. 코어는 동일하되 플레이 호흡만 플랫폼이 흡수한다. (원 코어, 투 플랫폼)
- **시즌 확장의 의도:** 장기 서사(U3)를 쌓기에 대회 4개는 짧으므로, 투어 5개(대회 20개)를 하나의 챔피언십 서사로 묶는다. 투어마다 무대·배경이 바뀌어 세계관(D02)·레벨 디자인(D08)과 자연스럽게 결합한다.
- **파생 질문 (후속 이관):** 투어(런) 실패 시 시즌 처리(투어 재도전 허용 여부), 챔피언십 포인트 누적 방식, 시즌 전체 실패 조건 → **D05(사망/판정 규칙), D08(구성·수치)에서 확정.**
- **레이스 내부 턴 구조·스핀 규칙:** D05로 위임. **대회 간 중간 결산 상세(보상·저장):** D06, D08로 위임.
- **신규 용어:** '투어', '시즌', '대회(그랑프리)', '챔피언십 포인트[가안]', '개러지[가안 — 허브 명칭]' → D02 용어집 등재 예정.

### 7. 소재 결합 개요 (레이싱 × 스핀)

- 세계관·설정은 완전 오리지널로 신규 창작한다(소재 레퍼런스: 신세기 GPX 사이버 포뮬러 — 분위기 참조용, 설정 차용 금지). (→ D02)
- '스핀'이 레이싱 세계에서 무엇을 의미하는지는 두 차원으로 나누어 확정한다: **세계관 언어 차원(명칭·설정·서사적 정당화)은 D02~D04에서**, **규칙 차원(레이스 전개의 릴 번역 방식, 턴의 정의 — 코너/랩/이벤트 단위)은 D05 착수 시점의 최우선 확정 질문으로** 다룬다. (마스터플랜 §3 순서 근거와 정합) 본 문서에서는 "스핀 결과 = 레이스 상황의 전개"라는 방향성(U1)만 확정한다.
- 무작위 결과의 연출은 텍스트 로그(최대 2줄 단문) + SFX + 화면 진동 조합을 기본으로 한다. (역기획 4단계 규칙 승계, → D04 작법 가이드)

### 8. 제작 전제 (Production Constraints — 전 문서 구속)

역기획 4단계 확정 사항을 프로젝트 헌장으로 승계한다. 모든 후속 문서는 아래를 위반할 수 없다.

1. **저비용 고밀도 연출:** 기본 연출은 정적 2D + 텍스트 로그 + SFX + 카메라 셰이크. 전용 일러스트는 희귀 이벤트(보스급 라이벌 조우, 히든 내러티브)에 한정. 단, VN 이벤트용 인물 스탠딩 아트(§4 G2 조건 1)는 '전용 일러스트'가 아닌 **재사용 자산의 별도 트랙**으로 관리하며 본 조항과 충돌하지 않는다. 또한, **상황 재사용형 저프레임 씬 컷(레이스 씬 패널 — D09 §3.1.1)**은 다음 조건 하에 '재사용 자산의 별도 트랙'으로 관리하며 본 조항과 충돌하지 않는다: ①컷당 최대 10프레임 ②상황 유한 목록(상한·목록은 D10 공동 확정)의 전 대회 재사용 — 아트 코스트는 '상황 수 × 프레임 수'에만 비례 ③정지 컷 폴백 상시 성립. *(v1.2 부기 — 조건부 예약 수정 R-D09-A, 결정 로그 #13)*
2. **턴제 상태 머신:** 실시간 액션·물리 충돌 판정 전면 배제.
3. **데이터 드리븐:** 이벤트·밸런스는 테이블 기반으로 설계하여 텍스트 이벤트 → 일러스트 이벤트 교체·확장이 용이한 구조로 구축.
4. **2줄 단문 규칙:** 모든 상황 묘사 텍스트는 최대 2줄 이내.
5. **폐기 목록 승계:** 실시간 액션/물리 판정, 방대한 분기형 다중 스토리 라인(뼈대는 선형, 턴 단위 상황 전개에서만 창발성 부여).
