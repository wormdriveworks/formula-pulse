## ① 문서 목적·범위

본 문서는 아웃게임 계층의 **공간(허브)·메뉴 구성·시스템 규칙·인스턴스 목록**을 확정하여, D06이 확정한 재화·Sink 구조(K1~K8)에 실체를 부여하고 D08(실배치)·D09(UI)·D13(수치)이 이어받을 수 있는 기반을 제공한다. 아울러 선행 문서 이관 항목(크루 직능 매핑·영입 조건, 스킬 인스턴스·덱 규칙, 관계 상태 추적, 베인 3단계 임계 수치, 소모품 인스턴스, 스폰서 계약 인스턴스)을 해소한다.

**범위 가드:** 아웃게임의 공간·메뉴 구성, 시스템 규칙, 인스턴스 목록까지. **가격·계수 등 밸런스 수치는 D13 / 콘텐츠 실배치·난이도 검증은 D08 / UI 레이아웃·플로우는 D09.** 플랫폼 중립(마스터플랜 0-5) — 본 문서에 특정 플랫폼 전용 규칙을 두지 않는다.

## ② 본문

### 0. 페이싱 기준선 선언 (총괄 재고지 F1-승계 — 필수 준수)

본 문서의 모든 리듬·밀도·기대치 서술은 아래 **작업 기준선**을 전제로 한다. 이는 D06 §0과 동일한 기준선이다.

| 항목 | 기준선 |
|---|---|
| 그랑프리 목표 길이 | **10~15분** (D05 §2.2 확정 기준값) |
| 투어 구성 | **투어당 4대회** |
| 투어 목표 길이 | **40~60분** |
| 시즌 구성 | **5투어 / 20대회** |

- **D02 §8 용어집의 `15~25분(확정)`을 기준선으로 삼지 않는다** — 해당 (확정)은 D08의 구조 수치 판정(마스터플랜 H1)으로 해소가 예약되어 있으며, D05 §2.2의 상향식 산정이 이미 10~15분을 지지한다.
- > **[재보정 조항 — 지점 1/3]** 구조 수치의 확정 권한은 **D08**에 있다. D08 판정이 본 기준선과 다를 경우, 본 문서의 시간·밀도 관련 기준값(§2.3 체류 리듬, §8 베인 임계 환산)은 **판정 결과에 연동하여 재보정한다.** 재보정 대상은 *스케일*이며, 메뉴 구성·규칙·인스턴스 구조는 불변이다.

### 1. 아웃게임 국면 정의 (DoD A4)

#### 1.1 계층 구조

아웃게임은 인게임(D05 §3 그랑프리 상태 머신)의 바깥에서 **3계층**으로 작동한다. D06 §3.1의 Sink 계층 배분을 공간·화면으로 번역한 것이다.

| 계층 | 공간·화면 | 허브 귀환 | 성격 |
|---|---|---|---|
| **대회 간** (투어 내부) | **간이 정산 화면** | ✕ | 런 중의 짧은 숨고르기 — 최소 기능만 |
| **투어 간** (런 경계) | **개러지** (허브) | ○ | 아웃게임의 본체 — 전 기능 |
| **시즌 간** | 개러지 + **시즌 오버홀** | ○ | 투어 간 전 기능 + 오버홀 실행 |

#### 1.2 접근 매트릭스 (확정)

| 기능 | 간이 정산 (대회 간) | 개러지 (투어 간) | 시즌 간 |
|---|---|---|---|
| 필드 정비 (K2) | **○** (D06 §3.3) | ✕ (전면 정비로 대체) | ✕ |
| 전면 정비 (K3) | ✕ | **○** | **○** |
| 소모품 보충 (K4) | **○** (D06 §3.5) | **○** | **○** |
| 머신 튜닝 (K1) | ✕ | **○** | **○** |
| 스킬 해금 (K5) · 덱 슬롯 확장 (K6) | ✕ | **○** | **○** |
| **덱 구성 교체** (무비용 설정) | **○ (확정)** | **○** | **○** |
| 크루 영입 (K7) | ✕ | **○** | **○** |
| 개러지 시설 (K8) | ✕ | **○** | **○** |
| 기록실 열람 | ✕ | **○** | **○** |
| 스폰서 계약 갱신 | ✕ | **○** (투어 결산 시) | **○** |
| 시즌 오버홀 | ✕ | ✕ | **○** (시즌 결산 직후 1회 — D06 §5.3) |

- **간이 정산의 최소주의 (확정):** 간이 정산 화면의 기능은 **필드 정비 / 소모품 보충 / 덱 교체 3종을 상한**으로 한다. 덱 프리셋 전환(시설 G3)은 덱 교체의 하위 기능으로 3종 상한 내에 포함된다. 축적형 Sink(K5~K8)는 개러지 전속이다 — D06 §3.1의 계층 배분("아웃게임" = 개러지 층)을 문자 그대로 이행하며, 런 중의 결정 밀도를 낮게 유지한다.
- **덱 교체 허용(간이 정산 포함 — 확정)의 근거:** 덱 교체는 재화 소모가 없는 설정 변경이므로 Sink 계층 규칙과 무관하다. 투어 내 전술 적응(다음 대회 상대·서킷에 맞춘 스킬 교체)을 허용하면 지식 기반 통제(D05 §6.3)가 아웃게임까지 연장된다. 런의 긴장은 섀시 컨디션·자원이 담당하므로(D05 §8) 덱 잠금으로 보강할 필요가 없다.

### 2. 허브 — 팀 개러지 (DoD B5·B6·B7)

#### 2.1 시설(메뉴) 목록과 Sink 대응 (DoD B5)

개러지는 단일 허브 화면 안의 **기능 스테이션** 집합으로 구성한다. 물리적 공간 이동을 요구하지 않는다(소규모 팀 전제 — 마스터플랜 0-4).

| 스테이션 | 기능 | Sink 대응 | 개방 조건 |
|---|---|---|---|
| **정비 베이** | 전면 정비, 소모품 보충 | K3·K4 | 시작 (테오 상주) |
| **튜닝 벤치** | 머신 튜닝 — 기본 4계통 | K1 | 시작 (마르타 상주) |
| **심화 튜닝 벤치** | 머신 튜닝 — 심화 2계통 | K1 | **오스카 합류** |
| **전략실** | 스킬 해금, 덱 구성, 덱 슬롯 확장 | K5·K6 | 시작 (합류 후 사샤 상주) |
| **기록실** | 라이벌 파일, 통산 기록, 아카이브 (§6) | — | 시작 |
| **스폰서 데스크** | 계약 체결·갱신 | — (Source S8 창구) | **나디아 합류** (D06 §2.5) |
| **크루 영입 (이벤트)** | 합류 이벤트 → 영입 실행 | K7 | 마일스톤 트리거 (§5.2) |
| **시설 확장 패널** | 개러지 시설 구매 (§2.2) | K8 | 시작 |

- **직능 = 스테이션 개방 원칙 (확정):** 크루 직능의 시스템 1:1 매핑(D03 §1.3)은 **"해당 크루가 해당 스테이션을 열고 지킨다"**로 구현한다. 크루가 채워질수록 개러지 화면이 채워진다 — "크루가 채워질수록 팀이 되어간다"(D03)의 시각 번역이며, 별도 연출 비용 없이 메뉴 개방 자체가 성장 체감이 된다.

#### 2.2 개러지 시설 인스턴스 (K8 — 축적형 Sink, DoD B6)

시설은 **선택지·편의 개방 전용**이다. 스탯 수치에 관여하지 않는다 — D06 §3.2 비중첩 매트릭스(축적형 = 선택지 증가 축)와 G-M2 정신의 이행.

| # | 시설 (명칭 확정) | 효과 | 비용 재화 |
|---|---|---|---|
| G1 | **텔레메트리 아카이브** | 기록실 심화 탭 개방 — 라이벌별 듀얼 전적·선착 카운터의 상세 열람 (§6.2) | 주행 데이터 (기준값 — D13) |
| G2 | **크루 라운지** | **연출 강화형 회상** 기능 개방 — 이벤트 체인 연속 재생(몰아보기)·크루 코멘터리 등. **기본 열람(스킵분 포함 전체)은 아카이브 탭이 무상·상시 담당한다 (§6.3, R-D07-VN)** — 비강제성 안전망(D01 §4 G2 조건 2)은 자원 게이트 뒤에 두지 않는다 | 주행 데이터 (D13) |
| G3 | **세컨드 워크벤치** | 덱 프리셋 저장 슬롯 개방 — 덱 구성 2세트 저장·즉시 전환 | 주행 데이터 (D13) |
| G4 | **스폰서 부스** | 동시 스폰서 계약 슬롯 +1 (기본 1 → 2, §5.4) | 주행 데이터 (D13) · 나디아 합류 후 |

- **비중첩 검증:** G1·G2 = 열람 편의, G3 = 설정 편의, G4 = 계약 선택지 확장. 스탯 상승·자원 회복·통제력 어느 축에도 진입하지 않는다 — D06 §3.2 위반 0건.
- 시설 수 4종은 1차 버전 기준 (확정)이며, 업데이트 추가분은 축적형 잔액의 소비처가 된다(D06 §5.5 R8 트랙).

### 3. 상점·튜닝·정비 (DoD C8~C11)

#### 3.1 소모품 인스턴스 (K4 — D06 §3.5 구조 승계, DoD C8)

**구속 승계 (D06 §3.5 확정):** 휴대 상한 대회당 2개(기준값) / 보충은 개러지 + 간이 정산 / 인게임 구매 없음 / 미사용분 이월(상한 초과 비축 불가) / **효과 범주 = 섀시 회복·상태 완화 전용 (R3)** / 필드 정비 대비 프리미엄 단가 (R4).

| # | 소모품 (명칭 확정) | 효과 | 성격 |
|---|---|---|---|
| P1 | **리페어 키트** | 섀시 컨디션 즉시 회복 (기준값: 필드 정비 회당 상한의 ½ = 15% 상당 (확정 기준값 — D13 검증)) | 기본 패닉 버튼 |
| P2 | **이머전시 실런트** | 섀시 소량 회복 + 이번 대회의 다음 트러블 1회의 섀시 소모 반감 (확정 기준값 — D13 검증) | 회복 + 완화 복합 |

- **R3 검증:** P1~P3 전부 섀시 회복·완화 축이다. 릴 결과·게이지·듀얼에 관여하는 인스턴스는 존재하지 않는다 — 통제 계열 진입 0건.
- 인스턴스 3종은 1차 기준 (확정). 확장(서킷 특화 소모품 등)은 D08.

#### 3.2 머신 튜닝 메뉴 (K1 — 회전형, DoD C9)

튜닝은 **효과 계수·최대치의 수치 상승 전용**이다. 릴의 심볼 출현(확률·구성)에는 절대 관여하지 않는다 — "크레딧으로 릴 결과를 산다"는 경로 차단(D06 §3.2 절대 금지 행 준수, 봉인 규칙 R1 정합).

| 계통 | 구분 | 효과 대상 | 개방 |
|---|---|---|---|
| T1 파워트레인 | 기본 | 슬립스트림(전진) 효과 계수 | 시작 (마르타) |
| T2 브레이크 | 기본 | 브레이킹(방어) 효과 계수 | 시작 (마르타) |
| T3 라인 컨트롤 | 기본 | 라인(공략) 효과 계수 | 시작 (마르타) |
| T4 섀시 보강 | 기본 | 섀시 컨디션 최대치 | 시작 (마르타) |
| T5 펄스 드라이브 정밀화 | **심화** | 듀얼 판정 기본 보정 | **오스카 합류** |
| T6 임팩트 스트럭처 | **심화** | 트러블의 섀시 소모 경감 계수 | **오스카 합류** |

| **오스카 브란트** | **첫 그랑프리 우승** 전후 | E1의 10% 상당 | 보레아스가 '증명'되는 시점 — 미인증 프로토타입이 이긴다는 소문 |
| **사샤 린드** | **기원 단서 2단계 교차 구간** (D04 §6.2·§7.1 — 3비트 구조의 ②흔들림 이후) + **추가 조건 (확정): 재회 축(카이) '대면' 이상 도달** | E1의 12% 상당 | 기원 서사 운반체 — 최후반 배치. 몰락의 응어리(카이·마르타 라인)가 풀리기 시작해야 복귀의 명분이 성립 |

- **순서의 자연 형성:** 앵커의 난도가 나디아 → 오스카 → 사샤 순으로 상승하므로 영입 순서가 자연히 형성되되, 강제 순서 규칙은 두지 않는다 (마일스톤만 넘으면 어느 쪽부터든 가능).
- **사샤 추가 조건 — 채택 확정 (결정 #4, 미결 #7 해소):** 사샤 복귀는 U3 재회 축과 기원 서사가 교차하는 지점(D04 §7.1)이므로 마일스톤 단독보다 관계 상태 결합이 서사 정합적이다.
- **D08 배치 구속 (신설 — 정합 리뷰 보정 ①):** 재회 축 '대면' 도달 이벤트는 **기원 단서 2단계 교차 구간 이전 또는 동시기에 도달 가능하도록** 배치한다. 위반 시 사샤 영입이 서사 진행상 불가능한 데드락 구간이 생긴다 — D08 실배치 시 필수 검증 항목.
- 합류 이벤트의 서사 내용은 D04 §7 확정 골격을 그대로 사용한다 — 본 문서는 텍스트를 작성하지 않는다 (범위 가드).

### 6. 기록실 (DoD F21~F23 — 핵심 결정 6 확정)

**단일 시설 통합 (확정):** '도감'과 '기록실'을 분리하지 않고, 개러지 내 **기록실 1개 시설 + 내부 3탭**으로 구성한다. 마스터플랜 §1의 "도감/기록실"은 본 시설의 두 얼굴로 해석하며, 역할 분리는 탭 층위에서 성립한다 (DoD F23).

| 탭 | 내용 | 대응 |
|---|---|---|
| **라이벌 파일** | 네임드 8인 + 팩토리 3팀 프로필, **U3 축 5종의 현재 관계 상태**, 대전 요약 | DoD F21 |
| **통산 기록** | 커리어 통산 지표 + **축적형 재화 누적 획득 총량** (D06 R7 채택 — 확정) | DoD F22 |
| **아카이브** | **전체 VN 이벤트 열람 (무상·상시 — 스킵분 포함, §6.3)**, 시즌별 챔피언십 결과, 칭호 이력 | 도감 역할 + **D01 §4 G2 조건 2 이행 지점** |

#### 6.1 라이벌 파일 — 관계 상태 표시 규칙 (DoD F21)

- **표시 (확정):** 현재 관계 상태의 **명칭과 도달 이력**을 표시한다. 상태 명칭은 D04 §4.2 정의를 그대로 사용 (예: 로렌츠 — '변수').
- **비노출 (확정):** **다음 전이의 조건은 표시하지 않는다** — 관계 전이는 목표 체크리스트가 아니라 레이스의 결과로 발견되는 서사다 (U3 "기록의 축적" 정합). 단, 형식 B의 주요 카운터 수치 자체(듀얼 전적 등)는 시설 G1 개방 시 심화 탭에서 열람 가능 — 수치는 보이되 임계는 보이지 않는다.
- **축 비대상 네임드 3인의 처리 (확정 — 정합 리뷰 보정 ⑤):** U3 확정 5축(D03 §5·D04 §4.2)에 속하지 않는 네임드 — **라몬 디아스·키라 볼코바·에드가 홀로웨이** — 는 라이벌 파일에 **프로필·대전 전적만 표시하며 관계 상태를 갖지 않는다.** D03 §4 관계도의 '호적수 축'·'구세대의 예우' 라벨은 관계 훅(서사 재료)이지 상태 추적 축이 아니다 — 이들의 관계 곡선(예: 디아스의 "적대→호적수")은 1차 버전에서 **고정 이벤트 풀**로 소화한다. 상태 축 신설은 D04 §4.2 확정(5축·축당 3~4상태)의 개정 사안이므로, 필요 판단 시 총괄 경유로만 가능하다. 단, 형식 B 카운터 인프라(§5.5)는 재사용 가능하도록 설계되어 있어 확장 비용은 낮다 — 확장 판단은 D08.
- **필러 드라이버:** 라이벌 파일은 네임드 8인 전속. 필러는 파일을 갖지 않는다 (D03 §2.1 위계 승계, 아트·데이터 비용 가드).

#### 6.2 통산 기록 (DoD F22)

- 기본 지표 (확정): 통산 완주·우승·포디움·듀얼 전적·최고 챔피언십 순위·시즌 수.
- **축적형 누적 획득 총량 표시 (확정 — D06 R7 채택):** 주행 데이터의 생애 누적 획득량을 통산 기록에 상시 표시한다. 포스트게임 잔액의 오인 방어(D06 R6 상보) + 베인 3단계 진행의 간접 가시화(§8) + 신규 비용 거의 0.
- 시설 G1(텔레메트리 아카이브) 개방 시 라이벌별·시즌별 심화 통계 탭 추가 (§2.2).
- **칭호 이력 표기 규칙 (확정 — 정합 리뷰 보정 ⑥):** 아카이브 탭의 칭호 이력은 D04 §9 확정 원칙을 따른다 — '더블 챔피언' 칭호는 **획득·병립이며 이전(移轉)이 아니다** (로렌츠는 에필로그까지 칭호 유지). 표기가 "로렌츠에게서 빼앗았다"로 오독되지 않도록 문면 규격은 D09에서 작성한다.

#### 6.3 아카이브 — VN 열람 규칙 (v1.1 신설 — R-D07-VN 집행, D01 §4 G2 조건 2 이행)

| 규칙 | 내용 |
|---|---|
| **등재 기준** | **발생(도달)한 모든 VN 이벤트가 자동 등재**된다 — 열람·스킵 여부를 불문한다. "모든 VN 이벤트는 스킵 가능하며, 놓친 서사는 기록실에서 다시 열람할 수 있다"(D01 §4 G2 조건 2 확정)의 문자적 이행 |
| **비용** | **무상·상시.** 아카이브 열람에는 어떤 재화·시설·해금 게이트도 걸지 않는다 — 비강제성 보장 장치를 자원 게이트 뒤에 두는 것은 조항 취지의 역전이다 (D02 §8 v1.9 '기록실' 정의의 구속 조항) |
| **비노출** | 미도달(미발생) 이벤트는 목록에 표시하지 않는다 — 스포일러 방지, §7.1 히든 업적 비노출 규칙과 동조 |
| **G2 역할 분리** | 시설 G2(크루 라운지)는 아카이브 위의 **연출 강화형 회상**(연속 재생·코멘터리)만 담당한다. 기본 열람 기능은 G2 구매 여부와 무관하게 항상 성립한다 |

|---|---|---|
| 스킬 티어 2·3 | 마일스톤 (첫 포디움 / 첫 우승) | 주축 원칙 ○ |
| 스킬 개별 · 덱 슬롯 · 시설 | 주행 데이터 구매 (자유 순서) | 보조 원칙 ○ — 하드 락 아님 |
| 심화 튜닝 · 오버홀 상세 · 스폰서 · 전략실 보정 | 크루 합류 (= 마일스톤 + 재화) | 주축+보조 복합 ○ |
| 기록실 심화 탭 · 회상 · 프리셋 | 시설 구매 | 보조 ○ |

- **복수 경로 검증 (D06 §6.3):** "통제력 부족" 정체의 해답은 ①스킬 해금(축적형) ②튜닝(회전형) ③오버홀 특성(진도) 최소 2개 축에서 항상 존재한다 — 본 문서의 어떤 해금도 단일 재화 단일 해답 게이트를 만들지 않음을 확인. **하드 락은 크루 스테이션 개방뿐이며, 이는 성장 게이트가 아니라 콘텐츠 개방이다** (D06 §6.1 용어 분리 준수 — 본 문서는 '벽(Wall)'을 사용하지 않는다).

### 8. 베인 3단계 임계 수치 (DoD G27 — 핵심 결정 8 확정)

**구속 승계 (D06 §5.4 확정):** 연동 축 = 주행 데이터의 **누적 획득 총량**(소비 무차감) / 공표 = 투어·시즌 경계 스냅 / 구현 = 단계별 대사 풀 교체.

**정의 방식 (확정 — 서사 앵커 + 기대치 환산):** 임계는 절대값이 아니라 **시즌 1 기대 누적 획득량 E1**(D13 산출 변수 — §0 기준선 전제)에 대한 비율로 정의한다. 확정하는 것은 "전환이 언제 체감되어야 하는가"라는 의도이며, 절대값은 D13의 단가 확정 시 자동 산출된다.

| 전환 | 임계 (기준값) | 도달 기대 시점 | 공표 스냅 | 서사 정렬 |
|---|---|---|---|---|
| 1→2단계 | **0.35 × E1** (확정 기준값 — 허용 대역 0.35~0.40, D13 검증) | 투어 2~3 결산 | **투어 경계** | 2막 '북풍' 구간 — 베인이 처음으로 자기 언어를 갖기 시작하는 시점이 시즌 중반의 상승 국면과 병주 |
| 2→3단계 | **1.0 × E1** (확정 기준값 — 허용 대역 0.9~1.1, D13 검증) | 시즌 1 결산 전후 | **시즌 경계** | 4막 '휠투휠' 진입 전후 — 완성된 파트너로서 왕좌 도전에 동행 |

- **산출 근거:** D06 §2.3 밀도표 기준 시즌 1의 축적형 획득 이벤트는 투어 결산 5회 + 시즌 결산 1회 + 마일스톤 다수(S5 주 수입)다. 마일스톤 보상이 전반부에 밀집하므로(첫 포디움·첫 우승 등) 투어 2~3 결산 시점의 누적은 E1의 35~40% 부근이 된다 — 2단계 앵커의 근거.
- **플레이 편차 허용 (확정):** 임계는 고정, 도달 시점은 플레이어 성적에 따라 자연 변동한다 — 잘 달릴수록 베인이 빨리 자란다. "달린 만큼 배운다"(D03 결정 7)의 문자적 이행.
- **공표 연출 위치 (확정 — 정합 리뷰 보정 ⑧):** 단계 전환의 공표 연출은 **경계 시점의 VN(파트너 축 슬롯) 또는 차기 그랑프리 도입부의 콕핏 국면**에서 수행한다. 베인의 표시처는 콕핏 HUD·VN 대화창로 한정되며(D03 §1.5) 베인은 관제 한정 존재(D02 §3.2 3조건)이므로, **개러지 화면에 베인을 상주·표시하지 않는다** — 본 문서의 개러지 스테이션 구성(§2.1)에 베인이 부재하는 것은 누락이 아니라 설정 준수다. 실배치는 D08, 파형 연출 규격은 D10.
- **포스트게임:** 3단계 완료 상태 유지 (D06 §5.5 확정 승계). 누적 획득량 표시는 §6.2 통산 기록이 담당.
- > **[재보정 조항 — 지점 3/3]** E1은 §0 기준선과 D13 단가에 종속한다. D08 구조 수치 판정·D13 단가 확정 시 절대값을 산출·검증하며, 비율 기준값 자체도 D13 시뮬레이션으로 재보정할 수 있다. **불변인 것은 서사 앵커(2단계=시즌 중반, 3단계=시즌 경계)와 스냅 규칙이다.**

### 9. 미니게임 — 1차 버전 불포함 (DoD G26 확정)

- **확정 (사용자 결정, 2026-07-26):** 미니게임은 **1차 버전(Steam·모바일 공통)에 포함하지 않는다.** 향후 업데이트 또는 후속작에서 진행한다.
- **처리:** ①본 절로 명문화 ②**D15 이관** — '출시 후 업데이트 방향'에 미니게임을 후보로 등재한다 (D06 R8의 "축적형 소진 요소 추가"와 동일 트랙 — 미니게임이 추가될 경우 축적형 Sink 후보를 겸할 수 있음을 부기) ③마스터플랜 §4-D07 해당 항목의 해소 문구를 v1.0 확정 시 총괄 발신분에 포함.
- **설계 여파 확인:** 본 문서의 어떤 시설·메뉴도 미니게임을 전제하지 않는다 — 불포함으로 인한 구조 공백 0건.
