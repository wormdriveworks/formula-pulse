### 2. 파생 경로 시트 (DoD #44 — 산출 근거 기록)

#### 2.1 A2 → 회전형 경제

```
포인트 단가 100 Cr (A2)
 ├─ S1 그랑프리 상금 = 300 + 포인트×100        → P1 1,300 / P8 400 / P9↓ 300
 ├─ S2 완주 보너스 200 Cr                       → 상금 최저치의 2/3 (바닥 보장)
 ├─ S10 환전율 = 완주 보너스의 10% = 20 Cr/차지  → D06 §4.1 명문 비율 그대로
 ├─ K2 필드 정비 기준액 200 Cr                   → 완주 보너스 1회분 = "1대회 완주로 1회 정비"
 │    └─ 체증 1.5^n → 4회차 675 Cr (누적 1,625) … R1 부등식 §3.1
 └─ K1 튜닝 단계 400/700/1,100/1,700/2,600 Cr    → 총 6,500/계통 · 기본 4계통 26,000 Cr
```

시즌 1 총수입 중앙값 **29,500 Cr** (§4.3 측정) 대비 기본 4계통 완성 소요 26,000 Cr = **88%** → "시즌 1 내 기본 튜닝 완성은 가능하나 정비·소모품과 경합" 상태가 성립한다.

#### 2.2 A3 → 축적형 경제

```
E1 = 820 DP (A3)
 ├─ 베인 1→2단계 = 0.35 × E1 = 287 → 290 DP     (D07 §8 허용 대역 0.35~0.40)
 ├─ 베인 2→3단계 = 1.00 × E1 = 820 DP           (허용 대역 0.9~1.1)
 ├─ 크루 영입 = E1의 8/10/12%
 │    → 나디아 65 / 오스카 80 / 사샤 100 DP      (D07 §5.3 비율 그대로)
 └─ 축적형 총 소요 = 스킬 810 + 슬롯 340 + 크루 245 + 시설 240 = 1,635 DP
      = 1.99 × E1  → D07 §4.3 예산 배율 1.5~2.0 **상단 충족** … R-D07-2 §3.2
```

#### 2.3 A4 → 코어 루프

```
기본 분포 (A4)
 ├─ 안정 완주율 = (1 - 0.18)^3 = 55.1%          → 차지 보조 충전 기대 0.55/턴
 ├─ 펄스 기대 출현 = 3 × 0.12 = 0.36/턴
 ├─ 차지 총생산 ≈ 0.91/턴 + 듀얼 승리 3          … R-D07-1 §3.2
 └─ 게이지 만충 100 ÷ 순증 기대 ≈ 6.0턴          → GP당 듀얼 기대 2.5회 (§4.3 측정 2.50) ✅
```

#### 2.4 A5 → 생존 자원

```
섀시 최대 100 (A5)
 ├─ 필드 정비 회당 상한 30 (30%)                 → 완전 회복 최소 4회 (D06 §3.3 명문)
 ├─ 투어 개시 무상 복원선 70                     → 30 구간이 전면 정비 전속 Sink
 ├─ P1 리페어 키트 15 (= 필드 정비 상한의 ½)      → D07 §3.1 명문 비율
 ├─ 이벤트 회복 상한 30 이하                     → D06 §3.4 경제 가드 (C1 카테고리 10~20 배정)
 └─ 트러블 소모 1/2/3매치 = 6/14/24              → 무개입 시 평균 GP당 소모 ≈ 38 (§4.3)
```

**K5-A 문언 보정 (결정 #8 — 확정):** 핵심 결정 K5-A 승인 시 병기했던 "S1 챔피언율 ≈5~10%"는 **"S1 챔피언 = 예외적 성취(0~2%) / 시즌 챔피언 중앙값 S2~S3"**로 보정한다. K5-A의 본체(도전형 — S1 중위 성적 3~5위권)는 무변경이며, 보정 대상은 부수 지표 1개 항이다.

- **보정 사유:** 챔피언 달성에는 로렌츠에 대한 **반복 승리**가 필요하고, 반복 승리가 가능한 전력이면 **첫 격파는 필연적으로 S1 조기**에 발생한다. 따라서 "로렌츠 첫 격파 중앙값 S2"(D08 §8.2 확정)와 "S1 챔피언율 5~10%"는 **동시 달성이 구조적으로 불가능**하다.
- **우선순위 근거:** ①D08은 확정 문서이고 K5-A는 본 채팅의 튜닝 타깃이므로 §0.7-3 상 확정 문서가 우선한다 ②D08 §8.2 시즌 챔피언 행의 허용 범위는 "S1~ (제한 없음)"이며 S1 달성률을 발주한 바 없다 ③D03 §3.1 "첫 시즌의 필패 경험"·D01 "왕좌의 격차" 서사와 0~2%가 정합적이다.

**프로파일 간 서열 정합:** 저숙련 5위 / 표준 4위 / 숙련 4위 (격파율 22% / 37% / 38%) — 숙련도가 성적에 단조 반영됨을 확인.
