## ① 문서 목적·범위

### 1. 수익 모델 총괄

| 플랫폼 | 배포 | 수익원 | 게임 내 재화 주입 |
|---|---|---|---|

| **모바일 (2차)** | 무료 다운로드 | **광고 수익 단일** (전면+보상형 — §3.1) | **0%** (§3.3 — 보상은 비재화) |

### 2. Steam 가격 정책

#### 2.1 정가 (결정 #7 — D01 미결 #4 해소)

- **정가 = $12.99 (USD).** D01 확정 범위($9.99~14.99, 결정 #3) 내 중앙값.
- **근거:** ①D01 결정 #3의 포지셔닝 서술("VS 상방, Balatro 이하")의 가격 직역값 ②VN 내러티브 층 + 시즌 로그라이트 볼륨이 $9.99대 미니멀 로그라이트와의 차별 근거 ③EA 지향(D01 결정 #4)이므로 D15가 EA 진입가를 정가 이하로 설계할 공간 확보.
- **지역 가격:** Steam 권장 지역 가격 매트릭스 **자동환산을 기준**으로 한다. 지역별 수동 조정 여부는 D15 스토어 준비 시점 검토 사항.

#### 2.2 에디션 구성 (결정 #8)

- **단일 에디션.** 복수 에디션(디럭스 등)은 두지 않는다 — 전제-3(차등 0)의 스토어 층 일관 확장이자 심의·패키징 비용 최소화.
- OST 등 부속물은 판매 항목이 아니며, 향후 상품 후보로서의 검토는 **D15 상품 정책 트랙에 등재**한다 (§8.4).

#### 2.3 EA와의 경계

- EA **범위·기간·진입가는 D15 소관** (D01 결정 #4). 본 문서는 관계 원칙 1건만 고정한다: **EA 진입가 ≤ 정가 $12.99** (정가는 상한 앵커). EA 종료 시 정가 도달.

- **온보딩 첫 4대회 (확정 기준값 — 결정 #14) 근거:** 시즌 1 첫 투어는 D04 1막(그리드의 노이즈) 도입 구간 — 튜토리얼과 첫 조우 필패 서사(D04 §1)가 포함되는 첫인상 보호 구간.
- **리타이어 제외 (확정 — 결정 #14) 근거:** 로그라이트 실패 직후는 감정 곡선의 최저점 — 이 시점의 광고는 이탈 촉진 요인 (D06 감정적 안전망·D08 C-1 감정 곡선 존치의 정신 승계). 어뷰징 벡터 아님 — 고의 리타이어는 해당 GP의 S1·S2 전액 상실(D06 §2.1)로 광고 회피 이득을 초과하는 자기 처벌.
- **순서 규칙 (서사 시퀀스 보호 — 확정, 결정 #14):** 투어 마지막 대회에서는 **광고(GP 결산 직후) → 투어 결산 리포트(D09 §5.1 — SET-01) → VN(투어 종료)** 순서가 고정된다. 광고는 항상 GP 결산 직후 단일 지점에만 위치하며 서사 시퀀스 내부에 끼어들지 않는다. 투어 경계 오퍼(K7-B — §3.3)는 투어 결산 리포트 화면 **내부의 명시적 UI**로만 존재하며(강제 전이 아님), 본 순서를 변경하지 않고 VN 재생과 간섭하지 않는다.

#### 3.3 보상형 광고 — 광고 면제권 (결정 #3·#10·#15)

**보상 = 전면 광고 면제권** — 기본 교환비: 시청 1회당 **3대회분 (확정 기준값 — 결정 #15 ㉮).** 수익 중립 상단 설정이며, 하향(수익 우위 측) 조정은 근거 없는 사전 조정 대신 **소프트 런칭 실측 후 D13 창구 재보정**으로 수행한다 (§8.3).

- **성격 규정 (결정 #10 — 확정):** 면제권은 재화·자원이 아닌 **클라이언트 상태 플래그**다. 저장은 되나 **재화 UI(잔고 표시 계열)에 진입하지 않으며, 거래·환전·타 효과 전환이 불가**하다. D06 §1.1 자원/재화 경계의 **외부**에 위치한다. (잔여 면제 상태의 안내 표시 여부·형태는 D09-2 UX 소관 — 재화 표기가 아닌 상태 안내로 한정.)
- **인게임 효과 0:** 면제권이 제거하는 것은 게임 외적 마찰(광고)뿐이다. 릴·게이지·재화·성장 어느 층에도 진입하지 않는다.
- **소모 규칙:** §3.2 파이프라인 ④에서만 소모된다 — 온보딩·쿨다운·리타이어 제외로 스킵된 슬롯은 소모하지 않는다.
- **보유 상한 (확정 — 결정 #14):** **잔여 면제분 존재 시 추가 시청 불가(버튼·오퍼 비활성).** 비축 개념을 만들지 않아 "면제권 파밍" 세션 왜곡을 차단. 아래 오퍼 2종에도 동일 적용 — 면제권 보유 중에는 어떤 오퍼도 노출되지 않는다.
- **시청 진입점 (규칙 층):** 비레이스·비VN 화면(결산·개러지 등 아웃게임 화면)의 **명시적 버튼 + 아래 오퍼 2종**에 한정 — 자발적 시청만 존재하며, 미시청 불이익은 없다(전면 광고 기본 노출은 불이익이 아니라 기본값). 실배치·버튼 좌표는 D09-2.
- **교환비 3대회분 근거 (확정):** 보상형 eCPM은 통상 전면의 2~3배 — 1:3 교환은 수익 중립 상단. 30~45분(GP 3회) 광고 프리는 체감 가치가 명확한 최소 단위.

**보상형 오퍼 지점 2종 (K7 — 결정 #15):**

| 오퍼 | 시점 | 내용 |

- **수익 구조 주석:** 슬롯 시점 오퍼는 전면 노출의 보상형 대체(eCPM 격차분이 수익), 투어 경계 오퍼는 기존 슬롯을 대체하지 않는 **신규 접점(가산 수익)**. IAP 부재 모델의 수익 확대는 이 두 경로 + 교환비 재보정 창구(§8.3)로 수행하며, 게임 내 지급물 확장으로는 수행하지 않는다 (결정 #12·#13).
- **명칭 처리 (역검색 수행 완료 — 결정 로그 #11 예정):** '광고 면제권'은 **내부 규격 용어**로 운용하며 D02 §8 등재 대상이 아니다 (D06 v1.1 §7.4의 'Source/Sink' 등재 제외 논리 준용 — §8.5). 인게임 표시 문면은 D09-2 소관. 후보 평가 결과: '피트 패스' 계열은 **기각** — '피트'는 D02 §2·D04 §5(피트 무전)·D08 별첨A(피트 워크)에서 산문 기사용, '패스'는 D02 §8 등재 서킷 **'서밋 패스'와 부분 문자열 충돌** (T-1 계열 검색 간섭). '클린 랩'은 신조 충돌 0으로 D09-2 문안 후보로 전달 — 단 '랩'은 D08 기사용(최종 랩 규칙)이므로 복합어로서의 충돌 경미 사실을 부기하여 인계한다.

#### 3.4 광고 불능·실패 처리 (결정 #9 — 보완 ①② 반영)

**비차단 원칙 (확정):** 광고는 **진행 조건이 아니라 병행 노출**이다. 게임이 광고에 의해 잠기는 상태는 존재하지 않는다.

**전면 광고 — 원인별 분기 (보완 ①):**

| 로드 상태 | 처리 |
|---|---|
| 사전 로드 성공 | 재생 |
| **No-fill** (온라인 확인됨·광고 재고 없음) | **즉시 통과** — 유저가 유발할 수 없는 서버 측 사정이므로 시간 비용을 부과하지 않는다 |
| **오프라인 / 타임아웃 / 로드 에러** | **30초 홀드 (확정 기준값)** — 아래 재시도 창 규칙 |

**30초 홀드 = 실제 재시도 창 (보완 ②):**
- 홀드 중 광고 로드를 **실제로 계속 재시도**하며, "광고를 불러오는 중" 계열 문구를 표시한다 — 문구와 실태가 일치한다.
- 재시도 **성공 시 즉시 광고 재생·홀드 종료** (일시적 네트워크 끊김 케이스의 수익 회수).
- 30초 만료 시 통과.
- **어뷰징 등가화 논증:** 회피(비행기 모드 등)의 이득은 광고 시청 시간의 절약인데, 홀드가 동등한 시간 비용을 부과하므로 **회피의 기대 이익 = 0.** 처벌이 아닌 시간 비용 등가화이며, 오프라인 정상 플레이어도 온라인 플레이어의 광고 시청과 동일한 시간 비용을 지불할 뿐이므로 형평 문제가 없다. 30초는 전면 광고의 통상 시간 비용과 동렬 유지 목적의 확정 기준값이다 (소프트 런칭 재보정 여지 — §8.3).
- 홀드 화면의 시각 규격·문면은 D09-2, 재시도 구현·타임아웃 판정 파라미터·에러 코드 분기의 기술 검증("기술적으로 가능하다면" 조건의 확정)은 D12 이관 (§8.2).

**보상형 광고 — 실패 처리:** 로드 실패 시 **버튼 비활성** (홀드 없음 — 자발적 시청이므로 어뷰징 벡터가 아니다). 시청 중단(도중 이탈) 시 보상 미지급 (SDK 표준).

**접근성 경계:** 광고·홀드는 게임 플레이 타이머가 아니므로 D09 §6.2 타이머 배율 옵션의 적용 대상이 아니다 (충돌 없음 확인).

#### 3.5 빈도 무결성 (수익 압력 방어)

IAP 부재(전제-2)로 모바일 수익이 광고 노출량 단일 변수에 걸리므로, 노출 상향 압력을 규칙으로 봉쇄한다.

- **규칙 층 (본 문서 개정 사안 — 임의 변경 금지):** 전면 노출 지점 1종(GP 결산 이탈 단일) / 대회당 최대 1회 / 보상형 오퍼 지점 2종(슬롯 시점·투어 경계 — **추가 신설도 개정 사안**) / 금지 구역 / 파이프라인 순서 / 비차단 원칙 / 보상 = 비재화(면제권 단일 — 결정 #12·#13의 불채택 판정 포함).
- **값 층 (확정 기준값 — 소프트 런칭 데이터 기반 재보정 여지, §8.3):** 쿨다운 8분 · 온보딩 보호 4대회 · 기본 교환비 3대회분 · 투어 경계 면제 폭 4대회 · 홀드 30초.
- 값 재보정도 규칙 층을 침범할 수 없다 — 예: 쿨다운을 0분으로 내려도 노출 지점·대회당 1회는 불변.

### 4. F2+F2-b 해소 판정 (한 몸 판단 — 결정 #3)

#### 4.1 F2 — 플랫폼 간 형평

- **해소 구조:** 광고 보상이 **게임 내 지급물을 갖지 않으므로**(면제권 = 게임 외적 마찰의 제거), 양 플랫폼의 게임 경제는 **주입 0% = 0%로 동일**하다.
- **"대가를 지불한 쪽이 불리한 구간" 부재 논증:** 모바일 유저가 광고 시청으로 얻는 최대치는 "광고가 없는 상태"인데, Steam 유저는 그 상태를 **기본값**으로 보유한다. Steam 구매가 사는 것 = 무광고 + 데스크탑 경험 전체. 형평 방향은 항상 **Steam ≥ 모바일**이며 역전 구간이 구조적으로 존재하지 않는다.
- 마스터플랜 §4-D16이 지시한 "I-5 비율 조정이 아닌 **모델 설계 차원의 해소**"의 이행이다 — 비율을 만지지 않고 주입물 자체를 소거했다.

#### 4.2 F2-b — Source 신설 판정

- **판정: 신규 Source 신설 없음.** D06 §2.1 Source 전수(S1~S10)는 불변이며, 광고는 어떤 재화·자원도 지급하지 않는다. **D06 무개정 — 총괄 경유 불요 성립** (마스터플랜 §4-D16의 "비재화 한정 시 Source 신설 회피" 경로의 이행).

#### 4.3 한 몸 판단의 교차 검증 (DoD D18)

- F2 해소안(비재화 보상)이 F2-b를 재발시키는가 → **아니오.** 지급물이 재화가 아니므로 Source 정의에 진입 자체가 불가.
- F2-b 해소안(Source 신설 회피)이 F2를 재발시키는가 → **아니오.** 게임 내 지급물이 없으므로 형평 역전의 재료가 없다.
- 두 안건은 **하나의 설계(면제권 모델)로 동시 해소**되며 상호 강화 관계다 — "따로 풀면 한쪽이 다른 쪽을 재발시킨다"(§4.5 인수 원장)는 리스크가 원천 소멸.

#### 4.4 미래 방어선

재화 지급형 보상이 재론될 경우, ①D06 §2.1 Source 개정(총괄 경유 필수) ②I-5 재판정(§5) ③F2 형평 재논증의 **3중 게이트**를 전부 통과해야 한다. §5의 I-5 존치(결정 #6)가 이 방어선의 실체다.

### 8. 후속 문서 이관 및 용어 판정

#### 8.1 D09-2 (모바일 UI — 직접 후속)

본 문서가 **규칙 층**을 고정했으므로 D09-2는 **배치 층**만 설계한다: ①전면 광고 전이 연출·홀드 화면("광고를 불러오는 중" 문면 포함) ②보상형 시청 버튼의 배치(허용 화면 범주는 §3.3 고정) ③면제 잔여 상태의 안내 표시 형태(재화 표기 금지 — §3.3) ④온보딩 보호 구간의 무광고 상태 처리 ⑤'클린 랩' 등 표시 문면 후보 평가 ⑥**오퍼 2종의 UI 설계** — 슬롯 시점 오퍼의 선택 다이얼로그(수락/거절 동등 가중 — 다크 패턴 금지)·투어 결산 리포트 내 오퍼 배치. **F2+F2-b는 본 문서에서 해소 완료**이므로 D09-2는 §4 판정을 전제로 작업한다 (마스터플랜 §4-D09-2의 "D16 공동 판단" 요건 이행).

#### 8.2 D12 (기술 설계)

①광고 SDK 선정·미디에이션 구성 ②에러 코드 분기의 기술 검증 — **No-fill vs 오프라인/타임아웃/에러 구분 가능성 확정** (보완 ①의 "기술적으로 가능하다면" 조건 해소 책임) ③30초 홀드의 실제 재시도 창 구현 ④타임아웃 판정 파라미터 확정 ⑤광고 계측(노출·완료율) 이벤트 설계 ⑥백그라운드 전환 중 광고 상태 처리(D09-2 백그라운드 인터럽트와 접점) ⑦결제 모듈 미탑재 확인 ⑧광고 규칙·기준값의 테이블 스키마(데이터 드리븐 — 하드코딩 금지).

- **폴백 규정 (확정):** D12 검증 결과 No-fill 구분이 기술적으로 불가하면, 해당 케이스는 **홀드가 아닌 즉시 통과 측으로 병합**한다 (무고 케이스 오폭 방지 우선 — 어뷰징 벡터인 오프라인/타임아웃 분기만 유지되면 §3.4 등가화 논증은 성립).

#### 8.3 D13 (데이터·밸런스)

본 문서 확정 기준값(쿨다운 8분·온보딩 4대회·기본 교환비 3대회분·투어 경계 면제 폭 4대회·홀드 30초)의 테이블 등재. **구조·규칙·상한의 존재는 불변, 값만 조정 가능** (D09 결정 #5 전례 준용). 소프트 런칭 실측 기반 재보정의 실행 창구 — **교환비·면제 폭이 재보정 1순위 대상**(결정 #15: 수익 우위 필요 시 하향은 반드시 이 창구로, 규칙 층 침범 금지).

#### 8.4 D15 (출시·운영)

①정가 $12.99의 스토어 등록·지역 매트릭스 실행 ②EA 진입가 설계(≤ 정가 앵커 — §2.3) ③OST 등 상품 후보 등재(§2.2) ④광고 SDK 개인정보·심의 고지(GDPR·아동 보호 등 스토어 준비물) ⑤소프트 런칭 여부·범위 판단 ⑥업데이트 동시 배포 운영(§6) ⑦**코스메틱 해금형 보상(릴 스킨 등 — K7-C) 업데이트 후보 등재**: 구조 합법(Steam 기본 전량 개방·차등 0 유지 조건)이나 신규 아트(D10)·해금 시스템(D07) 비용 유발로 1차 불채택 (결정 #15). 재론 시 차등 0 조건의 재검증 필수.

#### 8.5 용어 등재 판정 (D02 §8)

**등재 요청 0건.** '전면 광고'·'보상형 광고'는 업계 일반 용어, '광고 면제권'·'30초 홀드'·'노출 파이프라인'은 내부 규격 용어로 등재하지 않는다 (D06 v1.1 §7.4 등재 제외 논리 준용). 인게임 표시 문면('클린 랩' 후보 등)이 D09-2에서 고유 명칭으로 확정될 경우 **그 시점에 D09-2가 등재를 요청**한다 — 후보 역검색 결과(§3.3)를 함께 인계한다.
