## ① 문서 목적·범위

본 문서는 게임의 코어 루프 — **레이스(그랑프리)의 턴 구조, 스핀/릴 규칙과 심볼 체계, 무작위성 통제 규칙, 소프트 타임 리미트 규칙, 승패 판정** — 를 프로그래머가 턴제 상태 머신으로 구현 가능한 수준으로 확정한다. 아울러 D01·D03·D04에서 이관된 상위 판정 규칙(투어 실패 시 시즌 처리, 챔피언십 포인트 구조, 출주 대수, 시간 압박 수치, 이원 챔피언십 결정)을 해소한다.

**범위 가드 (DoD F26 구속):** 본 문서는 **규칙의 구조·판정 방식·기준값**까지만 확정한다. 아래는 범위 밖이다.
- 심볼별 등장 확률·밸런스 수치·성장 곡선 → **D13** (본 문서의 수치는 검증용 기준값 [가안])
- 서킷별 구성·이벤트 풀·난이도 곡선·연출 등급 빈도 상한·라이벌 패턴 수치화 → **D08**
- 재화 체계 전체(이원화/삼원화)·Source/Sink 맵·잔여 자원 환전 → **D06**
- 스킬 목록·해금·덱 세팅 규칙 → **D07**
- 릴·타이머의 화면 규격 → **D09** / 텍스트 풀 → D04 규격에 따라 후속 / 세이브 구현·RNG 시드 → **D12**

## ② 본문

### 1. 코어 루프 개관

```
[그랑프리 코어 루프 — 1턴 = 1섹터]

  섹터 개시 ─→ 스핀(릴 회전·순차 정지) ─→ 잠정 결과
                                            │
                              ┌─── 개입 창 (릴 국면 · 베인) ───┐
                              │  소프트 타임 리미트 작동        │
                              │  홀드·리스핀 / 스킬 / 펄스 차지 │
                              └──────── 확정 or 타임아웃 ───────┘
                                            │
  결과 번역 (전개 국면 · 중계 로그) ─→ 적용(게이지·순위·자원 정산)
                                            │
                          배틀 게이지 만충? ─→ [듀얼] 발동
                                            │
                     다음 섹터 / 랩 갱신 / 그랑프리 종료 판정
```

- 릴 국면(스핀~확정)의 화자는 베인, 전개 국면(결과 번역 이후)의 화자는 중계다 (D04 §8.1 국면 분리 원칙의 규칙 측 구현).
- 릴은 시스템적으로도 **플레이어(드라이버)와 베인 사이의 전용 인터페이스**다. 라이벌 AI는 릴을 사용하지 않는다(§4.4) — D02 §4 봉인 규칙 2(R2)가 규칙 구조로 보장된다.

### 2. 턴 구조 (결정 K1 — 섹터 단위)

#### 2.1 턴의 정의 (확정)

- **1턴 = 1섹터(Sector).** 서킷의 1랩은 3~5개 섹터로 분할되며, 각 섹터는 결절점이 되는 **대표 코너(브레이킹 포인트)**를 가진다. 릴이 도는 지점은 언제나 이 대표 코너다 — "코너마다 돌아가는 운명의 슬롯"(D01 태그라인)의 규칙 번역.
- '섹터'는 실제 모터스포츠의 랩 분할 단위를 그대로 차용한 세계관 정합 용어다(D04 §5.6-5).
- 섹터의 속성(직선형/테크니컬/고위험 등)은 데이터로 정의되어 심볼 가중·게이지 계수에 관여한다 (구조 확정 — 속성 축 목록·서킷별 배치는 D08).

#### 2.2 그랑프리 구성 구조 (기준값 — 최종 밸런스는 D08/D13)

| 항목 | 기준값 | 비고 |
|---|---|---|
| 랩 수 | 3랩 [가안 — D08 확정] | 그랑프리당 |
| 랩당 섹터 수 | 4~5개 (서킷별 상이) [가안 — D08 확정] | 서킷 개성의 1차 다이얼 |
| 그랑프리당 기본 턴 수 | 12~15턴 (+듀얼 삽입 시 가변) [가안 — D08 확정] | — |
| **그랑프리 목표 길이** | **10~15분 (확정 — 결정 로그 #9, 상향식 산정 기준)** | D01 [가안 15~25분]의 하향 보정 |

- **페이싱 다이얼 선언:** 그랑프리 길이는 `랩 수 × 섹터 수 × 턴당 소요시간`으로 결정된다. 본 구조는 턴 수 조정만으로 대회 길이를 10~25분 범위에서 스케일 가능하다.
- **총괄 리뷰(구조 수치 산술 모순)와의 관계:** 본 문서는 턴 구조의 자연 길이(상향식 산정)에 근거해 **그랑프리 목표 길이 10~15분을 D05 기준값으로 확정**한다. 이는 총괄 리뷰 해소안 ①(대회 길이 하향)을 지지하는 입력 데이터이며 — 10~15분 × 4대회 = 40~60분으로 투어 목표와 정확히 일치한다 — 구조 수치(투어당 대회 수·시즌당 투어 수)의 **최종 검증·판정 권한은 여전히 D08에 있다.** D08이 다른 해소안을 택할 경우 본 기준값은 재보정 대상이다.

> **[각주 — 플레이타임 산정 (검증용 참고, D08 입력 데이터)]**
> 상향식(턴 단위) 산정: 1턴 15~25초(릴 2~3초 + 개입 창 평균 5~7초 + 로그·정산 4~6초), 듀얼 회당 30~50초(GP당 2~4회 추정) → 그랑프리 순수 8~13분, 대회 간 이벤트·결산 포함 **10~15분** → 투어 40~60분 (D01 목표 일치).
> 진엔딩(첫 시즌 챔피언)까지: 첫 시즌 필패 설계(D03 §2.3) + 4막 마일스톤 + 메타 성장 곡선 기준 숙련 2~3시즌 / 평균 3~5시즌 / 저숙련 5~7시즌. 시즌당 3.5~5.5시간(대회 20개 + 아웃게임 10~15% 가산) → **진엔딩 약 12~27시간 (중심값 15~20시간)**, 에필로그 결말(2연속 챔피언) +1시즌 이상 = +4~9시간.
> 판정: 목표 가격대 $9.99~14.99의 로그라이트 첫 클리어 기대치(10~20시간대)와 정합. 투어 탈락은 시즌을 단축시키는 대신 시즌 수를 늘려 총량에서 대략 상쇄됨.

#### 2.3 턴 시퀀스 (확정 — 상태 머신의 1턴 내부)

| 단계 | 내용 | 국면/화자 |
|---|---|---|
| T1. 섹터 개시 | 섹터 속성·순위·게이지·잔여 자원 표시. 베인의 상황 브리핑(전개 후보의 언어) | 릴 국면 · 베인 |
| T2. 스핀 | 플레이어 입력으로 릴 회전 개시 → 순차 정지 (사전 텐션 구간 — 역기획 2단계) | 릴 국면 |
| T3. 잠정 결과 | 정지된 릴 = **전개 후보** (아직 사건이 아님 — R1 정합) | 릴 국면 · 베인 |
| T4. 개입 창 | **소프트 타임 리미트 작동 (§7).** 홀드·리스핀/스킬/펄스 차지 투입 또는 확정 | 릴 국면 · 베인 |
| T5. 확정·번역 | 확정된 결과를 레이스 상황(추월·방어·사고 등)으로 번역 — 중계 로그 최대 2줄 (D04 §5.1) | 전개 국면 · 중계 |
| T6. 적용·정산 | 게이지 증감 → 듀얼 발동 판정(§4.3) → 순위 갱신 → 섀시·차지 정산 → 백그라운드 AI 처리(§4.4) | 시스템 |

- 스핀 개시(T2)는 항상 플레이어 입력이다 — "결과를 내가 불러온다"는 의례가 사전 텐션의 전제 (ToF 승계).
- T5의 로그는 텍스트 키 발행으로 처리한다(실제 텍스트 풀은 본 문서 범위 밖 — D04 규격, D12 키 구조).

### 3. 그랑프리 상태 머신 (DoD A2)

```
[GP_START] 그리드 정렬(§4.5)·리소스 초기화
    │
    ▼
[LAP_LOOP] ──→ [SECTOR_TURN] ──→ (T1~T6, §2.3)
    ▲               │
    │               ├─ 게이지 만충 ──→ [DUEL] (§4.3) ──→ 복귀
    │               ├─ 섀시 컨디션 0 ──→ [RETIRE] (§9.2)
    │               └─ 랩 내 잔여 섹터 有 ──→ 다음 SECTOR_TURN
    │
    └── 랩 종료(잔여 랩 有) ── / ── 최종 랩 종료 ──→ [GP_FINISH]
                                        │
                                        ▼
                              [RESULT] 순위 확정·포인트 정산(§9)
                                        → 중간 결산·저장 지점 (D01 §6)
```

- 전 상태·전이는 위 다이어그램으로 폐쇄된다. 실시간 처리·물리 판정은 존재하지 않는다 (D01 §8-2).
- RESULT 종료 시점이 대회 간 저장 지점이다(구현은 D12, 결산 보상 상세는 D06/D08).

### 4. 순위 모델 (결정 K2 — 포지션 + 배틀 게이지)

#### 4.1 그리드·포지션 (결정 K7, DoD A4·A5)

- **출주 대수 = 16대 (확정).** 구성: 플레이어 1 + 네임드 라이벌 8 + **필러 드라이버 7** (D03 이관 해소 — 필러 수의 상위 결정). D08/D13 페이싱 검증에서 문제 발견 시 ±4대 범위 내 보정 가능(조건부).
- 순위는 **이산 포지션(P1~P16)**으로 표현된다. 연속 거리값은 존재하지 않는다 — 동순위가 구조적으로 발생하지 않는다.
- 필러 표기 (확정 — D03 §2.1 [가안] 해소): 중계 로그·순위표에서 "No.## 머신"으로 표기. 서사·아트 없음. 표기 확장은 D08.

#### 4.2 배틀 게이지 (확정 — 수치는 D13)

- 플레이어는 **앞차·뒤차 각각과 줄다리기형 배틀 게이지**를 가진다 (동시 최대 2개).
  - **전방 게이지:** 전진 계열 심볼·섹터 성과로 플레이어 측에 축적, 앞차의 저항(AI 파라미터)으로 감쇄. 플레이어 측 만충 → **추월 듀얼** 발동.
  - **후방 게이지:** 뒤차의 압박(AI 파라미터)으로 상대 측에 축적, 방어 계열 심볼로 감쇄. 상대 측 만충 → **방어 듀얼** 발동.
- **U2의 구현:** 같은 릴 결과도 게이지 상태·상대가 누구인가에 따라 가치가 달라진다. 추월 직전엔 전진 심볼이 승부수가 되고, 뒤가 위험할 땐 같은 스핀에서 방어 심볼이 절실해진다.
- 순위 스왑 시 게이지는 리셋되고 새 인접 상대와의 게이지가 개시된다 (확정: 리셋 — 이월 없음).

#### 4.3 듀얼 (Duel) — 승부수 국면 (확정 — 수치는 D13)

- 게이지 만충 시 다음 섹터가 **듀얼 섹터**로 전환된다: 해당 인접 상대와의 포지션을 건 결판.
- 진행: 듀얼 전용 스핀 1회 → 개입 창(소프트 타임 리미트 동일 적용) → 판정. **자원·스킬 투입 가치가 최고조가 되는 국면** — "찰나의 브레이킹 포인트에서 승부수를 던져라"(태그라인)의 규칙적 실체.
- 판정 (구조 확정 — 판정식·페널티 수치는 [가안 — D13 확정]): 확정 결과의 듀얼 판정치 vs 상대 파라미터. 성공 = 포지션 스왑(추월) / 포지션 방어(방어). 실패 = 게이지 리셋 + 페널티 [가안: 추월 실패 시 소폭 섀시 소모, 방어 실패 시 피추월].
- 듀얼은 연출 등급 상승의 주 발동처다(§5.5). 네임드 상대 듀얼의 결정타 = L2 후보 (D04 §5.5).

#### 4.4 백그라운드 순위 처리 (확정 — 수치·빈도는 D08/D13)

- **라이벌 AI는 릴을 돌리지 않는다.** AI 머신은 파라미터(페이스·공격성·안정성 등) 기반의 간이 판정으로 처리된다 — 플레이어 비인접 구간의 AI 간 순위 스왑은 섹터 정산(T6)마다 확률적으로 발생한다.
- 이 비대칭은 의도된 설계다: ①릴 = 플레이어·베인 전용 인터페이스라는 세계관 규칙(R2)의 시스템 보장 ②연산 비용·밸런스 변수의 통제 ③"릴은 나만의 무기"라는 판타지 보존.
- AI 리타이어 (확정 — 빈도는 D08): 트러블 이벤트로 AI 머신의 리타이어가 발생할 수 있다(순위 계산 즉시 반영).

#### 4.5 시작 그리드 (확정 — 산정식 수치는 D08/D13)

- 예선 세션은 별도로 두지 않는다(세션 길이 통제). 시작 포지션은 **직전 성적 기반 산정** — 투어 첫 그랑프리는 챔피언십/커리어 순위 기반, 이후는 직전 그랑프리 결과 기반 (산정식 수치는 D08/D13).
- 게임 최초 그랑프리의 플레이어는 **P16(최후미)에서 시작**한다 — 언더독의 등반 구조(서사 정합), 이후 성장의 체감 기준선.

#### 4.6 라이벌 주행 스타일의 파라미터 번역 (인터페이스 선언 — 수치화는 D08/D13)

D03 §2.4의 주행 스타일 시드는 본 모델에서 다음 파라미터 축으로 번역된다 (축 정의는 확정, 값은 D08/D13):

| 파라미터 축 | 정의 | 시드 예시 |
|---|---|---|
| 페이스 | 백그라운드 판정·게이지 기본 계수 | 로렌츠 = 전 구간 최상위 유지 |
| 공격성 | 후방 게이지 축적 속도·듀얼 시도 성향 | 디아스 = 최대치, 블로킹 불사 |
| 러시/후반 계수 | 랩 진행도별 페이스 변조 | 볼코바 = 초반 러시 / 홀로웨이 = 후반 강세 |
| 안정성 | 트러블·듀얼 실패 확률 | 비앙카 = 고안정·저압박 내성 |
| 시작 보정 | 시작 그리드 산정 보정치 | 마로 = 예선 스페셜리스트의 번역 |

### 5. 릴 규칙 (결정 K3 — 판정형 + 개입 창)

#### 5.1 릴 구성 (확정 — 3릴)

- **3릴 구성 (확정).** 각 릴은 동일 심볼 분류 체계를 공유하되, 릴별 심볼 가중은 데이터로 정의된다(서킷 속성·머신 상태·튜닝이 가중에 관여 — 연결은 D06/D07/D08).
- 릴은 순차 정지한다(1릴→2릴→3릴) — 정지 간 지연이 사전 텐션의 핵심 구간 (역기획 2단계). 정지 속도는 접근성 옵션 대상(D09 예약).
- 심볼은 텍스트 없이 0.1초 판독 가능한 아이콘으로 디자인한다 (인지 부하 최소화 원칙 — 규격은 D09/D10. 도상의 ToF 비유사 설계 의무는 §11.3).

#### 5.2 심볼 체계 (분류·명칭 확정 — 종수·확률은 D13)

심볼은 6분류 체계로 정의한다. **모든 심볼의 효과는 수치 증감이 아니라 레이스 상황으로 번역된다** (U1).

| 분류 | 명칭 (확정) | 효과 (게임 규칙) | 번역 (레이스 상황) |
|---|---|---|---|
| 전진 | **슬립스트림 (Slipstream)** | 전방 게이지 가산 | 앞차의 후류에 올라탄다 — 추월 기회의 축적 |
| 방어 | **브레이킹 (Braking)** | 후방 게이지 감쇄 / 방어 듀얼 판정 보정 | 라인을 닫고 자리를 지킨다 |
| 공략 | **라인 (Line)** | 소량 양방 게이지 보정 (안정 주행) | 이상적인 주행 라인의 확보 |
| 자원 | **펄스 (Pulse)** | 펄스 차지 +1 | 펄스 드라이브 출력의 여유분 확보 |
| 위험 | **트러블 (Trouble)** | 섀시 컨디션 소모 위험 / 후방 게이지 상대 가산 | 접촉 위험·머신 이상·노면 악화 |
| 희귀 | **찬스 (Chance)** | 게이지 대폭 가산 또는 듀얼 즉시 발동 등 강효과 | 결정적 순간이 열린다 |

- **매치 문법 (확정):** 동일 분류 심볼의 매치 수가 효과 강도를 결정한다 — 1개 = 약(단독 효과), 2개 = 중(강화), 3개 = 강(최대 효과 + 연출 등급 상승, §5.5). 혼합 결과는 각 심볼의 단독 효과가 §5.3의 고정 순서로 병렬 적용된다 (확정).
- **안정 완주의 정의 (확정 — 전수 리뷰 보정 R-B):** '안정 완주 섹터' = **트러블 효과가 발동하지 않은 채 정산된 섹터.** §6.2 보조 충전의 성립 조건이며, 라인 심볼의 유무와는 독립이다(라인은 게이지 보정 효과만 담당 — 정의 중복 제거).
- 심볼의 종수 확장(서킷 전용·이벤트 전용 심볼 등)은 데이터 드리븐으로 열어 둔다(분류 6종 안에서의 인스턴스 추가) — 확장은 D08.

#### 5.3 판정·적용 순서 (확정)

T6 정산은 다음 고정 순서를 따른다: **①위험(트러블) → ②자원(펄스) → ③방어 → ④전진·공략 → ⑤게이지 만충 판정 → ⑥듀얼 발동 → ⑦순위 갱신 → ⑧백그라운드 AI.**
- 위험을 먼저 적용하는 이유: "수습의 드라마"를 만들기 위해 — 같은 스핀 안에 트러블과 전진이 공존할 때, 위기를 안은 채 기회를 잡는 상황이 성립한다.

#### 5.4 개입 창 (확정)

- 릴 정지 직후의 잠정 결과는 **전개 후보**이며, 개입 창에서 아래 행동이 가능하다:
  - **확정:** 잠정 결과를 그대로 사건화. 여유 구간 내 확정 시 모멘텀 보너스(§7.3).
  - **홀드 & 리스핀:** 원하는 릴을 고정하고 나머지를 1회 재회전. 비용 = 펄스 차지 (기준값 1 [가안 — D13 확정]). **턴당 1회 한도** (확정 — 무한 리롤 방지).
  - **스킬 사용:** 장착 스킬의 개입 효과 발동(§6.1) — 비용·횟수는 스킬 데이터.
  - **차지 개입:** 펄스 차지 직접 소모로 정의된 즉효 개입 (기준값: 트러블 1개 무효화 = 2차지 [가안 — D13 확정]).
- 개입 후 재정지된 결과가 새 잠정 결과가 되며, 잔여 시간 내 확정하거나 타임아웃된다(§7).
- **용어 이층 운용 (확정 — 결정 로그 #10):** 릴 관련 용어는 두 층으로 운용한다.
  - **시스템·UI 층:** 홀드(Hold) / 리스핀(Re-spin) — 슬롯 국제 통용어 표기 유지 (주 타겟의 학습 비용 0, 부제 'Spin the Grid'가 공식화한 슬롯 문법의 일부).
  - **베인 발화 층:** 베인은 UI 용어를 발화하지 않고 **연산의 언어**로 말한다 — 홀드 = "후보 고정", 리스핀 = "재연산" (D02 §4 릴 정의·R1과 정합. 예: "2번 후보 고정. 잔여 변수 재연산합니다."). 이는 '텔레메트리 릴(세계관 명칭) = 릴 UI(시스템 실체)'의 기확정 이중 지시 구조(D02 §8)를 개입 용어에 연장한 것이다.
  - 정식 명칭 '텔레메트리 릴'의 시스템·문서 내 약칭 '릴' 사용은 기확립 관행으로 유지한다 (R3의 무약어 규칙은 '포뮬러 펄스' 전용 — 충돌 없음).

#### 5.5 연출 등급 매핑 (DoD B9 — D04 §5.5 접속, 빈도 상한은 D08)

| 등급 | 발동 조건 (심볼·규칙 측) |
|---|---|
| L0 | 일반 결과 (1매치·혼합·무사건) |
| L1 | 2매치 강화 효과 / 게이지 경유 추월·방어 성공 / 소규모 트러블 |
| L2 | 3매치 최대 효과 / **듀얼 결판(특히 네임드 상대)** / 대형 트러블·사고 |
| L3 | 찬스 계열 희귀 조합 + D08 정의 조건 (보스급 조우·히든 내러티브 한정 — D01 §8-1) |

- L2 이상의 그랑프리당 상한은 D08에서 설정한다 (D04 §5.5 — 희소성이 곧 보상감).

### 6. 무작위성 통제 (F1)

#### 6.1 통제 수단 — 개입 4타입 (확정, DoD C10)

모든 통제 수단은 다음 4타입으로 분류된다. **스킬은 이 타입들의 데이터 인스턴스**로 구현된다(데이터 드리븐 — 스킬 목록·해금·덱은 D07):

| 타입 | 정의 | 기본 제공 예 |
|---|---|---|
| 홀드 (Hold) | 릴 고정 + 재회전 | 기본 개입(§5.4) — 스킬 없이 상시 가용 |
| 변환 (Convert) | 심볼을 다른 심볼로 교체·승급 | 스킬 예: 트러블 1개 → 라인으로 (예시 — 인스턴스는 D07 확정) |
| 증폭 (Amplify) | 확정 결과의 효과 강화 | 스킬 예: 이번 턴 전진 효과 ×1.5 (예시 — D07) |
| 보험 (Insure) | 부정 결과의 완화·무효화 | 차지 개입(§5.4) / 스킬 예: 듀얼 패배 페널티 면제 (예시 — D07) |

- **이중 구조의 보장 (역기획 2단계 원칙):** 사전 텐션(T2~T3 릴 정지 과정) + 사후 개입(T4 개입 창)이 매턴 성립한다. 통제는 언제나 **자원·스킬·지식의 대가**를 요구한다 — 무비용 통제는 존재하지 않는다.

#### 6.2 펄스 차지 (Pulse Charge) — 통제 자원 (결정 K4, DoD C11)

- **정의 (명칭 확정):** 인게임 휘발성 통제 자원. 세계관 정당화 = 펄스 드라이브의 출력 여유분 — "출력을 언제 어디에 쓸 것인가"(D02 §3.1)의 규칙 실체.
- **획득 (릴 생산형 주축):** ①펄스 심볼(§5.2) ②안정 완주 섹터(§5.2 정의)마다 소량 자동 충전 (기준값 +1 [가안 — D13] — 바닥 방지 보조, 역기획 감정적 안전망) ③듀얼 승리 보너스 (기준값 +2 [가안 — D13]).
- **소모:** 홀드&리스핀 / 차지 개입 / 스킬 비용 / 듀얼 부스트(판정 보정) (기준값 1~3 [가안 — D13]).
- **보유 상한 (기준값 10 [가안 — D13])** — 상한 존재는 확정(무한 비축에 의한 통제 인플레이션 방지).
- **순환 구조:** 릴이 자원을 주고, 그 자원으로 릴을 통제한다 — "아끼면 릴에 휘둘리고, 쓰면 다음 통제력이 준다"는 푸시-유어-럭이 매턴 성립.
- **이월·소멸 (확정):** 그랑프리 간에는 이월된다(투어 = 1런의 연속 자원). **투어 종료 시 소멸** — 잔여분의 환전 여부·비율은 D06 소관(마스터플랜 D06 '잔여 자원 환전').

#### 6.3 지식 기반 통제 (확정 — DoD C12, VS 인사이트 승계)

- **사전 정보 공개:** 그랑프리 시작 전 베인 브리핑에서 해당 서킷의 심볼 가중 경향·섹터 구성을 열람할 수 있다 (숙련 유저의 준비 = 통제).
- **상대 학습:** 라이벌별 듀얼 성향·파라미터 경향은 대전 기록이 쌓일수록 기록실에서 구체화된다 (추적·표시 규칙은 D07 — U3 기록 축적과 동일 인프라).
- **규칙의 학습 가능성:** 매치 문법·적용 순서(§5.3)는 고정 규칙으로 공개되어, 반복 플레이의 숙련이 곧 통제력이 된다.

### 7. 소프트 타임 리미트 (F2 — 결정 K3 파생, DoD D13·D14)

#### 7.1 적용 국면 (확정)

- 타이머는 **개입 창(T4)과 듀얼의 개입 창에만** 걸린다. 스핀 개시(T2)·메뉴·결산에는 시간 제한이 없다 — 압박은 "달리는 머신 위의 결단"(D02 §4)에만 존재한다.

#### 7.2 구간 구조·경계 수치 (확정 — D04 §8.2 이관 해소)

- **기본 제한 시간: 10초** (기준값 — 접근성 옵션으로 연장·비활성 가능, D09 예약. 옵션 존재를 전제로 설계).
- **구간 경계는 잔여 시간 비율로 확정한다** (절대 시간을 조정해도 구간 구조·연출 문법이 불변하도록):

| 구간 | 잔여 시간 | 베인 발화 (D04 §8.2 연동) |
|---|---|---|
| 여유 | 100% ~ 60% | 표준 2줄 로그 |
| 경고 | 60% ~ 30% | 1줄 축약 |
| 임박 | 30% ~ 0% | 체언 종결 |

#### 7.3 빠른 결정 보너스·타임아웃 (확정 — 보너스량 수치는 D13)

- **모멘텀 보너스:** **여유 구간 내 확정** 시 전방 게이지 소폭 가산 (기준값 +1 상당 [가안 — D13]). 자원이 아닌 게이지 보상인 이유: 통제 자원(차지)의 경제와 분리하여 "빠른 결단 = 흐름을 탄다"는 레이스 문법으로 번역하기 위함.
- **타임아웃:** 잠정 결과가 **그대로 자동 확정**된다 — 무작위 행동 자동 발동(D01 F2)의 구현. 서사 번역은 "머신이 코너에 진입해버렸다"(D04 §8.2 — 베인의 자율 행동이 아닌 시간의 강제, R6 정합). 타임아웃 직후 베인 수습 대사 계열이 발화된다(텍스트 풀은 후속).
- 타임아웃 자체의 추가 페널티는 없다 (확정) — 잠정 결과의 방치가 곧 결과이며, 이중 처벌은 소프트 리미트의 '소프트'를 훼손한다.

### 8. 생존 자원 — 섀시 컨디션 (명칭·규칙 확정 — 수치는 D13)

- **정의:** 보레아스의 내구 상태. 투어(1런)를 관통하는 생존 자원 — 로그라이트의 HP에 해당.
- **소모 (항목 확정 — 수치는 D13):** 트러블 심볼 효과 / 사고 이벤트 / 듀얼 실패 페널티.
- **회복:** 그랑프리 간 자동 완전 회복은 **없다** (런의 긴장 유지). 회복 수단은 정비 계열(그랑프리 간 결산·크루 직능·소모품)로 한정 — 규칙 소유권은 D06/D07/D08, 본 문서는 "투어 관통 + 유상 회복" 원칙만 확정.
- **0 도달 = 리타이어 (§9.2).**
- 펄스 차지(공세 자원)와 섀시 컨디션(생존 자원)의 이원 구조가 인게임 자원의 전부다 (확정 — 제3 인게임 자원의 신설은 D06 재화 구조 확정 전 금지).

### 9. 승패·판정 (DoD E15~E19)

#### 9.1 그랑프리 종료·순위 판정 (확정)

- 최종 랩의 최종 섹터 정산 종료 시점의 포지션이 **최종 순위**다. 이산 포지션 모델이므로 동순위는 발생하지 않는다.
- 리타이어 머신은 리타이어 시점 역순으로 최하위부터 배치된다.

#### 9.2 리타이어 = 런 오버 (확정)

- 그랑프리 중 섀시 컨디션 0 도달 = **리타이어.** 해당 그랑프리는 무포인트 처리되고, **투어의 잔여 그랑프리는 몰수된다(출주 불가) — 투어 탈락(런 종료).**
- 로그라이트의 '사망'은 리타이어 하나로 단일화한다 (확정) — 그랑프리 실패와 런 실패를 분리하지 않는다(규칙 단순성 + 리타이어의 무게 보존).
- 투어 탈락 시에도 탈락 시점까지의 획득 성과(메타 재화 등)는 보존된다 — 감정적 안전망 (역기획 원칙, 보존 범위·환전은 D06).

#### 9.3 투어 판정·시즌 처리 (결정 K5 — 시즌 불중단, DoD E17)

- **투어 완주:** 구성 그랑프리 전 출주(리타이어 없이 최종 그랑프리 결산 도달).
- **투어 실패(탈락):** §9.2의 런 종료. 실패한 투어는 **그 시점까지의 성적으로 투어 종합이 마감**된다.
- **시즌은 중단되지 않는다.** 다음 투어는 예정대로 개막한다 — 시즌은 항상 5개 투어를 소화하고 챔피언십 결산에 도달한다. 같은 투어의 재도전은 없다 (확정 — 시즌이라는 달력은 플레이어를 기다리지 않는다: 세계관 정합적 긴장 + D04 §9의 시즌 반복 전제와 정합).

#### 9.4 챔피언십 포인트 — 2계층 구조 (확정, DoD E18 — 배분 수치는 D08/D13)

D02 §2.2("투어 종합 성적이 챔피언십 포인트로 환산")와 §2.3("상위 입상 포인트 배분의 모터스포츠 표준 문법")을 다음 2계층으로 통합 구현한다:

| 계층 | 규칙 | 배분표 (기준값 [가안 — D08/D13 확정]) |
|---|---|---|
| 1층: 그랑프리 → **투어 포인트** | 그랑프리 순위별 투어 포인트 배분. 투어 내 종합 순위 산출 | P1=10 / P2=8 / P3=6 / P4=5 / P5=4 / P6=3 / P7=2 / P8=1 (P9 이하 0) |
| 2층: 투어 종합 → **챔피언십 포인트** | 투어 종합 순위를 챔피언십 포인트로 환산. 시즌 총합으로 시즌 챔피언 판정 | 종합 1위=25 / 2위=18 / 3위=15 / 4위=12 / 5위=10 / 6위=8 / 7위=6 / 8위=4 / 9위=2 / 10위=1 |
| 동률 처리 (구조 확정) | 우승(1위) 횟수 → 최고 순위 → 최종전 순위 순으로 결정 | — |

- **2계층의 이점:** ①D02의 두 문장을 무모순 통합 ②투어당 그랑프리 수(D08 미확정)가 바뀌어도 챔피언십 층의 밸런스가 불변 — 총괄 리뷰의 구조 수치 해소(D08)와 절연 ③투어 탈락의 비용이 "챔피언십 포인트 기회 손실"로 명확히 환산.
- 시즌 챔피언 = 5투어 챔피언십 포인트 총합 1위 (D02 §2.2 확정 문법).

#### 9.5 시즌 결산 — 소프트 실패 (확정, DoD E19 — 세부 경계는 D08 공동)

- **시즌에 하드 실패는 없다.** 시즌은 항상 5투어를 소화하고 결산된다. 챔피언 미달성 = **소프트 실패**: 시즌 엔딩 VN(미달성 변형, D04 §3) → 시즌 오버홀(성적 비례 — G-M1 바닥 보장과 정합) → 다음 시즌.
- 로렌츠의 연속 우승 누적(D04 §9 수식 갱신 연출)은 본 구조의 직접 파생이다.
- 조기 확정(수학적 탈락/조기 우승) 시의 잔여 투어 처리 등 세부 변주는 D08 공동 확정.

### 10. 시즌 챔피언십 — 엔딩 계층 (결정 K6, DoD E20)

#### 10.1 이원 챔피언십 — 불채택 (확정)

- 드라이버/팀 양대 타이틀 구조는 **채택하지 않는다.** 챔피언십은 드라이버 단일 타이틀이다.
- 사유: 컨스트럭터 포인트는 팀 소속 드라이버 합산 구조인데 팩토리 2인 로스터 vs 노스윈드 1대 출주의 태생적 비대칭으로, 보정 규칙 없이는 달성 불가 목표·보정 시엔 차별성 소멸. '더블 챔피언'의 브랜드 가치는 이미 로렌츠 칭호로 회수되어 있음.

#### 10.2 엔딩 계층 — 진엔딩 유지 + 에필로그 결말 신설 (확정)

| 계층 | 조건 | 처리 |
|---|---|---|
| **진엔딩** (유지) | 첫 시즌 챔피언 달성 | D04 §1.1·4막 아크(휠투휠의 정서 규정) **무개정 보존** |
| **에필로그 결말** (신설) | **2시즌 연속 시즌 챔피언** | 포스트게임 최상위 목표. 중량형 VN — 테마: **"재현의 증명"** (악시온의 폐기 사유였던 '재현 불가능성'을 그들의 언어로 반박하는 종결. 내용·배치는 D04 개정 + D08) |

- **포스트게임 (확정):** 진엔딩 후에도 시즌 루프는 계속된다. 디펜딩 챔피언 상태의 이벤트 풀 변형(D04 §4 인프라 재사용)으로 세계가 반응한다 — 왕좌에서 내려온 로렌츠의 리매치 구도 포함(서사 상세는 D04/D08). **총괄 부대조건 (v1.1 접수):** ①에필로그는 기존 VN 규격·재사용 자산 범위 내 처리(신규 전용 아트 0) ②트리거의 시스템 판정·실배치는 D08 (본 문서의 발동 조건 정의 = 2연속 시즌 챔피언은 불변).
- 플레이어의 카 넘버는 챔피언 달성 후에도 **13 유지** (확정) — No.1 관례(D03 §2.3)를 따르지 않는다. 13은 커스터마이즈 불허의 브랜드 기호(D03 §1.1)이며, "그리드가 두려워하는 13번"의 완성이다. 관례 거부의 서사 처리(중계 언급 등)는 D04/D08.

#### 10.3 칭호 계승 규칙 (확정 — v1.1: D04 v1.1 확정형에 정합 보정)

- 플레이어가 2연속 챔피언 달성 시, 세계 규칙(D02 §8: "2시즌 연속 시즌 챔피언에게 붙는 칭호")에 따라 **'더블 챔피언' 칭호를 취득**한다. 신규 칭호는 만들지 않는다.
- **취득형 (D04 v1.1 §9 확정):** 세계관 정의는 이력 조건 충족형이므로 로렌츠의 칭호는 **박탈·이전되지 않는다.** '계승'은 에필로그의 서사 프레임이며, 중계 표현은 "두 번째 더블 챔피언의 탄생" 계열로 작성한다(칭호 이전 표현 금지). 취득 후 수식 운용의 실배치는 D08.
- R5 보정은 D04 v1.1에서 집행 완료: "개막 시점 기준 로렌츠 유일 + 계승 예외" (미결 #1 종결).
- 원안 '더블원'은 소재 미차용 원칙(D01 §7 — 명칭 차용 금지, 4개 문서 관통 확정)과의 충돌로 불채택 (핵심 결정 단계 평가 경유).

### 11. 플랫폼·구현 정합 (DoD F21·F22)

- **플랫폼 공통 (F21):** 본 문서의 전 규칙은 입력 수단·화면 방향·수익 모델과 무관하다. 소프트 타임 리미트의 백그라운드 인터럽트 예외(모바일 홈 버튼 등)는 **규칙이 아닌 구현 예외**로 D12/D09-2 소관임을 명시한다 — 본 문서는 "인터럽트 중 타이머 정지"라는 원칙만 선언한다 (확정).
- **제작 전제 (F22):** ①전 규칙은 §3 상태 머신으로 폐쇄 — 실시간 처리 없음 ②심볼·스킬·라이벌 파라미터·섹터 속성·포인트 테이블은 전부 데이터 테이블로 정의(스키마는 D12/D13) ③시스템이 발행하는 것은 텍스트 키이며 모든 로그는 D04 §5.1 규격(최대 2줄)을 따른다.

#### 11.3 레퍼런스 차별화 점검 — Tower of Fortune (확정 — 결정 로그 #10)

시스템 레퍼런스와의 구조 분기를 명문화하고, 표현 층의 회피 의무를 후속 문서에 이관한다 (D03 §6이 소재 레퍼런스에 대해 수행한 점검과 동일 관행).

| 층위 | ToF | 본작 |
|---|---|---|
| 승부 해소 | HP 삭감형 1:1 전투 (스핀 결과 = 데미지) | 포지션 + 배틀 게이지 + 듀얼 — 16대 순위 경쟁 (U2) |
| 결과의 의미 | 수치 증감 | 레이스 상황 번역 (U1) |
| 개입 시점 | 스핀 전 홀드 | 정지 후 개입 창 + 소프트 타임 리미트 (F2) |
| 진행 구조 | 던전 층 | 그랑프리 → 투어 → 시즌 챔피언십 |

- **판정:** 공유 요소는 "3릴 스핀 + 홀드/리스핀"이라는 슬롯 공용 문법(특정 게임의 자산이 아닌 업계 일반 용어·구조)뿐이며, 그 위의 해소 층은 전부 상이하다. 게임 규칙·시스템은 저작권 보호 대상이 아니고(표현만 보호), 슬롯×로그라이트는 기성 계보(예: Luck be a Landlord)가 존재하는 문법이다.
- **표현 층 회피 의무 (이관 — 구속):** 표절 시비의 실질 변수는 규칙이 아닌 표현이다. 다음을 후속 문서의 점검 항목으로 이관한다: ①심볼 아이콘 도상의 ToF 비유사 설계 → **D10** ②릴·화면 레이아웃의 ToF 구성 비복제 → **D09** ③아트 스타일(흑백 도트 등)의 차별화 → **D10**. 스토어 등록 전 법률 검토는 D15 상표 점검 트랙과 동일 트랙.
