# [D08 별첨A] 서킷 상세 — v1.1 (확정)

> **지위:** 본 별첨은 D08 콘텐츠 & 레벨 디자인 문서의 일부이며(D08 §0 — 결정 로그 #2), 판번·확정을 본 문서와 동기 운용한다. 독립 문서 번호를 갖지 않는다.
> **v1.1 (2026-08-06):** 본문 D08 v1.1(§8.2 기대 중앙값 2셀 보정·P-2 ② 집행)과의 **판번 동기 발행 — 별첨 내용 무변경**(서킷 20종·무대 5종·이벤트 풀 전량 무접촉).
> **내용:** 무대 5종 총론 + 서킷 20종 상세(B2 심층형) + 무대 전용 이벤트 풀 + 공통 이벤트 풀 대표 인스턴스 개요.

## 0. 기술 양식·공통 규칙

**서킷 기술 양식 (전 서킷 공통):**

| 항목 | 내용 |
|---|---|
| 명칭 | 서킷 고유명 **(확정 — 결정 로그 #10.** v1.0 확정 시 D02 §8 일괄 등재 + D15 상표 트랙) |
| 슬롯·역할 | 투어 내 제N전 — 오프너/빌드A/빌드B/피니셔 (D08 §4.3) |
| 구성 | 3랩 × 섹터 4 또는 5 (기본 12/15턴 — D08 §3.2) |
| 섹터 배치표 | 섹터별 로컬 명칭 · 주속성 · 부속성 · 규칙 노트 (속성 축 정의는 D08 §3.3) |
| 심볼 가중 | 정성 방향 — 계수 수치는 D13 |
| 듀얼·게이지 성향 | 승부처 위치·공방 밀도 방향 |
| 텍스트 디테일 소재 | 중계 로그·이벤트 라이팅 발주용 소재 목록 (실제 텍스트 작성은 라이팅 트랙 — D04 §5 규격 적용) |
| 연출 노트 | 무대 배경 아트 1종(D02 제작 전제) 활용 방침 · 무드 · L2 연출 소재 |
| 설계 노트 | 난이도 포지션·학습 목표·벽 조우 관계 |

**공통 규칙 재확인:** ①랩 3 고정, 랩 레이아웃 동일 반복 ②최종 랩 = 배틀 게이지 계수 전역 소폭 상승 (확정 — D08 §3.2, 계수 D13) ③서킷당 배틀 존 최소 1(주 또는 부속성) ④펄스 섹션은 각 무대 제3전(빌드B)에만 배치 ⑤섹터 로컬 명칭은 텍스트 디테일 층으로 D02 §8 등재 제외 (확정 — 결정 로그 #10) ⑥**레조넌스 섹터 오버레이 (D08 §3.7 — 결정 로그 #11):** 무대당 1회, 투어 개막 시 추첨된 서킷·섹터 슬롯 위에 발동 상태로 덧씌워진다 — 본 별첨의 서킷 설계·속성 배치는 무개정이며, 무대별 보너스는 D08 §3.7 R5 표를 따른다. 위치 비공개·진입 시 공표.

- **심볼 가중:** 전 분류 균형 + 찬스 소폭 ↑ (S5) — 시즌 전 학습의 결산.
- **듀얼·게이지:** 로렌츠 최종 듀얼의 정점 (확정 — S5 결속). 최종 랩 규칙과 겹쳐 시즌 최대 긴장을 형성.
- **텍스트 디테일 소재:** 다섯 무대의 문법이 한 서킷에 겹치는 감각 / 돔의 천정(天頂) 바로 아래 놓인 마지막 코너 — 서킷의 이름이 된 자리 / 로렌츠와 나란히 서는 마지막 랩(4막 '휠투휠'의 문자적 구현 무대) / 챔피언십 산술이 실시간으로 뒤집히는 전광판.

- **설계 노트:** 시즌 전체의 종합 시험 — 5무대 속성이 한 랩에 전부 등장한다. 시즌 챔피언 결정과 왕좌 축 서사의 물리적 정점.

## 6. 공통 이벤트 풀 — 대표 인스턴스 개요 (확정 — 결정 로그 #14, D08 §7.2 연동)

공통 풀 28종 + 무대 전용 20종(각 무대 총론) = **총 48종** (확정 — 목표 범위 44~52 내). 아래는 발주용 개요이며 실제 텍스트 작성은 라이팅 트랙(D04 §5 규격).
