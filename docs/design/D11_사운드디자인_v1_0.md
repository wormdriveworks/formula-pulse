## ① 문서 목적·범위

본 문서는 《Formula Pulse: Spin the Grid》의 **사운드 아이덴티티·SFX 체계·햅틱 실규격·BGM 체계·앰비언스·사운드 연출 규칙**을 확정하여, D04(연출 등급)·D09(채널 구성·감쇠 모델)·D10(도트 이펙트)이 예약한 사운드 층 실규격을 해소하고 D12(구현)·D13(수치)이 이어받을 기반을 제공한다.

**범위 가드:** 사운드의 목록·규격·규칙·매핑까지. **오디오 미들웨어·포맷·믹싱 구현·데이터 스키마는 D12 / 볼륨 기본값·덕킹 깊이·페이드 시간 등 수치 세부 조정은 D13 / OST 상품 구성은 D15 / 화면·옵션 UI의 실배치는 D09 소관**(오디오 옵션 편입은 §6.2의 총괄 경유 발신으로 처리 — 임의 편입 금지). 텍스트 실문안·악보·음원 실파일은 작성하지 않는다.

**플랫폼 층:** 본 문서 전 조항은 **[공통]**이다(원 코어, 투 플랫폼). 플랫폼 분화는 출력 장치 사상(§3.2 햅틱)과 모바일 광고 구간(§6.4)의 2개 지점뿐이며, 각 지점에 층 소속을 명기한다.

## ② 본문

### 1. 사운드 디렉션 (DoD B1~B4)

#### 1.1 사운드 아이덴티티 (결정 #2 — 사용자 지시, DoD B1)

- **전체 컨셉 (확정):** **레트로 — 16~32비트 콘솔 세대의 SFX·BGM 스타일.** 전면 도트 아트(D10)와 시각·청각의 세대를 통일한다.
- **이원 팔레트 (결정 #4 K1-C — 확정):**

| 층 | 팔레트 | 근거 |
|---|---|---|
| **SFX** | **16비트 질감** — 짧은 칩·샘플 음원. 어택 명료·꼬리 짧음 | 판독성·반복 내성이 본령. 0.1초 심볼 판독(D05 §5.2)·릴 텐션·UI 피드백에 최적, ToF 문법 정합. 도트 UI와 1:1 |
| **BGM** | **32비트 문법** — 샘플 기반, 당대 퓨처 레이싱 게임의 음악 어법 | 무드 폭이 본령. 투어 5무대의 감정 곡선(축제→쾌감→긴장→시련→절정, D02 §6)을 담는 폭 확보 |

- **다이내믹 설계 원칙:** 톤 기조 "절제가 기본값이기에 분출이 보상"(D04 §8.3)을 음향 층에서 이행한다 — 평시 음향은 담백·저밀도, 고양은 등급 스팅(§2.5)·긴장 레이어(§4.3)의 **희소 발동**으로만 표현한다. L2+의 GP당 상한(D08 §8.5 — L2 2회·L3 1회)이 뜨거운 소리의 희소성을 시스템으로 보장한다.
- **금지:** 실사 녹음 질감의 현대적 시네마틱 사운드, 오케스트라 실연 질감, 라우드니스 전쟁형 믹싱 — 세대 이질감 차단.

#### 1.4 이벤트 결속 원칙 (구속 — C-A2의 구조적 이행 장치, DoD A6·C8)

- **모든 SFX는 게임 이벤트(상태 전이·입력·판정)에 결속되며, 씬 컷·화면·컷 ID에 결속되지 않는다.** 씬 컷(SC-01~10)은 동일 이벤트의 시각 채널일 뿐이므로, **'씬 컷 전용 SFX'는 본 결속 구조에서 존재할 수 없다** — 정지 컷 폴백(O12) 시에도 사운드는 동일하게 발화한다(사운드가 컷의 유무·재생 상태와 독립).
- 이 원칙은 C-A2(씬 컷 전용 SFX 임의 신설 금지 — D01 v1.2 결정 #13·D09 §3.1.1·D10 §6.3)의 취지(비용이 컷 수에 비례 증가하는 것의 차단)를 구조로 보장한다. 존속 조항은 §7.4.

### 2. SFX 체계 (DoD C1~C8)

#### 2.1 ID 체계·버스 구조

- **ID 체계 (내부 규격 — D02 비등재, §9):** `SE-{군}{번호}` — 군: R(릴)·I(개입)·T(타이머)·E(결과)·L(등급 스팅)·RS(레조넌스)·D(듀얼·위험)·U(UI·아웃게임)·V(텍스트 큐) / 앰비언스 `AMB-nn` / BGM `BGM-nn` / 징글 `JG-nn`.
- **버스:** 마스터 → BGM 버스 / SFX 버스(앰비언스 포함) — 2버스 단순 구조 (확정 — 옵션 §6.2와 1:1, 실구현 D12).

#### 2.2 릴 텐션 SFX (DoD C2 — 역기획 2단계 사전 텐션 연동)

| ID | 사운드 | 규격 |
|---|---|---|
| SE-R01 | 스핀 개시 | T2 플레이어 입력에 동기 — "결과를 내가 불러온다"는 의례의 청각화(D05 §2.3). 기동 레버 계열 단음 (확정 방향) |
| SE-R02 | 릴 회전 루프 | 저밀도 회전 루프. 개시→정지 사이 지속 |
| SE-R03 | 릴 정지 ×3 | **1원음의 3피치 변형 (확정)** — 1릴→2릴→3릴 순차(0.4초 간격 — D09 §3.2 확정 기준값)로 피치 단계 상승, 3릴째가 최고음. 상승 곡선이 사전 텐션의 청각 문법 |
| SE-R04 | 매치 성립 (2매치) | 정지 완료 후 프레임 연결선 강조(D09 §3.2)에 동기 |
| SE-R05 | 매치 성립 (3매치) | 2매치와 음색 계열 동일·상위 변형 — 등급 스팅(§2.5)과 별개(매치 사실의 고지 전속) |

- **규칙 R-a (봉인 정합):** SE-R04/R05는 **정지 완료 후 전속** — 정지 중 매치 예고 발화 금지 (§1.3).
- **규칙 R-b (홀드 릴):** 홀드된 릴은 회전하지 않으므로 정지음이 발생하지 않는다 — SE-R03의 피치 변형은 **실제 정지하는 릴 순서** 기준으로 재배열 (확정).
- **규칙 R-c (일괄 정지 — O4):** SE-R03 3연타의 고속 압축 재생으로 처리 — 신규 에셋 0. "정지 이벤트 자체는 유지(연출 압축이지 결과 선표시 아님)"(D09 §3.2)의 사운드 이행.
