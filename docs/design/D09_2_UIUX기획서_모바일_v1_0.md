## ① 문서 목적·범위

본 문서는 모바일(2차 플랫폼)의 **세로 One-Thumb 화면 재구성·터치 인터랙션 규격·광고 UX 배치 층·백그라운드 인터럽트 예외 UX**를 확정하여, D09가 확정한 [공통] UX 규격에 모바일 화면 실체를 부여하고 D16이 확정한 광고 규칙 층에 배치 실체를 부여한다. D10(모바일 아트 규격)·D12(SDK·구현)·D13(기준값)이 이어받을 수 있는 기반을 제공한다.

## ② 본문

### 0. 페이싱 기준선 [승계 — D09 §0]

F1 종결 상태(그랑프리 10~15분·인게임 80~85%)를 그대로 승계한다. 광고는 페이싱 외부의 병행 노출(D16 §3.4 비차단 원칙)이며 게임 플레이 시간 산정에 불포함 — 본 문서의 광고 UX가 페이싱 기준선을 변경하는 경로는 존재하지 않는다.

#### 1.4 성능·연출 대응 방침 (DoD B10) [모바일]

- 연출 등급 L0~L3 채널 구성·채널 감쇠 모델은 [승계 — D09 §3.6·§6.3] 전 조항 — 모바일이 등급·데이터에 관여하는 경로는 없다.
- 저사양 대응은 **표현 채널 감쇠와 동일 레이어**로만 작동한다: 배터리 절약 옵션 O-M2 (확정 — 결정 #9·§7.3) = **프레임 상한 30fps + 시스템 주사율 60Hz 고정 (단일 구성)**. 씬 패널 정지 컷은 번들에서 제거 — 접근성 층 O12로 별도 존치 (연출 손해와 절전의 결합 해제). 실규격·기기 성능 등급 판정·실측 게이트는 D12 (§9.2).

#### 1.5 자수 규격 3종 — 모바일 폭 재검증 (DoD B11) [모바일 — D09 §6.6 재수행]

기준 논리 폭 390dp (확정 기준값), 본문 폰트 기준값 16sp (확정 기준값) 기준 검증:

| 규격 (D04 확정) | 모바일 검증 (기본 배율 100%) | 판정 |
|---|---|---|
| 레이스 로그 줄당 전각 22자 | 전폭 로그 존 390dp − 여백 ≈ 358dp ⊃ 22자 × 16dp = 352dp | **경계 수용 (확정)** — 폰트 기준값 16sp 이하에서 성립 |
| VN 대사 줄당 전각 24자 | 대사창 전폭 358dp ⊃ 24자 × 14.5dp — 대사창 폰트 14.5sp (확정 기준값) | **경계 수용 (확정)** |
| 선택지 전각 14자 | 중앙 패널 ⊃ 14자 × 16dp = 224dp | **수용** |

- **130% 팽창 여유:** 상기는 전각 만재 기준·라틴 반각 논리로 D09 §6.6과 동일하게 성립. 고정폭 요소(버튼 라벨) 최장 키 언어 기준 + 말줄임 금지 원칙 승계.
- **O7 텍스트 확대 × 표시 층 — 해소 확정 (결정 #5 · D09 v1.1 §7.3 이원 이행 접수):** 작성 층(D04 자수 규격)은 불변이며 규격 위반 차단의 정문 장치는 스트링 층 기계 검증(D12 — 마스터플랜 §4-D12 등재)이다. 모바일 표시 층은 O7 확대 시 시각 줄바꿈을 허용하고 아래 산출에 따라 **시각 줄 상한을 물리 고정**한다.

**시각 줄 상한 산출표 (확정 기준값 — 파라미터 확정·강건성 확인):**

| 대상 | 폰트 | O7 100% | 115% | 130% | **슬롯/창 시각 줄 상한** |
|---|---|---|---|---|---|
| 레이스 로그 (작성 2줄 × 전각 22자) | 16sp | 22자/줄 → 2 | 19자/줄 → 4 | 17자/줄 → 4 | **4 (확정 기준값)** |
| VN 대사창 (작성 2줄 × 전각 24자) | 14.5sp | 24자/줄 → 2 | 21자/줄 → 4 | 18자/줄 → 4 | **4 (확정 기준값)** — §5.1 명기 (총괄 판정 C — 본 문서 소관) |

- **감도 분석 (총괄 재검증 정정 반영):** 로그 — 작성 줄당 시각 줄이 3이 되는 경계는 시각 줄당 자수 ≤ 10 ⇔ 유효 폭 < **11 × 20.8 ≈ 229dp** *(v0.1 발신의 208dp는 자수 ≤ 9의 경계 — 결론 불변, 총괄 재계산 접수)*. VN 대사창 — 자수 ≤ 11 ⇔ 유효 폭 < 12 × 18.85 ≈ 226dp. 양쪽 모두 실기기 범위 밖 — **상한 4는 파라미터 현실 전 범위에서 강건**하다.

### 2. 화면 체계 (DoD C12~C15)

#### 2.1 화면 전수 대장 (결정 K6 — DoD C12) [승계 — D09 §2.2 + 모바일 증보]

**D09 25종 화면 ID를 동일 승계한다 (결정 #3 — K6):** SYS-01~05 / RACE-01~03 / RUN-01~02 / HUB-01~08 / NAR-01~02 / SET-01~02 / COM-01~02 / TUT-01 — ID·명칭·대응 규칙 원천·구성 전부 D09 §2.2 대장 그대로이며, 본 문서는 각 화면의 **세로 배치**만 별첨A에서 기술한다.

**모바일 신규 화면 2종 (증보 — §9.1 대장 등재):**

| ID | 화면 명칭 | 대응 규칙 원천 | 별첨A |
|---|---|---|---|
| **AD-01** | 광고 홀드 화면 | D16 §3.4 (30초 홀드·재시도 창) | §B-3 |
| **AD-02** | 오퍼 다이얼로그 (오버레이) | D16 §3.2 파이프라인 ⑤ (K7-A) | §B-4 |

- AD-02는 COM-01(확인 다이얼로그)과 별도 화면으로 분리한다 — COM-01은 비가역·유상 행동의 *확인*이고 AD-02는 *제안(오퍼)*으로 성격·규격(동등 가중 §6.6)이 다르다. K7-B(투어 경계 오퍼)는 신규 화면이 아니라 **SET-01 내부 블록**(§5.2·D16 §3.3 "SET-01 화면 내부의 명시적 UI")이다. 면제 잔여 상태 안내는 요소이지 화면이 아니다(§6.3).
- 모바일 화면 총수 = **27종** (25 승계 + 2 신규). 화면 수 억제 원칙 승계 — 신규는 광고 계열 2종뿐이다.

#### 2.2 플로우맵 폐쇄성 재검증 (DoD C13 — 총괄 부기 의무 이행) [모바일 — D09 §2.3 방법 승계]

D09 §2.3 플로우맵에 **광고 노드를 삽입한 모바일판**을 정의하고, D09와 동일 방법(상태 머신 1:1 대조·미정의 전이 0건)으로 폐쇄성을 재검증한다. 광고 삽입 지점은 D16 §3.2 확정 단일 지점 — **RACE-03 결산 이탈 시점**뿐이다.

```
RACE-03 그랑프리 결산 — [결산 확인 → 이탈 탭]
    │
    ▼
〔광고 판정 파이프라인 — D16 §3.2 ①~⑥ (화면 아님·즉시 판정)〕
    ├─ ①온보딩(첫 4대회) / ②쿨다운(8분) / ③리타이어 → 노출 없음 ──→ (다음 화면 직행)
    ├─ ④면제권 보유 → 1대회분 소모·노출 없음 ──────────────────→ (다음 화면 직행)
    ├─ ⑤보상형 로드 성공 시 → [AD-02 오퍼 다이얼로그]
    │       ├─ 수락 → 보상형 재생(SDK 전체화면) → 면제 부여·즉시 소모 → (다음 화면 직행)
    │       └─ 거절(=닫기) → ⑥으로
    └─ ⑥전면 로드 분기 (D16 §3.4)
            ├─ 로드 성공 → 전면 재생(SDK) ────────────────────→ (다음 화면 직행)
            ├─ No-fill → 즉시 통과 (AD-01 비표출) ─────────────→ (다음 화면 직행)
            └─ 오프라인/타임아웃/에러 → [AD-01 홀드 화면 — 최대 30초]
                    ├─ 재시도 성공 → 전면 재생 → (다음 화면 직행)
                    └─ 30초 만료 → 통과 ──────────────────────→ (다음 화면 직행)

(다음 화면) = D09 §2.3 기존 분기 그대로: [투어 내 잔여 대회 有] → RUN-02(발생 시) → RUN-01 → RACE-01
                                        [투어 최종 대회 or RETIRE] → SET-01
```

**폐쇄성 판정 (v0.1 수행·현행 유효 — 확정 전 재수행):**
- 신규 노드 AD-01·AD-02의 이탈 경로는 전부 **기존 플로우의 "다음 화면"으로 수렴**한다 — 미정의 전이 0건, 신규 도달 불능 상태 0건.
- 광고 노드는 D05 §3 상태 머신 **외부**(RACE-03 이탈 이후·다음 화면 진입 이전의 전이 구간)에 위치한다 — 상태 머신 무개정 (D16 비차단 원칙의 플로우 이행).
- 투어 마지막 대회 순서 고정: **광고(RACE-03 직후) → SET-01 → VN(투어 종료)** — D16 §3.2 서사 시퀀스 보호 규칙과 1:1. 광고가 SET-01·VN 사이에 끼어드는 경로는 존재하지 않는다.
- K7-B는 SET-01 내부 요소로서 화면 전이를 추가하지 않는다. 시즌 최종 투어의 완주 결산에서는 비표출 (D16 결정 #16 — SET-02·오버홀·시즌 엔딩 VN 특수 시퀀스 무간섭).
- 금지 구역 대조: 레이스 중·VN 중·기록실/아카이브에 광고 진입점 0건 — 플로우맵 전수에서 광고 노드는 상기 단일 지점뿐 (D16 §3.2 금지 구역 이행, §8.2 P-1 ④ 이중 방어).

#### 2.3 저장 지점·세션 단절 내성 (DoD C14) [승계 — D09 §2.4 + 모바일 대체]

- 자동 저장 지점 3종(RACE-03 진입 / SET-01 ⑧ / 시즌 경계)·저장 표시·수동 저장 없음·슬롯 3 — [승계 — D09 §2.4] 전 행.
- **클라우드 행 대체 [모바일]:** 플랫폼 클라우드 저장 (실선정 D12 이관 — 후보: iOS Game Center·iCloud / Android Google Play Games). SYS-02 동기 상태·최종 저장 시각 표시 규격은 승계.
- **세션 단절 내성 (모바일 신규 명기):** 앱 강제 종료·프로세스 킬 시 복귀 = 마지막 자동 저장 지점 — 레이스 중 킬은 해당 GP 시작 전 복귀(GP 재시작)다. 이는 저장 지점 규칙의 자연 귀결이며 신규 규칙이 아니다. **세이브 스커밍 벡터 아님 판정:** 킬로 무를 수 있는 단위는 GP 전체뿐이고 이는 데스크탑의 강제 종료와 동일하다(수동 저장 부재 구조가 양 플랫폼 공통 방어선 — D05 푸시-유어-럭 보호 불변).
- **광고와 저장의 순서 정합:** 광고 노드는 RACE-03(저장 지점) *이후*에 위치하므로 광고 중 어떤 단절이 발생해도 진행 유실이 없다 — 면제권 소모·노출 카운트의 단절 시 정합은 D12 이관 (§9.2).

#### 2.4 와이어프레임 표기 규격 (DoD C15) [승계 — D09 §2.5 + 모바일 대체]

별첨A 전 화면 = ①ASCII 레이아웃 ②요소 표(`화면ID-E##` — D09 별첨A와 요소 ID 연속 체계) ③진입/이탈 전이 ④**주 버튼 위치·엄지 존 판정** (패드 순회 행의 모바일 대체 — 초기 포커스 개념은 터치에서 부재). 좌표·치수는 1080×2340 기준의 비율 서술, 실치수는 D10/D12 실기 확정 이관.

- 상태 안내 노출 위치 = 보상형 버튼 위치와 동일 2지점 한정 — 면제 상태가 전 화면을 따라다니지 않는다 (광고 시스템의 존재감 최소화).

#### 6.4 온보딩 무광고 구간 처리 (DoD G32) [D16 §8.1-④]
