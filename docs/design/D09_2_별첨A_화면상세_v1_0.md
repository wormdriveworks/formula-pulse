# D09-2 별첨A. 모바일 화면 상세 명세 (와이어프레임) — v1.0 (확정)

> **상태:** **v1.0 확정** (2026-08-02) — 본문 D09-2 v1.0과 판번 동기 발행. 최소 성립선 9:16 검증·라벨 폭 검증·엄지 존 27/27 전수 확인 (본문 결정 #10). 압축 명세(§B-10)는 확정 형식 — D09 별첨A 단순 화면 압축 서술 전례. / (v0.5: 다이제틱 문면 / v0.4: 판단성 확정 / v0.3: 치수 확정 / v0.2: 최악 케이스 / v0.1: 초판.)
> **표기 규격 (본문 §2.4):** 각 화면 = ①ASCII 레이아웃 ②요소 표(`화면ID-E##` — D09 별첨A 요소 ID 연속 체계: 승계 요소는 원 ID 유지, 모바일 신규 요소는 M## 대역) ③진입/이탈 ④**주 버튼 위치·엄지 존 판정**. 좌표·치수는 1080×2340 (논리 폭 390dp (확정 기준값)) 기준 비율 서술 — 실치수는 D10/D12 실기 확정 이관.
> **공통 상속:** 전 HUB·SET 화면은 상단 공통 바(본문 §4 — 재화 2종 아이콘+수치 [B-1]·시즌/투어 진행·다음 일정 1행 압축)를 상속. 확인 = COM-01, 툴팁 = COM-02(롱프레스 호출 — 본문 §1.2). 세이프 에어리어 마진(본문 §1.1)은 전 화면 상속. 이하 개별 명세에서 반복 기재하지 않는다.
> **승계 원칙:** 요소의 내용·상태·규칙은 D09 별첨A 해당 절이 정문이며, 본 별첨은 **세로 배치·엄지 존 판정·모바일 신규 요소**만 기술한다.
