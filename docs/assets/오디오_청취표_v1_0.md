# 오디오 청취표 v1.0 — 에셋 트랙

> 작성: 에셋 트랙 (원격 세션) · 2026-08-24 · **IMPL-404**
> 근거: 총괄 배정(IMPL-402) — *"오디오 청취는 실물 플레이 검증 회차 전 완료 권고 — 청취 소견이 그 회차의 입력"*
> **청취는 사람의 귀 소관이다.** 원격 세션은 헤드리스라 소리를 들을 수 없으므로, **들을 수 있게 만드는 것**까지가 이 문서의 몫이다.

## 0. 미리듣기 2종 — 한 번에 듣도록 이어붙였다

| 파일 | 내용 | 길이 |
|---|---|---|
| `청취_jingle.wav` | 징글 5식 · 항목 사이 **0.45초** 무음 | 5.0초 |
| `청취_sfx.wav` | SFX 68식 · 항목 사이 **0.30초** 무음 · **아래 표 순서 그대로** | 37.6초 |

형식은 전건 **44.1kHz · 모노 · 16bit** 로 동일하므로 이어붙여도 이음이 생기지 않는다. 표의 **시작(초)** 열로 어느 항목을 듣고 있는지 짚을 수 있다.

## 1. 기계가 먼저 본 것 — 그리고 **결함이 아니라고 판정한 것**

| 축 | 결과 |
|---|---|
| 형식 | **73/73 이 44.1kHz·모노·16bit** — 편차 0 |
| 클리핑 | **0** |
| 피크 | 전건 0.2~0.99 안 (과소·과다 0) |
| 선행 무음 | **0** (>0.05초인 항목 없음) |
| 종단 클릭 | **0** — 릴리스 램프가 전건 0으로 끝난다 |
| 재현 계약 | `SFX_GEN PASS sounds=73` · `BGM_GEN PASS tracks=18` |

### 1.1 ⚠ 두 수치를 결함으로 올릴 뻔했고, 확인해 보니 **설계였다**

| 관측 | 확인 | 판정 |
|---|---|---|
| **51/73 이 첫 샘플부터 피크**(온셋 클릭처럼 보인다) | `sfx_params.json` 에 **`p_env_attack = 0.0` 이 67항 선언**돼 있다 | **sfxr 관용 — 즉시 어택이 곧 이 합성의 타격감이다.** 결함 아님 |
| **53/73 에 DC 성분**(징글은 −0.09~−0.14) | `wave_type=0`(구형파)·`p_duty=0.5` 는 sfxr 매핑상 **실제 듀티 25%** 다 — 25% 구형파는 평균이 0이 아니다 | **선언된 파형의 성질.** 결함 아님 |

> **이 세션에서 세 번째다** — 참이지만 다른 명제를 잰 뒤 **선언을 확인하고 되돌린** 사례(휘도 평균 · 팔레트 사용량 · 이번 온셋·DC). **측정이 이상을 가리켜도, 선언을 먼저 읽는다.**
>
> 다만 **귀로 확인할 값은 남는다:** 징글 DC −0.14 는 **헤드룸 14% 손실**이고 BGM 과 겹칠 때 저역이 뭉칠 수 있다. **수치가 아니라 소리로 판단할 항목**이므로 §3 에 넣었다.

## 3. 귀로만 판정되는 것 — 이것이 청취의 목적이다

| # | 무엇을 | 왜 기계가 못 하는가 |
|---|---|---|
| ① | **징글 5식이 한 세계로 들리는가** — 특히 `jg_04` 모티프가 나머지 4식과 같은 어법인가 | 어법 일관성은 스펙트럼 수치로 환원되지 않는다 |
| ② | **DC −0.14 가 실제로 들리는가** — 징글이 BGM 위에 얹혔을 때 저역이 뭉치는가 | §1.1 의 수치는 **원인**이고 들리는지는 **결과**다 |
| ③ | **SFX 68 중 서로 헷갈리는 쌍이 있는가** — 특히 같은 접두(`se_u*` 19식 · `se_i*` 14식) 안에서 | 글리프 혼동 쌍을 화소 차로 쟀듯, 소리의 혼동은 파형 차로 재지지 않는다 |
| ④ | **루프 항목의 이음이 들리는가** | 생성기 `seam` 수치는 **첫·끝 진폭 차**일 뿐이고, 위상 불연속·잡음 질감은 그 값이 0이어도 들린다(도구 주석 명문) |
| ⑤ | **BGM `_a`/`_b` 층이 겹쳤을 때 성립하는가** | 층 합성의 판정은 동시 재생으로만 선다 |
| ⑥ | **음량 균형** — SFX 대 징글 대 BGM | 피크는 맞아도 **체감 음량**은 다르다 |

## 4. 청취 결과를 어디에 적는가

이 문서에 **§5 청취 소견**을 덧붙이면 된다 — 항목 ID 와 한 줄 소견이면 충분하고, 재작업이 필요한 항목만 적어도 된다. 소견이 오면 에셋 트랙이 파라미터로 옮긴다(WAV 를 손으로 고치지 않는다 — `--check` 가 걸어낸다).
