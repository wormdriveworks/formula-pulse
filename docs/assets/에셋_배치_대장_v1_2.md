### 1.1 디렉토리 결정 근거

- `ui/`~`vane/` 11계 = **D10 §8.2 카테고리 1:1** (IMPL-021 확정). 신설·개명 금지.
- **무대 배경이 `backgrounds/`가 아니라 `scenecuts/`에 있는 이유:** D10 §8.2가 무대 배경 5식을 *씬 컷* 분류로 계상하고 `배경 = 4장`(개러지 2·VN 2)으로 못박았다. 대장이 D10 계상과 1:1 추적되도록 계상을 따랐다.
- **`audio/`·`platform/`·`store/` 3계는 신규 [가안].** D10 §8.2 카테고리 목록에 사운드·플랫폼 부속의 자리가 없다(CLAUDE.md 디렉토리 계약도 "아트·사운드 실물"이라 쓰고 목록에는 사운드가 없다). §9-①③ 등재 — 총괄 확인 대상.
- **`store/`가 `godot/` 밖인 이유:** 스토어 제출 소재는 게임 빌드에 실리면 안 된다(용량·무관 리소스). `res://` 밖에 두면 export preset 제외 규칙이 필요 없다.

## 3. 경로 유도 규칙 — 개발 에이전트용

코드는 아래 식으로 경로를 계산한다. 표 조회 불요.

| 대상 | 유도식 | 실측 근거 |
|---|---|---|
| 릴 심볼 | `res://assets/ui/icons/{symbol_id}.png` | race_screen.gd:455 (구현됨) |
| 섹터 속성 | `res://assets/ui/icons/{attr_id}.png` | race_screen.gd:499 (구현됨) |
| 재화 | `res://assets/ui/icons/currency_{credit\|data}.png` | hub_screen.gd:28-29 (**코드 하드코딩** — §9-⑤) |
| 스탠딩 기본 | `res://assets/characters/{char_id}_base.png` | 신규 규약 |
| 표정 차분 | `res://assets/characters/{char_id}_face_{expr}.png` | 신규 규약 |
| 머신 베이스 | `res://assets/machines/{machine_id}_base_{view}.png` | 신규 규약 |
| 머신 오버레이 | `res://assets/machines/nw01_boreas_overlay_{part}_{nn}_{view}.png` | 신규 규약 |
| 씬 컷 프레임 | `res://assets/scenecuts/{cut_id}_{frame:02d}.png` | 신규 규약 |
| 무대 배경 | `res://assets/scenecuts/{stage_id}_{far\|near}.png` | 신규 규약 |
| SFX | `res://assets/audio/sfx/{sfx_id}.wav` | 신규 규약 |
| BGM | `res://assets/audio/bgm/{track_id}.ogg` | 신규 규약 |

**`char_id`·`machine_id`·`stage_id`는 전부 실존 데이터 id다** — 새 식별자를 만들지 않았다. `ai_lorentz`·`crew_sasha`는 `ai_rivals.csv`·`crew.csv`의 id 열, `stage_metro_night`은 `stage_metro_night.json`의 id 필드.

**부재 시 계약 (구현됨 — race_screen.gd:450-462):** `asset_id`가 빈 문자열이면 조용히 null(정상 경로) · 파일이 없으면 `push_error` 1회 후 null(널도 캐시되므로 **에러는 id당 한 번만** 찍힌다) · **폴백 텍스처 없음.** 신규 소비부도 이 계약을 따를 것.

## 4. 이미지 대장

### 4.1 `ui/icons/` — 27종 · 전량 32×32 (D10 확정 21 + 업적 6 — P-9)

> ⚠ **릴 심볼 6종은 정확히 32×32여야 한다.** 릴 `TextureRect`가 `KEEP_CENTERED`(무배율)라, 크기가 다르면 확대·축소가 아니라 **잘리거나 여백이 생긴다**(race_screen.tscn:331-335 실측).
>
> **표시 크기 = 원도 크기다 (실측 — IMPL-106).** 전 아이콘 `TextureRect`가 `expand_mode = EXPAND_KEEP_SIZE`(기본값)이므로 **컨트롤의 최소 크기가 텍스처 크기**이고, 씬의 `custom_minimum_size`(14~16)는 그보다 작아 구속하지 않는다. 즉 32×32 원도는 캔버스 32px에 **1:1 무배율**로 그려지고 캔버스만 ×3 정수 확대된다 — 믹셀 0.
> **함의:** 화면에서 더 작은 아이콘이 필요하면 **표시 상자를 줄이지 말고 그 크기의 원도를 따로 만든다**(예: 재화용 16×16). 상자만 줄이면 `expand_mode`를 함께 바꿔야 하고, 그 순간 ÷2 다운샘플로 디테일 절반이 사라진다.

## 7. 배치 후 절차 (3단계)

```bash
git lfs install && git lfs pull
```
① **LFS 확인** — PNG·WAV·OGG·TTF는 LFS 추적 대상(.gitattributes). 파일이 수백 바이트면 포인터 텍스트다(IMPL-091 실측: 포인터 상태로 테스트가 36분 행).

```bash
& "C:\SDKs\godot\Godot_v4.7.1-stable_win64_console.exe" --headless --import
```
② **임포트** — `.import` 파일이 생긴다. **`.import`는 반드시 함께 커밋**한다(IMPL-003). 누락하면 반대편 머신이 기본값으로 재임포트해 니어리스트·정수 스케일이 조용히 깨진다.

> **⚠ 에디터가 켜져 있으면 이 명령은 실패한다 (2026-08-16 실측 · IMPL-137).** 헤드리스 임포트도 GDAI 애드온을 적재하는데, 에디터가 이미 MCP 포트 3571을 쓰고 있으면 `MCP server failed to start: Port 3571 is already in use` 뒤에 **접근 위반으로 죽는다**(exit `0xC0000005`). `.import`가 안 생긴 채 종료되므로 조용한 실패가 아니라 요란한 실패다.
> **대처 — 에디터를 끄지 말고 에디터에게 시킨다.** 다른 세션이 에디터를 쓰는 중일 수 있다. GDAI `execute_editor_script`로 `EditorInterface.get_resource_filesystem().scan()`을 한 번 부르면 신규 파일이 임포트되고 `.import`가 생성된다. 실제로 이 경로로 팔레트 2종을 임포트했다.
> **확장자별 차이:** `.gpl`처럼 Godot에 임포터가 없는 확장자는 **`.import`가 생기지 않는 것이 정상**이다 — 누락이 아니므로 찾지 말 것.

③ **임포트 설정 확인** — 신규 이미지는 압축 무손실·밉맵 off·니어리스트여야 한다(기존 아이콘 `.import`와 동일). 9패치(`_9p`)는 `NinePatchRect`로 소비하므로 코너 값을 코드/씬에서 지정한다(파일 자체에 코너 메타 없음).

> **주의:** LFS 복원 **전에** `--import`를 돌리면 포인터 텍스트가 이미지로 임포트되어 `.import`가 오염된다(IMPL-091 실측 — 16종 전건 원복 필요했다). 반드시 ①→② 순서.
