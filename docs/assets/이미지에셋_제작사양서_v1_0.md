## 1. 공통 기술 규격

### 1.1 캔버스·배율 (D10 §2.1 · D12 §9.1 — 확정)

| 항목 | 값 |
|---|---|
| 데스크탑 원도 캔버스 | **640×360px** → ×3 정수 표시 = 1920×1080 |
| 모바일 세로 원도 캔버스 | **360×780px** → ×3 정수 표시 = 1080×2340 |
| 배경류 블리드 | 좌우 각 **+24px** (모바일 너비 가변 대응 — D10 §2.5·D12 §9.2 기확정) |
| 스케일 규칙 | 정수 배율 + 니어리스트 필터 전역 + 픽셀 스냅. **비정수 리샘플 금지** |
| 그리드 | **믹셀 금지** — 한 화면 단일 픽셀 그리드. 회전·비정수 스케일 사전 베이크 금지 |

### 1.2 스타일 (D10 §1 — 확정)

전면 도트 통일 · 고밀도 디더링(버스트업·배경) / 간결 셀(필드 스프라이트·씬 컷)의 밀도 차등 · 야간 네온·텔레메트리 발광 컬러 · 텔레메트리 계기 의장. **금지:** 벡터·사진·3D 렌더 소스, CRT/스캔라인 필터, 판타지 어휘(목판 프레임·주화·보석·양피지 톤 — ToF 4중 분기, D10 §9).

### 1.3 파일·경로 규약 (IMPL-021·075 — 확정)

- 배치: `godot/assets/<카테고리>/` (D10 §8.2 카테고리 1:1) · 파일명 = 테이블 id (도상 경로 규약 — IMPL-075 [가안] 승계)
- PNG + **`.import` 반드시 커밋** (IMPL-003) · 임포트 = 니어리스트 고정
- 기존 플레이스홀더 16종(`assets/ui/icons/`)은 **같은 경로·파일명으로 원도만 교체** — 참조부 무변경

### 1.4 팔레트 (D10 §2.3~2.4 — 구조 확정 · 색상값 미유입)

마스터 56색: 코어 뉴트럴 16(야간 아스팔트·강철·콘크리트) + 텔레메트리 네온 12(시안·마젠타·앰버) + 팀 컬러 블록 16(팀당 4색) + 환경·피부·머티리얼 12. 색각 대체 1종(색상만 교체·도상 불변).
**⚠ 선행 과제:** 팔레트 실물 2식이 아직 없다(IMPL-071·075가 기능 컬러를 [가안]으로 운용 중). AI 산출물의 양자화 기준이므로 **모든 에셋 제작에 앞서 팔레트부터 확정**해야 한다. 팀 컬러 확정분 = 악시온 백×청 / 불카 흑×주황 / 그리폰 진녹×금 (D03 §2.2). **노스윈드 4색은 정본 미정** — [가안] 오프화이트×아이스 시안 (주인공 헬멧 무광 오프화이트·바이저 발광 라인과 정합) → 총괄 확인 필요.

## 2. AI 생성 공통 규격

### 2.1 공통 프리픽스 — 모든 프롬프트 앞에 결합

| | 프롬프트 |
|---|---|
| 국문 | 도트 픽셀 아트, 고밀도 디더링, 90년대 후반 콘솔 2D, 야간 네온 무드, 텔레메트리 발광, 시안·마젠타·앰버 액센트, 선명한 실루엣, 제한된 팔레트 |
| 영문 | pixel art, dense dithering, late 90s console 2D, night neon mood, telemetry glow, cyan magenta amber accents, crisp silhouette, limited palette |

### 2.2 공통 네거티브 — 모든 생성에 공통 제외

| | 프롬프트 |
|---|---|
| 국문 | 사진, 실사, 3D 렌더, 벡터, 부드러운 그라데이션, 텍스트, 워터마크, 판타지 장식, 양피지 톤, 흐릿함 |
| 영문 | photo, photorealistic, 3D render, vector art, smooth gradient, text, watermark, fantasy ornament, parchment tone, blurry |

### 2.3 생성 → 원도 파이프라인 (5단계)

AI 생성기는 32×32·180×240 같은 원도를 직접 산출하지 못한다. **①생성(원도의 4~8배 크기로) → ②정수 다운스케일(니어리스트) → ③마스터 56색 양자화 → ④그리드·윤곽 수작업 정리(믹셀 제거) → ⑤`godot/assets/` 배치 + `.import` 커밋.** 표정 차분·오버레이 파츠는 베이스에서 레이어 분리 후 부분 재생성(inpaint) 권장.

### 2.4 구속 조항 (프롬프트에 반영 의무)

- 베인 = **인체·마스코트 형상 절대 금지** (D03 §1.5·§6)
- 주인공 = **맨얼굴 금지** — 풀페이스 헬멧 + 틴티드 바이저 완전 차폐 (D03 §1.1·D10 §3.2)
- 중계 화자 인물 아트 금지 · 필러 인물 아트 금지 (D10 §3.4)
- 레퍼런스 2종(VA-11 Hall-A·핫라인 마이애미)은 기법·밀도·컬러 기준점만 — **구도·캐릭터 모사 금지, 프롬프트에 작품명 직접 기입 금지** (D10 §1.2)
- 씬 컷은 대치(마주보기) 구도 금지 — 측면·추격 상황 컷만 (ToF ②, D10 §9)
- 실존 모터스포츠 브랜드·실존 작품 도상 차용 금지 (D01 §7·D03 §6)
