## 1. 릴 심볼 — 2× 정수 배율

- 프로브(`_r6_reel_probe`)로 A 현행 64×62/32 · B 72×70/64(2×) · C 44×44/32 를 병치 캡처(1920×1080 실기 렌더) → 사용자 B 선택.
- `race_screen.tscn` Reel0~2: Frame `custom_minimum_size` 64×62 → 72×70 · Symbol 32×32 → 64×64 · `stretch_mode` KEEP_CENTERED(3) → KEEP_ASPECT_CENTERED(5).
  원도는 32 그대로(`_icon_texture` 무접촉 · UISCR "릴 심볼 6종 = 32 원도" 검사 유지) — 표시만 2×. 정수 배율이라 믹셀 0.
- 스냅숏 행(`E05Snapshot` Sym0~2)은 32 유지 — 살아 있는 릴(대형)과 이전 후보(소형)가 크기로 갈린다.
- 종전 "릴 32 무배율 계약"(D10 §2.2 · 대장 §4.1.1) 주석 3곳을 갱신 — 설계 정본은 아카이브 참고(개선 모드 규칙).

## 2. HUB-08 오버홀 포기 동선

- 증상: 잔여 슬롯·후보가 남으면 설치 외에 나갈 길이 없었다(`overhaul_screen.gd` 가안 "선택 필수").
- `overhaul_screen.tscn`: `ConfirmButton` 을 `ActionRow`(HBox) 로 감싸고 `SkipButton` 병치.
- `overhaul_screen.gd`: `_on_skip()` — `ui.overhaulScreen.skipConfirm`({slots}) 확정 창(비가역) → `_leave()`(설치·무후보 통과와 같은 체인 출구).
  무후보·무슬롯(통과 상태)에서는 포기 버튼을 숨긴다 — 확정 버튼이 이미 출구라 같은 뜻의 버튼이 둘 서지 않게.
- 스트링 2키: `ui.overhaulScreen.skip` / `.skipConfirm` (ko/en/ja).

## 3. SC3 심볼 복제 — 대상 지정

- 종전: 홀드 2개 → 낮은 인덕스 = 공여·높은 인덕스 = 대상(가안) — 체크박스 뜻("지킨다")과 반대로 켠 릴이 덮였다.
- 현행: **홀드한 릴 1개 = 원본(공여)**, 대상 = 이웃. 양 끝 릴은 즉시 발동, 가운데 릴은 방향 선택 대기 —
  고지 슬롯에 `ui.race.sc3PickDirection` + 아래 `Sc3DirectionRow`(← 1번 릴로 복제 / 3번 릴로 복제 →) 표출.
  입력 3경로: 방향 버튼(마우스·포커스) · 홀드 키 1/3 · 패드 X 홀드 + 커서 → A.
- 홀드 0개·2개 이상 = `ui.race.sc3HoldOne` 고지 + 거부음. 대기는 턴 경계·홀드 변경·발동에서 걷힌다.
- 구조: `_on_skill_slot` → (effect == symbol_clone) `_begin_symbol_clone` / 그 외 `_use_skill(index, _skill_args(family))`.
  `_skill_args("convert")` 는 이제 홀드 1개 = 대상만 돌려준다(donor 분기 제거).

## 4. 레이스 로그 화자 구분

- 코어: `RaceEngine._ev(phase, key, params, speaker = "relay", speaker_id = "")` — 사건 dict 에 `speaker`·`speaker_id`.
  플랫폼 무관 데이터 필드(혼입 0). 배정은 발행 지점에서(문면 키와 같은 자리).
- 표시: `LogFeed.push_line(mark, body, speaker, speaker_id)` · `ICON_BY_SPEAKER` 에 CREW(`speaker_crew_16`) 추가 ·
  RIVAL 은 `_speaker_asset()` 이 `speaker_rival_<id>_16` 개인 배지(8종)를 고르고 없으면 공용 헬멧(FILLER).
  `race_screen._log_speaker()` 가 필러 여부를 `engine.entrants` 에서 갈라 FILLER 로 보낸다. 표지 문면 키 `ui.race.speakerCrew`(피트)·`speakerRival`(상대).
- UISCR ②-1 갱신: 크루 = 도상 · 네임드 라이벌 = 개인 배지 · 배지 없는 참가자 = 공용 헬멧 · 미지정 = 텍스트.
