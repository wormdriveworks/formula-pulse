# 개선 회차 1 — 실기 점검 → 결함 4건 수정 + UX·연출 개선 8건 (2026-09-01)

> **문서 위상:** 이 문서는 개선 세션 산출물이다. `docs/design/`·`docs/handoff/`의 기존 개발
> 문서는 이 세션부터 **아카이빙된 참고 자료**로 취급한다(사용자 지시 2026-09-01) — 규격·정책

## 1. 실기 점검 요약

새 커리어(슬롯 3)로 프롤로그 VN → GP 3연전(듀얼·리타이어·레조넌스 발화 확인) → 결산 →
간이 정산 → 일시정지/옵션/타이틀 전 흐름을 실제 플레이. 코어 룰(스핀→개입→확정→정산)은
견고. 사용자 세이브(슬롯 1·2) 무접촉 — 시작 전 프로필 전체 백업(스크래치패드 `profile_backup/`).

## 2. 확정 결함 → 수정 (4건 + 부수 1건)

| # | 결함 | 원인 | 수정 |
|---|---|---|---|
| F1 | 간이 정산 소모품 구매 시 포커스 소실 → **패드 진행 불가** | `_refresh_consumables()`가 포커스 보유 버튼을 free 후 재생성, 복원 없음 | 버튼에 품목명 부여 + 재생성 후 같은 품목→첫 가용→주 버튼 순 복원(`_restore_list_focus`). 덱 목록·정비 버튼 비활성 전환도 동계열 가드 |
| F2 | **일시정지 중** Tab으로 배면 레이스 UI 포커스 탈출 → 정지 상태에서 소모품 실사용(실측: 리페어 키트 소진) | 오버레이가 액션 층만 차단, GUI 포커스 경로 무방비 | 일시정지 오버레이에 뷰포트 `gui_focus_changed` 트랩(밖으로 나가면 되끌어옴, `_enter/_exit_tree` 쌍 연결) + `_on_consumable`에 `_paused` 가드(겹 방어) |
| F3 | 일시정지→옵션→닫기 후 포커스 미복원 → 키보드·패드 무반응 | 옵션 오버레이 `queue_free` 시 포커스 허공 낙하 | `closed` 시그널에서 호출 버튼 재포커스(옵션·업적 양쪽) |
| F4 | 옵션 조작 탭 안내문이 **세로 한 글자씩** 렌더 + 화면 밖 유출 | 탭 패널 VBox가 앵커 없이 plain Control에 붙어 폭 0 → autowrap 글자 단위 꺾임 | 패널 전폭 앵커(`PRESET_FULL_RECT`). 전 탭 공통 수혜 |
| 부수 | 타이머 수치가 비개입 국면에 직전 값으로 잔류 표시 | `_update_timer_value` 가시 조건에 `_timer_active` 부재 (기본 끔이던 시절의 잠복 결함 — O6 기본 켬 전환이 드러냄) | 조건에 `_timer_active` 추가 |

## 3. UX·연출 개선 (8건)

| # | 항목 | 내용 |
|---|---|---|
| G1 | **그랑프리 결산 강화** | 좌측에 순위 변동(P{start}→P{finish})·듀얼 전적(n전 n승 n패)·트러블 턴 추가, 우측에 **전 참가자 최종 순위표**(플레이어 행 시안 강조·리타이어 표기). 소재 = 엔진 result 기존 값 + `start_rank` 1필드 신설(직렬화 포함) |
| G2 | **단축키 노출** | 홀드 토글 라벨 "홀드 1/2/3" · 리스핀/차지 개입/스킬 툴팁에 키 힌트 · **옵션 조작 탭에 바인딩 10행 대장**(공통 층 + 레이스 층, 키보드\|패드 병기) |
| G3 | **타이틀·슬롯 카드** | 타이틀에 키 비주얼(boot_splash 재사용·무배율) + 좌→우 감쇠 스크림(BG_DEEP 알파, 신규 색 0). 슬롯 카드에 크레딧·저장 시각 표기 + **슬롯 삭제**(같은 버튼 2회 확인 — 모달 불신설: 포커스 결함 계열 회피 의도) + `SaveManager.delete_progress()` 신설(진행·백업·스냅샷·격리 4파일) |
| G4 | **VN 화자 강조** | 비발화 스탠딩 0.62 등채널 감광(modulate — 조달 대장 문맥 제외 준수). 파형(베인) 슬롯 동일 적용 · `side=none`(지문)은 마지막 강조 유지 |
| G5-1 | 로그 문구 다양화 | `LOG_VARIANT_KEYS` 열거 대장 + 결정적 선택(턴·섹터·랩 유도 — RNG 스트림 무소비·재로드 동일). timeout×3·troubleHit×3·stableSector×3·momentum×2. ko/en/ja 병기 |
| G5-2 | 섀시 임계 연출 | 임계 진입 1회 로그 라인(`raceLog.chassisCritical01`) — SE-D06 경고음과 같은 판정·같은 재무장 규약 |
| G5-3 | 타이머 시인성 | **O6 수치 표시 기본값 켬** (D04 §8.2 "압박의 아날로그화"의 기본 끔 전제를 사용자 지시로 뒤집음 — 옵션 항목은 유지, 끄기 가능) |
| G5-4 | 간이 정산 피드백 | 결제 시 잔액 라벨 점멸(알파 트윈 — 색 불변) + 구매 버튼에 "보유 n" 병기 |

## 4. 검증

- 컴파일: 편집 12파일 `--check-only` 전건 exit 0
- 검증기: `VALIDATORS_PASS warnings=0` (PAL·V6 초기 지적 → 리터럴 대장화·modulate 인라인으로 규약 내 해소)
- 테스트: `TESTS_PASS suites=20` (UISCR 812 포함 · AUDIO_WIRING 1회 붉음은 부하 중 와치독 플레이크 — 단독·재주행 2회 녹색)
- 실기: F1(구매 후 포커스 유지 + 정비 비활성 시 주 버튼 이양)·F2(Tab 트랩)·F3(옵션 닫기 복원)·F4(조작 탭 정상 조판)·G1(하네스 캡처 — 순위표 16행·다이제스트)·G2·G3(카드 상세·2단 삭제 왕복)·G4(감광 3장면)·G5(변형 3종 발화·수치 기본 켬·잔류 소거·보유 표기) 전건 눈 확인
- 세이브: 슬롯 1·2 원본 유지 확인(카드 문면 대조) · 슬롯 3 = 테스트 후 삭제(빈 슬롯 환원)
