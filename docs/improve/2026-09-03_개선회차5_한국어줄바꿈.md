# 개선 회차 5 — 한국어 자동 줄바꿈 어절 단절 실험·수정 (2026-09-03)

> 회차 3 관찰(RUN-02 본문 `대신 시/선이`)의 후속. 사용자 선택(객관식) "한국어 줄바꿈 어절 단절 실험".

## 1. 증상

- 자동 줄바꿈(`autowrap_mode = WORD_SMART`) 라벨에서 한국어가 **어절 중간**에서 꺾인다 — `대신 시 / 선이 오간다`,
  `옆에서 졸 / 고 있고`. 랩 라벨 전반(이벤트 본문 · 확인 창 · 팁 · 옵션 안내 · 슬롯 카드 · 레이스 로그 · VN 대사 등 13지점)에
  같은 성질.
- 원인: TextServer(ICU)의 줄바꿈 기회 판정(UAX #14)이 한글 음절(H2/H3) 사이를 꺾을 수 있는 자리로 본다.
  한국어 조판 관례(어절 단위 — CSS `word-break: keep-all`)는 ICU 기본 규칙에 없다.

## 2. 실험 (프로브 `_r5_probe` — 동일 문안 · 280px · Galmuri9 9px)

| 변형 | 결과 |
|---|---|
| A 기본 WORD_SMART | `대신 시 / 선이` (어절 단절) |
| B `language = "ko"` | 동일 (ICU 한국어 로케일 테일러링 없음) |
| C 음절 사이 WORD JOINER(U+2060) 삽입 | **`대신 / 시선이`** — 띄어쓰기에서만 꺾임 · 글리프 없음(폭 0)으로 렌더 깨끗 |
| D `AUTOWRAP_WORD` | 동일 단절 |
| E ko + WORD | 동일 단절 |
| F/G 2번째 문안 기본 / WJ | `졸 / 고` → **`옆에서 / 졸고`** |

- 텍스트 서버 = ICU / HarfBuzz / Graphite (Built-in). WJ 는 Default_Ignorable 이라 폰트에 글리프가 없어도 폭 0 으로 처리된다(실측).

## 3. 수정

- `StringTable.text()` — **ko 열 한정**으로 결과 문면에 `keep_korean_words()` 적용: 어절 내부 경계(한글–한글 · 한글–영숫자 ·
  영숫자–한글)마다 U+2060 삽입. 문장 부호 앞은 UAX #14 가 이미 금지(× CL · × IS)하므로 무접촉. ja 는 음절 단위 꺾임이 관례라 제외.
- 문면 창구 한 곳이라 랩 라벨 13지점 전부가 수혜하고, 비랩 라벨(버튼·표제)에는 보이지 않는다(폭 0).
- 부수 검토: 글자 수 의존 소비부(타자 효과 `visible_characters` · `.text.length()`) 0건 — 영향 없음. 테스트는 `text()` 산출을
  양변에 두고 비교하므로(옵션 ⑤ 언어 전환 등) 일관.
- 상수는 `"\\u2060"` 이스케이프로 적는다 — 보이지 않는 리터럴은 편집기에서 사고를 부른다(도구 JSON 경로에서 `\\u2060` 이
  실문자로 풀려 들어간 것을 `cat -A` 로 잡아 교정).
