## 2. 결선 — 두 지점, 코드 1파일

| 지점 | 변경 |
|---|---|
| **관중 베드·무대 베드 = 레이스 화면 이탈** | RACE-01 `_audio_exit_events()` 가 `["reel_spin_loop", "timer_imminent_tick", "race_stage_enter"]` + 무대 파생 이벤트(`"%s_enter" % stage_id` · `sound_map` 에 있을 때만)를 돌려준다. 결산(RACE-03)으로 가든 정지 메뉴에서 타이틀로 나가든 화면이 내려가는 자리가 끝 — 사용자 결정 "GP 결산 진입에 끈다"의 일반형. BGM 행은 `stop_event` 가 건너뛰므로(트랙 교체 = 크로스페이드 몫) BGM 행만 있는 무대에서는 무해 |
| **룸톤 = 레이스 출발** | RACE-01 `_start_gp()` 첫머리 `stop_sfx("hub_enter")` — 관중 베드가 이어받는 자리. 개러지가 켠 루프를 개러지가 끄지 못하는 이유: 개러지는 하위 스테이션(HUB-02~08)을 오가며 트리를 떠나므로 이탈 훅에 두면 정비대에 들어설 때 룸톤이 끊긴다. 출발이 개러지 계를 떠나는 유일한 길이다(개러지 → 타이틀 경로 없음 · NAR-01 브리핑 동안은 룸톤 유지 = 피트에 있다) |

- 에셋 무접촉(`godot/assets` = 에셋 트랙 소유). 타 레인이 단발 14초로 바꿔 커밋하면 이 정지는 조기 종료가 되어 그대로 옳다 — 루프로 남아도 옳다.
- 값 없음 · 8단계 무접촉 · 정본 침묵 자리(D11 §5 앰비언스는 "저레벨 루프"만 말하고 종료를 말하지 않는다) → 구현 세부 결정 IMPL-533.

## 3. 검사

UISCR 1384 → **1393** — 축 55 확장 ⓔⓕ. 라우터 순서(세션 주입 → `add_child` → `bind`)로 RACE-01 을 세우고, 출발 전에 개러지가 켠 룸톤을 점유 유지 싱크(`HoldingOutput`)에 잡아 둔다.

| 축 | 잡는 것 |
|---|---|
| 55ⓔ | 룸톤 점유 1 → **레이스 출발 = 0 + 컬링 통지** · 출발 = 관중 베드 점유 1 · 허브 BGM 은 무접촉(무대 트랙으로 교체 — `stop_bgm` 전속) |
| 55ⓕ | 이탈 목록 = 릴 회전 · 임박 틱 · 관중 베드 · 무대 진입 · **이탈 = 관중 베드 0 + 컬링 통지** · 원본: 룸톤 정지가 `_start_gp` 안 · 관중 베드 발화보다 앞 |
