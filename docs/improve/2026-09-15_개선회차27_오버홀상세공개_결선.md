## 0. 배경 — 매뉴얼 9절 잔여 항목 ⑥

매뉴얼은 "오스카의 `overhaul_detail_reveal` — 오버홀 후보 표기는 바뀌지 않습니다. 실효 역할은 튜닝 심화 2계통을 여는 것"이라고 적었다. 조사해 보니 **가릴 것이 아예 없었다**.

정본 요구:

| 조항 | 내용 |
|---|---|
| D09 §4.6 | "후보 일람 → **전 후보 효과 열람** → 선택 → 비가역 COM-01. **오스카 합류 시 상세 수치 전문, 미합류 시 요약**(D07 §3.4)" |
| D07 §3.4 | "오스카 합류 시 후보의 **상세 수치·특성 전문**이 공개된다. **미합류 시 요약 설명만** 표시 (확정)" |
| D07 §5.1 | 오스카 = 심화 튜닝 벤치 개방 + 패시브 "시즌 오버홀 후보의 상세 정보 공개 — **지식 기반 통제**(D05 §6.3)의 아웃게임 연장" |
| D13 별첨A §5.1 | 오버홀 후보 상세 공개 = "정보 (수치 없음)" |

**선재 상태: 후보 행이 이름만 그렸다.** 효과도 대가도 화면에 없었으니 D09 가 요구한 "전 후보 효과 열람" 자체가 미구현이었고, 그래서 오스카의 패시브가 가릴 수치도 없었다. 이 회차는 **표시를 만들고 그 표시를 오스카로 가른다.**

### 단위 4종

부호는 **값이 지고 문면은 지지 않는다**(튜닝 벤치와 같은 규율 — 문면에 '+' 를 굳히면 감소 축이 증가로 읽힌다).

| 단위 | 형식 | 예 |
|---|---|---|
| `ratio` | `{축} {±n}%` | 전방 게이지 +8% · 트러블 섀시 소모 -20% |
| `flat` | `{축} {±n}` | 듀얼 판정 +8 · 섀시 최대치 -10 |
| `replace` | `{축} → {n}` | 차지 상한 → 12 · 무상 복원선 → 80 |
| `mult` | `{축} → ×{n}` | 최종 랩 게이지 → ×1.35 |

`replace` 를 가산과 가른 이유는 그 축들이 **갈아 끼우는 값**이기 때문이다(회차 19 의 `machine_override` 와 같은 구분) — "차지 상한 +12" 로 적으면 22 로 읽힌다.

## 2. 실렌더 (프로브 삭제 완료)

```
오스카 미합류                              오스카 합류
경량 모노코크 | 전방 게이지 · 대가 있음      전방 게이지 +8% · 섀시 최대치 -10
강화 임팩트 링 | 트러블 섀시 소모 · 대가 있음 트러블 섀시 소모 -20% · 전방 게이지 -5%
롱런 패키지   | 무상 복원선 · 대가 있음      무상 복원선 → 80 · 펄스 차지 -1
펄스 코일 확장 | 차지 상한                   차지 상한 → 12
라스트 랩 서지 | 최종 랩 게이지              최종 랩 게이지 → ×1.35
```

미합류에도 **무엇을 건드리는지와 대가가 있는지**는 보인다 — 그것이 "요약 설명"이고, 감추는 것은 수치다. D05 §6.3 의 지식 기반 통제를 아웃게임으로 옮긴 형태가 이 경계다.

## 3. ⚠ 불변규칙 9 — ⑤ 나디아의 '제시 후보 수 +1' (사용자 결정: 보고만)

| 조항 | 내용 |
|---|---|
| D07 §3 표 | 스폰서 데스크 = **나디아 합류**로 개통 (S8 창구) |
| D07 §5.1 | 나디아 패시브 = 스폰서 계약의 **제시 후보 수 +1** (확정) |
| D13 별첨A §5.1 | 스폰서 후보 수 **3종 → 4종** |

**데스크 자체가 나디아를 요구하므로 "후보 3종" 상태에 도달할 방법이 없다.** 패시브가 구조적으로 관측 불가이고, 어느 3종을 고를지도 정본이 침묵한다.

사용자 판정(객관식 2026-09-15): **그대로 두고 보고만 남긴다.** 도달 불가 분기를 코드에 남기지 않는다. 나디아의 실효 역할은 **스폰서 데스크와 스폰서 부스 시설의 개방**이며, 매뉴얼 9절도 그렇게 적혀 있다. 정본 개정이 필요하면 총괄 판정 경유 — D07·D13 은 수정하지 않았다.
