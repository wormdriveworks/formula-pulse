## 1. 패시브 로그 1줄 — 문면의 수치는 실제로 움직인 양이다

정산 ⑤ 직전의 `_apply_neighbor_passives()` 가 이벤트를 돌려주고 `_settle_sector` 가 그대로 싣는다(단계 신설 0 · 순서 불변 — 불변규칙 3).

| 상황 | 문면 (ko) | 매개 |
|---|---|---|
| 앞차·뒤차 둘 다 움직임 | `raceLog.neighborBoth01` 앞차 저항 -{resist} · 뒤차 압박 +{pressure}. | 둘 |
| 앞차만 | `raceLog.neighborFront01` 앞차 저항 -{resist}. | resist |
| 뒤차만 | `raceLog.neighborRear01` 뒤차 압박 +{pressure}. | pressure |
| 둘 다 0 | (줄 없음) | — |

**"실제로 움직인 양"** — 저항은 `min(저항, 현재 전방)`, 압박은 `min(압박, 만충 − 현재 후방)` 을 적용하고 그 값을 반올림해 싣는다. 게이지가 0 인데 "저항 −8" 을 적으면 회차 30 의 보고("표시는 + 인데 불변")가 방향만 바꿔 되돌아온다. 반올림 뒤 0 인 쪽은 문면에서 빠진다. 절단을 함수 안에서 직접 하지만 종전 ⑤ 말미의 `clampf` 와 결과는 같다(사이에 다른 대입이 없다).

문면 3종은 `strings.csv` 에 ko/en/ja 로 두었다. **V3 자수 규격(줄당 전각 22)** 에 en·ja 첫 안이 걸려(24.0 · 25.0) 다듬었다 — en "Resist -{resist} · Pressure +{pressure}." (20.0) · ja "前方抵抗 -{resist}・後方圧力 +{pressure}。" (21.0). ja 의 '後方圧力' 은 `ui.stat.rearPressure` 의 '後方プレッシャー' 와 다른 어휘다 — 자수 예산 안에서 고른 것이며 **내러티브 레인이 문면을 다듬을 수 있다**(레인 소유 조항 · 본 레인은 회차 6 이래 raceLog 문면을 유입한 전례로 추가했다).

**GLYPH 가 잡은 것** — 첫 안의 빼기 기호 U+2212(−)는 Galmuri14 에 글리프가 없어 GLYPH 스위트가 붉었다(3905 · 커버리지 부재 1자). 로그의 음수는 종전에도 `str()` 의 ASCII 하이픈(-)이라 세 문면 전부 하이픈으로 통일했다 — 자수 예산은 같다.

화면 층은 무접촉이다 — 기본 화자(중계)로 로그 피드에 흐르고, `SOUND_BY_KEY` 에 없으므로 소리는 없다. 슬롯 규격(D09 §3.3 · 최대 2줄 · 줄당 22자)은 V3 가 그대로 받친다.

## 3. 검사 헬퍼 개정 — 격리는 상대를 없애는 것이 아니라 패시브를 눕히는 것이다

TC-C 의 `_isolate_gauge_side(engine, side)` 는 종전에 **상대 자체를 없앴다**(선두/최후미 배치). 회차 30·31 규칙에서는 상대가 없는 자리의 측정이 곧 0 이라 그 헬퍼로 재는 전방·후방 프로브(SA1 풀 스로틀 · SC1 변환 · SA3 하드 브레이킹 등)가 전부 0 만 보게 된다. 개정: **상대를 두고 패시브만 0 으로** —

- front: 플레이어 P2, 앞차 = 선두. 저항 `3.0 + 페이스 × 1.5` → 페이스를 −(3.0/1.5) 로 눕혀 0.
- rear: 플레이어 P15, 뒤차 = 최후미. 압박 `(2.0 + 시드 공격성 × 2.2) × 소속` → 시드 공격성을 −(2.0/2.2) 로 눕혀 0.

두 자리 모두 정산 ⑧ 의 스왑 쌍(플레이어 포함 쌍 제외) 밖이라 이웃이 스왑으로 바뀌지 않는다(초판이 겪은 "시드마다 갈리는 검사"의 원인이 그 스왑이었다). 진짜 "상대 없음"이 필요한 자리(회차 30 축 ⓐ·ⓓ)는 `_place_player(engine, size − 1)` 로 명시한다. 기존 프로브는 호출부 무수정으로 종전 값을 되찾았다(전 축 통과).
