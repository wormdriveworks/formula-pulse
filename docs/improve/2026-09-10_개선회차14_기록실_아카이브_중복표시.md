## 0. 배경 (사용자 보고 · 조사)

**보고:** "개러지의 아카이브(기록실)에 재생됐던 VN 이 쌓이는데, 같은 VN 이 중복해서 표시된다. 첫 번째 세이브로 플레이해 보면 확인 가능. 같은 VN 은 한 번만 표시되게."

| 항목 | 실측 |
|---|---|
| 세이브 1번 발생 대장 (`narrative.vn_seen` · 읽기만) | `vn_act1` · **`vn_season_open_s1` · `_s2` · `_s3` · `_s4`** · `vnbeat_feat_finish` · `vnbeat_feat_point` · `vnbeat_reunion_alta` — 8 인스턴스 |
| 기록실 아카이브 탭 (실창 프로브 · 같은 대장을 심음) | **행 8 — "시즌 개막" 4행** · 1막 그리드의 노이즈 · 첫 완주 · 첫 포인트 · 투어 브리핑 |
| 기제 | `RecordsScreen._fill_archive()` 가 `narrative.archive_entries()`(= `vn_seen` 키 정렬)를 **인스턴스 그대로** 그린다. 시즌 경계 VN 은 `RunSession.season_vn_id(stem, season)` 으로 **시즌마다 다른 인스턴스 id** 를 발행하고, 그 id 가 `season_open_payload`/`season_close_payload` 의 **시즌당 1회 가드 열쇠**다(`vn_seen.has(vn_id)`). 장면은 하나(`vnbeat_season_open` · 라인 3)인데 표제 폴백이 전부 `ui.vnSlot.seasonOpen` 이라 같은 줄이 시즌 수만큼 선다 |
| 종전 의도 | 코드 주석(㊹ 상수 승격 · 내러티브 12차 §2.1) — *"경계 VN 의 `vn_id` 는 시즌마다 다른 인스턴스다(아카이브가 시즌당 한 줄을 남겨야 한다)"* · *"비트 id 로 바꾸면 전 시즌이 한 줄로 접힌다"* → **사용자 결정이 이를 뒤집는다**(같은 VN 은 한 번만) |
| 재열람 실체 | 어느 인스턴스로 재생해도 `_archive_source_payload` 가 줄기 → 슬롯 → **현재 관계 단계로 비트를 되찾으므로** 시즌별 인스턴스가 서로 다른 문면을 되돌려 준 적은 없다 — 접어도 잃는 장면이 없다 |

## 1. 결정

사용자 요청이 명시적이라 객관식 문의 없음 — **같은 VN(장면) = 1행.**

라운딩 판단(문의 없음): ①**발생 대장은 그대로 둔다** — `vn_seen` 인스턴스는 시즌당 1회 가드의 열쇠이고 세이브에 직렬화돼 있다. 대장을 합치면 가드가 풀려 개막이 매 시즌 재발화하지 못하거나(합친 뒤 `has` 가 참) 기존 세이브 마이그레이션이 필요해진다. 접는 것은 **표시 층으로 나가는 목록**만이다 ②접기는 **세션 층**(`RunSession`)에 둔다 — 인스턴스 id 를 만든 규칙(`split_season_vn_id`)이 그곳에 있으므로 포맷이 바뀌면 함께 따라간다. 화면이 `_s` 를 찢어 맞추게 두지 않는다 ③대표 인스턴스 = **가장 이른 시즌**(숫자 순 — 문자열 정렬은 s10 을 s2 앞에 둔다). 재생 페이로드는 종전과 동일 경로(인스턴스 id 유지).

## 2. 구현

```
narrative.vn_seen (인스턴스 · 불변 · 가드 열쇠)
   └─ RunSession.archive_entries()  ← 장면 열쇠(archive_scene_key = 줄기 or id)로 접고 대표 = 최소 시즌
        └─ RecordsScreen._fill_archive()  ← 종전 narrative.archive_entries() 직접 읽기 → 세션 창구
```

| 파일 | 변경 |
|---|---|
| `godot/ui/flow/run_session.gd` | `archive_entries()` 신설(장면 단위 · 대표 = 최소 시즌 · 정렬) · `static archive_scene_key(vn_id)`(접미 인스턴스 → 줄기 · 그 외 그대로 — `split_season_vn_id` 되짚기라 `vnbeat_clue_silence` 류는 걸리지 않는다) |
| `godot/ui/hub/records_screen.gd` | `_fill_archive()` 가 `session.archive_entries()` 를 읽는다 · 주석 |
| `godot/tests/test_ui_screens.gd` | 축 `_archive_dedup` ⓐ규칙(열쇠 3 · 표시 항목 = 세이브 1번 모양 + 엔딩 2시즌 → 6 · 대표 s1 · 숫자 순 s2<s10) ⓑ대장 불변(인스턴스 10 · 접힌 뒤 개막 재발행 0) ⓒ실화면(행 6 · "시즌 개막" 1행 · 표제 중복 0 · 재생 버튼 전부 활성) · 대조군(인스턴스 1개씩 = 대장 그대로) |

`narrative_service.gd` 무변경 — `NarrativeService.archive_entries()` 는 대장 그대로(코어는 세션 층의 인스턴스 규칙을 모른다). 문면·표·검증기 스키마 변경 없음.
