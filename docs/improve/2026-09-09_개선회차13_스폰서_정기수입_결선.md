## 1. 결정 (객관식 — 사용자 · 2026-09-09)

| Q | 항목 | 안 | 권고 | **결정** |
|---|---|---|---|---|
| Q1 | 탈락 투어의 정기 수입 | 지급(보너스는 조건 판정) / 미지급 | 지급 | **지급** |
| Q2 | 체결·교체 시점 | 투어 첫 출발 전(race_slot 1)만 · 그 외 열람 전용 / 상시 체결 | 시점 제한 | **투어 첫 출발 전만** |
| Q3 | SP3 "지정 라이벌 선착" | 네임드 라이벌 선착 1회 이상(투어당 1회 정액) / 라이벌 지정 열 신설 | 1회 이상 | **네임드 1회 이상 [가안]** |

라운딩 판단(문의 없음): SP2 "달성마다" = **횟수 배수** · 후보 3/4종 제시(D07 §5.4)는 두지 않음 — 데스크는 나디아 합류로만 열리고 그때 후보는 4종 전부(나디아 패시브 = 4종) · 임계(3·5)는 코드에 적지 않고 표 열로.

## 2. 설계·구현

```
GP 결산(close_gp) → outgame.record_gp_result → sponsor_tour_facts { finish_ranks[], beat_named_rival }   ← 완주 GP 만
투어 마감(session.close_tour) → last_tour_report["sponsor_conditions"] = sponsor_tour_conditions(report)   ← begin_tour 가 소재를 비우기 전 스냅숏
SET-01(settle_tour) → sponsor_settlement_breakdown(conditions) → gain_credits → 행 "스폰서 수입 {payout} Cr · 정기 + 보너스"
HUB-01(race_slot 1) → HUB-06: [체결]/[해지] 활성 · 그 외 GP 사이 방문 = 열람 전용(전부 소등 · 조건 진행 표기)
```
