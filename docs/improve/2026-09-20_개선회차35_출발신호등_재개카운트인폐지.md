## 1. 실물 조사

### 1.1 출발 효과음 — 로그 깔때기가 울리던 한 덩이 에셋

- 발화 경로(종전): `RaceScreen.SOUND_BY_KEY["raceLog.gpStart01"] = "gp_start"` → 엔진의 GP 개시 로그가 `_push_events` 를 지나며 `sound_map` 행 `sound_gp_start`(SE-U18 · P2)를 울렸다. 화면에 출발 **시각 연출은 없었다** — 씬 패널의 SC-08 스타트 컷(첫 섹터 컷 매핑 우선순위)만 선다.
- 에셋 실물 `se_u18.wav` = 44.1 kHz 모노 16bit · **1.165초**. 구성은 에셋 대장 §9-㉑(총괄 추인 IMPL-261 · 확정 구성): **동일 저음 3타(260 ms 간격 = 적색등 점등) + 상향 개시음 1타** — 개시음은 파일 안 **0.78초 지점**에 있다. D11 §2.9 규칙 U-c "당대 레이싱 문법의 시그널 시퀀스(적→소등 계열의 음정렬)".
- 함의: 이 소리는 **"3타 뒤 0.26초에 개시음"이 고정**된 한 덩이라, 점등에 맞춰 울리면 무작위 대기 동안 개시음이 먼저 난다. 무작위 대기(요청 1)와 한 덩이 에셋은 어느 한쪽을 양보해야 한다 — §2.3.

## 2. 결선 A — 출발 신호등

### 2.1 구성

| 항목 | 값 | 창구 |
|---|---|---|
| 등 수 | **5** (F1 문법) | 코드 상수 `START_LIGHT_COUNT` **[가안]** — 연출 구성이라 D13 수치 대장 밖(에셋 대장 §9-㉑ '타수 3+1' 과 같은 성격 · 총괄 추인 IMPL-261 "연출 구성 재량") |
| 점등 간격 | **0.3초** (등 k = (k−1)×0.3 → 전등 1.2초) | `param_start_light_interval_sec` **[가안]** |
| 전등 뒤 대기 | **무작위 [0.8, 1.5]초** — `reserve` 스트림 · 하한은 개시음 선행(0.78) 이상으로 코드가 받친다 | `param_start_light_hold_min_sec` · `param_start_light_hold_max_sec`(= 사용자 상한 1.5) **[가안·상한은 사용자 값]** |
| 개시음 선행 | **0.78초** (= 에셋 안 개시음 위치 3×0.26) | `param_start_signal_go_offset_sec` **[가안 — 에셋 구성 종속: 에셋 트랙이 se_u18 을 바꾸면 이 값이 따라간다]** |
| 출발 대기 총량 | **2.0 ~ 2.7초**/GP | — |

- 실물: 신규 `ui/race/start_lights.gd`(`class_name StartLights` · `Control`) — 시간을 모르는 그리기 노드. 격자 사각 5등(10px · 간격 4 · 함체 패딩 4 · 상단 여백 6)을 씬 패널 슬롯(`%E15ScenePanel`) 의 **둘째 자식**으로 코드 생성해 얹는다(같은 rect · 씬 패널의 저강조 곱연산 밖 · 비인터랙티브). 색은 전부 팔레트 상수(점등 `gauge_danger()` = 타이머 임박과 같은 조달 · 색각 대체 자동 · 소등 `GAUGE_TRACK` · 함체 `BG_DEEP`+`FRAME_LINE`) — 코드 색 리터럴 0(PAL) · 텍스트 0(V4·FONT).
- 진행은 `RaceScreen._process` 가 굴린다(`_process_start_lights`) — **정지 중(`_paused`) 함께 멎고**, 큰 delta 한 번에도 점등·개시음·소등 문턱을 한 번씩만 넘는다(검사가 `_process(60)` 으로 끝까지 돌린다). 첫 등은 `_start_gp` 에서 첫 T1 **앞에** 켠다(`_begin_start_lights` → `_next_turn` — 행동 잠금 갱신이 신호등 상태를 읽어야 한다).
- **소등이 출발이다.** 붉은 동안 T1 행동(스핀 · 소모품 4/5)이 잠긴다 — 버튼 술어(`can_spin`·`can_use_item`)와 핸들러(`_on_primary_action`·`_on_consumable`)가 같은 조건을 본다(14차 ⑦ "버튼과 핸들러가 같은 술어"). 홀드·스킬·리스핀·차지는 개입 창(T3/T4) 전속이라 무관.
- **TUT-01 은 소등 뒤 선다** — 종전에는 `_boot` 끝에서 `_start_gp` 직후 섰다. 붉은 동안 "스핀하라"는 콜아웃이 뜨면 지시 행동이 잠긴 채 첫 단계가 서고 지목 하이라이트가 신호등과 겹친다. 개시 창구 = `_finish_start_lights` 1곳.
- 정지 → 타이틀 이탈 등 도중 이탈: SE-U18 은 단발(1.165초)이라 이탈 정지 목록에 넣지 않았다(루프 아님).

### 2.2 무작위의 출처 — `reserve` 스트림

완급 비트(`RunSession.pacing_beat_due`)와 같은 자리다: 6스트림 고정(불변규칙 4)이라 표현 층 전용 스트림을 새로 만들 수 없고, 직렬화 밖 지역 난수는 재로드마다 다른 결과가 된다. `reserve` 는 세이브에 직렬화되므로 재로드가 리롤이 되지 않는다(D12 §6). 신호등은 상태 머신을 건드리지 않아(D05 §3 무개정 · 표현 층 전속) 스트림 소비가 게임 규칙에 닿는 경로는 없다. 창구 = `RunSession.start_light_hold_sec()`.

### 2.3 스타트 시그널 배치 — **개시음을 소등에 맞춘다** (권장안 · §7 Q1)

| 안 | 배치 | 귀결 |
|---|---|---|
| **ⓐ 채택 (권장)** — 개시음 = 소등 | SE-U18 을 **소등 0.78초 앞**에 울린다. 점등 5등은 무음(F1 도 점등은 무음), 전등 뒤 무작위 대기의 **마지막 0.78초를 3타가 채우고 개시음이 소등 순간에 떨어진다** | 에셋을 자르지 않고 그대로 쓴다 · 출발 순간의 A/V 동기가 정확하다 · 대기 하한을 0.78 이상으로 받쳐 3타가 점등 중에 시작하는 일이 없다. 3타가 시작되면 0.78초 뒤 출발이 예고되는 셈이라 F1 식 "언제 꺼질지 모름"은 3타 **시작 시점**의 무작위로 남는다 |
| ⓑ 3타 = 점등 · 개시음 삭제 | 마지막 3등을 3타에 맞춰 켜고, 개시음(0.78초)이 나기 전에 `stop_event` 로 자른다 · 전등 뒤 무작위 대기 · **소등은 무음**(F1 원형) | 에셋 의도(3타 = 적색등)와 F1 무음 소등에 충실 · 개시음(에셋의 절반 의도)이 영영 안 울린다 · 자르는 시점이 프레임 정밀도에 걸려 프레임 히치 때 개시음 머리가 샐 수 있다 |
| ⓒ 에셋 분할 발주 | 에셋 트랙에 SE-U18 변형 2식(단타 · 개시음) 발주 → 점등마다 단타 · 소등에 개시음 | A/V 완전 동기 · 타 레인 작업(에셋 대장 §5.1 · `sfx_params.json`)이 선행돼야 하며 이 세션에서는 끝나지 않는다(`godot/assets/` 무접촉) |
| ⓓ 소리는 종전대로 | 로그 깔때기에 두고 신호등만 독립 | 개시음이 신호등이 붉은 동안 울린다 — 채택 불가 |

- 채택 ⓐ 의 구현: `SOUND_BY_KEY` 에서 `gpStart01` 행 제거 → `_process_start_lights` 가 `sfx("gp_start")` 1곳에서 울린다. AUDIO-W 는 `SOUND_BY_KEY` 를 상수 맵으로 직접 읽으므로 제거가 표 대조를 어기지 않고, `sfx("gp_start")` 리터럴이 표 전수 대비 호출 지점을 채운다.

### 3.2 걷어낸 것

### 3.3 설계 정본 충돌 기록 (불변규칙 9 → 사용자 결정)

## 6. 실기 확인 항목 (사용자)

- 개러지 → [출발] → (브리핑 VN) → 레이스 진입: 씬 패널 상단 함체에 5등이 0.3초 간격으로 붉게 켜지는가 · 전등 뒤 잠깐 있다 **3타 → 개시음과 함께 일제히 꺼지는가** · 꺼지기 전에는 [스핀]이 잠겨 있는가(회색) · 꺼진 뒤 튜토리얼(첫 GP)이 서는가.
- 붉은 동안 Esc → 정지 → 재개: 신호등이 멈춘 자리에서 이어가는가.
- 레이스 중 Esc → 옵션 → 닫기 → [재개]: **카운트 없이 즉시** 돌아오는가 · 개입 창 중이었다면 가림막이 재개와 함께 내려가고 타이머가 바로 흐르는가.
- 색각 대체(O9) 켠 상태에서 점등색이 대체색으로 뜨는가(타이머 임박색과 같은 조달).

## 7. 객관식 상신 (사용자 결정)

- **Q1 스타트 시그널 배치** — ⓐ 개시음 = 소등(채택·권장) / ⓑ 3타 = 점등 · 개시음 삭제 · 소등 무음 / ⓒ 에셋 분할 발주(에셋 트랙) / ⓓ 종전대로(로그 깔때기 · 비동기).
- **Q2 템포** — 5등 × 0.3초(채택 · 전등 1.2초 + 대기 0.8~1.5) / 5등 × 0.5초(F1 감각에 가깝게 · 총 2.8~3.5초) / 3등 × 0.3초(에셋 3타 수와 같게 · 총 1.4~2.1초).
- **Q3 카운트인 처리** — 폐지 확정(채택 · 코드·값·문면·노드 걷음) / 값 스위치로 남김(`param_pause_countin_sec = 0` = 즉시 · 3 이면 종전) / 복원(요청 2 철회).
