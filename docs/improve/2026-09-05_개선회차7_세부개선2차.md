## 1. 라이벌 대사 성격 개별화

### 1.1 기제
- `RaceEngine` 은 종전대로 공용 키(`raceLog.duelStartOvertake01` 등 5사건) + `speaker_id` 를 발행한다. 소리(SOUND_BY_KEY)·연출(TRIGGER_BY_KEY)·듀얼 프레임(DUEL_RESULT_KEYS)은 원 키로 대조하므로 기계 거동이 갈리지 않는다.
- `race_screen.RIVAL_LINE_KEYS` = 사건 5 × 네임드 8 의 **열거형 리터럴 대장** (LOG_VARIANT_KEYS 와 같은 성격 — V6 고아·V2 실재 검사가 40키를 전부 보증). `_log_display_key(key, speaker_id)` 가 화자 id 로 개별 키를 고르고, 표에 없는 화자(필러·미등재·무화자)는 공용 문면.
- `_push_events` 는 화자를 문면보다 먼저 정한다(개별 문면이 화자 id 로 갈리므로).
- 키 문법 = `raceLog.<사건>.<라이벌>` 3단 (V8 정규식 합치 · 예 `raceLog.overtakeSuccess.maro`).

## 2. 필러 듀얼 상대 식별

- 현상: 필러 상대의 듀얼 로그가 공용 헬멧 도상만 달아 로그 이력에서 누구였는지 남지 않았다(네임드는 카 넘버 배지 16px).

- D09 §3.3 원문("공용 헬멧 아이콘 1종 + 카 넘버")과의 관계: 16px 표지 칸에 둘을 함께 둘 수 없어 사용자 선택으로 넘버만 남겼다(헬멧+넘버 병기는 표지 칸 공통 확장 = 본문 폭 −12px 이라 기각).
- 실기: `[25] 쉽게 내줄 자리는 아냐.` · `[25] …다음 코너에서 보자.` · `[28] 쉽게 내줄 자리는 아냐.` (3 GP · 필러 2인 상대) — 이력에서 상대가 갈린다.

- 부수 관찰: D패드 ↑ 로 홀드 체크박스(`Hold`)에 포커스가 가고 ✕ 로 토글되는 경로가 있다 — 공통 층 포커스 순회의 정상 동작(조합 없는 마우스 동치). X 조합 중에도 그 포커스가 움직이지 않는 것을 확인.
- 프로브 기록의 한계: 화면이 `_input` 에서 소비한 조합 입력은 `_call_input` 순회가 끊겨 프로브(부모 노드)의 `_input` 에 닿지 않는다 — 눌림 줄이 빠지고 뗌 줄만 남는다. 그 뗌 줄의 상태가 판정 근거다.
- 라이벌 개별 문면은 실기 3 GP 동안 네임드 듀얼이 성립하지 않아(후미 출발 · 필러 상대만) 미관측 — UISCR 실렌더 검사(문면 + 배지)가 대신 든다.

- **CLI 창 trap 복원의 상대 경로 사고.** 검증기·테스트 창을 `cd godot; …; cd ..` 로 짜고 trap 에 `cp "$BK" project.godot` 를 상대 경로로 두어 — 셸 종료 시점의 CWD 가 저장소 루트라 **루트에 `project.godot` 사본이 생기고 `godot/project.godot` 은 오토로드 제거 상태로 남았다.** 두 번의 "에디터가 오토로드를 지운다" 오판의 실체. 교정 = trap 의 경로 전부 절대 경로. 부수 = 오판 중 부른 `ProjectSettings.save()` 1회가 project.godot 을 에디터 서식으로 재직렬화(주석 소실·절 재배열) → `git show HEAD:godot/project.godot` + 오토로드 블록으로 복원.
- **V2 는 접두 비교 리터럴도 키 발행으로 읽는다** — `begins_with("raceLog.timeout")` 의 `"raceLog.timeout"` 이 미실재 키로 차단. 변형 대장 리터럴과 대조하는 형태로 바꿈.
- **UISCR ㉑ 은 문자열 검사다** — 프로브 주석의 `use_live_root()` 만으로 걸린다. 임시 프로브도 그 문자열을 적지 않는다.
- **테스트 하네스의 브로드캐스트 교차 간섭** — 뷰포트 경유로 바꾸자 함께 서 있던 업적 화면이 LB(`tab_prev`)를 먹고 포커스를 끌어갔다(재현 스크립트로 확증 · 재현 뒤 삭제). 대상 화면 외 처리 정지로 해소.
- 듀얼센스 USB 연결 플랩: 두 실기 모두 시작 직후(창 포커스 시점) 1~2회. 실기 조작 중 재현 없음. 방어 코드는 UISCR 로 확증.
