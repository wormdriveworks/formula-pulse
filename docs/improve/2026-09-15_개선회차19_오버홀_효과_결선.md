# 개선 회차 19 — 오버홀 11종 효과 결선 (2026-09-15)

> 세션 문서 (개선 모드). 설계 정본 D01~D16 은 참고 자료이며 사용자 요청이 우선한다. 단일 세션 · 주력 GUI 머신(Windows · GDAI).
> **상태: 구현 완료 · 게이트 녹색 · 사용자 확인 대기.** §5 검사·게이트 · §6 상태.

## 0. 배경 — 매뉴얼 9절 2항

12종 중 **`free_restore_line`(OV-S4) 하나만** 코드에서 소비되고 나머지 11종은 장착만 됐다. `parts_stat_bonus()` 는 정확히 구현돼 있었으나 **호출부가 0** 이었다. 시즌 결산의 유일한 성장 보상이 껍데기였다.

## 1. 정본 근거와 충돌

| 항목 | 정본 | 내용 |
|---|---|---|
| 12종 효과 대장 | D13 별첨A §7.2 | 문면이 전부 "A → B" 꼴이라 5종은 **대체**, 나머지는 가산·승산 |
| 사이드그레이드 | D13 별첨A §7.2 | "양수 효과 + 음수 대가 쌍" — **동시 적용** |
| 파츠 캡 | D13 별첨A §7.3 | 계통당 +10%p · 합산 +20%p — **파츠 전속**, 튜닝은 캡 밖 |
| 듀얼 슬롯 항 | D13 별첨A §2.4 · 본문 V-3 | 판정식에 `오버홀(슬롯×6)` · "슬롯당 듀얼 판정 +6" |

**정본 충돌 2건 + 침묵 7건**이 있었고, 사용자 판정으로 처리했다.

### 1.1 사용자 결정 (객관식 · 2026-09-15)

| 쟁점 | **결정** | 귀결 |
|---|---|---|
| OV-T4 × 배틀 존 = ×2.025 > 명문 상한 ×1.8 (§1.3 vs §7.2) | **상한 없이 곱셈** | 상한 문면은 속성 조합에 걸린 것으로 읽는다. OV-T4 가 강력한 특성으로 선다 |
| 듀얼 판정 `슬롯×6` vs 인스턴스 OV-S3 `+8` | **둘 다 센다** | 2슬롯 = +12, 거기에 OV-S3 를 얹으면 +20. 로렌츠 격파 중앙값 S2 발주가 유지된다 |
| 동일 오버홀 중복 장착 | **불가** | 현 코드 거동(추첨이 장착분 제외 + 재설치 거부)이 이미 그러하고 스킬의 중복 금지 조항과 짝이 맞는다 |
| OV-T2 "투어당 3회 한정"(표에서 3 유실) | **투어당 추가 홀드 3회분 예산** | 한 턴에 몰아 쓰든 나눠 쓰든 투어당 3회다 |
| 기본 홀드 2회 턴의 총량 가드 2 | **함께 3으로** | 정본이 총량 2 를 잡을 때의 전제("기본 홀드 1회")를 보존해 스킬 재회전 몫이 남는다 |

### 1.2 라운딩 판단

- **`front_gauge_ratio` 의 곱 대상** = 튜닝 계수와 같은 **심볼 유래 전방 증분**(슬립스트림·라인 전방·찬스). 모멘텀·레조넌스·앞차 저항은 제외한다.
- **`rear_pressure_ratio`** 는 소속 계수(불카 ×1.3) **뒤에** 곱한다 — 머신 쪽 사정이라 상대 소속과 독립이다.
- **`pulse_charge_yield` −1 은 생산값에서 먼저 깎고 하한 1**, 그 위에 SA2 배수가 붙는다.
- **파츠 캡은 §7.2 가 "(G-M2 캡 대상)"이라 부기한 2종 전속**(슬립스트림·브레이킹 계수)이다. OV-P3(차지 상한)·OV-P4(섀시 +15)는 %p 가 아니라 캡의 단위 밖이다 — 절단하면 +15 CH 가 +0.1 로 뭉개진다.
- **`gp_start_charge` 는 상한 절단을 지난다** — 차지 획득 창구를 그대로 탄다.
- **듀얼 슬롯 항의 '슬롯' = 장착 수**로 읽는다(§2.4 주석 "오버홀 2슬롯(+12) 확보"의 실물이 장착분이다).
