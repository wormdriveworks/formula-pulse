## 1. 효과음 복구 — 원인은 옵션이 아니었다

증상: "옵션을 만진 뒤 레이스를 재개하면 효과음이 안 나는 경우가 있다." 옵션 경로(`_shift` → `apply_volume_options` → 버스 dB · 뮤트 합성)를 따라가 보니 그 자체는 멀쩡했다. 원인은 **옵션이 지나가는 자리 옆의 두 결함**이었다.

### 1-A. 일시정지 → 타이틀로 = SFX 버스 뮤트 잔존

| | |
|---|---|
| 기제 | `RaceScreen._open_pause()` 가 `session.audio.set_paused(true)` 로 **SFX 버스를 뮤트**한다(D11 §4.3 "BGM 유지·SFX 뮤트"). 뮤트를 푸는 곳은 `resumed` 시그널 **하나**였다. |
| 경로 | 정지 메뉴 → (옵션을 열었다 닫고) → **타이틀로** → `go("SYS-01")`. 이 경로는 `resumed` 를 거치지 않으므로 디스패처가 정지 상태로 남는다. |
| 결과 | 타이틀·개러지·다음 레이스까지 **효과음 전부 무음**. BGM 은 버스가 달라 멀쩡 → "재개했는데 효과음만 안 난다"로 보인다. 다음 정지·재개까지 복구 수단 없음. |
| 수정 | `race_screen.gd _exit_tree()` — **정지의 뮤트는 이 화면의 상태**이므로 화면이 트리를 떠날 때 `set_paused(false)`. 재개 경로는 종전 그대로. |
| 검사 | UISCR 신설 `_race_pause_exit_unmutes` — 정지 → 타이틀로 요청(아직 정지) → 트리 이탈 = 해제 · 재개 경로도 해제. |

### 1-B. 징글 보이스 영구 점유 (누적형)

| | |
|---|---|
| 기제 | 디스패처는 채널이 `sfx` 든 `jingle` 이든 발화를 `_voices` 에 넣고 표현 층의 `release_voice()` 로 비운다. SFX 풀은 `finished` 가 결속돼 있었지만 **징글 플레이어는 `finished` 미결속** — 징글 1발 = 보이스 1개 영구 점유. |
| 경로 | GP 결산 징글(JG-01/02) · 리타이어 · 시즌 챔피언 · 타이틀 수여 — 결산마다 하나씩 쌓인다. |
| 결과 | 상한(`param_audio_virtual_channels` = 12)에 닿으면 새 발화는 살아 있는 P3 를 걷어내야만 서고(끊김), 걷을 것이 없으면 버려진다(무음). **조작음이 전부 P3** 라 그 자리가 먼저 조용해진다. 옵션과 무관하게 세션이 길어질수록 확률이 오르는 형태 — "경우가 있다"의 다른 절반. |
| 수정 | `game_audio_output.gd` — `_jingle_player.finished` 결속 · `_jingle_id` 추적 · 재생 중 징글 위에 새 징글이 오면 종전 점유를 먼저 해제(`play()` 재시작은 `finished` 를 내지 않는다) · 되읽기 `active_jingle()`. |
| 검사 | AUDIO-P 신설 ③-b `_jingle_release` — 결속 실재 → 점유 1 → 통지 → 0 · 겹침 = 점유 1 · **상한 초과 연타(14발) 뒤 점유 0 이고 조작음이 산다**(종전 결함의 재현 형태). 107 → **117**. |

관측 하나를 남긴다: 앰비언스 5식(`amb_01~05.wav`)이 HEAD 에서는 `loop_mode=2`(핑퐁 루프)로 임포트돼 있어 **끝나지 않는 P3 보이스**가 레이스마다 하나씩 남는다(에셋 레인이 작업 트리에서 `loop_mode=0` 으로 바꾸는 중 — 미커밋). 이 회차는 에셋을 건드리지 않았다.

## 2. 본문 원도 11px 승격 · O7/O8 제거

회차 25 가 "원도에 맞춘 2단"으로 세운 O7 의 확대 단이 **기본값**이 됐고, 고를 것이 없어진 O7 과 함께 O8(UI 스케일)도 항목·소비부·값·문면을 걷었다.

```
종전: 전역 Galmuri9 @ 9px · O7(100/122%) 가 세션 경유로 원도·크기를 갈아 끼움 · 씬 162노드 font_size = 9 를 런타임에 따라잡기
회차 28: 전역 Galmuri11 @ 11px · param_font_size_body = 11 · 씬 162노드 font_size = 11 · 갈아 끼우는 경로 없음
```

| 층 | 변경 |
|---|---|
| 전역 | `project.godot` `gui/theme/custom_font` → Galmuri11.ttf · `default_font_size` → 11 |
| 값 (D13 창구) | `core_params.csv` `param_font_size_body` 9 → **11** · `param_opt_ui_scale_1/2` · `param_opt_text_size_body_1` 삭제 |
| 씬 (18개) | `theme_override_font_sizes/font_size = 9` **162노드 → 11** (혼합 노드 0 — 크기 9 노드는 전부 폰트 미명시 = 본문 계열) |
| 코드 삭제 | `run_session.gd` `apply_display_options()`·`ui_scale_factor()`·`text_body_font_size()`·`text_body_font()`·`TEXT_SIZE_FONT_1` / `ui_theme.gd` `apply_text_size()` / `flow_screen.gd` `_rescale_body_labels()` + 세션 경유 크기 조달 → `param_font_size_body` 직접 / `options_store.gd` O7·O8 정의·탭 항목 / `options_screen.gd` `apply_display_options()` 호출 2곳 |
| 문면 | `ui.options.o7`·`o8`·`stepScale100/110/122/125` 6행 삭제 (V6 고아 0) |
| 기록실 | `records_screen.gd` 라이벌 이름 열 최소폭 110 → **135** — 11px 에서 `ui.rival.lorentz`(ja) 121px 가 110 을 넘어 그 행만 다음 열이 밀렸다(최소폭이라 절단은 아님) |

## 3. 레이스 HUD 재배치 — 11px 의 귀결

승격 뒤 실렌더에서 **RACE-01 만** 깨졌다. 다른 화면(옵션·개러지·기록실·VN·이벤트)은 G4W·UISCR 판정과 실렌더 모두 정상.

| 실측 (5슬롯 만재 덱) | 값 |
|---|---|
| 액션 열 필요 폭 (리스핀·S1~S5·차지 개입·확정) | **461px** ko · 468 en · 456 ja |
| 액션 열 예산 (좌열 6/10 − 릴 존 여백) | **371.6px** → 약 90px 초과 · 릴 존이 로그 존을 86px 덮음 |
| 릴 존 세로 여유(스페이서) | 16px(9px 시절) → **9px** · 개입 창의 타이머 수치 행 13px 이 8px 넘침 |

**사용자 결정 (객관식 2026-09-16) = 스킬 5칸을 하단 바로 이동.** 대안으로 낸 "레이스 HUD 만 9px 유지"·"문면 축약(비용 배지 → 툴팁)"은 채택하지 않았다.

| 변경 | 내용 |
|---|---|
| `race_screen.tscn` | `E08Skills`(Skill1~5) 노드를 `E08Actions` 에서 **`ZoneD/ResourceRow`(소모품 2칸 옆)** 로 이동. 액션 열 = 리스핀 · 차지 개입 · 확정(신축). 고유 이름이라 코드 경로(F1~F5 · RB 조합 · 클릭 · `_skill_buttons`) 무변경 |
| `race_screen.tscn` | `E04TimerValue`(타이머 수치)를 별도 행에서 **`NoticeRow`(거부 사유 행) 우측으로 병치** — 세로 행 하나를 되찾는다. 씬 패널(100px)은 건드리지 않았다: 배경 원도가 408×100 이라 줄이면 잘린다(질문에서 "씬 패널 100→92" 로 적었던 방안은 이 실독으로 철회 — 같은 목적을 병치로 달성) |
| 실측 (후) | 액션 열 178 ≤ 371 · 스킬 열 280 vs 하단 바 빈 폭: **여유 ko 52 · en 11 · ja 8px** · 하단 바 높이 26 불변 · 릴 존 스페이서 9px 유지(타이머 수치 행 0px) |

### 검사

| 축 | 내용 |
|---|---|
| UISCR ㉑ⓔ | 스킬 5칸 = 하단 바(`ResourceRow` 자식 · 액션 열 밖) · 액션 열 ≤ 예산 · **스킬 열 ≤ 하단 바 예산**(신설 `_skill_row_metrics()` — 캔버스 − 패널 여백 − 다른 고정 자식 최소폭 − 간격) · 스킬명 라벨은 하단 바 예산도 넘는다(S{n} 근거 유지) |
| UISCR ㉚ 3언어 | 액션 열 + **스킬 열** 각각 예산 안 · 덱 구성 전수 관측은 스킬 열로 |
| UISCR 라벨 트립와이어 | `ACTION_ROW_ZERO_ASSERTS` 두 문구 보존 |
