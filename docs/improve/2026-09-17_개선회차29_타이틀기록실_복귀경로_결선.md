## 0. 배경 — 사용자 보고 2건 + 선행 판단 위임 (2026-09-17)

| # | 보고 | 처리 |
|---|---|---|
| ① | 타이틀 → 기록실 → 세이브 선택 뒤 우측 상단 돌아가기 버튼의 문면이 **'개러지로'** (동작은 타이틀로 잘 감) | §3 — 문면이 돌아갈 자리를 따른다 |
| ② | 타이틀 → 기록실 → 아카이브 VN 감상 뒤 '개러지로' 를 누르면 **타이틀이 아니라 개러지**로 감 | §2·§3 — 나가는 페이로드가 `return` 을 되싣는다 |
| 선행 | 위 두 작업 전에 **타이틀 메뉴의 기록실 항목을 유지할지 먼저 판단**. 이 요건 때문에 코드가 복잡해지거나 부작용 위험이 오르면 제거해도 무방(판단 위임). 유지면 두 작업 + **또 다른 사이드이펙트 확인** | §1 판단 = **유지** · §4 점검표 |

## 1. 판단 — 유지한다

요건이 코드에 요구하는 것을 전부 세어 봤다.

| 자리 | 요건이 요구하는 것 | 크기 |
|---|---|---|
| `title_screen.gd` | 커리어가 있으면 점등 → `SYS-02 {mode: archive}` | 분기 1 |
| `save_slot_screen.gd` | 열람 모드 = 전용 문면 · 빈 슬롯 소등 · 삭제 없음 · 선택 = `restore` → `HUB-05 {tab, return: SYS-01}` | 분기 4 |
| `hub_screen.gd` | `_return_route` = 페이로드 `return` (기본 개러지) · 복귀 저장 = `return == HUB-01` · **(이번) 뒤로 문면 = 자리별** | 변수 1 · 판정 2 |
| `records_screen.gd` | **(이번) VN 으로 나가는 페이로드가 `return` 을 되싣는다** | 창구 1 |

두 보고의 뿌리는 **하나**다 — 돌아갈 자리는 페이로드로만 전해지는데, 기록실이 VN 으로 나가는 두 경로(개별 재생·연속 재생)가 복귀 페이로드에 **탭 힌트만** 되실었다. 재생을 마치고 돌아온 HUB-05 는 기본값(개러지)으로 섰다. ①은 문면이 `ui.hub.back` 하나로 고정돼 있던 별건이지만, 고치는 자리는 같은 열쇠(`_return_route`)다.

**유지 근거.** ⓐ 수정이 창구 1개 + 문면 1행이고 새 상태·새 플래그가 생기지 않는다(세션에 "열람 중" 표지를 두는 대안은 `begin_career`·`restore`·이어하기마다 지워야 하는 잠재 상태라 더 위험 — 채택하지 않았다) ⓑ 회차 26 의 격리(삭제 없음·빈 슬롯 소등·복귀 저장 = 개러지 한정)는 전부 유효하고 UISCR 52 가 잡고 있다 ⓒ 이번 결함 형태("HUB-05 를 떠나 돌아오는 경로가 `return` 을 빠뜨린다")는 **경로가 셋뿐**이고(뒤로·개별 재생·연속 재생) 셋 다 이번 축이 실 왕복으로 잰다 ⓓ 제거는 정본 §A-1 E02 가 "허용"으로 확정한 항목을 소거하는 쪽이고, 4파일·축 52·문면 1행을 철거하는 디프가 수정보다 크다. 부작용 점검(§4)에서 **이 경로가 새로 여는 위험은 ②의 숨은 절반(복귀 저장) 하나**였고 그것이 이번 수정 대상이다.

## 2. 원인 — 숨은 절반이 더 나쁘다

```
타이틀 → SYS-02(archive) → HUB-05 {tab: archive, return: SYS-01}     ← 회차 26 결선 · 뒤로 = 타이틀 · 저장 없음
                              └ 재생 → NAR-01 {…, next: HUB-05, next_payload: {tab: archive}}   ← return 이 빠짐
                                        └ 종료 → HUB-05 {tab: archive}  → _return_route = 기본값 HUB-01
                                                  └ 뒤로 → 개러지 (보고 ②) … 그리고 _saves_on_return() == true → save_progress()
```

보고 ②의 눈에 보이는 절반은 "개러지로 감"이지만, 그 자리는 회차 17 의 **복귀 저장 자리**다. 읽기만 하려고 연 커리어가 디스크에 쓰였다 — 회차 26 §2 가 "읽기만 했는데 저장된 자리가 생긴다"고 적어 막았다고 한 바로 그 창이, 재생 경로로 열려 있었다. 같은 커리어를 같은 상태로 쓰니 내용은 안 바뀌지만 저장 시각이 갱신되고, 회차 26 의 계약("열람은 디스크를 쓰지 않는다")이 거짓이 된다.

## 3. 구현

| 파일 | 변경 |
|---|---|
| `godot/ui/hub/records_screen.gd` | `_archive_return_payload()` = `{tab: archive, return: _return_route}` 신설 — 개별 재생(`archive_replay_payload`)·연속 재생(`archive_chain_payload`) **두 경로가 이 한 창구**를 쓴다. 탭 힌트만 실은 리터럴 사전 0 |
| `godot/ui/hub/hub_screen.gd` | `BACK_LABEL_KEYS` {HUB-01: `ui.hub.back`, SYS-01: `ui.hub.backTitle`} + `_back_label_key()` — 표에 없는 자리는 개러지 문면으로 접는다. 복귀 저장 판정과 같은 열쇠 |
| `godot/data/strings/strings.csv` | `ui.hub.backTitle` = 타이틀로 / To Title / タイトルへ (1행) |
| `godot/tests/test_ui_screens.gd` | 축 52 에 ⓔ·ⓕ 추가 (§5) |

'닫기'가 아니라 **'타이틀로'** 를 골랐다 — 같은 자리의 개러지 문면이 "어디로"를 적는 형식이라 짝을 맞췼고, 정지 메뉴의 `ui.pause.toTitle` 과 같은 문면이다(키는 기능별 체계라 재사용하지 않고 `ui.hub.` 아래 새로 두었다).

## 4. 사이드이펙트 점검표 — 타이틀에서 연 기록실이 새로 여는 위험

| 항목 | 확인 | 결과 |
|---|---|---|
| 재생 뒤 복귀 저장 | §2 — 재생에서 돌아온 HUB-05 가 개러지 기본값으로 서서 `save_progress()` 를 밟음 | **결함 → 이번 수정** |
| 세션 잔존 | 열람으로 세운 커리어가 타이틀 복귀 뒤에도 세션에 남는다(`profile_index`·`outgame`…). 타이틀 → 업적은 그 커리어의 진척을 보인다 | **정지 → 타이틀로 와 동형**(`go("SYS-01", {})` 도 세션을 지우지 않음). 계속하기·새 커리어가 `restore`/`begin_career` 로 다시 세운다. `last_hub_station`·`engine` 등 두 함수가 안 지우는 필드는 열람 경로가 건드리지 않는다 → 무접촉 |
| BGM | 타이틀 BGM 이 SYS-02·HUB-05 로 이어진다(hub_enter 없음). VN 재생 뒤 HUB-05 는 VN 트랙 유지 → 타이틀 복귀의 `title_enter` 가 BGM-01 로 되돌린다(같은 트랙이면 `_play_bgm` 이 재시작하지 않음) | 개러지 문맥(HUB-05 가 VN 트랙 유지 → `hub_enter` 가 되돌림)과 동형 → 무접촉 |
| 경계 저장분 열람 | 시즌 마감·투어 탈락 상태의 저장분을 열어도 `resume_route()` 를 거치지 않으므로 `close_season/close_tour` 가 돌지 않는다. 공통 바는 '시즌 N 마감' 문면 | 읽기 전용 — 계속하기보다 안전 |

## 5. 검사

축 52 (타이틀 → 기록실 열람 모드) 확장 — **1347 → 1361 (+14)**.

| 축 | 잡는 것 |
|---|---|
| 52ⓔ | 뒤로 문면 두 방향 — `return=SYS-01` 이면 `ui.hub.backTitle`, 기본(개러지)이면 `ui.hub.back` |
| 52ⓕ 나가는 페이로드 | 개별 재생·연속 재생 두 버튼을 눌러 받은 NAR-01 페이로드의 **사슬 꼬리**(`next == HUB-05`)가 `next_payload.return == SYS-01` 을 싣는가 (연속 재생은 `next=NAR-01` 로 감긴 사슬을 끝까지 따라간다 — `_chain_tail`) |
| 52ⓕ 실 왕복 | 그 페이로드로 **VN 화면을 세워 스킵** → 라우터가 받을 `HUB-05` 페이로드로 **기록실을 다시 세워 뒤로** → `SYS-01` · 문면 '타이틀로' · 디스크 무접촉(저장분 잔액 불변) — 3화면 왕복이 실제 결함 경로다 |
| 52ⓕ 원본 | `_archive_return_payload()` 정의 1 + 호출 2 · 탭 힌트만 실은 `{"tab": "archive"}` 리터럴 0 · `"return": _return_route` 1 — 다음 경로가 또 빠뜨리면 계수가 붉는다 |

부수: G4W 3276 → 3279 (새 키 3언어 폭 실측 편입). 로컬 UISCR 기준선이 회차 28 문서의 1348 이 아니라 1347 인 것은 `res://tests` 디렉토리 스윕(1658행)이 당시 프로브 파일을 셌기 때문이다(프로브 삭제 뒤 = 워크트리와 같은 1347).
