## 0. 배경 — 사용자 보고 2건 (2026-09-18)

1. "레조넌스 섹션은 그랑프리 중 한 번만 등장해야 하는데 표시가 한 번 노출되면 계속 표시된다. **표시의 문제인지 실제로 연속 등장하는지** 확인."
2. "투어 결산 화면의 효과음이 개러지로 넘어가도 꺼지지 않고 계속 출력된다. 확인 후 수정."

## 1. 진단 ① 레조넌스 — **표시의 문제다.** 실제 등장은 서킷 1곳 · 슬롯 1개

| 층 | 실물 |
|---|---|
| 추첨 | `SeasonState._draw_resonance()` — 투어 개막 1회 · `resonance` 스트림 · **(무대의 서킷 4종 중 1곳) × (그 서킷의 섹터 슬롯 1개)**. 투어의 나머지 3 GP 에는 레조넌스가 없다 |
| 판정 | `RaceEngine._is_resonance_sector()` = 추첨 서킷 ∧ `sector == slot` ∧ 듀얼 턴 아님. 랩 3 이므로 한 GP 에서 그 섹터에 **최대 3번**(랩마다 1번) 서고, 보너스는 `resonance_consumed` 로 **1회**(같은 슬롯을 다음 랩에 지나도 재지급 없음 — TC-C 기존 축) |
| 공표 | `begin_turn()` 이 첫 진입 턴에 `raceLog.resonanceEnter01` 1회 · `resonance_announced = true` (GP 개시에만 리셋) |
| **표시** | `race_screen._refresh_strip()` — `_e02_resonance.visible = engine.resonance_announced`. **announced 는 "공표를 한 번 했다"는 장부**라 첫 진입 뒤 GP 가 끝날 때까지 참 → 배너가 내내 켜져 있었다 |

정본: D09 §3.6 · 별첨A §A-6 E02 = "레조넌스 **진입 시** 전용 프레임·발광 변이 + **공표 배너 1회**". 배너는 진입의 공표이고 변이는 그 섹터에 있는 동안의 표시다. 현 구현은 라벨 하나가 둘을 겸하므로 **"그 섹터에 있는 동안"** 이 표시 상태의 근거여야 한다.

## 2. 수정 ① `RaceEngine.resonance_armed()` — 지금 그 섹터 ∧ 보너스 잔존

```gdscript
func resonance_armed() -> bool:
	return _is_resonance_sector() and not resonance_consumed
```

| 상황 | 종전 | 지금 |
|---|---|---|
| 레조넌스 슬롯 진입 턴 | 켜짐 | 켜짐 (공표 로그도 이 턴 1회) |
| 다음 섹터 | **켜짐 (결함)** | 꺼짐 |
| 3매치로 보너스 소진 → 같은 턴 갱신 | 켜짐 | 꺼짐 — "지금 여기서 3매치면 보너스"의 뜻이 사라졌으므로 |
| 미소진 상태로 다음 랩 같은 슬롯 | 켜짐(계속) | 다시 켜짐 · 공표 로그는 나지 않음 |
| 듀얼 턴 | 켜짐 | 꺼짐 (R7 무관여) |

봉인(불변규칙 5) 무저촉 — 섹터·서킷·듀얼 여부만 보고, `resonance_consumed` 는 확정 뒤 정산(② 자원)에서만 바뀐다. `resonance_announced` 는 공표 1회 장부로 그대로 둔다(세이브 직렬화 불변). 대안 규칙은 §8 Q1.

## 3. 진단 ② 루프 효과음 — **켠 쪽이 끄지 않았다** (같은 계열 3식)

**SE-U15 `settle_rollup`(결산 포인트 롤업)은 루프 에셋이다** — 에셋 대장 §5.1 "루프 에셋(루프 포인트 필수): `se_r02`·`se_t03`·`se_u15`·`amb_01`·`amb_04`·`amb_05`" · 임포터 `edit/loop_mode=2`(정방향) · 실물 0.59초. SET-01 이 진입에 켜고(`_audio_enter_events`) **끄는 쪽이 없다.** 재생기(`GameAudioOutput`)는 라우터(`app_root`)에 매달려 화면보다 오래 산다 — BGM 이 화면 전이마다 끊기지 않게 한 구조라 옳지만, 그래서 화면이 사라져도 루프는 계속 돈다. P3 라 채널 12 가 찰 때만 컬링되니 개러지에서는 좀처럼 멎지 않는다.

**프로브 실측 (실물 재생기 · 헤드리스 더미 드라이버 · 3초):**

| 에셋 | 임포트 loop | 길이 | 3초 뒤 |
|---|---|---|---|
| se_u15 롤업 | FORWARD | 0.59s | **생존** |
| se_r02 릴 회전 | FORWARD | 1.18s | **생존** |
| se_t03 임박 틱 | FORWARD | 0.60s | **생존** |
| se_u01 커서 · se_u06 정거장 | DISABLED | 0.04s · 0.09s | 종료(점유 해제) |

컬링(`cull_sfx`)으로는 즉시 멎는다 — 끄는 창구만 없었다.

**같은 계열 2식(부수 발견 · 같은 창구로 함께 결선):**
- **SE-R02 릴 회전 루프** — `_on_spin()` 이 스핀마다 켜고 아무도 끄지 않는다 → 스핀 수만큼 P3 루프가 쌓인다(D11 §2.2 "개시→정지 사이 지속"이 정본).
- **SE-T03 임박 틱** — `_process_timer_sound()` 가 링 점멸(5 Hz)마다 `sfx("timer_imminent_tick")` 을 **새로** 켠다. 루프 에셋이라 매 점멸이 끝나지 않는 **P1** 보이스를 하나 더 만든다. 프로브: 16회(3.2초) → **12/12 전부 SE-T03** · 그 뒤 `ui_decide`(P3)·`gp_start`(P2) 발화 **둘 다 거부**. 임박 구간을 한 번 끝까지 겪으면 세션 내내 BGM 외 효과음이 전부 죽는 경로다(회차 28 의 "효과음이 안 난다" 계열과 형태가 같다).

## 4. 수정 ② 정지 창구 + 화면 이탈 훅 — "루프는 켠 쪽이 끈다"

| 층 | 변경 |
|---|---|
| 코어 `AudioDispatcher.stop_event(event_id) -> Array` | 이벤트의 **sfx 채널** 행 보이스를 `_voices` 에서 걷어내고 `output.cull_sfx` 로 재생기에 통지 · 걷어낸 sfx id 배열 반환(같은 id 여럿이면 전부). BGM 무접촉(`stop_bgm` 전속) · 징글 무관 · 미등재/무발화 = 빈 배열. 규격 = 컬링과 같음(즉시 · 페이드 없음 — D11 §6.3) |
| 화면 `FlowScreen.stop_sfx(event_id)` | `sfx()` 의 짝 — 화면은 이벤트 id 만 던진다(C-A2 유지) |
| 화면 `FlowScreen._audio_exit_events()` + `_exit_tree()` | 화면이 트리를 떠날 때(라우터 `remove_child`) 끌 목록. 재정의하는 화면은 `super()` — 가상 메서드는 최하위 구현만 불리므로(UISCR 55ⓓ 가 원본으로 잡는다) |
| SET-01 | `_audio_exit_events = ["settle_rollup"]` |
| RACE-01 | `_audio_exit_events = ["reel_spin_loop", "timer_imminent_tick"]`(정지 메뉴 → 타이틀 경로) · `_exit_tree` 에 `super()` · **릴 정지 연출 끝** `stop_sfx("reel_spin_loop")` · **타이머 종료 창구 `_stop_timer()`**(확정·타임아웃·턴 경계 3곳이 각자 적던 두 줄 통합 + 틱 정지) · 연출 중 잔량 정지에도 틱 정지 · **임박 틱 = 점멸마다 직전 틱을 끄고 다시 켠다**(보이스 1 · 점멸 동기 유지) |

- D12 §10.2(보이스 매니저)는 정지를 말하지 않는다 — 구현 세부 결정(IMPL-532): **루프 에셋의 종료 = 켠 쪽의 책임**. 값 없음(불변규칙 2 무관) · 8단계 무접촉 · 에셋 무접촉(`godot/assets` 는 에셋 트랙 소유 · `amb_0*` 미커밋 변경 진행 중이라 앰비언스는 §8 Q3 로 상신).
- 임박 틱을 "임박 진입 1회 루프"로 바꾸지 않은 이유: 에셋 자체 주기(0.6초)가 점멸(0.2초)과 어긋나 D11 "고속 점멸 동기"를 잃는다. 재시작 방식은 종전 타이밍 논리를 그대로 두고 보이스만 1개로 묶는다 — 잘린 꼬리의 귀 판정은 실기 몫(§8 Q2).

## 7. 실기 확인 항목 (사용자)

- 레이스: 레조넌스 섹터 진입 턴에 배너 + "미승인 출력이 감지된다" · **다음 섹터에서 배너가 꺼지는가** · 그 섹터에서 3매치 → "레조넌스 — 출력이 넘친다" 뒤 배너가 꺼지는가 · 3매치를 못 냈으면 다음 랩 같은 섹터에서 다시 켜지는가.
- 투어 결산 → [개러지로]: 롤업음이 멎는가(투어 종료 VN 경유 경로 포함).
- 릴 정지 뒤 회전음이 멎는가 · 확정 뒤 임박 틱이 멎는가 · 임박 틱이 점멸에 맞춰 1겹으로 나는가(잘림·클릭이 거슬리는지 귀 판정).
- 정지 메뉴 → 타이틀(스핀 도중·임박 도중)에 소리가 함께 멎는가.
- 매뉴얼 5차 개정(v8): 레조넌스 절 표시 규칙 · 매스트헤드·푸터.

## 8. 객관식 상신 (사용자 결정)

- **Q1 배너 규칙** — 권장 = 지금 그 섹터 ∧ 보너스 잔존(구현) / ⓐ 그 섹터에 있는 동안은 소진 뒤에도 표시 / ⓑ 첫 진입 턴 1회만.
- **Q2 임박 틱** — 권장 = 점멸마다 재시작(보이스 1 · 구현) / ⓐ 임박 진입 1회 루프(에셋 주기 0.6초 · 점멸 비동기) / ⓑ 에셋 트랙에 `se_t03` 단발화 요청(코드는 점멸 발화 유지).
- **Q3 앰비언스** — AMB-01 관중 베드·AMB-04 룸톤은 HEAD 에서 루프였고 타 레인이 미커밋으로 단발(14초)로 바꾸는 중이다. 권장 = 관망(타 레인 커밋 뒤 판단) / ⓐ 같은 창구로 종료 지점(GP 결산 진입 · 레이스 출발) 결선.
