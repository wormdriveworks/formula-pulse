## 2. 결선

### 2.1 SYS-05 를 공용 씬으로 뽑는다 — 실물은 하나

- 신규 `ui/sys/pause_overlay.tscn`(uid `lgo6poer12ro`) = 종전 인라인 서브트리 그대로(가림막 · 딤 · 중앙 패널 · 버튼 4 · 경고 라벨 · 스타일박스). 스크립트는 `ui/race/pause_overlay.gd` → **`ui/sys/pause_overlay.gd` 로 이동**(git mv · uid 불변).
- `race_screen.tscn` 은 인라인 서브트리(63행)와 전용 스타일박스를 지우고 공용 씬을 **인스턴스**한다(`%PauseOverlay` 유지 · `visible=false`). 인스턴스 루트가 자기 고유 이름 노드(`%BoardMask` 등)를 소유하므로 스크립트의 `%` 참조와 기존 검사(57 등)가 그대로 선다.
- `setup(run_session, title_warning = true)` — 저장 지점 경고 표시만 호스트가 정한다(첫 버튼 문면은 두 호스트 모두 '재개' — §8). `close()`(공개) = 즉시 닫힘 + `resumed` · `_resume()` 은 그 위의 버튼 핸들러.

### 2.2 HUB-01 결선

| 항목 | 결선 |
|---|---|

| 소리 | 버튼은 자동 조작음 결속 · Esc 열기 = `ui_decide`(버튼 경로와 같게) · Esc/B 닫기 = `ui_cancel`(뒤로 축) |

### 2.3 타이틀로 앞 저장 — 떠나는 자리의 규칙 (권장안 · §7 Q1)

개러지에서 타이틀로 나가는 자리는 회차 17 이 세운 "저장은 떠나는 자리에 붙인다"의 자리다. 영입(§1) 같은 개러지 내부 변화가 다음 저장 지점까지 디스크에 없으므로, 저장 없이 나가면 **메뉴 한 번에 영입이 사라진다.** 그래서 개러지 호스트는 저장 뒤 나가고, SYS-05 의 "진행은 최근 저장 지점 기준" 경고는 끈다(지금이 그 지점이다). 레이스의 타이틀로는 종전대로(GP 중간은 저장 지점이 아니다 · 경고 표시). 대안 = D09 문면 그대로(저장 없음 + 경고) — §7.

## 6. 실기 확인 항목 (사용자)

- 개러지 푸터 우단에 ≡ 이 보이는가(출발 버튼 오른쪽) · 클릭 → 재개/옵션/업적/타이틀로 메뉴(레이스와 같은 문면) · 첫 포커스 = 재개 · 저장 지점 경고 문구가 **없는가**.
- Esc / 패드 Start 로 열리고 다시 Esc / B 로 닫히는가 · 닫힌 뒤 포커스가 열기 전 자리로 돌아오는가.
- 옵션·업적이 개러지 위 오버레이로 열리고 닫히면 메뉴로 돌아오는가.
- 타이틀로 → 타이틀 → 이어하기: 개러지 상태(영입 직후 포함)가 그대로인가(저장 표시가 뜨는가).
- 정비 베이 등 하위 스테이션에서는 종전처럼 Esc·B = 개러지로(메뉴 없음).
- 레이스의 일시정지 메뉴가 종전 그대로인가(재개 · 경고 문구 표시 · 개입 창 가림막).

## 8. 추가 요청 — 첫 버튼 문면 '재개' 통일 (사용자 · 2026-09-20)

"개러지에서 열리는 시스템 메뉴의 닫기 텍스트도 레이스에서 열릴 때와 동일하게 '재개'로 변경해주세요." → `setup()` 의 첫 버튼 문면 인자를 걷고 두 호스트 모두 `ui.pause.resume`('재개')을 쓴다. 갈리는 것은 저장 지점 경고 표시 여부만(`setup(session, title_warning)`). 회차 36 에서 신설한 `ui.pause.close`(닫기/Close/閉じる)는 소비자가 없어져 걷었다. 검사 58ⓑ = 첫 버튼 문면이 레이스와 같은 '재개'인지 본다. 게이트 = §5 와 같은 워크트리 절차(재주행 결과는 §5 하단 행).
