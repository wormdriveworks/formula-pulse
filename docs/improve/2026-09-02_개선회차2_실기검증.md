## 2. 중결함 (진행 차단·상태 오염)

### L1 — 투어 마지막 GP 결산에서 끄면 커리어 재개 불가 (실측)
- 저장 3지점 중 RACE-03 진입 저장은 `close_gp()`로 `race_slot`이 **다음 GP로 증가한 뒤** 기록된다.
- 투어 마지막(4/4) GP의 결산 화면에서 종료 → 저장분 `race_slot=5` → 로드는 무조건 RACE-01 착지
  (`save_slot_screen.gd:168`) → `current_circuit_id()` 인덱스 초과 → `begin_gp()` 실패 →
  **빈 레이스 화면**(실측: `race_screen.gd:538 season layer produced no circuit for this slot`).
- 다음 저장(SET-01 진입)이 덮기 전까지 그 상태가 유일 저장분 = 재로드 무한 동일. **커리어 벽돌.**
- 같은 기제: 시즌 최종 투어의 SET-01 진입 저장분(`tour_slot=6`)도 로드 파손(분석 판정 — SET-02·HUB-08
  구간에서 종료 시. 오버홀 확정 후 `begin_next_season()+save`가 덮을 때까지).

### L2 — 리타이어 결산에서 끄면 탈락한 투어를 다시 달림 (코드 확정)
- 리타이어 시 RACE-03가 `mark_dropout()` **후** 저장 → `tour_dropped_out=true` 직렬화.
- 그 화면에서 종료 → 로드 → RACE-01 착지는 dropout을 보지 않음 → 탈락 투어의 잔여 GP 재개.
- 유령 GP 결과가 `record_gp`로 챔피언십 포인트에 반영 = **상태 오염 + 세이브 스커밍 구멍**.

**수정 방향(공통 근인 = 로드 착지가 상태를 보지 않음):** `RunSession.resume_route()` 신설 —
`tour_dropped_out or race_slot > races_per_tour()` → `close_tour()` 후 SET-01 착지(그 안에서 시즌
최종이면 기존 분기로 SET-02 체인) / 그 외 RACE-01. `save_slot_screen`이 이 라우트로 `go`.
(RACE-03 재표시는 불가 — `last_gp_result` 미직렬화. 투어 결산부터 재개가 최소 충실 수정.)

## 5. 이벤트 대화상자 (RUN-02)

- **E1 (데이터)**: 이벤트 본문 문안이 **존재하지 않는다** — `strings.csv`에 `event.*` 본문 0건,
  `events.csv`는 `name_key`(표제)뿐. 기본 이벤트 48종 전부 표제+보상행만 뜬다(회차 1 관찰의 근인).
- **E2 (코드)**: 변형 본문 결선 어긋남 — `EventService._select_variant`는 `text_key`로 반환
  (`event_service.gd:131`), 화면은 `variant["name_key"]`를 읽음(`event_node_screen.gd:30`).
  **집필돼 있는 변형 문안 10키(6이벤트, `event_variants.json`)조차 표시된 적이 없다.**
  부수: 무일치 시 `{"tag":"","text_key":""}` 반환이라 빈 키 가드도 필요.
- 수정 방향: ⓐE2 결선 1줄+가드(즉시) ⓑ48종 기본 본문 집필(ko/en/ja — 문안 승인 필요).

## 7. 검증 방법 기록 (재현용)

- 세이브 구축 하네스 = 에디터 `execute_editor_script`: `RunSession.begin_career(3)` → GP 자동 주행
  루프(`begin_gp → engine.start_gp() → begin_turn/spin/confirm(1.0) → close_gp/settle_gp/judge_event`)
  → `save_progress()`. **`engine.start_gp()` 누락 시 섀시 0으로 즉시 리타이어**(첫 시도 실측 —
  화면 `_start_gp`가 부르는 개시 함수라 세션 API만으로는 안 선다).
- 허브 프로브 = `godot/tests/_hub_probe.{gd,tscn}`(검증 후 삭제): 미니 라우터 + 인메모리 세션
  (`use_test_root` — depart의 save_progress도 실 프로필 무접촉).
- 흐름 경계(VN 종료→개러지)는 **배치 입력 금지** — H6 때문에 여분 accept 1회가 곧 출발이다.
  매 입력 후 스크린샷 확인이 유일하게 안전했다.
