## 3. 결함 후보

### T1 — 튜닝 벤치 통화 불일치 (중)
- 코어 `OutgameState.buy_tuning` 은 **크레딧**을 차감한다(`_spend_credits`; 정본 D13 별첨A §3.5 "단계별 비용 (Cr)").
- 화면은 비용을 `ui.tuningBench.costFormat = "{amount} DP"` 로 적고, 강화 버튼을 **`drive_data < cost`** 로 잠근다
  (`tuning_bench_screen.gd:100`). 실측: Cr 2400 → 2000 차감, DP 600 불변, 그런데 파워트레인 2단계(700 "DP")가 DP 600 기준으로
  **잠김** — 지불 능력이 있는데 못 산다 / 잔액 표시가 다른 통화를 가리킨다.
- 수정: costFormat → Cr 표기 · 게이트 → `credits < cost` · 구매 후 `refresh_currency()` 는 그대로.

### F1 — 시설 확장 표시 가격 할인 미반영 (경)
- `unlock_facility` 는 `unlock_cost(cost_dp)`(사샤 패시브 −10%)를 차감 — 실측 45 표시 → 41 차감(DP 510 → 469).
- 카드는 원가 45 를 표시하고 원가로 게이트한다(`facility_screen.gd:72`). 전략실은 `unlock_cost` 로 표시·게이트 모두 맞춤.
- 수정: 카드 가격·게이트에 `unlock_cost()` 적용.

### O1 — 탭 순회 후 포커스 소실 (중 · 포커스 계열)
- 옵션·기록실·업적의 `_cycle_tab → _select_tab` 은 패널 가시성만 바꾼다. 포커스가 패널 **안**(옵션 스테퍼·아카이브 재생 버튼)에
  있을 때 Q/E·LB/RB 로 탭을 넘기면 숨겨진 컨트롤이 포커스를 잃어 **포커스 = none** (실측 `focus=none`).
- 결과: 패드는 십자키 무반응(B 로만 탈출), 키보드는 Tab 으로만 복귀 — 회차 2 H1·H6 과 같은 잠금 계열.
- 수정: `_select_tab` 뒤 포커스가 비었거나 숨은 노드면 **활성 탭 버튼**으로 이양(탭 순회 문맥에서 자연스러운 자리).

### R-F1 — RACE-01 초기 포커스 부재 (경)
- 별첨A §A-6 "초기 포커스 = 스핀(=확정)"인데 GP 개시 시 `grab_focus` 가 없다(조합 해제 경로에서만 확정으로 되돌림).
  실측: 개시 150프레임 뒤 `focus=none`. A/Space 는 액션 경로라 스핀은 되지만, 십자키 이동의 출발점이 없다.
- 수정: 턴 개시(`_next_turn`/`_refresh_action_enabled` 활성 전환) 시 포커스 부재면 확정 버튼으로.

### H8-O1 — 시즌 체인 중 공통 바 진행 표기 (경 · 표시)
- SET-02 → HUB-08 구간에서 시즌 층은 `tour_slot = 6 · race_slot = 5`(마감 후 값)이라 공통 바가 **'시즌 1 · 투어 6 · 제5전'** 을
  표시한다(실측). 매 시즌 말 한 번씩 보인다.
- 수정: `season_finished()` 이면 진행 문면을 '시즌 {n} 마감' 로(스트링 1키), 아니면 종전.

### S2-O1 — SET-02 시즌 결산 조판 단조 (개선 후보)
- 좌열 라벨 나열(표제 · 판정 · 요약 · 순위 10행)만 있고 우측 절반이 빈다 — SET-01 종전 상태와 같은 결. 회차 3 SET-01 조판
  문법(헤더 배지·강조 값·우측 표)을 이식할 수 있다.

## 4. 하네스 관찰 (결함 아님)

- 시즌 체인 끝에 막 VN 4건(act1·act2·act4·origin)이 연속 발화 — 자동 주행이 투어 경계마다 개러지를 방문하지 않아
  브리핑 슬롯 대기분이 누적된 하네스 산물. 실플레이는 투어마다 개러지 출발을 지나므로 경계당 1~2건. 다발 발화 자체는 체인이 무결하게
  소화했다(라우트 로그 9홉 · 최종 RACE-01 S2 T1 R1).
