## 2. 원인 분석 (D14 §8.2 경로)

### ① ±15% 규격과 정수 소척도 지표의 부정합 (괴리 4종의 주 원인)

순위·투어는 **정수 척도이고 값이 작다**(4~8). 1단위 차이가 곧 20~60% 괴리다:
- 챔피언십 순위 4 → 5 = 1칸 차이 = +25%
- 첫 포디움 투어 2 → 3 = 1투어 차이 = +50%

반면 **연속 지표는 전량 통과**했다 (E1 −14.9% · GP 길이 +1.0% · 듀얼 −10.9% · AI 리타이어 +0.8%). 즉 ±15% 규격은 연속 지표에서는 잘 작동하고, 정수 소척도 지표에서는 사실상 "완전 일치"를 요구한다. **허용 범위(D08 §8.3) 판정은 이 4종 모두 통과**한다.

> **총괄 판정 요청 A:** 정수 소척도 지표(순위·투어)에 ±15% 상대 괴리를 적용하는 것이 D14 §8.2의 의도인가, 아니면 그 지표군은 **허용 범위 판정 전속**인가. 후자로 판정되면 표준·저숙련은 이탈 0으로 통과한다.

### ② 첫 그랑프리 우승 지연 (실기 투어 8 vs 모델 5)

허용 범위(S1 투어2 ~ S2) 내이나 괴리가 가장 크다. 가설 2건:
1. **벽 라이벌 가중이 모델에 없었을 가능성** — 벽 무대 가중(D13 §6.2 디아스 +1.4·카이 +1.9·홀로웨이 +1.4·로렌츠 +1.0)과 듀얼 임계 +6은 **2026-08-16 T1(IMPL-110)에서 처음 결선**됐다. 시뮬 측정(2026-08-06)은 그 이전 값으로 산출됐을 개연이 있다 — 사실이면 실기가 모델보다 어려운 것이 정상이며 모델 측 재산출이 필요하다.
2. 러너 정책이 생존 편향 — 매 GP 필드 정비·패닉 소모품으로 리타이어를 회피(0.20 vs 0.33)하는 대신 공격 자원(차지)을 덜 쌓았을 수 있다.

> **총괄 판정 요청 B:** 시뮬 측정값(D13 §4.3)이 **벽 가중 결선 이전** 산출인지 확인 요망. 그렇다면 대조 기준선 자체의 갱신이 선행돼야 한다 (D13 §8.4 값 조정 절차와는 별개 — 모델 재산출 사안).

### ③ 숙련 S1 챔피언 달성률 2.4% (허용 상한 2% 초과 — 유일한 범위 이탈)

n=250에서 6런. 표본 오차 범위이며 표준 1.8%·저숙련 0.0%로 **서열은 정합**하다. D13 결정 #8이 "S1 챔피언 = 예외적 성취(0~2%)"로 보정한 취지(로렌츠 첫 격파 S2와의 구조적 배타성)는 유지된다 — 숙련 프로파일에서 0.4%p 초과.

> **총괄 판정 요청 C:** 허용 0~2%가 **표준 프로파일 기준**인지 **전 프로파일 공통**인지. 전자면 이탈 0이다.

### 4.1 ① 완급 비트 GP 길이 흡수 — 실측 (n=20 · 실시간 주행)

RACE-01 실화면을 20 GP 주행하며 **게임 시간 델타를 누적**했다. 개입 창은 즉시 확정하므로 측정값은 **기계가 강제하는 시간**만 담는다(플레이어 숙고 0).

| 축 | 실측 |
|---|---|
| 화면 기계시간 | 평균 **24.3초** (P90 25.6 · 최소 21.2 · 최대 27.7) |
| 턴 | 평균 14.4 (섹터 12.0 · 듀얼 2.5) |
| 턴당 기계시간 | **약 1.7초** (릴 정지 0.4×3 + 공개 마무리 + 듀얼 결과 표기 0.6) |
| **완급 비트 증분 (투영)** | 섹터턴 12.0 × 1.0초 = **12.0초 = 0.20분** |

**판정: 증분이 대역을 넘지 않는다 → ① 판정 문면 충족.** 대역 폭 5분(10~15) 대비 완급 비트 증분은 **4%**이며, 숙고 0~10초 전 구간에서 합성 GP 길이는 4.16~6.76분(비트 포함 4.36~6.76분)으로 상한 15분에서 8분 이상 남는다.

**⚠ 조건부인 이유 — 전제 미성립:** 규격 문면은 "**완급 비트 정상 작동 하**"인데 **재생 소비부가 없다.** `param_pacing_beat_max_sec 2.5`·`param_pacing_beat_probability 0.40`·`param_time_pacing_beat_sec 1.0`은 데이터에 전사돼 있고 검사도 곱의 정합을 보지만, 화면에는 `E15ScenePanel` 노드만 있고 구동 코드가 없다(씬 컷 에셋도 미유입 — T6). 위 증분은 **데이터 산출 투영값**이다. 재생 결선 후 재측정이 정확하다.

**[보고] GP 길이 대역은 플레이어 자율 페이스에 지배된다.** 모델은 21초/턴을 쓰는데, 기계가 강제하는 것은 **연출 1.7초 + 개입 창 상한 10초 = 최대 11.7초/턴**뿐이다. 나머지 약 9초/턴은 플레이어가 로그를 읽고 다음 스핀을 누르는 자율 시간이어야 한다(T1에는 타이머가 없다). 즉 10~15분 대역 달성은 구현이 보장하는 값이 아니라 **페이스 가정에 의존**한다 — 총괄 판단 대상(§4.3).

**계측 방법 주의:** `Engine.time_scale` 가속본은 프레임 양자화로 대기 구간이 부풀어 **실시간 대비 약 30% 과대**로 나왔다(8배속 31.6초 vs 실시간 24.3초). 실시간 3GP 대조로 확인한 뒤 전량 실시간으로 재측정했다. **연출 시간 계측에 시간 가속을 쓰지 않는다.**

### 4.2 ③ 모멘텀 × 개입 4타입 매트릭스 — 통과

같은 시드·같은 행동열로 엔진 두 대를 몰고 `confirm()`의 **잔여 비율만** 다르게 주어 전방 게이지 차를 본다. 개입이 소비하는 난수도 양쪽이 같으므로 차이는 모멘텀 항 하나뿐이어야 한다.

| 개입 타입 (D05 §6.1) | 결과 |
|---|---|
| 홀드 (Hold) | 델타 불변 (+5G) — 중첩·소거 0 |
| 보험 (Insure — 차지 개입) | 델타 불변 |
| 홀드 + 보험 중첩 | **1회분만** |
| 증폭 (Amplify — 듀얼 부스트) | **구조적 배타** — 모멘텀은 비듀얼 전속·부스트는 듀얼 전속. 양방향 확인(듀얼 턴 여유 확정 시 모멘텀 0 / 비듀얼 턴 증폭 거부) |
| 변환 (Convert) | **미측정** — 엔진 API 부재. D05가 스킬 인스턴스로 규정하는데 RACE-01 스킬 슬롯이 전 슬롯 잠금(IMPL-071)이라 주입할 개입이 없다 |

**정의 외 상호작용 0** (측정 3행 기준). 돌연변이 양방향 검출: 홀드 시 보너스 2배 주입 → 2건 발화 / 보험 시 모멘텀 소거 주입 → 2건 발화.

### 4.3 총괄 판단 대상 (§8.4 경로 — 임의 조정 금지)

1. **①을 '통과'로 기록해도 되는가** — 완급 비트 재생 미구현 상태의 투영 판정이다. (a)조건부 통과로 확정하고 재생 결선 시 재측정 / (b)재생 결선까지 '미실행' 유지 중 택일.
2. **GP 길이 대역의 페이스 의존** — 기계 강제분이 최대 11.7초/턴이라 21초/턴 모델은 플레이어 자율 시간 약 9초/턴을 전제한다. 값 조정이 아니라 **모델 전제의 명문화 여부**가 판단 대상이다.
3. **② 입력 지연** — MP-L 조달 전까지 측정 불가. MS-5 실기 게이트 윈도 합류가 총괄 배정대로다.
