## 1. 착수 전 필수 절차

1. **`git pull` 먼저.** 두 머신이 같은 브랜치를 오간다. 그다음 `godot --headless --path godot --import` 1회(캐시 재생성).
2. 루트 `CLAUDE.md` 정독 — **STEP 0 환경 감지를 먼저 실행**하고 감지된 환경의 규칙만 따른다. 불변 규칙 9항 준수.
3. **MS-1 회귀 확인** — 아래 3개가 전부 통과해야 착수한다. 하나라도 깨져 있으면 **먼저 고치고 보고**한다.
   ```
   bash tools/validators/validate.sh          # → VALIDATORS_PASS warnings=0
   godot --headless --path godot --script tests/test_core_loop.gd    # → CORE_LOOP_TEST_PASS
   godot --headless --path godot --script tests/test_save_reload.gd  # → SAVE_RELOAD_TEST_PASS
   ```
4. **MS-1 독립 검증을 먼저 돌린다 (이월 — 이전 세션에서 미이행).**
   MS-1 검증은 구현자 본인이 수행했다. 위임 레인(서브에이전트)이 두 차례 정지해 **독립 레인의 반증 시도가 이뤄지지 못했다.** 새 세션은 새 프로세스이므로 여기서 먼저 닫는다.
   - 검증관을 **별도 컨텍스트로 띄우고**, "통과했는가"가 아니라 **"틀리게 만들면 실패하는가"**로 판정하게 한다. 사본에 결함을 주입하고 검출되는지 확인하는 방식(원본 무접촉).
   - 이미 이빨이 확인된 항목은 IMPL-019·IMPL-020에 있다(혼입 0·V4·V8·V7 경고 전용·RNG 직렬화·정산 C-2 가드·구조 JSON 누락 값). **중복하지 말고 아직 안 본 곳을 노려라** — 특히 정산 8단계의 각 단계가 실제로 D13 값을 쓰는지, 개입 4타입의 효과량, 게이지·차지·섀시 수지.
   - 검증관은 **파일을 수정하지 않는다.** 결함은 고치지 말고 보고.
   - 차단 결함이 나오면 MS-2 본작업 전에 처리한다.
5. `docs/decisions/impl_log.md` 전문 정독 (IMPL-001~020 · U-1~U-3 · 실측 확인 사항).
6. 참조 정본 정독 (이 순서로):
   - `docs/design/D08_콘텐츠레벨디자인_v1_1.md` + `docs/design/D08_별첨A_서킷상세_v1_1.md` **§1 무대 1 전량** — MN-1 하버 프런트(제1전·오프너) / MN-2 크로스타운(제2전·빌드A) / MN-3 올드 쿼터(제3전·빌드B, 펄스 섹션 배치) / MN-4 그랜드 서큘러(제4전·피니셔, 로렌츠 필패 이벤트) + 무대 전용 이벤트 풀 4종

## 2. 착수 시 확인·질문할 것 (임의 판단 금지)

MS-1과 달리 MS-2는 범위 해석의 여지가 크다. **아래 2건은 구현 시작 전에 사용자에게 확인한다.**

1. **TC-O(아웃게임 8항)의 MS-2 적용 범위.** D15 §1.1은 MS-2 완료 조건에 TC-O를 포함시키지만, TC-O1(개러지 G1~G4)·TC-O2(튜닝·오버홀 12종)·TC-O7(스킬 티어)·TC-O8(관계 카운터)은 무대 1에 국한되지 않는 전역 시스템이다. "무대 1 수직 절단면"이 **시스템은 전량 구현하되 콘텐츠만 무대 1로 한정**하는 뜻인지 확인한다. — 임의 축소·임의 확대 금지.
2. **`godot/assets/` 디렉토리 계약 편입** (§0.2-5). MS-2에서 아트·사운드 실물이 들어오므로 배치 규칙을 먼저 확정해야 한다.

## 3. 작업 범위 (In)

1. **D09 실화면 구현** — 디버그 UI 1장을 D09 §8.1 화면 대장의 실화면으로 대체. 레이스 4존·개입 창·중계 로그 존을 실규격으로. TL-2 기능 체크리스트(D14 §2.2 생성 규칙) 대상이 된다.
2. **무대 1 콘텐츠 충전** — 서킷 4종(MN-1~MN-4) 데이터, 무대 전용 이벤트 풀 4종, 레조넌스 섹터 오버레이(무대당 1회 — D08 §3.7), 제3전 펄스 섹션, 제4전 로렌츠 필패 이벤트. **값은 전량 D13/D08 별첨A에서 옮긴다.**
3. **아트 투입 (D10)** — 무대 1 배경 아트 1종, 심볼 6분류 32px, 8px 한글 폰트 파이프라인, UI 도상. 정수 배율·니어리스트·픽셀 스냅(D12 §9.1) 유지 — **`.import` 커밋 필수.**
4. **사운드 투입 (D11)** — 무대 1 소요분 SFX·BGM, 오디오 층위. **릴 정지 연출 완료 전 결과 암시음 금지**(봉인 규칙의 사운드 축 — TC-C11).
5. **VN·중계 (D04)** — 시즌/투어 시작·종료 VN 이벤트, 스킵, **기록실 재열람**(TC-O4). 중계 로그 실텍스트. 베인 대사 풀 3단계 필터(D12 §5.7) + **베인 파형 런타임 렌더(D12 §9.3 — G-5 대상)**.
6. **아웃게임 (D06·D07)** — §2-1 확인 결과에 따른 범위. 개러지 시설·튜닝/오버홀·스폰서·스킬 티어·크루 패시브·관계 카운터·아카이브·**환전 가드 G1~G4**.
7. **세이브 시스템 완성 (D12 §7)** — MS-1 골격에서 실사용 수준으로. **백업 1세대 복구**(TC-P8) · **마이그레이션 + 클라우드 충돌 정책 + 프로필 3 독립성**(TC-P9). 어댑터 뒤의 클라우드는 계약만 유지(실연동은 MS-5).
8. **연출 등급 L0~L3 + L2+ 상한 카운터** (§0.2-3 이월분 — D12 §5.8).
9. **테스트 확충** — TC-C 13항·TC-O 8항을 **자동화 가능한 만큼 헤드리스 로직 테스트로 결속**한다. TC-C10(정산 8단계 불변)·TC-C11(봉인 5경로)·TC-C12(스커밍 무효)는 자동화 우선순위 최상.
