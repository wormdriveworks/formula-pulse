**무대 1(메트로 나이트) 완결 품질 수직 절단면의 표현 층 성립 + 실기 게이트 판정.**

## 1. 착수 전 필수 절차

1. **`git pull` 먼저.** 두 머신이 같은 브랜치를 오간다.
2. **STEP 0 환경 감지를 실행**하고 `ENV=주력GUI(Windows)`를 확인한다. 감지된 환경의 규칙만 따른다.
   `ENV=원격헤드리스`가 나오면 판정식이 깨진 것이므로 **중단·보고**(IMPL-004 재발).
3. **CLI는 예외 없이 `_console.exe`.** GUI exe는 stdout을 셸에 반환하지 않아 `--check-only` 에러·검증기 결과·
   테스트 PASS/FAIL이 전부 소실되고 자가 수정 루프가 성립하지 않는다(IMPL-005 실측).
   ```powershell
   & "C:\SDKs\godot\Godot_v4.7.1-stable_win64_console.exe" --headless --import   # pull 후 1회
   ```
4. **MS-2 회귀 확인 — 아래 두 명령이 통과해야 착수한다.** 하나라도 깨져 있으면 **먼저 고치고 보고**한다.
   ```
   bash tools/validators/validate.sh    → VALIDATORS_PASS warnings=0
   bash tools/validators/run_tests.sh   → COMPILE_GATE_PASS scripts=39 · TESTS_PASS suites=9
   ```
   두 명령은 **종료코드로** 판정한다. 파이프(`| tail`)를 걸면 종료코드가 가려진다 —
   실제로 그렇게 실패 상태를 커밋한 사례가 있다.
5. `docs/decisions/impl_log.md` 전문 정독 (IMPL-001~069 · U-1~U-6 · 실측 확인 사항).
6. `docs/handoff/MS2_주력머신_인계.md` 정독.
7. 참조 정본 정독 (이 순서로):
   - `docs/design/D09_UIUX기획서_데스크탑_v1_2.md` + `D09_별첨A_화면상세_v1_2.md` — **화면 명칭 정본 = D09 §8.1 대장 25종.** 데스크탑 화면 구현의 정본
   - `docs/design/D10_아트디렉션리소스목록_v1_0.md` — 캔버스·팔레트·에셋 목록·도트 규격 (§2.2 믹셀 금지 · §8.2 카테고리 총계)
   - `docs/design/D11_사운드디자인_v1_0.md` — SFX 68식·BGM 13+1·오디오 층위·§2.5 등급 채널 합성표 (**릴 정지 전 결과 암시음 금지**)
   - `docs/design/D04_내러티브디자인_v1_2.md` — VN·중계 로그 작법과 자수 제약 (중계 2줄×22전각 / VN 2줄×24전각 — V3에 결속돼 있다)
   - `docs/design/D14_QA테스트계획서_v1_1.md` — **§2.2 TL-2 생성 규칙 · §5.1 G-1 · §5.2 G-2 · §5.5 G-5 · §5.8 기록 양식.** 합격선 문면

## 2. 착수 시 확인·질문할 것 (임의 판단 금지)

**아래 2건은 구현 시작 전에 사용자에게 확인한다.**

1. **D09 화면 25종 중 MS-2 구현 범위.** D09 §8.1 대장은 25종(SYS 5 · RACE 3 · RUN 2 · HUB 8 · NAR 2 · SET 2 · COM 2 · TUT 1)이다.
   "무대 1 완결 품질 수직 절단면"이 **25종 전량**을 뜻하는지, 아니면 무대 1 1회차 플레이에 도달 가능한 화면으로
   한정하는지 확인한다. 아웃게임 시스템은 이미 전량 구현돼 있으므로(사용자 확정 — IMPL-021) HUB 8종을 전부 세울
   근거는 있으나, TUT-01·SYS-04(업적) 등은 MS-2 완료 조건과의 거리가 있다. — 임의 축소·임의 확대 금지.
2. **G-1·G-2 평가자 표본 확보 방식.** D14 §5.1~5.2가 **평가자 5인**을 확정 기준으로 못박았다
   (G-1: 5인 × 문항 40 / G-2: 5인 × 제시 60). 1인 개발 체제에서 5인 표본을 어떻게 조달할지 확인한다 —
   표본 미달로 게이트를 자체 완화하는 것은 D14 구속 위반이므로, 조달 불가라면 **총괄 경유로 표본 설계 조정**을
   발신해야 한다(단독 완화 금지 — D14 §5 공통 원칙).

## 3. 작업 범위 (In)

### 3.1 D09 실화면 구현 — **씬 소유권**

- **`.tscn` 구조의 소유권은 이 머신에 있다.** 원격 MCP가 만든 `.tscn`은 비표준 최소 포맷이라 에디터가
  재정규화하며 디프가 튄다 — 그래서 원격은 씬을 만들지 않았다.
- `godot/ui/debug_race.gd`·`.tscn`을 **D09 §8.1 대장의 실화면으로 대체**한다. 레이스 4존·개입 창·중계 로그 존을 실규격으로.
- 대체 시 §0.4의 이월 3건(리스핀 즉시 공개 · UI 레이아웃 수치 · SEAL-E 검사)을 함께 정리한다.
- **세이브는 `SaveManager` 경유로 한다.** 디버그 UI가 `SaveService`를 평면 경로로 직접 불러 프로필 분리·백업 회전·
  마이그레이션을 전부 우회하던 것을 이번에 결선했다(IMPL-037). 다시 직접 부르면 **ARCH 정적 규칙이 빌드를 막는다.**
- 표시 문자열은 **전량 스트링 키**다. V4가 확대돼 `.text`에 리터럴을 넣으면 한글이 아니어도 막힌다(IMPL-027) —
  서식 문자열도 키로 옮긴다(`ui.debug.timerFormat` 전례).
- **코어에 `print(`·`push_warning(`을 넣지 마라** — ARCH 규칙이 차단한다. 봉인 누출 경로이기 때문이다(IMPL-046·059).

### 3.2 아트 투입 (D10)

- 배치 경로 = **`godot/assets/` + D10 §8.2 카테고리별 하위** (사용자 확정 — IMPL-021):
  `characters/ vane/ machines/ scenecuts/ ui/{icons,frames}/ glyphs/ fonts/ palettes/ backgrounds/ illustrations/`
- 에셋 ID = `A-<분류>-##` (D10 §8.1).
- MS-2 소요분: 무대 1 배경 아트 1종 · 심볼 6분류 32px · **8px 한글 폰트 파이프라인** · UI 도상 · 베인 파형 규격.
- **`.import` 커밋 필수**(IMPL-003). 정수 배율·니어리스트·픽셀 스냅(D12 §9.1) 유지 —
  누락 시 반대편 머신이 기본 설정으로 재임포트해 믹셀이 된다. `*.uid`도 커밋 대상이다.

### 3.3 사운드 투입 (D11)

- 무대 1 소요분 SFX·BGM, 오디오 층위. 값은 D13 별첨A §8.3(볼륨 80 · 덕킹 −6dB/0.3초 · 크로스페이드 0.8초 ·
  등급 스팅 L1 0.8/L2 1.5/L3 2.5초 · BGM 90~150초 루프 · 함성 재트리거 4초).
- **릴 정지 연출 완료 전 결과 암시음 금지** — 봉인 규칙의 사운드 축(TC-C11·G-6).
  사운드는 `sound_map` 테이블 경유로만 발화하는 구조(D12 §5.10)를 지킨다.
- **햅틱 지속 시간은 D13 대장에 없다**(IMPL-035 보고 항목). D11 §3.1이 L1 0.1초·L2 0.25초를 '확정 기준값(창구 D13)'으로
  명기하는데 D13 §8.3에 해당 행이 없다. 연출 등급 테이블은 세기 등급(none/weak/strong)까지만 담고 있다 —
  햅틱 실구현 착수 시 **D13 전사 여부를 총괄에 확인**한다. 임의 산정 금지.

### 3.4 연출 등급 표현 채널 결선

`presentation_grade.gd`가 등급→채널 매핑과 상한 카운터를 이미 갖고 있다(데이터·규칙 층 성립).
**표현 채널(로그/SFX/진동/씬 컷)에 실제로 물리는 것이 이 머신 몫**이다. 등급 판정 자체는 불변이며,
채널 감쇠(D09 §6.3 옵션 연동)는 출력 단계 마스킹으로 처리한다(D12 §5.8 명문).

### 3.5 실기 게이트 3종 — **사람 판정**

전제: **하한 프로파일 기기(MP-L) + 실기 렌더 빌드.** 결과는 D14 §5.8 양식으로 기록하고,
불통과 시 **총괄 경유 발신** — 단독 확정·단독 보정 금지.

| 게이트 | 판정 기준 (D14 §5) | 표본 설계 | 불통과 발신 |
|---|---|---|---|
| **G-1** 8px 한글 가독성 | ①문자 오독률 ≤ 5% **및** ②수치·단위 어휘(숫자·Cr·%·DP·초) 오독 **0**. 한 축만 위반해도 불통과 | 평가자 5인 × 문항 40 (수치·단위 포함 문장 30%) · 문항당 노출 3초 | D13(로그 존 폭) — **자수 22자·시각 줄 2는 불변** |
| **G-2** 심볼 32px 판독 | ①분류 오독률 ≤ 2% **및** ②혼동쌍 편중 불검출(단일 혼동쌍이 전체 오독의 50% 초과 시 불통과 — 전체율 통과와 무관) | 평가자 5인 × 제시 60회 (6분류 × 10회, 단독 제시와 릴 맥락 제시 반반) · **혼동 행렬 6×6 기록** | D10(도상 보정) |
| **G-5** 베인 파형 렌더 스모크 | 4상태 각 60초 연속 + 상태 전환 20회 → 프레임 유지(30fps) **및** 시각 결함(찢김·잔상) 0 | — (채택 판정의 확증이며 재판정이 아니다) | 폴백 재론 |

### 3.6 TL-2 기능 체크리스트 (D14 §2.2)

실화면이 서면 TL-2 대상이 된다. 화면당 5축으로 기계 생성한다 —
①진입/이탈 경로(플로우맵 대조) ②표시 요소 전수(별첨A 명세 대조) ③옵션 반영(O1~O15) ④T-1 용어 표기(완칭) ⑤금지 구역 진입점 0.

### 3.7 export preset 자격증명 종단 확인 (§0.4-1)

에디터 익스포트 다이얼로그에서 preset 1개를 실제로 만들고, 서명 정보가 `export_presets.cfg` **본체에 평문으로
들어가지 않는지** 눈으로 확인한다. 평문이 들어가면 **A안 폐기 → C안(템플릿 커밋 + 빌드 시 주입)으로 후퇴**하고 보고한다.
